# 문제

<a id="1c3eda9b0fe1817db09dc6f92bfed612"></a>

## <strong>3&#46; 최대점수 구하기(DFS)</strong>

---

<a id="1c3eda9b0fe18145b862cf15893bb0ee"></a>

### 설명

<a id="1c3eda9b0fe181248536fa28cb1200c5"></a>

이번 정보올림피아드대회에서 좋은 성적을 내기 위하여 현수는 선생님이 주신 N개의 문제를 풀려고 합니다&#46;

<a id="1c3eda9b0fe1814e9c62eeb47115a0fe"></a>

각 문제는 그것을 풀었을 때 얻는 점수와 푸는데 걸리는 시간이 주어지게 됩니다&#46;

<a id="1c3eda9b0fe181db83cfe8b8f3b3d3bb"></a>

제한시간 M안에 N개의 문제 중 최대점수를 얻을 수 있도록 해야 합니다&#46;

<a id="1c3eda9b0fe181069cd6ebf3237d8fcd"></a>

(해당문제는 해당시간이 걸리면 푸는 걸로 간주한다, 한 유형당 한개만 풀 수 있습니다&#46;)

<a id="1c3eda9b0fe18134a83ed2954d3b2c2b"></a>

### 입력

<a id="1c3eda9b0fe1816f828ec0d7f675932d"></a>

첫 번째 줄에 문제의 개수N(1&#60;=N&#60;=20)과 제한 시간 M(10&#60;=M&#60;=300)이 주어집니다&#46;

<a id="1c3eda9b0fe18145a732dab153d28ef7"></a>

두 번째 줄부터 N줄에 걸쳐 문제를 풀었을 때의 점수와 푸는데 걸리는 시간이 주어집니다&#46;

<a id="1c3eda9b0fe181929813f9e3e6e32a12"></a>

### 출력

<a id="1c3eda9b0fe18136a789d1c7d7a6519e"></a>

첫 번째 줄에 제한 시간안에 얻을 수 있는 최대 점수를 출력합니다&#46;

---

<a id="1c3eda9b0fe1816da47dfed51fca8c8b"></a>

5 20

## 풀이1) DFS, ArrayList&#60;int&#91;&#93;&#62;

<a id="1c3eda9b0fe1811d9447df2548759c6e"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int maxTime, n, answer=Integer.MIN_VALUE;
    static ArrayList<int[]> arr;
    public void DFS(int L, int sumTime, int sumValue){
        if(sumTime> maxTime) return;
        if(n==L){
            answer=Math.max(answer, sumValue);
        }
        else {
            DFS(L+1, sumTime+arr.get(L)[1], sumValue+arr.get(L)[0]);
            DFS(L+1, sumTime, sumValue);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        maxTime=sc.nextInt();
        arr= new ArrayList<>();
        for(int i=0; i<n; i++){
            arr.add(new int[2]);
        }
        for(int i=0; i<n; i++){
            int a=sc.nextInt();
            int b=sc.nextInt();
            arr.get(i)[0]=a;
            arr.get(i)[1]=b;
        }
        T.DFS(0, 0, 0);
        System.out.print(answer);
    }
}
```

## 풀이2) DFS, class

<a id="1c3eda9b0fe18186b0fdd27657c2b717"></a>

```javascript
import java.util.*;

class Problem {
    int score, time;
    Problem(int score, int time){
        this.score=score;
        this.time=time;
    }
}

public class Main {
    static Problem[] arr;
    static int n, maxTime, answer=Integer.MIN_VALUE;

    public void DFS( int L, int sumTime, int sumScore){
        if(sumTime > maxTime) return;
        if(L==n){
            answer=Math.max(sumScore, answer);
        }
        else {
            DFS(L+1, sumTime+arr[L].time, sumScore+arr[L].score);
            DFS(L+1, sumTime, sumScore);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc = new Scanner(System.in);
        n=sc.nextInt();
        maxTime=sc.nextInt();
        arr = new Problem[n];
        for(int i=0; i<n; i++){
            int s=sc.nextInt();
            int t=sc.nextInt();
            arr[i]=new Problem(s, t);
        }
        T.DFS(0, 0, 0);
        System.out.println(answer);
    }
}
```
