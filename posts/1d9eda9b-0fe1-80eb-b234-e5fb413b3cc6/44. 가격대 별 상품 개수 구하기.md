## 문제

<a id="1d9eda9b0fe180b3a9c5d97a88640605"></a>

### <strong>문제 설명</strong>

<a id="1d9eda9b0fe18047ae15e04da00a2207"></a>

다음은 어느 의류 쇼핑몰에서 판매중인 상품들의 정보를 담은 <code>PRODUCT</code> 테이블입니다&#46; <code>PRODUCT</code> 테이블은 아래와 같은 구조로 되어있으며, <code>PRODUCT&#95;ID</code>, <code>PRODUCT&#95;CODE</code>, <code>PRICE</code>는 각각 상품 ID, 상품코드, 판매가를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PRODUCT&#95;ID | INTEGER | FALSE |
| PRODUCT&#95;CODE | VARCHAR(8) | FALSE |
| PRICE | INTEGER | FALSE |

<a id="1d9eda9b0fe180b6bcefe3b108537a74"></a>

상품 별로 중복되지 않는 8자리 상품코드 값을 가지며 앞 2자리는 카테고리 코드를 나타냅니다&#46;

---

<a id="1d9eda9b0fe180bd9a41dc31c5e4e2e8"></a>

### 문제

<a id="1d9eda9b0fe180f5b37cedbd7a0e9715"></a>

<code>PRODUCT</code> 테이블에서 만원 단위의 가격대 별로 상품 개수를 출력하는 SQL 문을 작성해주세요&#46; 이때 컬럼명은 각각 컬럼명은 PRICE&#95;GROUP, PRODUCTS로 지정해주시고 가격대 정보는 각 구간의 최소금액(10,000원 이상 &#126; 20,000 미만인 구간인 경우 10,000)으로 표시해주세요&#46; 결과는 가격대를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="1d9eda9b0fe18067a90dc86368909490"></a>

### 예시

<a id="1d9eda9b0fe1807d8e93eb863e5436e9"></a>

예를 들어 <code>PRODUCT</code> 테이블이 다음과 같다면

|  |  |  |
| --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;CODE | PRICE |
| 1 | A1000011 | 10000 |
| 2 | A1000045 | 9000 |
| 3 | C3000002 | 22000 |
| 4 | C3000006 | 15000 |
| 5 | C3000010 | 30000 |
| 6 | K1000023 | 17000 |

<a id="1d9eda9b0fe18023a24ff9fa1a809c37"></a>

만원 단위의 가격대 별로 상품을 나누면

- 가격대가 0원 &#126; 1만원 미만인 상품은 <code>PRODUCT&#95;ID</code> 가 2인 상품 1개,

- 가격대가 1만원 이상 &#126; 2만원 미만인 상품들은 <code>PRODUCT&#95;ID</code> 가 1, 4, 6인 상품 3개,

- 가격대가 2만원 이상 &#126; 3만원 미만인 상품은 <code>PRODUCT&#95;ID</code> 가 3인 상품 1개,

- 가격대가 3만원 이상 &#126; 4만원 미만인 상품은 <code>PRODUCT&#95;ID</code> 가 5인 상품 1개,

<a id="1d9eda9b0fe1807aba62ed9adaac2c8b"></a>

에 각각 해당하므로 다음과 같이 결과가 나와야 합니다&#46;

|  |  |
| --- | --- |
| PRICE&#95;GROUP | PRODUCTS |
| 0 | 1 |
| 10000 | 3 |
| 20000 | 1 |
| 30000 | 1 |

<a id="1d9eda9b0fe180289c87f65ff1c2fcf9"></a>

## 풀이

> ✏️ 
> 
> <a id="1d9eda9b0fe18034ac5afca142b41840"></a>
> 
> 조건
> 
> -  만원 단위의 가격대 별로 상품 개수를 출력
> 
> - 각각 컬럼명은 PRICE&#95;GROUP, PRODUCTS로 지정
> 
> - 가격대 정보는 각 구간의 최소금액(10,000원 이상 &#126; 20,000 미만인 구간인 경우 10,000)으로 표시
> 
> - 가격대를 기준으로 오름차순 정렬

<a id="1d9eda9b0fe180c3afe8ca7b0effec86"></a>

```sql
-- 코드를 입력하세요
SELECT
    (FLOOR(PRICE/10000) * 10000) AS PRICE_GROUP,
    COUNT(*) AS PRODUCTS
FROM PRODUCT
GROUP BY PRICE_GROUP
ORDER BY PRICE_GROUP
```
