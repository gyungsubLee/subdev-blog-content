## 9&#46; 조합 구하기

<a id="1c3eda9b0fe18165bd65cbea4b819a5f"></a>

### 설명

<a id="1c3eda9b0fe18143bc04eb9104d7a7a3"></a>

1부터 N까지 번호가 적힌 구슬이 있습니다&#46; 이 중 M개를 뽑는 방법의 수를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181a8904fe599c998ddea"></a>

### 입력

<a id="1c3eda9b0fe1813f803af554b59e46c8"></a>

첫 번째 줄에 자연수 N(3≤N≤10)과 M(2≤M≤N)이 주어집니다&#46;

<a id="1c3eda9b0fe18142b793cd8c4fc08a06"></a>

### 출력

<a id="1c3eda9b0fe181219c68d03406c5345b"></a>

첫 번째 줄에 결과를 출력합니다&#46;

<a id="1c3eda9b0fe1816a9691c6888ed3940b"></a>

출력순서는 사전순으로 오름차순으로 출력합니다&#46;

# 풀이

> n 개 중 m 개를 뽑는 경우의 수

<a id="1c3eda9b0fe18111ac27c9f7ee408e88"></a>

## 풀이1)  <code>강의풀이</code> 인자 &#43; 1

<a id="1c3eda9b0fe1811baee3fab03f9dfdec"></a>

```java
import java.util.*;

public class Main {
    static int[] combi;
    static int n, m;
    public void DFS(int L, int s) {
        if(L==m){
            for(int x : combi) System.out.print(x+" ");
            System.out.println();
        }
        else {
            for(int i=s; i<=n; i++){
                combi[L]=i;
                DFS(L+1, i+1);
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        combi=new int[m];
        T.DFS(0, 1);
    }
}
```
