## 문제

<a id="1d2eda9b0fe1805194d5ea4411e1598a"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe18091a2d2c59c693eac8e"></a>

다음은 식품의 정보를 담은 <code>FOOD&#95;PRODUCT</code> 테이블입니다&#46; <code>FOOD&#95;PRODUCT</code> 테이블은 다음과 같으며 <code>PRODUCT&#95;ID</code>, <code>PRODUCT&#95;NAME</code>, <code>PRODUCT&#95;CD</code>, <code>CATEGORY</code>, <code>PRICE</code>는 식품 ID, 식품 이름, 식품 코드, 식품분류, 식품 가격을 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PRODUCT&#95;ID | VARCHAR(10) | FALSE |
| PRODUCT&#95;NAME | VARCHAR(50) | FALSE |
| PRODUCT&#95;CD | VARCHAR(10) | TRUE |
| CATEGORY | VARCHAR(10) | TRUE |
| PRICE | NUMBER | TRUE |

---

<a id="1d2eda9b0fe1806394ffd117b2bd5e84"></a>

### 문제

<a id="1d2eda9b0fe1803b8b14c44d9ef046d3"></a>

<code>FOOD&#95;PRODUCT</code> 테이블에서 가격이 제일 비싼 식품의 식품 ID, 식품 이름, 식품 코드, 식품분류, 식품 가격을 조회하는 SQL문을 작성해주세요&#46;

---

<a id="1d2eda9b0fe1808e94bad17d9e695f2b"></a>

### 예시

<a id="1d2eda9b0fe180cf89d6d8119291a6f4"></a>

<code>FOOD&#95;PRODUCT</code> 테이블이 다음과 같을 때

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;NAME | PRODUCT&#95;CD | CATEGORY | PRICE |
| P0018 | 맛있는고추기름 | CD&#95;OL00008 | 식용유 | 6100 |
| P0019 | 맛있는카놀라유 | CD&#95;OL00009 | 식용유 | 5100 |
| P0020 | 맛있는산초유 | CD&#95;OL00010 | 식용유 | 6500 |
| P0021 | 맛있는케첩 | CD&#95;OL00001 | 소스 | 4500 |
| P0022 | 맛있는마요네즈 | CD&#95;OL00002 | 소스 | 4700 |

<a id="1d2eda9b0fe1807aa839c08d145dd7dc"></a>

SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;NAME | PRODUCT&#95;CD | CATEGORY | PRICE |
| P0020 | 맛있는산초유 | CD&#95;OL00010 | 식용유 | 6500 |

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe180c7a4dad69d8c04c632"></a>
> 
> 조건
> 
> - 가격이 제일 비싼 식품의 식품 ID, 식품 이름, 식품 코드, 식품분류, 식품 가격을 조회

<a id="1d2eda9b0fe180f38f0ec2fcbd401415"></a>

### 풀이1) <strong><code>서브쿼리</code></strong><strong> &#43; </strong><strong><code>MAX()</code></strong>

<a id="1d2eda9b0fe1804db600c2dddd28f52e"></a>

```sql
SELECT PRODUCT_ID, PRODUCT_NAME, PRODUCT_CD, CATEGORY, PRICE
FROM FOOD_PRODUCT
WHERE PRICE = (SELECT MAX(PRICE) FROM FOOD_PRODUCT)
```

<a id="1d2eda9b0fe18096aed5c343211a1e94"></a>

### 풀이2) <strong><code>ORDER BY</code></strong><strong> &#43; </strong><strong><code>LIMIT</code></strong><strong> (MySQL 등)</strong>

<a id="1d2eda9b0fe180cd9956c797a956bd72"></a>

```sql
SELECT PRODUCT_ID, PRODUCT_NAME, PRODUCT_CD, CATEGORY, PRICE
FROM FOOD_PRODUCT
ORDER BY PRICE DESC
LIMIT 1;
```

<a id="1d2eda9b0fe180af984de0201f2dc825"></a>

### 풀이3) <strong><code>RANK()</code></strong><strong> or </strong><strong><code>ROW&#95;NUMBER()</code></strong><strong> (윈도우 함수 사용)</strong>

<a id="1d2eda9b0fe1809dac1fea55e5e6632a"></a>

```sql
SELECT product_id, product_name, product_cd, category, price
FROM (
    SELECT *,
           RANK() OVER (ORDER BY price DESC) AS ranking
    FROM FOOD_PRODUCT
) ranked
WHERE ranking = 1;
```

<a id="1d2eda9b0fe18027bcf8c7df5a45375a"></a>

<strong>✅ 해결1) 백틱(</strong><strong><code>&#96;&#96;</code></strong><strong>)</strong>

<a id="1d2eda9b0fe18018809fc30a4fa4ebff"></a>

```sql
SELECT product_id, product_name, product_cd, category, price
FROM (
    SELECT *,
           RANK() OVER (ORDER BY price DESC) AS `rank`
    FROM FOOD_PRODUCT
) ranked
WHERE `rank` = 1;
```

<a id="1d2eda9b0fe180be94a2e0eb79c58819"></a>

<a id="1d2eda9b0fe180a4b1dee5869be1c3d5"></a>

### 추가) 1 &#126; 3 위 랭크 컬럼 출력

<a id="1d2eda9b0fe180cca2bbc27357c7f64b"></a>

```sql
SELECT product_id, product_name, product_cd, category, price
FROM (
    SELECT *,
           ROW_NUMBER() OVER (ORDER BY price DESC) AS ranking
    FROM FOOD_PRODUCT
) ranked
WHERE ranking BETWEEN 1 AND 3;
```

<a id="1d2eda9b0fe18083a4c8d0c551db5cb0"></a>

```sql
SELECT product_id, product_name, product_cd, category, price
FROM FOOD_PRODUCT
ORDER BY PRICE DESC
LIMIT 3;
```

| ✅ <strong>부분 집계</strong> | 어려움 | 가능함 (ex&#58; 그룹별 상위 N개) |
