## Auditing

---

> 📖 
> 
> <a id="159eda9b0fe181c2af32f20700d5afb2"></a>
> 
> Auditing 기능을 통해 자동으로 <u>생성 날짜와, 업데이트 날짜, 생성 유저, 수정 유저</u> 등의 정보를 관리할 수 있다&#46; 

<details>
<summary>Auditing</summary>

![](10febcc0d385de49.webp)

> Auditing 을 사용하면 엔티티를 누가 언제 생성/마지막 수정 했는지 자동으로 기록 가능하다&#46;

<a id="159eda9b0fe1819cabd9f252c096f335"></a>

```java
@CreatedDate
private Date created;

@LastModifiedDate
private Date updated;

@CreatedBy
@ManyToOne
private Account createdBy;

@LastModifiedBy
@ManyToOne
private Account updatedBy;
```

</details>

<details>
<summary>Auditing 적용</summary>

1. root 클래스에 <code>&#64;EnableJpaAuditing</code> 추가
    <a id="159eda9b0fe18036b3f6cf28d42e6c83"></a>

    ```java
    @EnableJpaAuditing
    @SpringBootApplication
    public class Application {
    ```

1. Auditing 기능을 구현할 클래스에 <code>&#64;EntityListeners(AuditingEntityListener&#46;class)</code> 적용
    - <code>&#64;MappedSuperclass</code>를 적용하여, 각 엔티티에 상속 처리를 함으로써  간단하게 Auditing 기능 필드만 추가하여 구현 가능하다&#46;

    <a id="159eda9b0fe180ef8005d19d8285c8d7"></a>

    ```java
    엔티티 클래스 위에 @EntityListeners(AuditingEntityListener.class) 추가
    @Getter
    @MappedSuperclass
    @EntityListeners(AuditingEntityListener.class)
    public class TimeStamp {
        @CreatedDate
        private LocalDateTime createdAt;

        @CreatedBy
        @ManyToOne
        private User createdBy;

        @LastModifiedDate
        private LocalDateTime modifiedAt;

        @LastModifiedBy
        @ManyToOne
        private User modifiedBy;
    ```

</details>

<details>
<summary>AuditorAware 구현체 만들기</summary>

1. 생성 유저( <code>createdBy</code> ), 수정 유저 ( <code>modifiedBy</code> )를 구현하려면 <strong><u>AuditorAware 구현체가 필요</u></strong>하다&#46; 
    - 생성일 (<code>createdAt</code>), 수정일 (<code>modifiedAt</code>) 은 구현체 없이 동작 가능하다&#46;

    <a id="159eda9b0fe180c8accbc10be2b6fe32"></a>

    ```java
    @Service
    public class UserAuditorAware implements AuditorAware<User> {
        @Override
        public Optional<User> getCurrentAuditor() {
            Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
    			
            if (authentication == null || !authentication.isAuthenticated()) {
                return Optional.empty();
            }

            return Optional.of(((UserDetailsImpl) authentication.getPrincipal()).getUser());
        }
    }
    ```

    > 💡 
    > 
    > <a id="22f93dae59a346acb0c8dcf85ec6db2d"></a>
    > 
    > SpringSecurity 의 <code>SecurityContextHolder</code> 에서 인증 정보 안에 담긴 <code>UserDetailsImpl</code> 을 사용하여 user 객체를 가져와서 넣어준다&#46;
    > 
    > <details>
    > <summary>SpringSecurity의 JwtFilter</summary>
    > 
    > <a id="159eda9b0fe180c19ee2c19ad2c9345a"></a>
    > 
    > ```java
    > @Slf4j
    > @RequiredArgsConstructor
    > public class JwtAuthFilter extends OncePerRequestFilter {
    >

    > 
    >     @Override
    >     protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) throws ServletException, IOException {
    >         String token = jwtUtil.resolveToken(request);
    >

    >             if(!jwtUtil.validateToken(token)){
    >                 jwtExceptionHandler(response, "Token Error", HttpStatus.UNAUTHORIZED.value());

    >             Claims info = jwtUtil.getUserInfoFromToken(token);
    > 						// 인증정보 세팅함수 호출

    >         }
    >         try {
    >             filterChain.doFilter(request, response);

    >         SecurityContext context = SecurityContextHolder.createEmptyContext();

    >     }
    > 		...
    > }
    > ```
