## 문제

<a id="1cfeda9b0fe18000a9f7e4cd4dda657c"></a>

### <strong>문제 설명</strong>

<a id="1cfeda9b0fe18074856cd1ff19710c2f"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1cfeda9b0fe180d7871bf009c710c6ea"></a>

동물 보호소에 들어온 동물 중 젊은 동물<a href="https://school.programmers.co.kr/learn/courses/30/lessons/59037#fn1">1</a>의 아이디와 이름을 조회하는 SQL 문을 작성해주세요&#46; 이때 결과는 아이디 순으로 조회해주세요&#46;

<a id="1cfeda9b0fe1805fab24e8584b47f097"></a>

### 예시

<a id="1cfeda9b0fe1801888c0f1fae9d5827d"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A365172 | Dog | 2014&#45;08&#45;26 12&#58;53&#58;00 | Normal | Diablo | Neutered Male |
| A367012 | Dog | 2015&#45;09&#45;16 09&#58;06&#58;00 | Sick | Miller | Neutered Male |
| A365302 | Dog | 2017&#45;01&#45;08 16&#58;34&#58;00 | Aged | Minnie | Spayed Female |
| A381217 | Dog | 2017&#45;07&#45;08 09&#58;41&#58;00 | Sick | Cherokee | Neutered Male |

<a id="1cfeda9b0fe1802b9a1dc9418b3c47ae"></a>

이 중 젊은 동물은 Diablo, Miller, Cherokee입니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| ANIMAL&#95;ID | NAME |
| A365172 | Diablo |
| A367012 | Miller |
| A381217 | Cherokee |

<a id="1cfeda9b0fe180a495c7f30645f1022e"></a>

## 풀이

> ✏️ 
> 
> <a id="1cfeda9b0fe18053a4b7e3b0964fb455"></a>
> 
> 조건
> 
> - 동물 보호소에 들어온 동물 중 젊은 동물의 아이디와 이름을 조회
> 
> - 결과는 아이디 순으로 조회

<a id="1cfeda9b0fe1802c986be505651c5d56"></a>

```sql
SELECT ANIMAL_ID, NAME
FROM ANIMAL_INS
WHERE INTAKE_CONDITION NOT IN ("Aged")
ORDER BY ANIMAL_ID
```
