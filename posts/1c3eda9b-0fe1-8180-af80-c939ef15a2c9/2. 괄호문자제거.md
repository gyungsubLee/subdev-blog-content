# 문제

<a id="1c3eda9b0fe181f08a78cab0aeef5c22"></a>

## <strong>1&#46; 올바른 괄호</strong>

---

<a id="1c3eda9b0fe1819084a3d77791ed4ccd"></a>

### 설명

<a id="1c3eda9b0fe1811d8b37eec4c3e61f5b"></a>

입력된 문자열에서 소괄호 ( ) 사이에 존재하는 모든 문자를 제거하고 남은 문자만 출력하는 프로그램을 작성하세요&#46;<br>

<a id="1c3eda9b0fe1813bb0d2c1faced5d5fd"></a>

### 입력

<a id="1c3eda9b0fe18174a2f5d752c76b2cc3"></a>

첫 줄에 문자열이 주어진다&#46; 문자열의 길이는 100을 넘지 않는다&#46;

<a id="1c3eda9b0fe181eda218de1041b7d792"></a>

### 출력

<a id="1c3eda9b0fe181ea8680f51c31a090cc"></a>

남은 문자만 출력한다

---

<a id="1c3eda9b0fe181649c19fc77206738ae"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1814eab34fd53b13176ac"></a>

```plaintext
(A(BC)D)EF(G(H)(IJ)K)LM(N)
```

<a id="1c3eda9b0fe181b0a6c2f9abf7b2d3a3"></a>

### 예시 출력 1

# 풀이

<a id="1c3eda9b0fe18113802edb871359d7d7"></a>

## 풀이1) 내풀이

<a id="1c3eda9b0fe1810a8adbc36ae0951751"></a>

```java
import java.util.*;
public class Main {
    public String  solution(String str){
        String answer="";
        Stack<Character> stack= new Stack<>();
        for(char x : str.toCharArray()){
            if(x == '(') stack.push(x);
            else if(x==')') stack.pop();
            else{
                if(stack.isEmpty()) answer+=x;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.nextLine();
        System.out.println(T.solution(str));
    }
}
```

## 풀이2) 강의풀이, 더 올바른 풀이?

<a id="1c3eda9b0fe181d6a659f44f3f0dce8d"></a>

```java
import java.util.*;
public class Main {
    public String  solution(String str){
        String answer="";
        Stack<Character> stack= new Stack<>();
        for(char x : str.toCharArray()){
            if(x == ')') {
                while(stack.pop()!='(');
            }
            else stack.push(x);
        }
        for(int i=0; i<stack.size(); i++) answer+=stack.get(i);
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.nextLine();
        System.out.println(T.solution(str));
    }
}
```
