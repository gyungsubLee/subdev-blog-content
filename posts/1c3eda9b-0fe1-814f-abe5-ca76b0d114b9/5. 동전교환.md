# 문제

<a id="1c3eda9b0fe181fe89f8f59f90fe4974"></a>

## <strong>5&#46; 동전교환</strong>

---

<a id="1c3eda9b0fe18163a5cbd898561e1b0a"></a>

### 설명

<a id="1c3eda9b0fe181b484f0ce07d4458cf9"></a>

다음과 같이 여러 단위의 동전들이 주어져 있을때 거스름돈을 가장 적은 수의 동전으로 교환해주려면 어떻게 주면 되는가?

<a id="1c3eda9b0fe1816b8a54d295136465ba"></a>

각 단위의 동전은 무한정 쓸 수 있다&#46;

<a id="1c3eda9b0fe181289c60de700010a36d"></a>

### 입력

<a id="1c3eda9b0fe181869298fcd747d9c788"></a>

첫 번째 줄에는 동전의 종류개수 N(1&#60;=N&#60;=12)이 주어진다&#46; 두 번째 줄에는 N개의 동전의 종류가 주어지고,

<a id="1c3eda9b0fe1814db20ec76703b8ae80"></a>

그 다음줄에 거슬러 줄 금액 M(1&#60;=M&#60;=500)이 주어진다&#46;각 동전의 종류는 100원을 넘지 않는다&#46;

<a id="1c3eda9b0fe1812eaebfd496658530cf"></a>

### 출력

<a id="1c3eda9b0fe1817ea78fcf96f9b8c399"></a>

첫 번째 줄에 거슬러 줄 동전의 최소개수를 출력한다&#46;

---

## 풀이1) <code>내풀이</code> BFS

<a id="1c3eda9b0fe18103a124d2870c846354"></a>

### BFS 요소 

> 1&#46; Q<br>2&#46; L(depth)<br>3&#46; len(Q&#46;size)

<details>
<summary>1) 0부터 시작</summary>

<a id="1c3eda9b0fe181f08b41f0ee9353fa7c"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int n, t;
    static int[] dis;
    public int BFS(int v){
        Queue<Integer> Q=new LinkedList<>();  
        int L=0;
        Q.offer(v);
        while(!Q.isEmpty()){
            int len = Q.size();
            for(int i=0; i<len; i++){
                int x=Q.poll();
                for(int dx : dis){
                    int nx=x+dx;
                    if(nx==t) return L+1;
                    if(nx<t){
                        Q.offer(nx);
                    }
                }
            }
            L++;
        }
        return L;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        dis=new int[n];
        for(int i=0; i<n; i++){
            dis[i]=sc.nextInt();
        }
        t=sc.nextInt();
        System.out.println(T.BFS(0));
    }
}
```

</details>

```java
import java.util.*;

public class Main {
    public int BFS(int target, int n, int[] coinTypes) {
        Queue<Integer> Q=new LinkedList<>();
        int L=0;
        Q.offer(target);
        while(!Q.isEmpty()){
            int len=Q.size();
            for(int i=0; i<len; i++){
                int currenTargetValue = Q.poll();
                for(int coin : coinTypes){
                    int nextTargetValue = currenTargetValue - coin;
                    if(nextTargetValue == 0) return L+1;
                    if(nextTargetValue > 0) Q.offer( nextTargetValue );
                }
            }
            L++;
        }
        return L;

    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int[] coinTypes=new int[n];
        for(int i=0; i<n; i++){
            coinTypes[i]=sc.nextInt();
        }
        int target=sc.nextInt();
        System.out.println(T.BFS(target, n, coinTypes));
    }
}
```

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int n, answer=Integer.MAX_VALUE;
    static int[] arr;
    public void DFS(int v, int L){
        if(v<0 || L>=answer) return;
        if(v==0) {
            answer=Math.min(answer, L);
        }
        else {
            for(int dv : arr){
                int nv=v-dv;
                DFS(nv, L+1);
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        arr=new int[n];
        for(int i=0; i<n; i++) arr[i]=sc.nextInt();
        int t=sc.nextInt();
        T.DFS(t, 0);
        System.out.println(answer);
    }
}
```

### 해결

<a id="1c3eda9b0fe181209ed3e01bba7dd9cd"></a>

<a id="1c3eda9b0fe181159ae9f2957d69ba25"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int n, answer=Integer.MAX_VALUE;
    static int[] arr;
    public void DFS(int v, int L){
        if(v<0 || L>=answer) return;  // 백트래킹
        if(v==0) {
            answer=Math.min(answer, L);
        }
        else {
            for(int i=arr.length-1; i>=0; i--){
                DFS(v-arr[i], L+1);
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        arr=new int[n];
        for(int i=0; i<n; i++) arr[i]=sc.nextInt();
        int t=sc.nextInt();
        T.DFS(t, 0);
        System.out.println(answer);
    }
}
```

```java
import java.util.*;

public class Main {
    static int n, target, answer=Integer.MAX_VALUE;
    static int[] coinTypes;
    public void DFS(int L, int sum) {
        if(sum>target || L>=answer) return;
        if(sum==target) answer=Math.min(answer, L);
        else for(int coin : coinTypes) DFS(L+1, sum+coin);
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        coinTypes=new int[n];
        for(int i=0; i<n; i++){
            coinTypes[i]=sc.nextInt();
        }
        target=sc.nextInt();
        T.DFS(0, 0);
        System.out.println(answer);
    }
}
```

## 풀이3) <code>강의풀이</code>&#43; <code>수정</code>  DFS

<a id="1c3eda9b0fe1819d85dffb1d572ac230"></a>

### 오류) sum&#43;<code>=</code><em>coinType</em>&#91;i&#93;

> <code>&#43;=</code> 은 외부 변수의 스코프까지 영향을 준다&#46; 

<a id="1c3eda9b0fe181d3b682dcb6abe67415"></a>

해당 로직에  ‘<code>=</code>’ 연산이 추가될 경우, 해당 DFS연산이 종료 되어도, 값이 남음&#46;

<a id="1c3eda9b0fe181a09340f17e59aea2f3"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int n, m, answer=Integer.MAX_VALUE;
    public void DFS(int L, int sum, int[] arr){
        if(sum>m || L>=answer) return;
        if(sum==m) answer=Math.min(answer, L);
        else {
            for(int i=n-1; i>=0; i--) DFS(sum+arr[i], L+1, arr);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        int[] arr=new int[n];
        for(int i=0; i<n; i++) arr[i]=sc.nextInt();
        m=sc.nextInt();
        T.DFS(0, 0, arr);
        System.out.println(answer);
    }
}
```
