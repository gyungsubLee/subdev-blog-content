> <code>&#64;Autowired</code>는 타입(Type)으로 조회한다&#46; 
> 
> <a id="1c3eda9b0fe18129a9ebd1e81064daab"></a>
> 
> ```java
> @Autowired
> private DiscountPolicy discountPolicy
> ```

<a id="1c3eda9b0fe181e199ddd2acbc823261"></a>

이전 스프링 빈 조회에서 한번 학습했듯이, <strong>타입으로 조회 시 선택된 빈이 2개 이상일 때</strong> <code>NoUniqueBeanDefinitionException</code> 오류가 발생한다&#46;

>  <code>ac&#46;getBean(DiscountPolicy&#46;class)</code> <br> → <strong> </strong><code>FixDiscountPolicy</code>, <code>RateDiscountPolicy</code> (<code>NoUniqueBeanDefinitionException</code> ) 

<a id="1c3eda9b0fe18144b7b5cfd7013a1258"></a>

### 프로젝트에서 해당 오류 확인

---

> 1&#46; <code>FixDiscountPolicy</code>, <code>RateDiscountPolicy</code> 스프링 빈 선언

<a id="1c3eda9b0fe181508b13cfa2c9f993ee"></a>

```java
@Component
public class FixDiscountPolicy implements DiscountPolicy {}
```

<a id="1c3eda9b0fe181c48642f7735cc5f0a2"></a>

```java
@Component
public class RateDiscountPolicy implements DiscountPolicy {}
```

> 2&#46; 의존관계 자동 주입

<a id="1c3eda9b0fe181aeaf6dfa3ce11dfd1c"></a>

```java
@Autowired
private DiscountPolicy discountPolicy
```

> 3&#46; 테스트에서 빈 조회,  <code>NoUniqueBeanDefinitionException</code> 오류 발생

<a id="1c3eda9b0fe1810c80f8d004c604a3ea"></a>

```java
ac.getBean(DiscountPolicy.class);
```

<a id="1c3eda9b0fe18188b15dfa4779df20d2"></a>

```plaintext
NoUniqueBeanDefinitionException: No qualifying bean of type
 'hello.core.discount.DiscountPolicy' available: expected single matching bean
 but found 2: fixDiscountPolicy,rateDiscountPolicy
```

<a id="1c3eda9b0fe1814fb412c4395f85ceac"></a>

해당 오류 메세지를 통해, 하나의 빈이 아닌 <code>fixDiscountPolicy</code> , <code>rateDiscountPolicy</code> 2개의 빈이 발견되었다는 것을 알 수 있다&#46;

<a id="1c3eda9b0fe1812eac10f9f403e08124"></a>

### 해결 방법

---

<a id="1c3eda9b0fe181bc8750d506311d2b24"></a>

### 오류&#58; 인터페이스 타입으로 조회 →  2개의 구현체  <br>

> <strong>하위 타입인 각 구현클래스로 타입 변경  &#91; </strong><strong>X </strong><strong>&#93;</strong>

<a id="1c3eda9b0fe181b68666d4edd45c77e8"></a>

이렇게 <strong>상위 타입(인터페이스)가 아닌 하위 타입(구현체)으로  조회 방법</strong>은 <strong>DIP를 위배</strong>하고<strong> </strong><strong>유연성이 떨</strong>어진다&#46;  그리고 이름만 다르고, 완전히 똑같은 타입의 스프링 빈이 2개 있을 때 해결이 안된다&#46;

> <strong>스프링 빈을 수동 등록 </strong>

<a id="1c3eda9b0fe1815f813fe5aef1001758"></a>

스프링 빈을 수동으로 등록하여 직접 의존관계를 명시하여 해결<br>그러나 <strong>자동으로 의존관계를 처리하는 좋은 방법들</strong>이 있음
