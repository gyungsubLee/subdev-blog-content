## 문제

<a id="15beda9b0fe180dc809cc0d04bcc48cd"></a>

### <strong>문제 설명</strong>

<a id="15beda9b0fe180ea858ad543829d5875"></a>

다음은 아이스크림 가게의 상반기 주문 정보를 담은 <code>FIRST&#95;HALF</code> 테이블과 아이스크림 성분에 대한 정보를 담은 <code>ICECREAM&#95;INFO</code> 테이블입니다&#46; <code>FIRST&#95;HALF</code> 테이블 구조는 다음과 같으며, <code>SHIPMENT&#95;ID</code>, <code>FLAVOR</code>, <code>TOTAL&#95;ORDER</code> 는 각각 아이스크림 공장에서 아이스크림 가게까지의 출하 번호, 아이스크림 맛, 상반기 아이스크림 총주문량을 나타냅니다&#46; <code>FIRST&#95;HALF</code> 테이블의 기본 키는 <code>FLAVOR</code>입니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| SHIPMENT&#95;ID | INT(N) | FALSE |
| FLAVOR | VARCHAR(N) | FALSE |
| TOTAL&#95;ORDER | INT(N) | FALSE |

<a id="15beda9b0fe18000b117d0aae5a87508"></a>

<code>ICECREAM&#95;INFO</code> 테이블 구조는 다음과 같으며, <code>FLAVOR</code>, <code>INGREDITENT&#95;TYPE</code> 은 각각 아이스크림 맛, 아이스크림의 성분 타입을 나타냅니다&#46; <code>INGREDIENT&#95;TYPE</code>에는 아이스크림의 주 성분이 설탕이면 <code>sugar&#95;based</code>라고 입력되고, 아이스크림의 주 성분이 과일이면 <code>fruit&#95;based</code>라고 입력됩니다&#46; <code>ICECREAM&#95;INFO</code>의 기본 키는 <code>FLAVOR</code>입니다&#46; <code>ICECREAM&#95;INFO</code>테이블의 <code>FLAVOR</code>는 <code>FIRST&#95;HALF</code> 테이블의 <code>FLAVOR</code>의 외래 키입니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| FLAVOR | VARCHAR(N) | FALSE |
| INGREDIENT&#95;TYPE | VARCHAR(N) | FALSE |

---

<a id="15beda9b0fe18021b189d5516a9de0cb"></a>

### 문제

<a id="15beda9b0fe1805c9617ef8f7c53b1a2"></a>

상반기 동안 각 아이스크림 성분 타입과 성분 타입에 대한 아이스크림의 총주문량을 총주문량이 작은 순서대로 조회하는 SQL 문을 작성해주세요&#46; 이때 총주문량을 나타내는 컬럼명은 TOTAL&#95;ORDER로 지정해주세요&#46;

---

<a id="15beda9b0fe180d1b08dfacb296e85bb"></a>

### 예시

<a id="15beda9b0fe180928939f8c06ab53358"></a>

예를 들어 <code>FIRST&#95;HALF</code> 테이블이 다음과 같고

|  |  |  |
| --- | --- | --- |
| SHIPMENT&#95;ID | FLAVOR | TOTAL&#95;ORDER |
| 101 | chocolate | 3200 |
| 102 | vanilla | 2800 |
| 103 | mint&#95;chocolate | 1700 |
| 104 | caramel | 2600 |
| 105 | white&#95;chocolate | 3100 |
| 106 | peach | 2450 |
| 107 | watermelon | 2150 |
| 108 | mango | 2900 |
| 109 | strawberry | 3100 |
| 110 | melon | 3150 |
| 111 | orange | 2900 |
| 112 | pineapple | 2900 |

<a id="15beda9b0fe1804caf88c2d0cedc2196"></a>

<code>ICECREAM&#95;INFO</code> 테이블이 다음과 같다면

|  |  |
| --- | --- |
| FLAVOR | INGREDIENT&#95;TYPE |
| chocolate | sugar&#95;based |
| vanilla | sugar&#95;based |
| mint&#95;chocolate | sugar&#95;based |
| caramel | sugar&#95;based |
| white&#95;chocolate | sugar&#95;based |
| peach | fruit&#95;based |
| watermelon | fruit&#95;based |
| mango | fruit&#95;based |
| strawberry | fruit&#95;based |
| melon | fruit&#95;based |
| orange | fruit&#95;based |
| pineapple | fruit&#95;based |

<a id="15beda9b0fe1805a84a5fc2816e39c6a"></a>

상반기에 아이스크림의 주 성분이 설탕인 아이스크림들에 대한 총주문량을 구하면 3,200 &#43; 2,800 &#43; 1,700 &#43; 2,600 &#43; 3,100 = 13,400입니다&#46; 아이스크림의 주 성분이 과일인 아이스크림들에 대한 총주문량을 구하면 3,100 &#43; 2,450 &#43; 2,150 &#43; 2,900 &#43; 3,150 &#43; 2,900 &#43; 2,900 = 19,550입니다&#46; 따라서 총주문량이 작은 순서대로 조회하는 SQL 문을 실행하면 다음과 같이 나와야 합니다&#46;

<a id="15beda9b0fe180958b83cf134e76e0fd"></a>

&#124; INGREDIENT<u>TYPE &#124; TOTAL</u>ORDER &#124;

<a id="15beda9b0fe1804098def9599bfd07ff"></a>

&#124;&#58;&#45;&#45;&#45;&#45;&#124;&#45;&#45;&#45;&#45;&#124;

<a id="15beda9b0fe18094b4e6ea138def31fe"></a>

&#124; sugar<u>based &#124; 13400 &#124;&#124; fruit</u>based &#124; 19550 &#124;

<a id="b03e0c2b5d5c44c1939b90380c6a4701"></a>

## 풀이

<a id="15beda9b0fe180f18fb0cba3bd7846b1"></a>

```sql
SELECT
    I.INGREDIENT_TYPE,
    SUM(F.TOTAL_ORDER) AS TOTAL_ORDER
FROM FIRST_HALF F
JOIN ICECREAM_INFO I
ON F.FLAVOR = I.FLAVOR
GROUP BY I.INGREDIENT_TYPE;
```
