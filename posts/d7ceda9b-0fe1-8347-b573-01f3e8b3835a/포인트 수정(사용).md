## 요청 응답 예시

---

> 해당하는 값이 없는 경우,  테이블 삭제 후 <code>None</code> 명시

<a id="8a3eda9b0fe18397ae8781a4cd0000ad"></a>

### 요청 

- Path Variable&#58; <code>None</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | matchingCount | Long | None | 포인트 사용 횟수 |
    | 2 | details | String | <code>Nullable</code> | 포인트 사용 내역 |

- HTTP 요청
    <a id="8e1eda9b0fe18221b3258181666d2096"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) PATCH /api/points/1 HTTP1.1
    ```

    <details>
    <summary>요청 예시 </summary>

    <a id="8eaeda9b0fe18246828081ece9773962"></a>

    ```json
    PATCH /api/points/1 HTTP1.1

    {
        "matchingCount": 10,
        "details" : "first test"
    }
    ```

    </details>

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | PointResponseDto | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>None</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None | 포인트 ID |
    | 2 | userId | Long | None | 사용자 ID |
    | 3 | amount | decimal | None | 포인트 금액 |
    | 5 | createdAt | timestamp | None | 포인트 생성 날짜 |
    | 6 | updatedAt | timestamp | None | 포인트 수정 날짜 |

    </details>

    <details>
    <summary>응답 예시 </summary>

    <a id="f9beda9b0fe1839481c0010705735dda"></a>

    ```json
    HTTP/1.1 204 NO CONTENTS

    {
        
    }
    ```

    </details>

- HTTP Status
    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
    | --- | --- | --- | --- |
    | 1 | <code>200 </code> | <code>OK</code> | 성공 |
    | 2 | <code>400</code> | <code>Bad Request</code> | 잘못된 요청 |
    | 3 | <code>401</code> | <code>Unauthorized</code> | 인가되지 않은 요청 |
    | 4 | <code>404</code> | <code>Not Found</code> | 해당 정보 찾을 수 없음 |
