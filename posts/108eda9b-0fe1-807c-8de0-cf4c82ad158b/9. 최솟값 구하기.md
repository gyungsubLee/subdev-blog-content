## 문제

<a id="1cfeda9b0fe1806faa19de293da79bbf"></a>

### <strong>문제 설명</strong>

<a id="1cfeda9b0fe18057968ffa5ac7de981e"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1cfeda9b0fe1803b80caeaf7370127cf"></a>

동물 보호소에 가장 먼저 들어온 동물은 언제 들어왔는지 조회하는 SQL 문을 작성해주세요&#46;

<a id="1cfeda9b0fe180b0af6dcba1111c27d5"></a>

### 예시

<a id="1cfeda9b0fe1801a9397ee1649932295"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A399552 | Dog | 2013&#45;10&#45;14 15&#58;38&#58;00 | Normal | Jack | Neutered Male |
| A379998 | Dog | 2013&#45;10&#45;23 11&#58;42&#58;00 | Normal | Disciple | Intact Male |
| A370852 | Dog | 2013&#45;11&#45;03 15&#58;04&#58;00 | Normal | Katie | Spayed Female |
| A403564 | Dog | 2013&#45;11&#45;18 17&#58;03&#58;00 | Normal | Anna | Spayed Female |

<a id="1cfeda9b0fe180709652ea986395420b"></a>

가장 먼저 들어온 동물은 Jack이고, Jack은 2013&#45;10&#45;14 15&#58;38&#58;00에 들어왔습니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

<a id="1cfeda9b0fe1804b88f3c49c57c713b9"></a>

시간

---

<a id="1cfeda9b0fe18068b145ded4b7cb73f7"></a>

2013&#45;10&#45;14 15&#58;38&#58;00

---

<a id="1cfeda9b0fe180218c8dcdaea23528c1"></a>

※ 컬럼 이름(위 예제에서는 &#34;시간&#34;)은 일치하지 않아도 됩니다&#46;

<a id="1cfeda9b0fe18048bcd8c1bcd7fbac26"></a>

## 풀이

> ✏️ 
> 
> <a id="1cfeda9b0fe180dfb1f0eb4e6c336b8e"></a>
> 
> 조건
> 
> - 동물 보호소에 가장 먼저 들어온 동물은 언제 들어왔는지 조회

<a id="1cfeda9b0fe180cfb146fbbe4b50cda0"></a>

```sql
# 1. ORDER BY + LIMIT
SELECT DATETIME AS "시간"
FROM ANIMAL_INS
ORDER BY DATETIME
LIMIT 1;
```

<a id="1cfeda9b0fe18090a761f818130a4293"></a>

```sql
# 2. 서브쿼리 + MIN()
SELECT DATETIME AS "시간"
FROM ANIMAL_INS
WHERE DATETIME = (SELECT MIN(DATETIME) FROM ANIMAL_INS)
```
