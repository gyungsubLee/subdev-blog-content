## 문제

<a id="136eda9b0fe18061b80ceaacdb338a1d"></a>

# <strong><a href="https://leetcode.com/problems/reverse-string/">44&#46; Reverse String</a></strong>

<a id="136eda9b0fe1803cb76edd9d8cb0f49d"></a>

Write a function that reverses a string&#46; The input string is given as an array of characters <code>s</code>&#46;

<a id="136eda9b0fe1800fb9c3d2ce3320dccc"></a>

You must do this by modifying the input array <a href="https://en.wikipedia.org/wiki/In-place_algorithm">in&#45;place</a> with <code>O(1)</code> extra memory&#46;

<a id="136eda9b0fe1801b8901daa367800b0e"></a>

<strong>Example 1&#58;</strong>

<a id="136eda9b0fe180dbb0d9e1c2704f9a8f"></a>

```plaintext
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]

```

<a id="136eda9b0fe180ffa14ac5a7eed533d7"></a>

<strong>Example 2&#58;</strong>

<a id="136eda9b0fe1803ebfb0d26b3b0e467b"></a>

```plaintext
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]

```

<a id="136eda9b0fe18022bd4ede5851ed4eef"></a>

<strong>Constraints&#58;</strong>

- <code>1 &#60;= s&#46;length &#60;= 105</code>

- <code>s&#91;i&#93;</code> is a <a href="https://en.wikipedia.org/wiki/ASCII#Printable_characters">printable ascii character</a>&#46;

<a id="136eda9b0fe181fc8f66d03ce222f1fd"></a>

## 풀이

<a id="136eda9b0fe1806f8da7c57d80184126"></a>

리트코드는 특이한게 값을 리턴하지 않아서 알아서 정답을 읽어준다&#46;  <br>편하긴 하지만, 뭔가 명시적이지 않아 불편하다 

<a id="136eda9b0fe18094a64be5f412c16e79"></a>

### 풀이 1 &#45;  투포인터, 값 바꿈

<a id="136eda9b0fe1801f9791ceeb311c6e22"></a>

파이썬은 중간에 값을 저장하지 않아도 바로 바꿔주던데, 자바는 그런 부분이 없는게 조금 아쉽다&#46; 

<a id="136eda9b0fe1807b859ef839ba0c58d0"></a>

```java
class Solution {
    public void reverseString(char[] s) {
        int start = 0;
        int end = s.length-1;

        while( start < end ){
            char tmp = s[end];
            s[end] = s[start];
            s[start] = tmp;
            start++;
            end--;
        }
    }
}
```

<a id="136eda9b0fe18095859df02a6d233be1"></a>

### 풀이 2 &#45; 코틀린

- <code>&#46;also { }</code> 
    -  also 함수를 사용하여 한번에 스왑 처리

    - also 내부 로직까지 실행되기 전, 값 변경이 일어나지 않음

<a id="136eda9b0fe180d8a18af0b9055d19db"></a>

```java
class Solution {
    fun reverseString(s: CharArray): Unit {
        var start = 0
        var end = s.size - 1

        while (start < end) {
            s[start] = s[end].also { s[end] = s[start] }
            start++
            end--
        }
    }
}

```
