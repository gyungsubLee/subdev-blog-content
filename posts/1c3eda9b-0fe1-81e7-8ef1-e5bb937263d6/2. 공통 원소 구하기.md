# 문제

<a id="1c3eda9b0fe181b09458cedac9366ff4"></a>

## <strong>2&#46; 공통원소 구하기</strong>

---

<a id="1c3eda9b0fe181a69ce0d929ec208bff"></a>

###  설명

<a id="1c3eda9b0fe181febe28c88c8932ddca"></a>

A, B 두 개의 집합이 주어지면 두 집합의 공통 원소를 추출하여 오름차순으로 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181319135cae4e0b84599"></a>

### 입력

<a id="1c3eda9b0fe181f48557f20faa166ab1"></a>

첫 번째 줄에 집합 A의 크기 N(1&#60;=N&#60;=30,000)이 주어집니다&#46;

<a id="1c3eda9b0fe181b6aad5e26145bdbce1"></a>

두 번째 줄에 N개의 원소가 주어집니다&#46; 원소가 중복되어 주어지지 않습니다&#46;

<a id="1c3eda9b0fe181989bbdd5024889480a"></a>

세 번째 줄에 집합 B의 크기 M(1&#60;=M&#60;=30,000)이 주어집니다&#46;

<a id="1c3eda9b0fe181dca699ee331e94b825"></a>

네 번째 줄에 M개의 원소가 주어집니다&#46; 원소가 중복되어 주어지지 않습니다&#46;

<a id="1c3eda9b0fe181df9932dbe60a230eb6"></a>

각 집합의 원소는 1,000,000,000이하의 자연수입니다&#46;

<a id="1c3eda9b0fe181f18deec26ad04affe5"></a>

### 출력

<a id="1c3eda9b0fe1814f9a33d4e052e88457"></a>

두 집합의 공통원소를 오름차순 정렬하여 출력합니다&#46;

---

<a id="1c3eda9b0fe18175ba51ea8a189c4759"></a>

### 예시 입력 1

<a id="1c3eda9b0fe18159b181e34fd0216a11"></a>

```plaintext
5
1 3 9 5 2
5
3 2 5 7 8

```

<a id="1c3eda9b0fe1812cb744e27df4f0f156"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181448600e4cdcf56a051"></a>

```plaintext
2 3 5
```

# 풀이

<a id="1c3eda9b0fe18167ac9cc9a4f32c066d"></a>

### 풀이1)

<a id="1c3eda9b0fe1811882c7f3db4615d3c6"></a>

정렬&#58; <code>Arrays&#46;sort()</code>

<a id="1c3eda9b0fe181748ca2cbafbc6fd8b4"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public ArrayList<Integer> solution(int n1, int n2, int[] arr1, int[] arr2) {
        ArrayList<Integer> answer=new ArrayList<>();
        Arrays.sort(arr1);
        Arrays.sort(arr2);
        int p1=0, p2=0;
        while(p1<n1 && p2<n2){
						if(arr1[p1]==arr2[p2]){
                answer.add(arr1[p1]);
                p1++; p2++;
            }
            else if(arr1[p1] < arr2[p2]) p1++;
            else  p2++;
        }
        return answer;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n1 = sc.nextInt();
        int[] arr1 = new int[n1];
        for(int i=0; i<n1; i++){
            arr1[i]=sc.nextInt();
        }

        int n2 = sc.nextInt();
        int[] arr2 = new int[n2];
        for(int i=0; i<n2; i++){
            arr2[i]=sc.nextInt();
        }
        for(int x: m.solution(n1, n2, arr1, arr2)){
            System.out.print(x+" ");
        }
    }
}
```
