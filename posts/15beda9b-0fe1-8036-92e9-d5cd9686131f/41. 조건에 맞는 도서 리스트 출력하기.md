## 문제

<a id="15beda9b0fe180e78e7bca56ae0e7182"></a>

### <strong>문제 설명</strong>

<a id="15beda9b0fe18045a27ef2e0579bca3d"></a>

다음은 어느 한 서점에서 판매중인 도서들의 도서 정보(<code>BOOK</code>) 테이블입니다&#46;

<a id="15beda9b0fe1807585d1f4c71436e0e2"></a>

<code>BOOK</code> 테이블은 각 도서의 정보를 담은 테이블로 아래와 같은 구조로 되어있습니다&#46;

|  |  |  |  |
| --- | --- | --- | --- |
| Column name | Type | Nullable | Description |
| BOOK&#95;ID | INTEGER | FALSE | 도서 ID |
| CATEGORY | VARCHAR(N) | FALSE | 카테고리 (경제, 인문, 소설, 생활, 기술) |
| AUTHOR&#95;ID | INTEGER | FALSE | 저자 ID |
| PRICE | INTEGER | FALSE | 판매가 (원) |
| PUBLISHED&#95;DATE | DATE | FALSE | 출판일 |

---

<a id="15beda9b0fe18077a867e6ac8ed16d10"></a>

### 문제

<a id="15beda9b0fe1806c8063d4707eb835b1"></a>

<code>BOOK</code> 테이블에서 <code>2021년</code>에 출판된 <code>&#39;인문&#39;</code> 카테고리에 속하는 도서 리스트를 찾아서 도서 ID(<code>BOOK&#95;ID</code>), 출판일 (<code>PUBLISHED&#95;DATE</code>)을 출력하는 SQL문을 작성해주세요&#46;

<a id="15beda9b0fe1803493c2e03aedb442c9"></a>

결과는 출판일을 기준으로 오름차순 정렬해주세요&#46;

---

<a id="15beda9b0fe18090a4c4d81574391f74"></a>

### 예시

<a id="15beda9b0fe18021b3ccf927337a4dea"></a>

예를 들어 <code>BOOK</code> 테이블이 다음과 같다면

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| BOOK&#95;ID | CATEGORY | AUTHOR&#95;ID | PRICE | PUBLISHED&#95;DATE |
| 1 | 인문 | 1 | 10000 | 2020&#45;01&#45;01 |
| 2 | 경제 | 2 | 9000 | 2021&#45;02&#45;05 |
| 3 | 인문 | 2 | 11000 | 2021&#45;04&#45;11 |
| 4 | 인문 | 3 | 10000 | 2021&#45;03&#45;15 |
| 5 | 생활 | 1 | 12000 | 2021&#45;01&#45;10 |

<a id="15beda9b0fe180d39370ebc150b238fd"></a>

조건에 속하는 도서는 도서 ID 가 3, 4인 도서이므로 다음과 같습니다&#46;

|  |  |
| --- | --- |
| BOOK&#95;ID | PUBLISHED&#95;DATE |
| 3 | 2021&#45;04&#45;11 |
| 4 | 2021&#45;03&#45;15 |

<a id="15beda9b0fe18065b812c633ecbed49e"></a>

그리고 출판일 오름차순으로 정렬하여야 하므로 다음과 같은 결과가 나와야 합니다&#46;

|  |  |
| --- | --- |
| BOOK&#95;ID | PUBLISHED&#95;DATE |
| 4 | 2021&#45;03&#45;15 |
| 3 | 2021&#45;04&#45;11 |

---

<a id="15beda9b0fe180e5a644fd18eb342f08"></a>

### 주의사항

<a id="15beda9b0fe18040bf41fee3e0b8ce29"></a>

<code>PUBLISHED&#95;DATE</code>의 데이트 포맷이 예시와 동일해야 정답처리 됩니다&#46;

<a id="74904c18f3f94f6b931afcf59fb26dd5"></a>

## 풀이

<a id="15beda9b0fe180148869e2400cb23dea"></a>

```sql
SELECT
    BOOK_ID,
    DATE_FORMAT(PUBLISHED_DATE, '%Y-%m-%d') PUBLISHED_DATE
FROM BOOK
WHERE CATEGORY = '인문' AND PUBLISHED_DATE LIKE '2021%'
ORDER BY PUBLISHED_DATE;
```
