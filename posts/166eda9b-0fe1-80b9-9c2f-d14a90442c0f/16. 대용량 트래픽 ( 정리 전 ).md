# DB 다중화의 문제

- 복제 지연

- 동기화 성능 저하

- 데이터 불일치 
    - Master ↔ Slave 간 복제가 완료되기 전에 장애가 발생하는 경우 데이터 불일치가 발생할 수 있다&#46; 
        <a id="166eda9b0fe180c489d2f4882f730e02"></a>

        이는 데이터를 신뢰할 수 없는 상황을 만들 수 있다&#46; 

- 비용 증가 
    - 여러 대의 DB를 운영해야 하므로 관리 포인트도 늘어나고 그에 따른 비용도 늘어난다&#46;

<a id="166eda9b0fe1805fa6d0c80072dbbcb0"></a>
