<strong>Anthropic 공식 마켓플레이스 (Claude Code)</strong>

<a id="2e7eda9b0fe180ef8778de35430a56fc"></a>

```bash
# Step 1: 마켓플레이스 등록
/plugin marketplace add anthropics/skills

# Step 2: Plugin 목록 확인
/plugin
# → Discover 탭에서 브라우징

# Step 3: 원하는 Skills 설치
/plugin install document-skills@anthropic-agent-skills
/plugin install example-skills@anthropic-agent-skills
```

<a id="2e8eda9b0fe18034b881c9e8d0a08752"></a>

<br>커뮤니티 마켓플레이스

<a id="2e8eda9b0fe180bc88b4e54bdbca78bf"></a>

```bash
# Engineering Workflows (Git, 테스트, 코드리뷰)
/plugin marketplace add mhattingpete/claude-skills-marketplace

# Netresearch (PHP, Go, Jira 통합)
/plugin marketplace add netresearch/claude-code-marketplace

# Project Planner (기획 문서 자동화)
/plugin marketplace add adrianpuiu/claude-skills-marketplace
```

<a id="2e7eda9b0fe18019a045ccd3767a5dad"></a>

CLI로 빠른 설치 (npx)

<a id="2e8eda9b0fe180088d3afbc4803b3b71"></a>

```bash
# 프론트엔드 디자인
npx claude-plugins install @anthropics/claude-code-plugins/frontend-design

# UI 디자이너
npx claude-plugins install @ananddtyagi/claude-code-marketplace/ui-designer

# 복합 엔지니어링 (27 에이전트 + 20 커맨드 + 12 스킬)
npx claude-plugins install @EveryInc/every-marketplace/compound-engineering
```

<a id="2e8eda9b0fe180648149d1683ecd0b36"></a>

```bash
1단계: Marketplace 등록

# Anthropic 공식
/plugin marketplace add anthropics/skills

# Engineering Workflow (Git, 테스트, 코드리뷰)
/plugin marketplace add mhattingpete/claude-skills-marketplace

# Project Planning (기획 문서)
/plugin marketplace add adrianpuiu/claude-skills-marketplace

# Superpowers (TDD, 디버깅)
/plugin marketplace add obra/superpowers-marketplace


2단계: Skills 설치

# Document Skills (문서화 - docx, xlsx, pptx, pdf)
/plugin install document-skills@anthropic-agent-skills

# Example Skills (frontend-design, mcp-builder, internal-comms)
/plugin install example-skills@anthropic-agent-skills

# Engineering Workflow (feature-planning, git-push, fix-failing-tests)
/plugin install engineering-workflow-plugin@mhattingpete

# Visual Documentation (다이어그램, 아키텍처)
/plugin install visual-documentation-plugin@mhattingpete

# Project Planner (기능 기획)
/plugin install project-planner-skill@claude-skills-marketplace


3단계: 확인

/plugin
# → Installed 탭에서 설치된 Skills 확인
```

## 클로드 플러그인

---

[Create and distribute a plugin marketplace &#45; Claude Code Docs]()

> ✏️ 
> 
> <a id="2e7eda9b0fe180019b73f8eaad74a398"></a>
> 
> 사용자 생성 플러그인을 통해 설정한  <code>슬래시 명령어</code>, <code>에이전트</code>, <code>훅</code>, <code>스킬</code> 및 <code>MCP 서버</code>를 프로젝트에 빠르게 적용 가능하다&#46;
> 
> - 플러그인을 사용하면 프로젝트 및 팀 간에 공유할 수 있는 사용자 지정 기능을 추가하여 Claude Code 확장이 가능하다&#46;

### <strong>플러그인 구성 요소 참조</strong>

<details>
<summary>Commands</summary>

[Slash commands &#45; Claude Code Docs]()

> ✏️ 
> 
> <a id="2e7eda9b0fe1800cab6cedc854b4573c"></a>
> 
> 플러그인에 Claude Code의 명령 시스템과 완벽하게 통합되는 <strong><u>사용자 지정 슬래시 명령을 추가</u></strong>할 수 있다&#46; 

- <strong>위치</strong>&#58; <code>commands/</code>,  플러그인 루트 디렉토리

- 파일 형식&#58; 프론트매터가 포함된 마크다운 파일

</details>

<details>
<summary>Agents</summary>

[Slash commands &#45; Claude Code Docs]()

> ✏️ 
> 
> <a id="2e7eda9b0fe1809bb4d4c736208909d6"></a>
> 
> 플러그인에 <strong><u>특정 작업을 위한 전문화된 하위 에이전트를 추가</u></strong>할 수 있으며, 클로드는 필요에 따라 이러한<strong><u> 에이전트를 자동으로 호출 가능</u></strong>하다&#46;

- <strong>위치</strong>&#58; <strong><code>agents/</code></strong><strong>, </strong>플러그인 루트 디렉토리

- 파일 형식&#58; 이전트 기능을 설명하는 마크다운 파일

- ex)
    <a id="2e7eda9b0fe180b3a5f9fc3519caf258"></a>

    ```markdown
    ---
    description: Brief description of what the command does
    ---

    # Command Name

    Detailed instructions for Claude on how to execute this command.
    Include specific guidance on parameters, expected outcomes, and any special considerations.
    ```

</details>
