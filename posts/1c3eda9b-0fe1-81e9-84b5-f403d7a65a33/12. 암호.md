# 문제)

<a id="1c3eda9b0fe1815bb83ac2d6b15ae98b"></a>

## <strong>12&#46; 암호</strong>

<a id="1c3eda9b0fe1814897e3d78586d65a76"></a>

### 설명

<a id="1c3eda9b0fe1812c9e98cacd65880a21"></a>

현수는 영희에게 알파벳 대문자로 구성된 비밀편지를 매일 컴퓨터를 이용해 보냅니다&#46;

<a id="1c3eda9b0fe181a39df1cddc3838ef11"></a>

비밀편지는 현수와 영희가 서로 약속한 암호로 구성되어 있습니다&#46;

<a id="1c3eda9b0fe181bf8acae239472abf61"></a>

비밀편지는 알파벳 한 문자마다 &#35; 또는 &#42;이 일곱 개로 구성되어 있습니다&#46;

<a id="1c3eda9b0fe1810f9023c73396d0ce37"></a>

만약 현수가 “&#35;&#42;&#42;&#42;&#42;&#42;&#35;”으로 구성된 문자를 보냈다면 영희는 현수와 약속한 규칙대로 다음과 같이 해석합니다&#46;

<a id="1c3eda9b0fe1814191ffe47ffd15dc74"></a>

1&#46; “&#35;&#42;&#42;&#42;&#42;&#42;&#35;”를 일곱자리의 이진수로 바꿉니다&#46; &#35;은 이진수의 1로, &#42;이진수의 0으로 변환합니다&#46; 결과는 “1000001”로 변환됩니다&#46;

<a id="1c3eda9b0fe18131b0d1d419948765ed"></a>

2&#46; 바뀐 2진수를 10진수화 합니다&#46; “1000001”을 10진수화 하면 65가 됩니다&#46;

<a id="1c3eda9b0fe181b6b00fd656f2d9bd58"></a>

3&#46; 아스키 번호가 65문자로 변환합니다&#46; 즉 아스크번호 65는 대문자 &#39;A&#39;입니다&#46;

<a id="1c3eda9b0fe1811493c3e64b12c3a866"></a>

참고로 대문자들의 아스키 번호는 &#39;A&#39;는 65번, ‘B&#39;는 66번, ’C&#39;는 67번 등 차례대로 1씩 증가하여 ‘Z&#39;는 90번입니다&#46;

<a id="1c3eda9b0fe1815ea7ced03cf0706b0e"></a>

현수가 4개의 문자를 다음과 같이 신호로 보냈다면

<a id="1c3eda9b0fe181f1b34cc436d59a5f1a"></a>

&#35;&#42;&#42;&#42;&#42;&#35;&#35;&#35;&#42;&#42;&#35;&#35;&#35;&#35;&#35;&#42;&#42;&#35;&#35;&#35;&#35;&#35;&#42;&#42;&#35;&#35;&#42;&#42;

<a id="1c3eda9b0fe181d391edc65934f7ebb6"></a>

이 신호를 4개의 문자신호로 구분하면

<a id="1c3eda9b0fe18159a0afee8d4381783a"></a>

&#35;&#42;&#42;&#42;&#42;&#35;&#35; &#45;&#45;&#62; &#39;C&#39;

<a id="1c3eda9b0fe181e59d10c24bb523ab74"></a>

&#35;&#42;&#42;&#35;&#35;&#35;&#35; &#45;&#45;&#62; &#39;O&#39;

<a id="1c3eda9b0fe181d2ab13d8ba468a2ee4"></a>

&#35;&#42;&#42;&#35;&#35;&#35;&#35; &#45;&#45;&#62; &#39;O&#39;

<a id="1c3eda9b0fe181908025f1fa7fa89fdc"></a>

&#35;&#42;&#42;&#35;&#35;&#42;&#42; &#45;&#45;&#62; &#39;L&#39;

<a id="1c3eda9b0fe181baa7c4f631d0b663d1"></a>

최종적으로 “COOL&#34;로 해석됩니다&#46;

<a id="1c3eda9b0fe181039af4ed002ff428d2"></a>

현수가 보낸 신호를 해석해주는 프로그램을 작성해서 영희를 도와주세요&#46;

<a id="1c3eda9b0fe1812ebe0dc8dfe4a1b86d"></a>

### 입력

<a id="1c3eda9b0fe18116a7eee10d162209be"></a>

첫 줄에는 보낸 문자의 개수(10을 넘지 안습니다)가 입력된다&#46; 다음 줄에는 문자의 개수의 일곱 배 만큼의 &#35;또는 &#42; 신호가 입력됩니다&#46;

<a id="1c3eda9b0fe181b894eae8dabebaf1ea"></a>

현수는 항상 대문자로 해석할 수 있는 신호를 보낸다고 가정합니다&#46;

<a id="1c3eda9b0fe181609b52eb256e6c17b7"></a>

### 출력

<a id="1c3eda9b0fe1818cbdd5fc7a95408cb1"></a>

영희가 해석한 문자열을 출력합니다&#46;

---

<a id="1c3eda9b0fe18193bf26fa7b76789399"></a>

# 풀이)

<a id="1c3eda9b0fe18131970ce6a724a578fd"></a>

### 풀이1) 

<a id="1c3eda9b0fe18105a518f2d7ab378ce7"></a>

```java
import java.util.Scanner;

public class Main {
    // 1. 문자열 7개 별로 분리: s.substring(0,7),  s=s.substring(7)
    // 2. # -> 1, * -> 0 변환: .replace("#", "1").replace("*", "0")
    // 3. 이진수 -> 숫자 변환: Integer.parseInt(tmp, 2)
    // 4. 숫자(아스키번호) -> 알파벳 변환: (char)num;
    public String solution(int n, String s){
        String answer = "";
        for(int i=0; i<n; i++){
            String tmp = s.substring(0,7).replace("#", "1").replace("*", "0");
            int num = Integer.parseInt(tmp, 2);
            answer += (char)num;
            s=s.substring(7);

        }
        return answer;
    }
    public static void main(String[] args){
        Main m = new Main();
        Scanner sc=new Scanner(System.in);
        int n = sc.nextInt();
        String str = sc.next();
        System.out.print(m.solution(n, str));
    }
}
```
