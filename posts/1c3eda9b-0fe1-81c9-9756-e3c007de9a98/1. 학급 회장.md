# 문제

<a id="1c3eda9b0fe18117b9b8c4e47aca3659"></a>

## <strong>1&#46; 학급 회장(해쉬)</strong>

---

<a id="1c3eda9b0fe181458795ee8d54b67f7f"></a>

### 설명

<a id="1c3eda9b0fe1817283a8ee5fb12e8dd2"></a>

학급 회장을 뽑는데 후보로 기호 A, B, C, D, E 후보가 등록을 했습니다&#46;

<a id="1c3eda9b0fe1819990caf44beacace91"></a>

투표용지에는 반 학생들이 자기가 선택한 후보의 기호(알파벳)가 쓰여져 있으며 선생님은 그 기호를 발표하고 있습니다&#46;

<a id="1c3eda9b0fe181c9bb8ad67defa7059b"></a>

선생님의 발표가 끝난 후 어떤 기호의 후보가 학급 회장이 되었는지 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181e19556e986bb8e38a4"></a>

반드시 한 명의 학급회장이 선출되도록 투표결과가 나왔다고 가정합니다&#46;

<a id="1c3eda9b0fe181199ab0e8d057090f41"></a>

### 입력

<a id="1c3eda9b0fe1812090abc36c90615449"></a>

첫 줄에는 반 학생수 N(5&#60;=N&#60;=50)이 주어집니다&#46;

<a id="1c3eda9b0fe181a9a141c65532877c30"></a>

두 번째 줄에 N개의 투표용지에 쓰여져 있던 각 후보의 기호가 선생님이 발표한 순서대로 문자열로 입력됩니다&#46;

<a id="1c3eda9b0fe181aebe15d42580df96c2"></a>

### 출력

<a id="1c3eda9b0fe1815a8a68d0e5e7feceef"></a>

학급 회장으로 선택된 기호를 출력합니다&#46;

---

<a id="1c3eda9b0fe1819aae77dda425935e1c"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1817da6a7c2d3bbe6666b"></a>

```plaintext
15
BACBACCACCBDEDE
```

### 예시 출력 1

# 풀이

<a id="1c3eda9b0fe181ef8405d6fb89e362f9"></a>

## 풀이1) HashMap&#46;<code>getOrDefault(value, default)</code>

<a id="1c3eda9b0fe1819bb764d520dfb1c3f0"></a>

```java
import java.util.*;
public class Main {
    public char solution(int n, String str){
        char answer=' ';
        HashMap<Character, Integer> map = new HashMap<>();
        for(char x: str.toCharArray()){
            map.put(x, map.getOrDefault(x, 0)+1);
        }
        int max=0;
        for( char key: map.keySet()){
            int num=map.get(key);
            if(num>max){
                max=num;
                answer=key;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        String str= sc.next();
        System.out.print(T.solution(n, str));
    }
}
```
