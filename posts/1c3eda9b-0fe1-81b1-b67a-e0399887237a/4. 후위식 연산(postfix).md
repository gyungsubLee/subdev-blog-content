# 문제

<a id="1c3eda9b0fe181eb9915f2880266f3ab"></a>

## <strong>4&#46; 후위식 연산(postfix)</strong>

---

<a id="1c3eda9b0fe1811bb586cbb92ac62bcc"></a>

### 설명

<a id="1c3eda9b0fe181bb8754eebace21001f"></a>

후위연산식이 주어지면 연산한 결과를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1818ba0e4c43c94710426"></a>

만약 3&#42;(5&#43;2)&#45;9 을 후위연산식으로 표현하면 352&#43;&#42;9&#45; 로 표현되며 그 결과는 12입니다&#46;

<a id="1c3eda9b0fe181289512e74818d40625"></a>

### 입력

<a id="1c3eda9b0fe1818c82abe98ce0fb0a3e"></a>

첫 줄에 후위연산식이 주어집니다&#46; 연산식의 길이는 50을 넘지 않습니다&#46;

<a id="1c3eda9b0fe181d7a24bd9a66e972e40"></a>

식은 1&#126;9의 숫자와 &#43;, &#45;, &#42;, / 연산자로만 이루어진다&#46;

<a id="1c3eda9b0fe181c38e28cc179ed6a2da"></a>

### 출력

<a id="1c3eda9b0fe181c990b1c741ec0ad84c"></a>

연산한 결과를 출력합니다&#46;

---

<a id="1c3eda9b0fe1816b8e4dd3980f9482e9"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181ab8080d2ecf3cfa523"></a>

```plaintext
352+*9-

```

<a id="1c3eda9b0fe18181822ccb9349f78418"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181b49621e861940c010e"></a>

12
```

function int microCalculator(int num1, int num2, String operator) {
  if(operator === '+') {
    return num1 + num2;
  } else if(operator === '-') {
    return num1 - num2;
  } else if(operator === '*') {
    return num1 * num2;
  } else if(operator === '/') {
    return num1 / num2;
  }
}
```

import java.util.*;
public class Main {
    public int microCalculator(int num1, int num2, char operator) {
        if(operator == '+')  return num1 + num2;
        else if(operator == '-')  return num1 - num2;
        else if(operator == '*')  return num1 * num2;
        else return num1 / num2;
    }

    public int  solution(String str){
        Stack<Integer> stack = new Stack<>();
        for(char x : str.toCharArray()){
            if(x<58 && x>48) stack.push(x-48);
            else {
                int num2 = stack.pop();
                int num1 = stack.pop();
                int sum = microCalculator(num1, num2, x);
                stack.push(sum);
            }
        }
        int answer=stack.pop();
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.next();
        System.out.println(T.solution(str));
    }
}
```

import java.util.*;
public class Main {
    public int  solution(String str){
        Stack<Integer> stack = new Stack<>();
        for(char x : str.toCharArray()){
            if(Character.isDigit(x)) stack.push(x-48);
            else {
                int rt = stack.pop();
                int lt = stack.pop();
                if(x=='+') stack.push(lt+rt);
                else if(x=='-') stack.push(lt-rt);
                else if(x=='*') stack.push(lt*rt);
                else stack.push(lt/rt);
            }
        }
        return stack.get(0);
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.next();
        System.out.println(T.solution(str));
    }
}
```
