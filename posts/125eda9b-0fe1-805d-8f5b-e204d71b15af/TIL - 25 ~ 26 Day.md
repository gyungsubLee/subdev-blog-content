- 과제 &#45; 숫자 야구 게임
    > <a href="#/post/126eda9b-0fe1-8018-bac8-f61d440b8857">페이지</a> 

    <details>
    <summary>IntelliJ 로 빌드 시, 생성되는 XML 파일(<code>&#46;iml</code>)의 의미</summary>

    - <code>&#46;iml</code> 파일은 인텔리제이 모듈의 메타데이터를 저장하는 역할을 함
        - 소스 폴더 경로

        - 빌드 결과물 제외 경로

        - 의존성 설정 (JDK, 라이브러리 등)

        - 모듈의 타입 (Java, Web, Android 등)

    - <strong>직접적으로 수정할 필요가 거의 없으며</strong>, IntelliJ가 자동으로 관리함

    - 프로젝트를 열거나 빌드할 때 IntelliJ는 이 파일을 참고해 모듈의 빌드 경로나 소스 폴더 구조 등을 이해하고 처리함

    <details>
    <summary>&#91; XML &#93;<code> 프로젝트명&#46;iml</code></summary>

    <a id="126eda9b0fe180c9bc9de406c5a5c3de"></a>

    ```java
    <?xml version="1.0" encoding="UTF-8"?>
    <module type="JAVA_MODULE" version="4">
      <component name="NewModuleRootManager" inherit-compiler-output="true">
        <exclude-output />
        <content url="file://$MODULE_DIR$">
          <sourceFolder url="file://$MODULE_DIR$/src" isTestSource="false" />
        </content>
        <orderEntry type="inheritedJdk" />
        <orderEntry type="sourceFolder" forTests="false" />
      </component>
    </module>
    ```

    <details>
    <summary><code>&#60;module&#62;</code>&#58; 모듈 시작을 알리는 태그</summary>

    - 모듈의 타입&#58; <code>type = JAVA&#95;MODUL</code>

    -  해당 모듈이 자바 프로젝트로 설정되어 있다는 뜻

    </details>

    <details>
    <summary><code>&#60;component&#62;</code></summary>

    - IntelliJ의 모듈 컴포넌트를 정의하는 곳

    - 이 안에 모듈이 어떤 구조로 되어 있는지, 컴파일러와 관련된 설정 등이 들어감

    </details>

    <details>
    <summary><code>&#60;exclude&#45;output /&#62;</code></summary>

    - 컴파일 결과물이 모듈의 소스 코드와 분리되도록 하는 설정

    -  즉, 빌드 시 생성되는 파일(예&#58; &#46;class 파일)이 소스 폴더에 포함되지 않도록 설정하는 역할

    </details>

    <details>
    <summary><code>&#60;content&#62;</code> </summary>

    - 해당 모듈의 소스 폴더 경로를 저장

    - <code>url=&#34;file&#58;//&#36;MODULE&#95;DIR&#36;/src&#34;</code>
        - 이 모듈의 소스 폴더가 src 디렉토리에 있다는 것을 의미

    </details>

    <details>
    <summary><code>&#60;sourceFolder&#62;</code><strong><code> </code></strong></summary>

    - 모듈의 실제 소스 코드가 위치한 디렉토리 나타냄

    -  src 디렉토리가 소스 폴더로 설정되어 있음
        - <code>file&#58;//&#36;MODULE&#95;DIR&#36;/src</code>

    </details>

    <details>
    <summary><code>&#60;orderEntry&#62;</code></summary>

    - 모듈이 의존하는 JDK나 외부 라이브러리 등의 정보를 정의함

    - <code> type=&#34;inheritedJdk”</code>
        -  모듈이 상위 프로젝트에서 설정된 JDK를 상속받는 것을 뜻

    </details>

    </details>

    </details>
