## <strong> Server&#45;Sent Events (SSE)</strong>

---

> 📖 
> 
> <a id="212eda9b0fe180ae8628ffda15285204"></a>
> 
> <strong><code>SSE ( Server&#45;Sent Events )</code></strong>는 <u>서버가 </u><strong><u>HTTP 연결을 유지</u></strong>하면서 <strong><u>클라이언트에게 실시간으로 데이터를 push</u></strong>할 수 있는 기술이다&#46;
> 
> - HTTP/1&#46;1 기반 단방향 통신 (서버 → 클라이언트)
> 
> - <code>Content&#45;Type&#58; </code><strong><code>text/event&#45;stream</code></strong> 사용
> 
> - 클라이언트는 <strong><code>EventSource API</code></strong>로 구독

    <a id="28beda9b0fe180d9a9f8f9204e7f59b1"></a>

    ```java
    // 	SSE 엔드포인트 정의
    @GetMapping(produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    ```

    - <code>Flux&#60;T&#62;</code>,  <code>Mono&#60;T&#62;</code> 를 통해 HTTP 스트림 응답 제공

    - 내결합성 및 백프레셔(backpressure) 설계

- <strong>Spring Data Redis의 리액티브 Pub/Sub</strong>
    <a id="28beda9b0fe1808f8f90e42afbe3924b"></a>

    ```java
    // 메시지 발행
    ReactiveRedisOperations.convertAndSend(...)

    // 지원
    ReactiveRedisConnectionFactory
    		.getReactiveConnection()
    		.pubSubCommands()
    		.publish(...)
    		
    // 채널 구독
    ReactiveRedisOperations

    ```

<details>
<summary><strong>ex) Spring WebFlux  SSE</strong></summary>

- <strong>아키텍처 요약</strong>
    <a id="212eda9b0fe180638337cd5b81a8db31"></a>

    ```java
              [브라우저]
                 │
                 ▼
     EventSource('/sse/subscribe')
                 │
                 ▼
     ┌──────────────────────────────┐
     │       Spring WebFlux         │
     │  @GetMapping + Flux<String>  │
     │ produces = text/event-stream │
     └──────────────────────────────┘
                 │
                 ▼
         메시지 발생 (Flux emit)
     
              ↙          ↘
        Redis Pub/Sub   Kafka
    ```

    1. 클라이언트는 <code>/see/subscribe</code>  엔드포인트로 연결

    1. 서버는 Flux를 통해 메세지를 지속적으로 push

    1. 메세지 소스는 내부 <code>Queue</code>, <code>Redis</code>, <code>Kafka</code> 등 다양

- <strong>Controller</strong>
    <a id="213eda9b0fe180aeb600f7cd4c5b675b"></a>

    ```java
    @GetMapping(value = "/sse/subscribe", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<String> subscribe() {
        return Flux.interval(Duration.ofSeconds(1))
               .map(seq -> "data: 현재 시간 = " + LocalDateTime.now() + "\n\n");
    }
    ```

    - <code>TEXT&#95;EVENT&#95;STREAM&#95;VALUE</code>&#58; text/event&#45;stream MIME 타입

    - <code>Flux&#46;interval(Duration&#46;ofSeconds(1))</code>&#58; 1초마다 메세지를 push

- <strong>클라이언트(JS)</strong>
    <a id="213eda9b0fe180cb879ffcc9d0facaaa"></a>

    ```javascript
    <script>
    	const eventSource = new EventSource("/see/subscribe");
    	
    	eventSource.onmessage = (e) => {
    		console.log("수신된 메세지: ", e.data);
    	};
    	
    	eventSource.onerror = (e) => {
    		console.error("SSE 오류: ", e);
    	};
    <script>
    ```

<details>
<summary>ex2) <strong>Spring WebFlux &#43; 리액티브 Redis 기반의 실시간 SSE 채팅 시스템</strong></summary>

- <strong>아키텍처 요약</strong>
    <a id="213eda9b0fe180188553cf926194cb5d"></a>

    ```javascript
    [클라이언트 브라우저]
         │                       ▲
         │ SSE 구독               │ 채팅 메시지 전송 (POST)
         ▼                       │
    [ WebFlux Controller ] ←─────┘
         │
         ▼
    [ Redis (Pub/Sub) ]
         ▲
         │
    [ ReactiveRedisSubscriber (Flux sink → emit) ]  // 서버 동기화 
    ```

    > ✏️ 
    > 
    > <a id="213eda9b0fe180839325d0ffb376b4b0"></a>
    > 
    >  클러스터 환경 동기화를 위한 <code>Redis pub/sub</code> 추가

- <strong>의존성 설정 ( Gradle ) </strong>
    <a id="213eda9b0fe18010a3bfffb699244ad8"></a>

    ```groovy
    dependencies {
        implementation 'org.springframework.boot:spring-boot-starter-webflux'
        implementation 'org.springframework.boot:spring-boot-starter-data-redis'
    }
    ```

    - <a href="https://mvnrepository.com/artifact/org.springframework.boot/spring-boot-starter-data-redis"><code>spring&#45;boot&#45;starter&#45;data&#45;redis</code></a>&#58; 리액티브 Redis API 포함 ( ReactiveTemplate )

    - <code>spring&#45;boot&#45;starter&#45;webflux</code>&#58; Flux, Mono, SEE 기반 비동기 스트리밍 제공

- <strong>Redis 설정</strong>
    <a id="213eda9b0fe180e28e12f2054bddc76d"></a>

    ```java
    @Configuration
    public class RedisConfig {

        @Bean
        public ReactiveRedisTemplate<String, String> reactiveRedisTemplate(ReactiveRedisConnectionFactory factory) {
            RedisSerializationContext<String, String> context = RedisSerializationContext
                    .<String, String>newSerializationContext(RedisSerializer.string())
                    .value(RedisSerializer.string())
                    .build();
            return new ReactiveRedisTemplate<>(factory, context);
        }
    }
    ```

- Redis 채팅 서비스
    <a id="213eda9b0fe18042bf88c85924ad834e"></a>

    ```java
    @Service
    @RequiredConstructor
    public class ChatService {

    		private final ReactiveRedisTemplate<String, String> redisTemplate;
    		private final Sink.Many<String> sink = Sink.many().multicast().onBackpressureBuffer();
    		
    		public Mono<Long> sendMessage(String roomId, String message) {
    				return redisTemplate.convertAndSend("chatroom:" + roomId, message); 				
    		}
    		
    		public Flux<String> subscribe(String roomId) {
    				return redisTemplate.listenToChannel("chatroom:" + roomId)		
    		}
    }
    ```

- <strong>WebFlux Controller</strong>
    <a id="213eda9b0fe1808bb7fbd9fe8566f424"></a>

    ```java
    @RestController
    @RequiredArgsConstructor
    @RequestMapping("/chat")
    public class ChatController {

        private final ChatService chatService;

        @PostMapping("/{roomId}")
        public Mono<Long> sendMessage(@PathVariable String roomId, @RequestBody String message) {
            return chatService.sendMessage(roomId, message);
        }

        @GetMapping(value = "/subscribe/{roomId}", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
        public Flux<String> subscribe(@PathVariable String roomId) {
            return chatService.subscribe(roomId);
        }
    }
    ```
