> 📌 스프링 컨테이너에 실제 스프링 빈들이 잘 등록되었는지 확인

<a id="1c3eda9b0fe1815db531de3644c37991"></a>

### <strong>스프링에 등록된 모든 빈 출력</strong>

> <strong>•</strong> <code>ac&#46;getBeanDefinitionNames()</code>&#58;스프링에 등록된 모든 빈 이름 조회<code><br></code><strong>• </strong><code>ac&#46;getBean()</code>&#58; 빈 이름 →빈 객체(인스턴스) 조회

<a id="1c3eda9b0fe18191b775fc21325aef65"></a>

### <strong>애플리케이션 빈 출력</strong><br> <code>getRole()</code>, 스프링 빈 구분 가능

> <strong>•</strong> <code>ROLE&#95;APPLICATION</code> &#58; 일반적으로 사용자가 정의한 빈<br><strong>•</strong> <code>ROLE&#95;INFRASTRUCTURE</code> &#58; 스프링이 내부에서 사용하는 빈

<a id="1c3eda9b0fe181c18136cc49d368a9eb"></a>

### <strong>ApplicationContextInfoTest</strong>

<a id="1c3eda9b0fe181dfa102d1ecae6ed960"></a>

```java
package hello.core.beanfind;

import hello.core.AppConfig;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.config.BeanDefinition;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;

public class ApplicationContextInfoTest {
    AnnotationConfigApplicationContext ac = new AnnotationConfigApplicationContext(AppConfig.class);

    @DisplayName("모든 빈 출력하기")
    @Test
    void findAllBean() {
        String[] beanDefinitionNames = ac.getBeanDefinitionNames();
        for (String beanDefinitionName : beanDefinitionNames) {
            Object bean = ac.getBean(beanDefinitionName);
            System.out.println("name = " + beanDefinitionName + " objcet= "+ bean);
        }
    }


    @DisplayName("애플리케이션 빈 출력하기")
    @Test
    void findApplicationBean() {
        String[] beanDefinitionNames = ac.getBeanDefinitionNames();
        for (String beanDefinitionName : beanDefinitionNames) {
            BeanDefinition beanDefinition = ac.getBeanDefinition(beanDefinitionName);

            // Role ROLE_APPLICATION: 직접 등록한 애플리케이션 빈
            // Role ROLE_INFRASTRUCUTURE
            if(beanDefinition.getRole() == BeanDefinition.ROLE_INFRASTRUCTURE) {
                Object bean = ac.getBean(beanDefinitionName);
                System.out.println("name = " + beanDefinitionName + " objcet= " + bean);
            }
        }
    }
    
}
```
