<a id="160eda9b0fe1805e9520c0fa47baeaf7"></a>

Write a solution to&#58;

- Find the name of the user who has rated the greatest number of movies&#46; In case of a tie, return the lexicographically smaller user name&#46;

- Find the movie name with the <strong>highest average</strong> rating in <code>February 2020</code>&#46; In case of a tie, return the lexicographically smaller movie name&#46;

<a id="160eda9b0fe1804aa25bc934bca9fb25"></a>

The result format is in the following example&#46;

## 풀이

<a id="160eda9b0fe1805f8d34faa199193cb8"></a>

### 조건 

1. <strong>가장 많은 영화에 평점을 준 사용자 찾기</strong>
    - 각 사용자가 평점을 준 영화의 개수를 센다&#46;

    - 개수를 기준으로 내림차순 정렬한다&#46;

    - 만약 동률인 경우, 사용자의 이름을 사전순(알파벳순)으로 정렬한다&#46;

1. <strong>2020년 2월에 평균 평점이 가장 높은 영화 찾기</strong>
    - <code>MovieRating</code> 테이블에서 2020년 2월에 작성된 평점 데이터를 필터링한다&#46;

    - 각 영화의 평균 평점을 계산한다&#46;

    - 평균 평점을 기준으로 내림차순 정렬한다&#46;

    - 동률인 경우, 영화 제목을 사전순으로 정렬한다&#46;

1. <strong>결과를 요구된 형식으로 출력</strong>
    - 두 결과를 하나로 결합한다&#46;

### 풀이 1 

<details>
<summary>Input</summary>

<a id="160eda9b0fe18037b895c7d410a56663"></a>

```sql
Movies =
| movie_id | title    |
| -------- | -------- |
| 1        | Avengers |
| 2        | Frozen 2 |
| 3        | Joker    |

Users =
| user_id | name   |
| ------- | ------ |
| 1       | Daniel |
| 2       | Monica |
| 3       | Maria  |
| 4       | James  |

MovieRating =
| movie_id | user_id | rating | created_at |
| -------- | ------- | ------ | ---------- |
| 1        | 1       | 3      | 2020-01-12 |
| 1        | 2       | 4      | 2020-02-11 |
| 1        | 3       | 2      | 2020-02-12 |
| 1        | 4       | 1      | 2020-01-01 |
| 2        | 1       | 5      | 2020-02-17 |
| 2        | 2       | 2      | 2020-02-01 |
| 2        | 3       | 2      | 2020-03-01 |
| 3        | 1       | 3      | 2020-02-22 |
| 3        | 2       | 4      | 2020-02-25 |
```

</details>

<details>
<summary>Output</summary>

<a id="160eda9b0fe1806985c7d5fbe7473013"></a>

```sql
| results  |
| -------- |
| Daniel   |
| Frozen 2 |
```

- <strong>Expected</strong>
    <a id="160eda9b0fe180a3a522efa484c4a945"></a>

    ```sql
    | results  |
    | -------- |
    | Daniel   |
    | Frozen 2 |
    ```

</details>

<a id="160eda9b0fe18016a0eceab7964dfe6b"></a>

```sql
-- Step 1: 가장 많은 평점을 준 사용자 찾기
WITH UserRatings AS (
    SELECT 
        u.name AS user_name,
        COUNT(mr.movie_id) AS rating_count
    FROM 
        Users u
    JOIN 
        MovieRating mr
    ON 
        u.user_id = mr.user_id
    GROUP BY 
        u.name
    ORDER BY 
        rating_count DESC, user_name ASC
    LIMIT 1
),

-- Step 2: 2020년 2월에 평균 평점이 가장 높은 영화 찾기
MovieAverageRatings AS (
    SELECT 
        m.title AS movie_title,
        AVG(mr.rating) AS average_rating
    FROM 
        Movies m
    JOIN 
        MovieRating mr
    ON 
        m.movie_id = mr.movie_id
    WHERE 
        mr.created_at BETWEEN '2020-02-01' AND '2020-02-29'
    GROUP BY 
        m.title
    ORDER BY 
        average_rating DESC, movie_title ASC
    LIMIT 1
)

-- Step 3: 결과 합치기
SELECT 
    user_name AS results
FROM 
    UserRatings
UNION ALL
SELECT 
    movie_title AS results
FROM 
    MovieAverageRatings;
```

### 풀이 2

<a id="160eda9b0fe180a7870bf61add219453"></a>

```sql
-- 1. 가장 많은 평점을 준 사용자 찾기
(SELECT name AS results
FROM MovieRating JOIN Users USING(user_id)
GROUP BY name
ORDER BY COUNT(*) DESC, name
LIMIT 1)

UNION ALL --결과 합침

-- 2. 2020년 2월에 평균 평점이 가장 높은 영화 찾기
(SELECT title AS results
FROM MovieRating JOIN Movies USING(movie_id)
WHERE EXTRACT(YEAR_MONTH FROM created_at) = 202002
GROUP BY title
ORDER BY AVG(rating) DESC, title
LIMIT 1);
```
