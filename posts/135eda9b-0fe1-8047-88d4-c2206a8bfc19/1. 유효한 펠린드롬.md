## 문제

<a id="135eda9b0fe180d79381fb5acb9f1c5d"></a>

# <strong><a href="https://leetcode.com/problems/valid-palindrome/">125&#46; Valid Palindrome</a></strong>

<a id="135eda9b0fe18030a07fe637442cb728"></a>

A phrase is a <strong>palindrome</strong> if, after converting all uppercase letters into lowercase letters and removing all non&#45;alphanumeric characters, it reads the same forward and backward&#46; Alphanumeric characters include letters and numbers&#46;

<a id="135eda9b0fe18068b331e62a185cebd6"></a>

Given a string <code>s</code>, return <code>true</code><em> if it is a </em><em><strong>palindrome</strong></em><em>, or </em><code>false</code><em> otherwise</em>&#46;

<a id="135eda9b0fe1801da147ea8a393e6625"></a>

<strong>Example 1&#58;</strong>

<a id="135eda9b0fe180c1a6cdd5ea1867333c"></a>

```plaintext
Input: s = "A man, a plan, a canal: Panama"
Output: true
Explanation: "amanaplanacanalpanama" is a palindrome.

```

<a id="135eda9b0fe180bbb2dbe479955996f4"></a>

<strong>Example 2&#58;</strong>

<a id="135eda9b0fe1808dbd4fc3ddc9375fc2"></a>

```plaintext
Input: s = "race a car"
Output: false
Explanation: "raceacar" is not a palindrome.

```

<a id="135eda9b0fe180278a4de34227049a70"></a>

<strong>Example 3&#58;</strong>

<a id="135eda9b0fe1808daa65d3438c3d684c"></a>

```plaintext
Input: s = " "
Output: true
Explanation: s is an empty string "" after removing non-alphanumeric characters.
Since an empty string reads the same forward and backward, it is a palindrome.

```

<a id="135eda9b0fe180c688f4e904d2cd741e"></a>

<strong>Constraints&#58;</strong>

- <code>1 &#60;= s&#46;length &#60;= 2 &#42; 105</code>

- <code>s</code> consists only of printable ASCII characters&#46;

<a id="135eda9b0fe181eea4a8e852904506f2"></a>

## 풀이

<a id="135eda9b0fe18060a53dff0245a67cae"></a>

### 풀이 1  &#45;  내 풀이, 정규식, 투포인터

- 문자열 포맷
    - <code>“&#91;^A&#45;Za&#45;z0&#45;9&#93;&#34;</code>&#58; 영문자, 숫자가 아닌 문자열 

    - <code>&#46;replaceAll(조건, 변환될 문자)</code>&#58; 조건에 맞는 문자들을 변환 문자로 모두 변경함

    <a id="135eda9b0fe18059be29da7c600ed06b"></a>

    ```java
    String str = s.replaceAll("[^A-Za-z]", "").toLowerCase();
    ```

<a id="135eda9b0fe180ea84d8dd11d6a542b7"></a>

```java
class Solution {
    public boolean isPalindrome(String s) {
        String str = s.replaceAll("[^A-Za-z0-9]", "").toLowerCase();
        
        int l =0, r=str.length()-1;
        while(l<r){
            if(str.charAt(l) != str.charAt(r)) return false;
            l++;
            r--;
        }

        return true;
    }
}
```

### 풀이 2 &#45;<code> isLetterOrDigit()</code>, <code>toLowerCase()</code>, 투포인터

- <code>isLetterOrDigit()</code> 으로 문자, 숫자 판별

- <code>toLowerCase()</code>

<a id="135eda9b0fe18063bbe5ea64b0ad47cb"></a>

```java

class Solution {
    public boolean isPalindrome(String s) {
        int start = 0;
        int end = s.length() - 1;

        while( start < end ){
            if( !Character.isLetterOrDigit(s.charAt(start)) ) start++;
            else if( !Character.isLetterOrDigit(s.charAt(end)) ) end--;
            else {
                if ( Character.toLowerCase(s.charAt(start)) != Character.toLowerCase(s.charAt(end))) return false;
                start++;
                end--;
            }
        } 

        return true;
    }
}
```

<a id="135eda9b0fe1802ba5a1ec2292b70de4"></a>

### 풀이 3 &#45; <code>정규식</code>,  <code>StringBuilder</code> &#43; <code>reverse()</code>

- <code>StringBuilder</code>를 사용하여 문자열을 뒤집은 값을 생성하고<br><code>equals()</code> 로 비교 후 <code>true</code>, <code>false</code> 판별

<a id="135eda9b0fe1801cb1f6d410356e9c2a"></a>

```java
class Solution {
    public boolean isPalindrome(String s) {
        String s_filtered = s.replaceAll("[^A-Za-z0-9]", "").toLowerCase();
        
        String s_reversed = new StringBuilder(s_filtered).reverse().toString();

        return str.equals(s_reversed);
    }
}
```

### 풀이 4 &#45; 코틀린

>  혹시 모르니 코틀린 풀이도 정리함

<a id="135eda9b0fe1804e93b3f67242f0791f"></a>

자바 랑 비슷하면서도 문법이 간소하다&#46;

- 문자열 List 처럼 바로 indexing 가능

- 끝에 <code>;</code> 안씀

- 화살표 함수

- when 절 → <code>if</code>, <code>else if</code> 를 명시하지 않아도 분기를 나눌 수 있음

<a id="135eda9b0fe1805e98d9ee0743dbd263"></a>

```java
class Solution {
    fun isPalindrome(s: String): Boolean {
        var start = 0
        var end = s.length - 1
        while (start < end) {
            when {
                !Character.isLetterOrDigit(s[start]) -> start++
                !Character.isLetterOrDigit(s[end]) -> end--
                else -> {
                    if(Character.toLowerCase(s[start]) != Character.toLowerCase(s[end])) {
                         return false
                    }
                    start++
                    end--
                }
            }
        }
        return true
    }
}
```
