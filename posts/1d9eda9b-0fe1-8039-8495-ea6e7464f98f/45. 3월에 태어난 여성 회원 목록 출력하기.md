## 문제

<a id="1d9eda9b0fe1805a9c69c43513d1591c"></a>

### <strong>문제 설명</strong>

<a id="1d9eda9b0fe18037af39f07f30b73814"></a>

다음은 식당 리뷰 사이트의 회원 정보를 담은 <code>MEMBER&#95;PROFILE</code> 테이블입니다&#46; <code>MEMBER&#95;PROFILE</code> 테이블은 다음과 같으며 <code>MEMBER&#95;ID</code>, <code>MEMBER&#95;NAME</code>, <code>TLNO</code>, <code>GENDER</code>, <code>DATE&#95;OF&#95;BIRTH</code>는 회원 ID, 회원 이름, 회원 연락처, 성별, 생년월일을 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| MEMBER&#95;ID | VARCHAR(100) | FALSE |
| MEMBER&#95;NAME | VARCHAR(50) | FALSE |
| TLNO | VARCHAR(50) | TRUE |
| GENDER | VARCHAR(1) | TRUE |
| DATE&#95;OF&#95;BIRTH | DATE | TRUE |

---

<a id="1d9eda9b0fe1805eb31cf84e296bc1ec"></a>

### 문제

<a id="1d9eda9b0fe1802dbb28e9b089bab448"></a>

<code>MEMBER&#95;PROFILE</code> 테이블에서 생일이 3월인 여성 회원의 ID, 이름, 성별, 생년월일을 조회하는 SQL문을 작성해주세요&#46; 이때 전화번호가 NULL인 경우는 출력대상에서 제외시켜 주시고, 결과는 회원ID를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="1d9eda9b0fe18029a1bbe0d3ec760e83"></a>

<a id="1d9eda9b0fe18039b761dace0fb7b9e5"></a>

<code>MEMBER&#95;PROFILE</code> 테이블이 다음과 같을 때

SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

|  |  |  |  |
| --- | --- | --- | --- |
| MEMBER&#95;ID | MEMBER&#95;NAME | GENDER | DATE&#95;OF&#95;BIRTH |

### 주의사항

<a id="1d9eda9b0fe180108bfde4228c43fd55"></a>

<code>DATE&#95;OF&#95;BIRTH</code>의 데이트 포맷이 예시와 동일해야 정답처리 됩니다

<a id="1d9eda9b0fe180098111f73d3b1e9350"></a>

## 풀이

> ✏️ 
> 
> <a id="1d9eda9b0fe180479f0fed75927c24d6"></a>
> 
> 조건
> 
> - 생일이 3월인 여성 회원의 ID, 이름, 성별, 생년월일을 조회
> 
> -  전화번호가 NULL인 경우는 출력대상에서 제외
> 
> - 결과는 회원ID를 기준으로 오름차순 정렬<br>

<a id="1d9eda9b0fe1808d846fc1988dffe2f5"></a>

### 풀이 1) <code>LIKE</code>

<a id="1d9eda9b0fe180a18e2af740ee65751f"></a>

```sql
SELECT 
    MEMBER_ID, 
    MEMBER_NAME,
    GENDER, 
    DATE_FORMAT(DATE_OF_BIRTH, '%Y-%m-%d') AS DATE_OF_BIRTH
FROM MEMBER_PROFILE
WHERE 
    GENDER = 'W'
    AND DATE_OF_BIRTH LIKE '%-03-%'
    AND TLNO IS NOT NULL
ORDER BY MEMBER_ID;
```

<a id="1d9eda9b0fe180cc9e58f712dc4f7d77"></a>

### 풀이 2) <code>MONTH()</code>

<a id="1d9eda9b0fe18052aac0c1006cfd14ee"></a>

```sql
SELECT 
    MEMBER_ID, 
    MEMBER_NAME,
    GENDER, 
    DATE_FORMAT(DATE_OF_BIRTH, '%Y-%m-%d') AS DATE_OF_BIRTH
FROM MEMBER_PROFILE
WHERE 
    GENDER = 'W'
    AND MONTH(DATE_OF_BIRTH) = 3
    AND TLNO IS NOT NULL
ORDER BY MEMBER_ID;
```
