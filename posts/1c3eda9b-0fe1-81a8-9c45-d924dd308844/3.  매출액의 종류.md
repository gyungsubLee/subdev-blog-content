# 문제

<a id="1c3eda9b0fe181fabe77ce801ffd5216"></a>

## <strong>3&#46; 매출액의 종류</strong>

---

<a id="1c3eda9b0fe181b0a771f82e8d155901"></a>

### 설명

<a id="1c3eda9b0fe181eeb1a9eae3c734be63"></a>

현수의 아빠는 제과점을 운영합니다&#46; 현수아빠는 현수에게 N일 동안의 매출기록을 주고 연속된 K일 동안의 매출액의 종류를

<a id="1c3eda9b0fe181a9a1ccdd073c8c30aa"></a>

각 구간별로 구하라고 했습니다&#46;

<a id="1c3eda9b0fe181a1a61bc3e3bca42161"></a>

만약 N=7이고 7일 간의 매출기록이 아래와 같고, 이때 K=4이면

<a id="1c3eda9b0fe181b89197fbd77fdaaa57"></a>

20 12 20 10 23 17 10

<a id="1c3eda9b0fe1811fb12ff51ea940f0d6"></a>

각 연속 4일간의 구간의 매출종류는

<a id="1c3eda9b0fe181908a75d2b4936b6140"></a>

첫 번째 구간은 &#91;20, 12, 20, 10&#93;는 매출액의 종류가 20, 12, 10으로 3이다&#46;

<a id="1c3eda9b0fe1815a9f30e79d4564eb90"></a>

두 번째 구간은 &#91;12, 20, 10, 23&#93;는 매출액의 종류가 4이다&#46;

<a id="1c3eda9b0fe181f2b6cac8517dba3094"></a>

세 번째 구간은 &#91;20, 10, 23, 17&#93;는 매출액의 종류가 4이다&#46;

<a id="1c3eda9b0fe1812789d5ed124f11ef0a"></a>

네 번째 구간은 &#91;10, 23, 17, 10&#93;는 매출액의 종류가 3이다&#46;

<a id="1c3eda9b0fe181188d99ee06555918b8"></a>

N일간의 매출기록과 연속구간의 길이 K가 주어지면 첫 번째 구간부터 각 구간별

<a id="1c3eda9b0fe18111a9f9eb620039243b"></a>

매출액의 종류를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1811caa2cc863093bb25f"></a>

### 입력

<a id="1c3eda9b0fe181c7897ddbbe1ad676e8"></a>

첫 줄에 N(5&#60;=N&#60;=100,000)과 K(2&#60;=K&#60;=N)가 주어집니다&#46;

<a id="1c3eda9b0fe181f8bca3d30aa1a84435"></a>

두 번째 줄에 N개의 숫자열이 주어집니다&#46; 각 숫자는 500이하의 음이 아닌 정수입니다&#46;

<a id="1c3eda9b0fe181f78873dcc26ef2951d"></a>

### 출력

<a id="1c3eda9b0fe181bcbcdcd429960bf1de"></a>

첫 줄에 각 구간의 매출액 종류를 순서대로 출력합니다&#46;

---

<a id="1c3eda9b0fe181c3a974d7a0393bb09b"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1814b89b8e40c9a517510"></a>

```plaintext
7 4
20 12 20 10 23 17 10
```

<a id="1c3eda9b0fe1814da189ee7b20c64d3b"></a>

### 해결) 슬라이싱 윈도우 &#91;O(n^2) → O(n)&#93;

<a id="1c3eda9b0fe181e0810dd6e2784754e6"></a>

```java
import java.util.*;
public class Main {
    public ArrayList<Integer>  solution(int n, int k, int[] arr){
        ArrayList<Integer> answer =new ArrayList<>();
        HashMap<Integer, Integer> map=new HashMap<>();
        for(int i=0; i<k; i++){
            map.put(arr[i], map.getOrDefault(arr[i], 0)+1);
        }
        answer.add(map.size());

        for(int i=k; i<n; i++){
            map.put(arr[i], map.getOrDefault(arr[i], 0)+1);
            int l=arr[i-k];
            if(map.get(l)>1) {
                map.put(l, map.get(l)-1);
                answer.add(map.size());
                continue;
            }
            map.remove(l);
            answer.add(map.size());
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n= sc.nextInt();
        int k= sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        for(int x: T.solution(n, k, arr)){
            System.out.print(x+" ");
        }
    }
}
```

## 강의풀이) 투포인터, 최적화

```java
import java.util.*;
public class Main {
    public ArrayList<Integer>  solution(int n, int k, int[] arr){
        ArrayList<Integer> answer =new ArrayList<>();
        HashMap<Integer, Integer> map=new HashMap<>();
        for(int i=0; i<k-1; i++){
            map.put(arr[i], map.getOrDefault(arr[i], 0)+1);
        }
        int lt=0;
        for(int rt=k-1; rt<n; rt++){
            map.put(arr[rt], map.getOrDefault(arr[rt], 0)+1);
            answer.add(map.size());
            map.put(arr[lt], map.get(arr[lt])-1);
            if(map.get(arr[lt])==0) map.remove(arr[lt]);
            lt++;
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n= sc.nextInt();
        int k= sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        for(int x: T.solution(n, k, arr)){
            System.out.print(x+" ");
        }
    }
}
```
