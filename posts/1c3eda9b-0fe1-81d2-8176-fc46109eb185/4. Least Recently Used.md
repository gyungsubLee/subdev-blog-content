# 문제

<a id="1c3eda9b0fe1816d84f2dc491958fe2b"></a>

## <strong>4&#46; Least Recently Used</strong>

---

<a id="1c3eda9b0fe181919ccde110538d7a07"></a>

### 설명

<a id="1c3eda9b0fe181b79f54c20a659010f8"></a>

캐시메모리는 CPU와 주기억장치(DRAM) 사이의 고속의 임시 메모리로서 CPU가 처리할 작업을 저장해 놓았다가

<a id="1c3eda9b0fe181d69615d61ed46d6bc1"></a>

필요할 바로 사용해서 처리속도를 높이는 장치이다&#46; 워낙 비싸고 용량이 작아 효율적으로 사용해야 한다&#46;

<a id="1c3eda9b0fe181d497f3d272b5cc8c68"></a>

철수의 컴퓨터는 캐시메모리 사용 규칙이 LRU 알고리즘을 따른다&#46;

<a id="1c3eda9b0fe181a5b688ed52c731278f"></a>

LRU 알고리즘은 Least Recently Used 의 약자로 직역하자면 가장 최근에 사용되지 않은 것 정도의 의미를 가지고 있습니다&#46;

<a id="1c3eda9b0fe181d6801de71e3fa62826"></a>

캐시에서 작업을 제거할 때 가장 오랫동안 사용하지 않은 것을 제거하겠다는 알고리즘입니다&#46;

![](https://cote.inflearn.com/public/upload/c366c701c2.jpg)

<a id="1c3eda9b0fe181169c11c9030691192b"></a>

캐시의 크기가 주어지고, 캐시가 비어있는 상태에서 N개의 작업을 CPU가 차례로 처리한다면 N개의 작업을 처리한 후

<a id="1c3eda9b0fe181179443fee3bf68306a"></a>

캐시메모리의 상태를 가장 최근 사용된 작업부터 차례대로 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe18178a17bffe02d1c777b"></a>

### 입력

<a id="1c3eda9b0fe18145bc91e2c4a36f5b43"></a>

첫 번째 줄에 캐시의 크기인 S(3&#60;=S&#60;=10)와 작업의 개수 N(5&#60;=N&#60;=1,000)이 입력된다&#46;

<a id="1c3eda9b0fe18157b4fbdd5a83c79f8b"></a>

두 번째 줄에 N개의 작업번호가 처리순으로 주어진다&#46; 작업번호는 1 &#126;100 이다&#46;

<a id="1c3eda9b0fe181278dedd3486385e64d"></a>

### 출력

<a id="1c3eda9b0fe181a5b975d7629f3293f8"></a>

마지막 작업 후 캐시메모리의 상태를 가장 최근 사용된 작업부터 차례로 출력합니다&#46;

## 풀이1)  <code>내 풀이</code>  stack 2개

<a id="1c3eda9b0fe1813fac05cad5ebe56c9b"></a>

```java
import java.util.*;

public class Main {
public void solution(int n, int s, int[] arr){
        Stack<Integer> stack = new Stack<>();
        Stack<Integer> stack2 = new Stack<>();
        for(int x: arr){
            if(stack.contains(x)){
                while(stack.peek()!=x) stack2.push(stack.pop());
                int tmp=stack.pop();
                while(!stack2.isEmpty()) stack.push(stack2.pop());
                stack.push(tmp);
            }
            else {
                if(stack.size()<n) stack.push(x);
                else {
                    while(stack.size()!=1) stack2.push(stack.pop());
                    stack.pop();
                    while(!stack2.isEmpty())stack.push(stack2.pop());
                    stack.push(x);
                }
            }
        }
        while(!stack.isEmpty()){
            System.out.print(stack.pop()+" ");
        }
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int s=sc.nextInt();
        int[] arr = new int[s];
        for(int i=0; i<s; i++){
            arr[i] = sc.nextInt();
        }
        T.solution(n, s, arr);
    }
}
```

## 풀이2) <code>강의 풀이</code> int&#91;&#93; , 더 깔끔한 풀이

```java
import java.util.*;

public class Main {
    public int[] solution(int size, int n, int[] arr) {
        int[] cache=new int[size];
        for(int x : arr){
            int pos=-1;
            for(int i=0; i<size; i++) if(arr[i]==x) pos=i;
            if (pos == -1) {
                for(int i=size-1; i>0; i--) cache[i]=cache[i-1];
                cache[0]=x;
            }
            else {
                for(int i=pos; i>0; i--) cache[i]=cache[i-1];
                cache[0]=x;
            }
        }
        return cache;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int size =sc.nextInt();
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(size, n, arr)){
            System.out.print(x+" ");
        }

    }
}
```
