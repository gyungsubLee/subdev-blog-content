# 문제

<a id="1c3eda9b0fe181d8bb7ec4967d59d8c0"></a>

## <strong>1&#46; 두 배열 합치기</strong>

---

<a id="1c3eda9b0fe181aa9f6af7935c95aedf"></a>

### 설명

<a id="1c3eda9b0fe181f18c7bf785c118a53a"></a>

오름차순으로 정렬이 된 두 배열이 주어지면 두 배열을 오름차순으로 합쳐 출력하는 프로그램을 작성하세요&#46;

---

<a id="1c3eda9b0fe181469264ede17f5a243a"></a>

### 입력

<a id="1c3eda9b0fe181e19844d3f03ea86b6f"></a>

첫 번째 줄에 첫 번째 배열의 크기 N(1&#60;=N&#60;=100)이 주어집니다&#46;

<a id="1c3eda9b0fe181d4970fdd3d2da83d6a"></a>

두 번째 줄에 N개의 배열 원소가 오름차순으로 주어집니다&#46;

<a id="1c3eda9b0fe18138b509fe9beccee35e"></a>

세 번째 줄에 두 번째 배열의 크기 M(1&#60;=M&#60;=100)이 주어집니다&#46;

<a id="1c3eda9b0fe181f99bf4f6dbd1c91f70"></a>

네 번째 줄에 M개의 배열 원소가 오름차순으로 주어집니다&#46;

<a id="1c3eda9b0fe181cb8711d3a11d6e3526"></a>

각 리스트의 원소는 int형 변수의 크기를 넘지 않습니다&#46;

<a id="1c3eda9b0fe1811bad80f9e482bfeca9"></a>

### 출력

<a id="1c3eda9b0fe181049d83d05b6cef283d"></a>

오름차순으로 정렬된 배열을 출력합니다&#46;

---

<a id="1c3eda9b0fe181b4873feb896b8a4b58"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181a48f25deaca324457c"></a>

```plaintext
3
1 3 5
5
2 3 6 7 9

```

<a id="1c3eda9b0fe181e8b828ccfdbd982637"></a>

1 2 3 3 5 6 7 9

### 풀이1) 굉장히 번거로움 → 최적화 필요

<a id="1c3eda9b0fe181b4a980f61701507cf7"></a>

2) 로직부터 개선 필요

<a id="1c3eda9b0fe1814c9c5ce4ef1798d266"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public int[] solution(int n1, int n2, int[] arr1, int[] arr2) {
        int num = n1+n2;
        int[] answer=new int[num];
        int p1=0, p2=0;
				// 1)
        for(int i=0; i<num; i++) {
            if(p1>=n1||p2>=n2) break;
            else if (arr1[p1] <= arr2[p2]) {
                answer[i] = arr1[p1];
                p1++;
            }
            else if (arr1[p1] > arr2[p2]) {
                answer[i] = arr2[p2];
                p2++;
            }
        }
				// 2)
        if(p1<=n1-1){
            int l= n1-p1-1, i=num-l-1;
            while(p1<=n1-1 && i<=num-1){
                answer[i]=arr1[p1];
                p1++; i++;
            }
        }
        if(p2<=n2-1){
            int l= n2-p2-1, i=num-l-1;
            while(p2<=n2-1 && i<=num-1){
                answer[i]=arr2[p2];
                p2++; i++;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n1 = sc.nextInt();
        int[] arr1 = new int[n1];
        for(int i=0; i<n1; i++){
            arr1[i]=sc.nextInt();
        }

        int n2 = sc.nextInt();
        int[] arr2 = new int[n2];
        for(int i=0; i<n2; i++){
            arr2[i]=sc.nextInt();
        }
        for(int x: m.solution(n1, n2, arr1, arr2)){
            System.out.print(x+" ");
        }
    }
}
```

### 풀이2) &#91;1풀이&#93; 개선

<a id="1c3eda9b0fe181f8baacfefbff596574"></a>

cnt 변수를 생성하여, 한쪽 배열이 다 쓰여 정렬이 종료되는 인덱스를 추출함&#46;

<a id="1c3eda9b0fe18162ad25f1a39ae3b0ff"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public int[] solution(int n1, int n2, int[] arr1, int[] arr2) {
        int num = n1+n2;
        int[] answer=new int[num];
        int p1=0, p2=0, cnt=0;
        for(int i=0; i<num; i++) {
            if(p1>=n1||p2>=n2) {  // == p1<n1 && p2<n2
                // 남은 정렬 인덱스
                cnt=i;
                break;
            }
            else if (arr1[p1] <= arr2[p2]) {
                answer[i] = arr1[p1];
                p1++;
            }
            else if (arr1[p1] > arr2[p2]) {
                answer[i] = arr2[p2];
                p2++;
            }
        }

        if(p1<=n1-1){     // p1 < n1
            while(p1<=n1-1 && cnt<=num-1){
                answer[cnt]=arr1[p1];
                p1++; cnt++;
            }
        }
        if(p2<=n2-1){     // p2 < n2
            while(p2<=n2-1 && cnt<=num-1){
                answer[cnt]=arr2[p2];
                p2++; cnt++;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n1 = sc.nextInt();
        int[] arr1 = new int[n1];
        for(int i=0; i<n1; i++){
            arr1[i]=sc.nextInt();
        }

        int n2 = sc.nextInt();
        int[] arr2 = new int[n2];
        for(int i=0; i<n2; i++){
            arr2[i]=sc.nextInt();
        }
        for(int x: m.solution(n1, n2, arr1, arr2)){
            System.out.print(x+" ");
        }
    }
}
```

### 풀이3) 강의 풀이 &#45; 가장 깔끔한 풀이

- 개선점

<a id="1c3eda9b0fe181599984cc62f7687146"></a>

&#45;List → ArrayList

<a id="1c3eda9b0fe181029fe1d65f84af9cdd"></a>

&#45;arr&#91;p1&#93;, p&#43;&#43; → <code>arr&#91;p1&#43;&#43;&#93;</code> 로 축약 가능

<a id="1c3eda9b0fe18119b6f7f121e2a98ebd"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public ArrayList<Integer> solution(int n1, int n2, int[] arr1, int[] arr2) {
        ArrayList<Integer> answer=new ArrayList<>();
        int p1=0, p2=0;
        while(p1<n1 && p2<n2){
            if(arr1[p1]<arr2[p2]) answer.add(arr1[p1++]);
            else answer.add(arr2[p2++]);
        }
        while(p1<n1) answer.add(arr1[p1++]);
        while(p2<n2) answer.add(arr2[p2++]);
        return answer;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n1 = sc.nextInt();
        int[] arr1 = new int[n1];
        for(int i=0; i<n1; i++){
            arr1[i]=sc.nextInt();
        }

        int n2 = sc.nextInt();
        int[] arr2 = new int[n2];
        for(int i=0; i<n2; i++){
            arr2[i]=sc.nextInt();
        }
        for(int x: m.solution(n1, n2, arr1, arr2)){
            System.out.print(x+" ");
        }
    }
}
```
