# 문제

<a id="1c3eda9b0fe1816bb8f1e304e71f0ea7"></a>

##  <strong>3&#46; 최대 부분 증가수열</strong>

<a id="1c3eda9b0fe1813698c8c4fc763bcc6f"></a>

### 설명

<a id="1c3eda9b0fe18189a40ef383d7911500"></a>

N개의 자연수로 이루어진 수열이 주어졌을 때, 그 중에서 가장 길게 증가하는(작은 수에서 큰 수로) 원소들의 집합을 찾는 프로그램을 작성하라&#46;

<a id="1c3eda9b0fe18190862ac697a9885d85"></a>

예를 들어, 원소가 2, 7, 5, 8, 6, 4, 7, 12, 3 이면 가장 길게 증가하도록 원소들을 차례대로 뽑아내면 2, 5, 6, 7, 12를 뽑아내어

<a id="1c3eda9b0fe1817ea492f5f602996ce7"></a>

길이가 5인 최대 부분 증가수열을 만들 수 있다&#46;

<a id="1c3eda9b0fe18135ae97c1e2a42d2153"></a>

### 입력

<a id="1c3eda9b0fe181bfbb71d44cd11d52af"></a>

첫째 줄은 입력되는 데이터의 수 N(3≤N≤1,000, 자연수)를 의미하고,

<a id="1c3eda9b0fe1816e8680d6e2f7a2880c"></a>

둘째 줄은 N개의 입력데이터들이 주어진다&#46;

<a id="1c3eda9b0fe181db969df034fa79bd7f"></a>

### 출력

<a id="1c3eda9b0fe181cc8bf6d8b427220744"></a>

첫 번째 줄에 부분증가수열의 최대 길이를 출력한다&#46;

---

<a id="1c3eda9b0fe1813fa0efd125f838ec9a"></a>

<a id="1c3eda9b0fe1812c85a8cfb07ea3cff7"></a>

8
5 3 7 8 6 2 9 4

# 풀이

<a id="1c3eda9b0fe181f689adc7ce299a8538"></a>

## 풀이1)

<a id="1c3eda9b0fe18125817fef81004f0ecd"></a>

```java
import java.util.*;

public class Main {
    static int[] dy;
    public int solution(int[] arr){
        int answer=0;
        dy=new int[arr.length];
        dy[0]=1;
        for(int i=1; i<arr.length; i++){
            int max=0;
            for(int j=i-1; j>=0; j--){
                if(arr[j]<arr[i] && dy[j]>max) max=dy[j];
            }
            dy[i]=max+1;
            answer=Math.max(answer, dy[i]);
        }
        return answer;
    }

    public static void main(String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int  n= sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.println(T.solution(arr));
    }
}
```
