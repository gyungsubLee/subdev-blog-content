&#34;선택적으로 초점 맞추기 지침 포함&#34;은 Claude Code의 <strong>slash commands</strong> 또는 <strong>Skills</strong>에서 사용되는 기능입니다&#46;

<a id="2e7eda9b0fe1801d9c93cb0dc60e8c62"></a>

이것은 명령어 파일의 <strong>frontmatter</strong>에서 <strong><code>context&#58; fork</code></strong>를 설정할 때 관련됩니다&#46; 명령이 분리된 서브에이전트 컨텍스트에서 실행될 때, 선택적으로 <strong>focus instructions</strong>(초점 지침)을 포함하여 Claude가 특정 작업에 집중하도록 안내할 수 있습니다&#46;

<a id="2e7eda9b0fe1807a8059ec9f6ea72f0d"></a>

예를 들어, Skills에서는 <strong><code>context&#58; fork</code></strong>를 사용하여 복잡한 다단계 작업을 메인 대화를 어지럽히지 않고 격리된 컨텍스트에서 실행할 수 있습니다&#46;

<a id="2e7eda9b0fe18022b59ec33281f6bb02"></a>

더 알고 싶으시면 다음 페이지를 참고하세요&#58;

<a id="2e7eda9b0fe180519cbfd527f0420697"></a>

## 슬래시 명령어 ( <strong>Slash commands)</strong>

---

> 📖 
> 
> <a id="2e7eda9b0fe18084b6ffdccc7d5daa9c"></a>
> 
> 슬래시 명령어를 통해 대화형 세션 중 cli 형태로 명령어를 처리할 수 있으며, 반복되는 동작을 명령어로 템플릿 처리하여 생산성을 증대 시킬 수 있다&#46; 

<a id="2e7eda9b0fe1805786b6fa21dcc23f5a"></a>

### 내장 슬래시 명령

- <code>/login</code>&#58; Switch Anthropic 계정

- <code>/logout</code>&#58; Anthropic 계정 로그아웃

- <code>/add&#45;dir</code>&#58; 추가 작업 디렉토리 추가

- <code>/agents</code>&#58; 특수 작업을 위한 맞춤형 AI 하위 에이전트 관리

- <code>/bashes</code>&#58; 백그라운드 작업을 나열하고 관리

- <code>/clear</code>&#58; 대화 기록 삭제

- <code>/compact</code>&#58;<strong> </strong>이전 대화 context 축약 

- <code>/config</code>&#58; 설정 인터페이스(구성 탭)을 연다&#46;

- <code>/cost</code>&#58; 토큰 사용 통계 표시

- <code>/exit</code>&#58; REPL 종료

- <code>/export &#91;filename&#93;</code>&#58; 현재 대화를 파일이나 클립보드로 내보내기

- <code>/hooks</code>&#58; 툴 이벤트에 대한 후크 구성 관리

- <code>/memory</code>&#58; <code>CLAUDE&#46;md</code>메모리 파일을 편집

- <code>/mcp</code>&#58; MCP 서버 연결 및 OAuth 인증 관리

- <code>/model</code>&#58; AI 모델을 선택하거나 변경

- <code>/output&#45;style &#91;style&#93;</code>&#58; 출력 스타일을 직접 설정하거나 선택 메뉴 통해 설정

- <code>/plan</code>&#58; 프롬프트에서 바로 계획 모드 진입

- <code>/plugin</code>&#58;

### <strong>사용자 지정 슬래시 명령</strong>

> ✏️ 
> 
> <a id="2e7eda9b0fe180f597f0c3f1340362a8"></a>
> 
> 사용자 지정 슬래시 명령을 사용 시, <strong><u>자주 사용하는 프롬프트를 Claude Code에서 실행 가능한 Markdown 파일로 정의</u></strong>할 수 있다&#46;

<a id="2e7eda9b0fe180d78a92e71311189736"></a>

```markdown
/<command-name> [arguments]
```

<a id="2e7eda9b0fe180e4bf30e9f6e6c439ed"></a>

<strong>매개변수</strong>

| <strong>매개변수</strong> | <strong>설명</strong> |
| --- | --- |
| <strong><code>&#60;command&#45;name&#62;</code></strong> | <strong><code>&#46;md</code></strong> 확장자를 제외한  마크다운 파일 이름에서 파생된 이름이다&#46; |
| <strong><code>&#91;arguments&#93;</code></strong> | 명령에 전달되는 선택적 인수 |
