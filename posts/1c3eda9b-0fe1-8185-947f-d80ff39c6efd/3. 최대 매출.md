# 문제

<a id="1c3eda9b0fe1814daf5fecd222d609e3"></a>

## <strong>3&#46; 최대 매출</strong>

---

<a id="1c3eda9b0fe18167af0ad6c9b0e43e49"></a>

### 설명

<a id="1c3eda9b0fe181fbb969c693785be60c"></a>

현수의 아빠는 제과점을 운영합니다&#46; 현수 아빠는 현수에게 N일 동안의 매출기록을 주고 연속된 K일 동안의 최대 매출액이 얼마인지 구하라고 했습니다&#46;

<a id="1c3eda9b0fe181f1b05ec58b7d3c4566"></a>

만약 N=10이고 10일 간의 매출기록이 아래와 같습니다&#46; 이때 K=3이면

<a id="1c3eda9b0fe1813491b8c8781ce3292f"></a>

12 1511 20 2510 20 19 13 15

<a id="1c3eda9b0fe1816da16bde7541f4aa97"></a>

연속된 3일간의 최대 매출액은 11&#43;20&#43;25=56만원입니다&#46;

<a id="1c3eda9b0fe18156b9d1c94bdd3585ba"></a>

여러분이 현수를 도와주세요&#46;

<a id="1c3eda9b0fe1817ebd3de62bcc5002d0"></a>

### 입력

<a id="1c3eda9b0fe1813ca972fd4a2ce08e8e"></a>

첫 줄에 N(5&#60;=N&#60;=100,000)과 K(2&#60;=K&#60;=N)가 주어집니다&#46;

<a id="1c3eda9b0fe181449f31c6a10347fec3"></a>

두 번째 줄에 N개의 숫자열이 주어집니다&#46; 각 숫자는 500이하의 음이 아닌 정수입니다&#46;

<a id="1c3eda9b0fe181f4b77cfdd43813e3f4"></a>

### 출력

<a id="1c3eda9b0fe18126a5dcfacac9017dd5"></a>

첫 줄에 최대 매출액을 출력합니다&#46;

---

<a id="1c3eda9b0fe18103bef6db7f58aae771"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1814baa80c5037df545b1"></a>

```plaintext
10 3
12 15 11 20 25 10 20 19 13 15
```

<a id="1c3eda9b0fe181d78574c4f5ceb54571"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181598df6ef2cd12b23b3"></a>

```plaintext
56
```

<a id="1c3eda9b0fe18122b2aec0a415ba94c0"></a>

# 풀이

<a id="1c3eda9b0fe1818bb9c7f0dcb7b28b51"></a>

### 풀이1) O(n^2) 풀이 → 최적화 필요 

<details>
<summary>오답</summary>

<a id="1c3eda9b0fe181ffa25bf002834fa92e"></a>

조건을 잘못 이해함&#46; 3개의 비교군이 고정값이 아님&#46;

<a id="1c3eda9b0fe1819b9c1ece5327d0279b"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public int solution(int n, int t, int[] arr) {
        int max=Integer.MIN_VALUE;
        for(int i=0; i<n-2; i++){
            int sum = arr[i]+arr[i+1]+arr[i+2];
            if(sum>max){
                max=sum;
            }
        }
        return max;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.print(m.solution(n, t, arr));
    }
}
```

</details>

<details>
<summary>해결</summary>

<a id="1c3eda9b0fe181a0a6cdd95991a8d4aa"></a>

비교군 수 로 받아오는 인수인 k로 처리

<a id="1c3eda9b0fe1816b9fbfe608b920e077"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public int solution(int n, int t, int[] arr) {
        int max=Integer.MIN_VALUE;
        for(int i=0; i<n-t-1; i++){
            int sum=0;
            for(int j=0; j<t; j++) sum+=arr[i+j];
            if(sum>max){
                max=sum;
            }
        }
        return max;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.print(m.solution(n, t, arr));
    }
}
```

### 풀이2)  &#91;슬라이싱 윈도우&#93; O(n) 

<a id="1c3eda9b0fe1816bb491e315c0fe06bd"></a>

<del>이야 어케 이런 생각을 했지? 재밌구만</del>

<a id="1c3eda9b0fe181b0933ec106c4057916"></a>

k 번째까지의 합을 구해놓고 처음 수를 빼고 다음 수를 더해가면서 비교함&#46;

<a id="1c3eda9b0fe181edb98ee6301171af4e"></a>

→ O(n) 연산 

<a id="1c3eda9b0fe181fc9a76f2797a27d54e"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {
    public int solution(int n, int t, int[] arr) {
        int max, sum=0;
        for(int i=0; i<t; i++) sum+=arr[i];
        max=sum;
        for(int i=t; i<n; i++){
            sum += arr[i]-arr[i-t];
            max=Math.max(max, sum);
        }
        return max;
    }

    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
         System.out.print( m.solution(n, t, arr));
    }
}
```
