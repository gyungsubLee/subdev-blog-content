# 회원 웹 기능 &#45; 홈 화면 추가 (view)

<a id="1c3eda9b0fe18120a7d9e701c45a3803"></a>

### <code>&#64;GetMapping(url)</code>

<a id="1c3eda9b0fe18161b2e6cdbcd5f12d8f"></a>

<code>&#64;GetMapping</code> 어노테이션을 통해 <strong>특정 url</strong>에서의 <strong>view 템플릿을 반환</strong> 시킬 수 있다&#46; 

<a id="1c3eda9b0fe181deb29ad135726f616f"></a>

view 템플릿은 <strong>매핑된 함수의 반환값</strong>을  <strong>src/main/resouces/templates</strong>에서 찾아 가져온다&#46; 

> 스프링은 스프링 컨테이너에서 관련 컨트롤러를 먼저 찾고 없으면 static 파일 찾는다&#46; 

<details>
<summary>ex1) (강의) <code>&#64;GetMapping(&#34;/&#34;)</code>  </summary>

<a id="1c3eda9b0fe18178ae6ad5277a4563ad"></a>

 <code>&#64;GetMapping(&#34;/&#34;)</code>   → <a href="http://localhost:8080/">localhost&#58;8080/</a> 요청이 들어오면 아래의 함수를 실행

<a id="1c3eda9b0fe18185b0d4efcd2a45e780"></a>

해당 함수에서는<strong> </strong><strong><code>home</code></strong><strong> 리턴</strong>한다&#46; 그러면 <strong>Spring이 자동으로 </strong><strong><code>src/main/resouces/templates</code></strong><strong>에서  </strong><strong><code>home&#46;html</code></strong><strong>을 찾</strong>아서 반환한다&#46;

<a id="1c3eda9b0fe181d58391db3cd782acc1"></a>

```java
@Controller
public class HomeController {

    @GetMapping("/")
    public  String home() {
        return "home";
    }
}
```

<a id="1c3eda9b0fe1818a817bce74490858b5"></a>

위에서 한번 설명했듯이 <code>static/index&#46;html</code>이 존재하지만, 스프링 컨테이너에서의 컨트롤러의 우선순위가 더 높아 <code>templates/home&#46;html</code>이 반환된다&#46; 

</details>

<details>
<summary>ex2) <code>&#64;GetMapping(&#34;hello&#34;)</code></summary>

<a id="1c3eda9b0fe181398018fb0f45ff01fe"></a>

 <code>&#64;GetMapping(&#34;hello&#34;)</code>   → <a href="http://localhost:8080/">localhost&#58;8080/</a>hello 요청이 들어오면 아래의 함수를 실행

<a id="1c3eda9b0fe181c488a5f4f2611df862"></a>

위와 같이 <strong><code>src/main/resouces/templates</code></strong><strong>에서  </strong><strong><code>hello&#46;html</code></strong><strong>을 찾</strong>아서 반환

<a id="1c3eda9b0fe1811787b1ea98ff445f96"></a>

```java
@Controller
public class HelloController {

    @GetMapping("hello")
    public String hello(){
        return "hello";
    }
}
```

</details>

### FormController ( MemberConroller )

<a id="1c3eda9b0fe181b4b75bf30af058498d"></a>

<strong>회원 컨트롤러에서 회원을 실제 등록하는 기능</strong>

> controller/MemberController

<a id="1c3eda9b0fe1815b933cec90044ab0cf"></a>

```java
// controller/memberController

@Controller
public class MemberController {

		 .   .   .

    @GetMapping("/members/new")
    public String createForm() {
        return "members/createMemberForm";
    }

    @PostMapping("/members/new")
    public String create(MemberForm form) {
        Member member = new Member();
        member.setName(form.getName());

        memberService.join(member);

        return "redirect:/";   // 홈 화면으로 리턴
    }
}
```

### <strong>회원 컨트롤러 &#45; 회원 리스트 조회</strong>

<a id="1c3eda9b0fe181679037e0dd11f6dfbe"></a>

```java
@Controller
public class MemberController {

				 .     .     .

		@GetMapping(value = "/members")
		 public String list(Model model) {
		     List<Member> members = memberService.findMembers();
		     model.addAttribute("members", members);
		     return "members/memberList";
		}
}
```
