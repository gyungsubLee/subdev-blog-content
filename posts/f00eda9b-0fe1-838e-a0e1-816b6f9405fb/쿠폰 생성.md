## 요청 응답 예시

---

<a id="ecaeda9b0fe18342892c010013965210"></a>

### 요청 

- Path Variable&#58; <code>None</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- <strong>Body</strong>
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | name | String | 쿠폰 이름 |
    | 2 | description | String | 쿠폰 설명 |
    | 3 | count | int | 쿠폰 수량 |

- HTTP 요청
    <a id="9e0eda9b0fe183c0bf6101db7d494ecc"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) POST /api/coupons HTTP/1.1
    ```

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | <code>CouponResponseDto</code> | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>CouponResponseDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None | 수정된 쿠폰 ID |
    | 2 | name | String | None | 수정된 쿠폰 이름 |
    | 3 | description | String | None | 수정된 쿠폰 설명 |
    | 4 | count | int | None | 수정된 쿠폰 수량 |
    | 5 | createdAt | timestamp | None | 쿠폰 생성 날짜 |
    | 6 | updatedAt | timestamp | None | 쿠폰 수정 날짜 |

    </details>

    <details>
    <summary>응답 예시 </summary>

    ```json
            "id": 2,
            "name": "Winter Sale",
            "description": "20% discount on all items",
            "count": 100,

        }
    }
    ```

    </details>

    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
