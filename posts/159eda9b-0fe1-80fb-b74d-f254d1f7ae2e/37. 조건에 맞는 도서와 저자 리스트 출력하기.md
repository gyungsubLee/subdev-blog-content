## 문제

<a id="159eda9b0fe1806eac95d98292aab157"></a>

### <strong>문제 설명</strong>

<a id="159eda9b0fe180fcb2d9f13eec95873e"></a>

다음은 어느 한 서점에서 판매중인 도서들의 도서 정보(<code>BOOK</code>), 저자 정보(<code>AUTHOR</code>) 테이블입니다&#46;

<a id="159eda9b0fe180129c7afbe998c3ce28"></a>

<code>BOOK</code> 테이블은 각 도서의 정보를 담은 테이블로 아래와 같은 구조로 되어있습니다&#46;

|  |  |  |  |
| --- | --- | --- | --- |
| Column name | Type | Nullable | Description |
| BOOK&#95;ID | INTEGER | FALSE | 도서 ID |
| CATEGORY | VARCHAR(N) | FALSE | 카테고리 (경제, 인문, 소설, 생활, 기술) |
| AUTHOR&#95;ID | INTEGER | FALSE | 저자 ID |
| PRICE | INTEGER | FALSE | 판매가 (원) |
| PUBLISHED&#95;DATE | DATE | FALSE | 출판일 |

<a id="159eda9b0fe1805db6f0ed542361df3d"></a>

<code>AUTHOR</code> 테이블은 도서의 저자의 정보를 담은 테이블로 아래와 같은 구조로 되어있습니다&#46;

|  |  |  |  |
| --- | --- | --- | --- |
| Column name | Type | Nullable | Description |
| AUTHOR&#95;ID | INTEGER | FALSE | 저자 ID |
| AUTHOR&#95;NAME | VARCHAR(N) | FALSE | 저자명 |

---

<a id="159eda9b0fe1804bab7ade6e7ed1bebb"></a>

### 문제

<a id="159eda9b0fe1805a9935c5dd8d18f409"></a>

<code>&#39;경제&#39;</code> 카테고리에 속하는 도서들의 도서 ID(<code>BOOK&#95;ID</code>), 저자명(<code>AUTHOR&#95;NAME</code>), 출판일(<code>PUBLISHED&#95;DATE</code>) 리스트를 출력하는 SQL문을 작성해주세요&#46;

<a id="159eda9b0fe180eab7abe8bfed1a4a6c"></a>

결과는 출판일을 기준으로 오름차순 정렬해주세요&#46;

---

<a id="159eda9b0fe180719248e092385dc64e"></a>

### 예시

<a id="159eda9b0fe180c9b98adb97559e0f2d"></a>

예를 들어 <code>BOOK</code> 테이블과 <code>AUTHOR</code> 테이블이 다음과 같다면

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| BOOK&#95;ID | CATEGORY | AUTHOR&#95;ID | PRICE | PUBLISHED&#95;DATE |
| 1 | 인문 | 1 | 10000 | 2020&#45;01&#45;01 |
| 2 | 경제 | 1 | 9000 | 2021&#45;04&#45;11 |
| 3 | 경제 | 2 | 11000 | 2021&#45;02&#45;05 |

|  |  |
| --- | --- |
| AUTHOR&#95;ID | AUTHOR&#95;NAME |
| 1 | 홍길동 |
| 2 | 김영호 |

<a id="159eda9b0fe1809891dac2477302f199"></a>

<code>&#39;경제&#39;</code> 카테고리에 속하는 도서는 도서 ID가 2, 3인 도서이고, 출판일을 기준으로 오름차순으로 정렬하면 다음과 같은 결과가 나와야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| BOOK&#95;ID | AUTHOR&#95;NAME | PUBLISHED&#95;DATE |
| 3 | 김영호 | 2021&#45;02&#45;05 |
| 2 | 홍길동 | 2021&#45;04&#45;11 |

---

<a id="159eda9b0fe1802398aacf4e7c65b866"></a>

### 주의사항

<a id="159eda9b0fe1808c92a2c7542082ae5e"></a>

<code>PUBLISHED&#95;DATE</code>의 데이트 포맷이 예시와 동일해야 정답처리 됩니다&#46;

<a id="159eda9b0fe1812c9e24d8773db86a5b"></a>

## 풀이

> ✏️ 
> 
> <a id="1d7eda9b0fe180559c38fe53e8e022f8"></a>
> 
> 조건
> 
> - <code>&#39;경제&#39;</code> 카테고리에 속하는 도서들의 도서 ID(<code>BOOK&#95;ID</code>), 저자명(<code>AUTHOR&#95;NAME</code>), 출판일(<code>PUBLISHED&#95;DATE</code>) 리스트를 출력
> 
> -  출판일을 기준으로 오름차순

<details>
<summary>1차 풀이 fail</summary>

<a id="159eda9b0fe1803d946ecc3e999889ad"></a>

```sql
SELECT
    b.BOOK_ID,
    a.AUTHOR_NAME,
    b.PUBLISHED_DATE
FROM
    BOOK b
JOIN
    AUTHOR a
ON 
    b.AUTHOR_ID = a.AUTHOR_ID
WHERE
    b.CATEGORY = '경제'
ORDER BY
    b.PUBLISHED_DATE ASC;
```

- 조건 중 ‘<code>PUBLISHED&#95;DATE</code>의 데이트 포맷이 예시와 동일’ 을 나중에 확인함

- 아래와 같이 <code>DATE&#95;FORMAT()</code>를 통해 포맷을 동일하게 맞춤
    <a id="159eda9b0fe180e9bf00feb5f291bb04"></a>

    ```java
     DATE_FORMAT(b.PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE 
    ```

</details>

<a id="159eda9b0fe18058a2dcec93f587582a"></a>

```sql
SELECT
    b.BOOK_ID,
    a.AUTHOR_NAME,
    DATE_FORMAT(b.PUBLISHED_DATE, '%Y-%m-%d') AS PUBLISHED_DATE  -- 날짜 형식 변환
FROM BOOK b
JOIN AUTHOR a
ON b.AUTHOR_ID = a.AUTHOR_ID
WHERE b.CATEGORY = '경제'
ORDER BY b.PUBLISHED_DATE ASC;
```

<a id="159eda9b0fe1805daf75f52b6678c5de"></a>

```sql
SELECT 
    B.BOOK_ID, 
    A.AUTHOR_NAME, 
    DATE_FORMAT(B.PUBLISHED_DATE, '%Y-%m-%d') PUBLISHED_DATE
FROM BOOK B
JOIN AUTHOR A ON A.AUTHOR_ID = B.AUTHOR_ID
WHERE B.CATEGORY LIKE '%경제%'
ORDER BY B.PUBLISHED_DATE

```
