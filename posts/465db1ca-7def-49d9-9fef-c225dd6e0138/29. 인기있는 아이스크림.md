## 문제

<a id="109eda9b0fe180e19ee3ce84fbdad304"></a>

<strong>FIRST&#95;HALF</strong> 테이블은 아이스크림 가게의 상반기 주문 정보를 담은 테이블입니다&#46;

<a id="109eda9b0fe18003b437da6abf1a4622"></a>

FIRST&#95;HALF 테이블 구조는 다음과 같으며, SHIPMENT&#95;ID, FLAVOR, TOTAL&#95;ORDER는 각각 아이스크림 공장에서 아이스크림 가게까지의 출하 번호, 아이스크림 맛, 상반기 아이스크림 총주문량을 나타냅니다&#46;

| NAME | TYPE | NULLABLE |
| --- | --- | --- |
| SHIPMENT&#95;ID | INT(N) | FALSE |
| FLAVOR | VARCHAR(N) | FALSE |
| TOTAL&#95;ORDER | INT(N) | FALSE |

---

<a id="109eda9b0fe180de8081e62fa303f248"></a>

### 문제

<a id="109eda9b0fe180e39f51fdaaec0e0e2c"></a>

상반기에 판매된 아이스크림의 맛을 총주문량을 기준으로 내림차순 정렬하고 총주문량이 같다면 출하 번호를 기준으로 오름차순 정렬하여 조회하는 SQL 문을 작성해주세요&#46;

---

<a id="c4a41ac89afc44b3a05a0a0d3a70382b"></a>

### 예시

<a id="109eda9b0fe18077bdabcacc91d42a62"></a>

예를 들어 FIRST&#95;HALF 테이블이 다음과 같을 때&#58;

| SHIPMENT&#95;ID | FLAVOR | TOTAL&#95;ORDER |
| --- | --- | --- |
| 101 | chocolate | 3200 |
| 102 | vanilla | 2800 |
| 103 | mint&#95;chocolate | 1700 |
| 104 | caramel | 2600 |
| 105 | white&#95;chocolate | 3100 |
| 106 | peach | 2450 |
| 107 | watermelon | 2150 |
| 108 | mango | 2900 |
| 109 | strawberry | 3100 |
| 110 | melon | 3150 |
| 111 | orange | 2900 |
| 112 | pineapple | 2900 |

<a id="109eda9b0fe18073986bff55292bd1bc"></a>

상반기 아이스크림 맛을 총주문량을 기준으로 내림차순 정렬하고, 총주문량이 같은 경우 출하 번호를 기준으로 오름차순 정렬하면 아래와 같이 조회되어야 합니다&#58;

| FLAVOR |
| --- |
| chocolate |
| melon |
| white&#95;chocolate |
| strawberry |
| mango |
| orange |
| pineapple |
| vanilla |
| caramel |
| peach |
| watermelon |
| mint&#95;chocolate |

<a id="109eda9b0fe18047a317faaa7083a682"></a>

## 풀이

<a id="9df739121d7e47ec88aad2db7047c05d"></a>

해당 문제는 아이스크림 주문량에 따라 맛을 정렬하는 방법을 묻는다&#46; 

- 조건
    - <strong>총주문량(TOTAL&#95;ORDER)</strong>을 기준으로 내림차순 정렬

    - 총주문량이 같은 경우, <strong>출하 번호(SHIPMENT&#95;ID)</strong>를 기준으로 오름차순 정렬

<a id="a513b9270c60480bbfefa5a96b6bd00f"></a>

### SQL

<a id="109eda9b0fe1809e8f30c9b2d6e73f5b"></a>

```sql
SELECT FLAVOR
FROM FIRST_HALF
ORDER BY TOTAL_ORDER DESC, SHIPMENT_ID ASC;
```

- <code>SELECT FLAVOR</code>&#58; FLAVOR 컬럼(열)만 선택하여 결과에 출력

- <code>FROM FIRST&#95;HALF</code>&#58; FIRST&#95;HALF 테이블에서 데이터 조회

- <code>ORDER BY TOTAL&#95;ORDER DESC, SHIPMENT&#95;ID ASC</code>
    - 먼저 <strong>TOTAL&#95;ORDER</strong> 기준으로<strong><u> 내림차순(DESC)</u></strong> 정렬, 높은 주문량이 먼저 나옴

    - 주문량이 같은 경우, <strong>SHIPMENT&#95;ID</strong>를 기준으로 <strong><u>오름차순(ASC)</u></strong><strong> </strong>정렬
