# 문제

<a id="1c3eda9b0fe181e78027f01337c3cc36"></a>

## <strong>8&#46; 응급실</strong>

---

<a id="1c3eda9b0fe1819ea346ce2e9ee788db"></a>

### 설명

<a id="1c3eda9b0fe181d083faef93c9d8c8d2"></a>

메디컬 병원 응급실에는 의사가 한 명밖에 없습니다&#46;

<a id="1c3eda9b0fe181b89c69ec8593e08812"></a>

응급실은 환자가 도착한 순서대로 진료를 합니다&#46; 하지만 위험도가 높은 환자는 빨리 응급조치를 의사가 해야 합니다&#46;

<a id="1c3eda9b0fe18182812ae2643a4a1879"></a>

이런 문제를 보완하기 위해 응급실은 다음과 같은 방법으로 환자의 진료순서를 정합니다&#46;

- 환자가 접수한 순서대로의 목록에서 제일 앞에 있는 환자목록을 꺼냅니다&#46;

- 나머지 대기 목록에서 꺼낸 환자 보다 위험도가 높은 환자가 존재하면 대기목록 제일 뒤로 다시 넣습니다&#46; 그렇지 않으면 진료를 받습니다&#46;

<a id="1c3eda9b0fe181d798f1caa0d168022d"></a>

즉 대기목록에 자기 보다 위험도가 높은 환자가 없을 때 자신이 진료를 받는 구조입니다&#46;

<a id="1c3eda9b0fe181f6880fd2ae31855717"></a>

현재 N명의 환자가 대기목록에 있습니다&#46;

<a id="1c3eda9b0fe18105b724dd54118db513"></a>

N명의 대기목록 순서의 환자 위험도가 주어지면, 대기목록상의 M번째 환자는 몇 번째로 진료를 받는지 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181929f67f407341a7d1d"></a>

대기목록상의 M번째는 대기목록의 제일 처음 환자를 0번째로 간주하여 표현한 것입니다&#46;

<a id="1c3eda9b0fe18191a412eb8ba0187f3f"></a>

### 입력

<a id="1c3eda9b0fe18123bb95e7361990fa3f"></a>

첫 줄에 자연수 N(5&#60;=N&#60;=100)과 M(0&#60;=M&#60;N) 주어집니다&#46;

<a id="1c3eda9b0fe1818a8aeac0a82523cdc3"></a>

두 번째 줄에 접수한 순서대로 환자의 위험도(50&#60;=위험도&#60;=100)가 주어집니다&#46;

<a id="1c3eda9b0fe1817bb12fdab645af92c4"></a>

위험도는 값이 높을 수록 더 위험하다는 뜻입니다&#46; 같은 값의 위험도가 존재할 수 있습니다&#46;

<a id="1c3eda9b0fe1815d8d9cc23bfea87f78"></a>

### 출력

<a id="1c3eda9b0fe181449665d33833d75c14"></a>

```java
import java.util.*;
public class Main {
    public int  solution(int n, int t, int[] arr){
        int answer=0;
        Queue<Integer> Q = new LinkedList<>();
        for(int x: arr) Q.offer(x);
        while(!Q.isEmpty()){
            int target = Q.poll();
            if(target < Q.peek()) Q.offer(target);
            else {
                answer++;
                if(target == t) break;
            }
        }
       return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        int target = arr[m];
        System.out.println(T.solution(n, target, arr));
    }
}
```

## 풀이2) 강의 풀이 (이해 X)

<a id="1c3eda9b0fe181ad81a3d85eba2ec1d5"></a>

```java
import java.util.*;

class Person{
    int id;
    int priority;
    public  Person(int id, int priority){
        this.id=id;
        this.priority=priority;
    }
}

public class Main {
    public int  solution(int n, int m, int[] arr){
        int answer=1;
        Queue<Person> Q = new LinkedList<>();
        for(int i=0; i<n; i++) Q.offer(new Person(i, arr[i]));
        while(!Q.isEmpty()){
            Person tmp=Q.poll();
            for(Person x: Q){
                if(x.priority > tmp.priority){
                    Q.offer(tmp);
                    tmp=null;
                    break;
                }
            }
            if(tmp!=null){
                if(tmp.id==m) return answer;
                else answer++;
            }
        }
       return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.println(T.solution(n, m, arr));
    }
}
```
