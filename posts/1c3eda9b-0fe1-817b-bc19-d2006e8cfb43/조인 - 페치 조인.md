## <strong>조인 </strong>&#45; <strong>페치 조인</strong>

---

> 📖 
> 
> <a id="1c3eda9b0fe1815da530ed8267192d2f"></a>
> 
> 페치 조인은 SQL에서 제공하는 기능은 아니다&#46; <u>SQL 조인을 활용</u>해서 <u>연관된 엔티티를 SQL 한번에 조회</u>하는 기능이며  주로 <u>성능 최적화</u><u>에 사용</u>한다&#46;

<details>
<summary>페치 조인 미적용</summary>

- 지연로딩으로 설정,  Member 조회 시 Team은 조회하지 않는다&#46; 
    - <code>emf&#46;getPersistenceUnitUtil()&#46;isLoaded(findMember&#46;getTeam())</code>
        - <code>isLoaded&#58;</code> 특정 엔티티 또는 연관 엔티티가 초기화되었는지 확인한다&#46;

        - <code>findMember&#46;getTeam()</code>은 <strong>Lazy Loading</strong>이기 때문에 초기화되지 않은 상태이다&#46;

        - 따라서 <code>false</code> 가 return 된다&#46; 

<a id="1c3eda9b0fe181478456e396bac14c4f"></a>

```java
@PersistenceUnit
EntityManagerFactory emf;

@Test
public void fetchJoinNo() throws Exception {
 
     em.flush();
     em.clear();
     
     Member findMember = queryFactory
             .selectFrom(member)
             .where(member.username.eq("member1"))
             .fetchOne();
             
     boolean loaded = emf.getPersistenceUnitUtil().isLoaded(findMember.getTeam());
     
     assertThat(loaded).as("페치 조인 미적용").isFalse();
}
     
```

</details>

<details>
<summary>페치 조인 적용</summary>

> ✏️ 
> 
> <a id="1c3eda9b0fe1812aad93e49d5335be6d"></a>
> 
> 사용 방법
> 
> - <code>join(), leftJoin()</code> 등 조인 기능 뒤에 <code>fetchJoin()</code> 추가

> <code>fetch join</code>&#58; <u>지연로딩으로 설정된 연관된 entity</u>를 <u>join을 사용</u>하여 <u>한번의 SQL</u>로 가져온다 

- <code>&#46;join(member&#46;team, team)&#46;fetchJoin()</code>
    - 연관된 Team 엔티티를 함께 가져온다&#46; 

    - 따라서 <code>&#46;isLoaded(findMember&#46;getTeam())</code>는 <code>true</code>가 된다&#46; 

<a id="1c3eda9b0fe181ddb118cbd33609d28e"></a>

```java
@PersistenceUnit
EntityManagerFactory emf;

@Test
public void fetchJoinNo() throws Exception {
 
     em.flush();
     em.clear();
     
     Member findMember = queryFactory
             .selectFrom(member)
             .join(member.team, team).fetchJoin()
             .where(member.username.eq("member1"))
             .fetchOne();
             
     boolean loaded = emf.getPersistenceUnitUtil().isLoaded(findMember.getTeam());
     
     assertThat(loaded).as("페치 조인 적용").isTrue();
}
     
```

</details>
