### 요청 

- Path Variable&#58; <code>None</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | date | timestamp | None | 일정 날짜 |
    | 2 | title | String |  | 일정 제목 |
    | 3 | details | String |  | 일정 설명 |
    | 4 | contentsId | Array&#60;Long&#62; | None | 컨텐츠 식별 번호 리스트 |

- HTTP 요청
    <a id="233eda9b0fe1821885050118b6f8c038"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) POST  /api/schedules  HTTP1.1
    ```

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | <code>ScheduleResponseDto</code> | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>ScheduleResponseDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None | — 식별자 |
    | 2 | date | Timestamp | None | 일자 |
    | 3 | title | String | None | 일정 이름 |
    | 4 | details | String | None | 일정 설명 |
    | 5 | contentId | Array&#60;Long&#62; | None | 컨텐츠 식별 번호 리스트 |
    | 6 | createdAt | Timestamp | None | 생성 일자 |
    | 7 | updatedAt | Timestamp | None | 수정 일자 |

    </details>

    <details>
    <summary>응답 예시 </summary>

    <a id="cdbeda9b0fe183c3bf40816154f6ac90"></a>

    ```json
    {
        "message": "일정 생성 완료",
        "data": {
            "id": 4,
            "date": "2025-01-13",
            "title": "모각코",
            "details": "coding together!",
            "contentIds": [
                1
            ],
            "createdAt": "2025-01-09T19:37:40.845675",
            "updatedAt": "2025-01-09T19:37:40.845675"
        }
    }
    ```

    </details>

- HTTP Status
    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
    | --- | --- | --- | --- |
    | 1 | <code>200 </code> | <code>OK</code> | 성공 |
    | 2 | <code>400</code> | <code>Bad Request</code> | 잘못된 요청 |
    | 3 | <code>401</code> | <code>Unauthorized</code> | 인가되지 않은 요청 |
    | 4 | <code>404</code> | <code>Not Found</code> | 해당 정보 찾을 수 없음 |
