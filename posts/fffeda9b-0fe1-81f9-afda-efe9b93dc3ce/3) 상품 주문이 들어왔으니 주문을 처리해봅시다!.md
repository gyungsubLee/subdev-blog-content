이제 상품 주문이 들어왔으니 어떤 고객에게 어떤 주문이 들어왔는지를 파악할 수 있는 orders(주문) 테이블이 아래에 있습니다&#46;

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| id | customer&#95;id | product&#95;id | amount | shipping&#95;fee | order&#95;date |
| 1 | 719 | 1 | 3 | 50000 | 2023&#45;11&#45;01 |
| 2 | 131 | 2 | 1 | 10000 | 2023&#45;11&#45;02 |
| 3 | 65 | 4 | 1 | 20000 | 2023&#45;11&#45;05 |
| 4 | 1008 | 3 | 2 | 25000 | 2023&#45;11&#45;05 |
| 5 | 356 | 1 | 1 | 15000 | 2023&#45;11&#45;09 |

1. <strong><code>orders</code></strong> 테이블에서 주문 수량(amount)이 2개 이상인 주문을 진행한 소비자의 ID(customer&#95;id)만 선택하는 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe180b880a7e7461e20c5c6"></a>

    ```sql
    select customer_id, amount
    from orders
    where amoumt >= 2;
    ```

1. <strong><code>orders</code></strong> 테이블에서 2023년 11월 2일 이후에 주문된 주문 수량(amount)이 2개 이상인 주문을 선택하는 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe1804ca56dcb9176b539c5"></a>

    ```sql
    select customer_id, amount, order_date
    from orders
    where amoumt >= 2 and order_date >= '2023-11-02'
    ```

1. <strong><code>orders</code></strong> 테이블에서 주문 수량이 3개 미만이면서 배송비(shipping&#95;fee)가 15000원보다 비싼 주문을 선택하는 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe180429bc7ce5c8734bd89"></a>

    ```sql
    select customer_id, amount, shipping_fee
    from orders
    where amoumt < 3 and shipping_fee > 15000
    ```

1. <strong><code>orders</code></strong> 테이블에서 배송비가 높은 금액 순으로 정렬하는 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe180ab8825de388a2ca9b5"></a>

    ```sql
    select *
    from orders
    order by shipping_fee desc
    ```
