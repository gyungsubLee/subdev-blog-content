## 문제

<a id="13beda9b0fe18039a779e8294940bd6e"></a>

# <strong><a href="https://leetcode.com/problems/most-common-word/">819&#46; Most Common Word</a></strong>

<a id="13beda9b0fe180a68952d15cc3be25fe"></a>

Given a string <code>paragraph</code> and a string array of the banned words <code>banned</code>, return <em>the most frequent word that is not banned</em>&#46; It is <strong>guaranteed</strong> there is <strong>at least one word</strong> that is not banned, and that the answer is <strong>unique</strong>&#46;

<a id="13beda9b0fe1802a9608d5bd404549a1"></a>

The words in <code>paragraph</code> are <strong>case&#45;insensitive</strong> and the answer should be returned in <strong>lowercase</strong>&#46;

<a id="13beda9b0fe1803bb465ed3625bea615"></a>

<strong>Example 1&#58;</strong>

<a id="13beda9b0fe1801ca6e1e8964e1b2a0f"></a>

```plaintext
Input: paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
Output: "ball"
Explanation:
"hit" occurs 3 times, but it is a banned word.
"ball" occurs twice (and no other word does), so it is the most frequent non-banned word in the paragraph.
Note that words in the paragraph are not case sensitive,
that punctuation is ignored (even if adjacent to words, such as "ball,"),
and that "hit" isn't the answer even though it occurs more because it is banned.

```

<a id="13beda9b0fe18013b53fec76cb1eaacd"></a>

<strong>Example 2&#58;</strong>

<a id="13beda9b0fe18021bcb8c0650fe7e945"></a>

```plaintext
Input: paragraph = "a.", banned = []
Output: "a"

```

<a id="13beda9b0fe18072b9e4d3c7c3955866"></a>

<strong>Constraints&#58;</strong>

- <code>1 &#60;= paragraph&#46;length &#60;= 1000</code>

- paragraph consists of English letters, space <code>&#39; &#39;</code>, or one of the symbols&#58; <code>&#34;&#33;?&#39;,;&#46;&#34;</code>&#46;

- <code>0 &#60;= banned&#46;length &#60;= 100</code>

- <code>1 &#60;= banned&#91;i&#93;&#46;length &#60;= 10</code>

- <code>banned&#91;i&#93;</code> consists of only lowercase English letters&#46;

## 풀이

<a id="13beda9b0fe18055b311ff7592cf6e00"></a>

### 풀이 1 &#45;  자바

<details>
<summary>🧐  <code>Collections<br></code>              <code>&#46;max(counts&#46;entrySet(),Map&#46;Entry&#46;comparingByValue())<br></code>              <code>&#46;getKey()</code></summary>

---

- <code>counts&#46;entrySet()</code>&#58; Map의 모든 엔트리(키&#45;값 쌍)를 Set 형태로 반환

- <code>Collections&#46;max()</code>&#58; 주어진 컬렉션에서 가장 큰 요소를 반환
    - 여기서는 <code>counts&#46;entrySet()</code>에서 <code>Map&#46;Entry&#46;comparingByValue()</code>를 기준으로 최대값을 찾음

- <code>Map&#46;Entry&#46;comparingByValue()</code>&#58; 값에 따라 엔트리를 비교하는 Comparator 제공

- <code>getKey()</code>&#58; 가장 큰 값의 키 반환<br><br>

</details>

<a id="13beda9b0fe18049b5bafca5dd676b28"></a>

```java
class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        // 금지어 목록이 String 배열이기 때문에, 비교 메서드(.contains())를 제공하는 Set으로 변경
        Set<String> ban = new HashSet<>(Arrays.asList(banned));
        
        Map<String, Integer> counts = new HashMap<>();

        String[] words = paragraph.replaceAll("\\W+", " ").toLowerCase().split(" ");

        for (String w : words) {
            if (!ban.contains(w)){
                counts.put(w, counts.getOrDefault(w, 0) +1); // 값이 없는 경우 0으로 초기화 or 있는 경우 +1
            }
        }
        
        return Collections.max(counts.entrySet(), Map.Entry.comparingByValue()).getKey();
    }
}
```

```java
import java.util.Map;
import java.util.HashMap;

class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        String[] words = paragraph.toLowerCase().replaceAll("[^a-z]", " ").split("\\s+");

        Set<String> bannedSet = new HashSet<>(List.of(banned));

        Map<String, Integer> map = new HashMap<>();
        String answer ="";
        int maxCount = 0;

        for(String word : words) {
            if(bannedSet.contains(word) || word.isEmpty()) continue;

            map.put(word, map.getOrDefault(word, 0) + 1);

            if (map.get(word) > maxCount) {
                maxCount = map.get(word);
                answer = word;
            }
        }
        return answer;
    }
}
```
