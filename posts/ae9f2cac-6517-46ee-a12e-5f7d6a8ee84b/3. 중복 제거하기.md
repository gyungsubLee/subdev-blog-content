## 문제

<a id="1cfeda9b0fe180498d1efedebcdbceb1"></a>

### <strong>문제 설명</strong>

<a id="1cfeda9b0fe180d188c4e0431d9eaa46"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1cfeda9b0fe18044be5ffb7c7c530def"></a>

동물 보호소에 들어온 동물의 이름은 몇 개인지 조회하는 SQL 문을 작성해주세요&#46; 이때 이름이 NULL인 경우는 집계하지 않으며 중복되는 이름은 하나로 칩니다&#46;

<a id="1cfeda9b0fe180009186caa64bceae57"></a>

### 예시

<a id="1cfeda9b0fe1806ab958f364c9925ebe"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A562649 | Dog | 2014&#45;03&#45;20 18&#58;06&#58;00 | Sick | NULL | Spayed Female |
| A412626 | Dog | 2016&#45;03&#45;13 11&#58;17&#58;00 | Normal | &#42;Sam | Neutered Male |
| A563492 | Dog | 2014&#45;10&#45;24 14&#58;45&#58;00 | Normal | &#42;Sam | Neutered Male |
| A513956 | Dog | 2017&#45;06&#45;14 11&#58;54&#58;00 | Normal | &#42;Sweetie | Spayed Female |

<a id="1cfeda9b0fe1807a99e9f11cd3bda09a"></a>

보호소에 들어온 동물의 이름은 NULL(없음), <code>&#42;Sam</code>, <code>&#42;Sam</code>, <code>&#42;Sweetie</code>입니다&#46; 이 중 NULL과 중복되는 이름을 고려하면, 보호소에 들어온 동물 이름의 수는 2입니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

<a id="1cfeda9b0fe180b88661ccd06caa6076"></a>

count

---

<a id="1cfeda9b0fe180c2a34ef2ace785d002"></a>

2

---

<a id="1cfeda9b0fe18010b522ecd569bd80ca"></a>

※ 컬럼 이름(위 예제에서는 count)은 일치하지 않아도 됩니다&#46;

<a id="1cfeda9b0fe18069837ccba36bd69529"></a>

## 풀이

<a id="1cfeda9b0fe1809d8d9ae635d4828ca6"></a>

### 1차 시도&#58;  fail

<a id="1cfeda9b0fe180c3aab6d03d42ff9374"></a>

```sql
SELECT DISTINCT COUNT(*) AS count
FROM ANIMAL_INS
WHERE NAME IS NOT NULL:
```

- <code>COUNT()</code>와 <code>DISTINCT</code> 키워드는 올바르게 사용했으나,  <br>COUNT 함수 외부에서 사용하여 카운팅된 결과에 DISTINCT가 적용되 중복 수에 대한 필터링이 제대로 이뤄지지 않았다&#46;

<a id="1cfeda9b0fe18053a0b5d331e2e01d06"></a>

### 2차 시도&#58; success

<a id="1cfeda9b0fe180948169e16c6914f576"></a>

```sql
SELECT COUNT(DISTINCT NAME) AS count
FROM ANIMAL_INS
WHERE NAME IS NOT NULL;
```
