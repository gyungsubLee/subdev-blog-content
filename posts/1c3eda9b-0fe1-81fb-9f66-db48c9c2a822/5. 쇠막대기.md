# 문제

<a id="1c3eda9b0fe1811c9852fbd65794d847"></a>

## <strong>5&#46; 쇠막대기</strong>

---

<a id="1c3eda9b0fe181639161fd0af670bc3c"></a>

### 설명

<a id="1c3eda9b0fe181cd88a8c9aeeb7b32ca"></a>

여러 개의 쇠막대기를 레이저로 절단하려고 한다&#46; 효율적인 작업을 위해서 쇠막대기를 아래에서 위로 겹쳐 놓고,

<a id="1c3eda9b0fe181f0af03e4e5e4a699fa"></a>

레이저를 위에서 수직으로 발사하여 쇠막대기들을 자른다&#46; 쇠막대기와 레이저의 배치는 다음 조건을 만족한다&#46;

- 쇠막대기는 자신보다 긴 쇠막대기 위에만 놓일 수 있다&#46; &#45; 쇠막대기를 다른 쇠막대기 위에 놓는 경우 완전히 포함되도록 놓되,

<a id="1c3eda9b0fe1817cb6e3e2efd86b74bf"></a>

끝점은 겹치지 않도록 놓는다&#46;

- 각 쇠막대기를 자르는 레이저는 적어도 하나 존재한다&#46;

- 레이저는 어떤 쇠막대기의 양 끝점과도 겹치지 않는다&#46;

<a id="1c3eda9b0fe18143b434d357d9a70ea0"></a>

아래 그림은 위 조건을 만족하는 예를 보여준다&#46; 수평으로 그려진 굵은 실선은 쇠막대기이고, 점은 레이저의 위치,

<a id="1c3eda9b0fe1815c8504c9f9b2c7313a"></a>

수직으로 그려진 점선 화살표는 레이저의 발사 방향이다&#46;

![](https://cote.inflearn.com/public/upload/35b4910834.jpg)

<a id="1c3eda9b0fe18109a6f0d66eaa6e6d64"></a>

이러한 레이저와 쇠막대기의 배치는 다음과 같이 괄호를 이용하여 왼쪽부터 순서대로 표현할 수 있다&#46;

<a id="1c3eda9b0fe181db9a7cd0ebaa15d0d4"></a>

1&#46; 레이저는 여는 괄호와 닫는 괄호의 인접한 쌍 ‘( ) ’ 으로 표현된다&#46; 또한, 모든 ‘( ) ’는 반 드시 레이저를 표현한다&#46;

<a id="1c3eda9b0fe181cf84aee4df28fed083"></a>

2&#46; 쇠막대기의 왼쪽 끝은 여는 괄호 ‘ ( ’ 로, 오른쪽 끝은 닫힌 괄호 ‘) ’ 로 표현된다&#46;

<a id="1c3eda9b0fe1816c8be1cc25b8dadc95"></a>

위 예의 괄호 표현은 그림 위에 주어져 있다&#46;

<a id="1c3eda9b0fe1812f945bf9032c7dcaba"></a>

쇠막대기는 레이저에 의해 몇 개의 조각으로 잘려지는데, 위 예에서 가장 위에 있는 두 개의 쇠막대기는 각각 3개와 2개의 조각으로 잘려지고,

<a id="1c3eda9b0fe1811f8f39ce9a148361a7"></a>

이와 같은 방식으로 주어진 쇠막대기들은 총 17개의 조각으로 잘려진다&#46;

<a id="1c3eda9b0fe18103adbcdeb91f777039"></a>

쇠막대기와 레이저의 배치를 나타내는 괄호 표현이 주어졌을 때, 잘려진 쇠막대기 조각의 총 개수를 구하는 프로그램을 작성하시오&#46;

<a id="1c3eda9b0fe1811fa53cc0d7cf25ca76"></a>

### 입력

<a id="1c3eda9b0fe181909c66cfb2aa65a4af"></a>

한 줄에 쇠막대기와 레이저의 배치를 나타내는 괄호 표현이 공백없이 주어진다&#46; 괄호 문자의 개수는 최대 100,000이다&#46;

<a id="1c3eda9b0fe181ea8870d550f451e20d"></a>

### 출력

<a id="1c3eda9b0fe1818aad5ddef0e764856b"></a>

잘려진 조각의 총 개수를 나타내는 정수를 한 줄에 출력한다&#46;

---

## 풀이1)

<a id="1c3eda9b0fe181d3a151c671712b136d"></a>

```java
import java.util.*;
public class Main {
    public int  solution(String str){
        int answer=0;
        Stack<Character> stack = new Stack<>();
        char[] arr=str.toCharArray();
        for(int i=0; i<arr.length; i++){
            char t = arr[i];
            if(t=='(') stack.push(t);
            else if(arr[i-1]!=t && t==')'){
                stack.pop();
                answer+=stack.size();
            }
            else {
                stack.pop();
                answer++;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.next();
        System.out.println(T.solution(str));
    }
}
```

import java.util.*;
public class Main {
    public int  solution(String str){
        int answer=0;
        Stack<Character> stack = new Stack<>();
        for(int i=0; i<str.length(); i++){
            if(str.charAt(i)=='(') stack.push('(');
            else{
                stack.pop();
                if(str.charAt(i-1)=='(') answer+=stack.size();
                else answer++;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.next();
        System.out.println(T.solution(str));
    }
}

### 풀이3) 2차 풀이

<a id="1c3eda9b0fe181b88fcdd7c4e25df6d0"></a>

prev 변수 생성, 이전 값 저장

<a id="1c3eda9b0fe18160939cd50746d48ec6"></a>

```java
import java.util.*;
public class Main {
    public int solution(char[] arr){
        int answer=0;
        char prev='(';
        Stack<Character> stack = new Stack<>();
        for(char x : arr){
            if(x==')'){
                if(prev==')'){
                    answer++;
                    stack.pop();
                }
                else {
                    stack.pop();
                    answer+=stack.size();
                }
            }
            else{
                stack.push(x);
            }
            prev=x;
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str = sc.next();
        System.out.println(T.solution(str.toCharArray()));
    }
}
```
