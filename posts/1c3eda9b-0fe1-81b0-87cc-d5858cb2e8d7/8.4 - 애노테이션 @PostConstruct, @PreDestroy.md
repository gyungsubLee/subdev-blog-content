## <strong>애노테이션 </strong><code>&#64;PostConstruct</code>, <code>&#64;PreDestroy</code>

---

> <code>&#64;PostConstruct</code>, <code>&#64;PreDestroy</code> 이 두 애노테이션을 사용하면 가장 편리하게 초기화 와 종료를 실행할 수 있다&#46;

<a id="1c3eda9b0fe1810b8199dcb74e2a9dc9"></a>

### NetworkClient

<a id="1c3eda9b0fe1813fb99ce1d6ad233e4d"></a>

```java
package hello.core.lifecycle;

import jakarta.annotation.PostConstruct;
import jakarta.annotation.PreDestroy;

public class NetworkClient {
    private String url;

    public NetworkClient() {
        System.out.println("생성자 호출, url = " + url);
    }

    public void setUrl(String url) {
        this.url = url;
    }

    //서비스 시작시 호출
    public void connect() {
        System.out.println("connect: " + url);
    }

    public void call(String message) {
        System.out.println("call: " + url + " message = " + message);
    }

    //서비스 종료시 호출
    public void disConnect() {
        System.out.println("close + " + url);
    }
    @PostConstruct
    public void init() {
        System.out.println("NetworkClient.init"); connect();
        call("초기화 연결 메시지");
    }

    @PreDestroy
    public void close() {
        System.out.println("NetworkClient.close");
        disConnect();
        }
    }
```

### <strong>&#64;PostConstruct, &#64;PreDestroy 애노테이션 특징</strong>

<a id="1c3eda9b0fe1811ebc81f0fdfae4298d"></a>

최신 스프링에서 가장 권장하는 방법으로 <strong>해당하는 애노테이션 하나만 붙</strong>이면 되므로 <strong>매우 편리</strong>하다&#46;

<a id="1c3eda9b0fe181f7ab87d5f0a013fbb1"></a>

<br>패키지를 잘 보면 <code>javax&#46;annotation&#46;PostConstruct</code>이다&#46; 스프링에 종속적인 기술이 아니라 <code>JSR&#45;250</code>라는 자바 표준이다&#46; 따라서 스프링이 아닌 다른 컨테이너에서도 동작한다&#46;

<a id="1c3eda9b0fe181329873fec523084825"></a>

애노테이션 하나로 자동으로 처리하기 때문에 컴포넌트 스캔과  잘 어울린다&#46; (유사?하다)

<a id="1c3eda9b0fe1813fbd51ccc43cb72763"></a>

<br>유일한 단점은 <strong>외부 라이브러리에는 적용하지 못</strong>한다는 것이다&#46;

<a id="1c3eda9b0fe1819cbdbec7991441a0e7"></a>

→  외부 라이브러리를 초기화, 종료해야한다면,  <a href="#/post/1c3eda9b-0fe1-8167-8069-db2a9f35c681">페이지</a> 사용
