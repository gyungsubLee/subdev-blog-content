## 멀티 쓰레드

---

> 📖 
> 
> <a id="1ceeda9b0fe1804193e6c76477b00eff"></a>
> 
> Java는 메인 쓰레드가 <code>main()</code> 메서드를 실행시키면서 시작된다&#46; 
> 
> - 메인 쓰레드는 필요에 따라 작업 쓰레드들을 생성해 병렬로 코드를 실행시킬 수 있다&#46; 
>     <a id="1ceeda9b0fe1809fb5a5c95398694e34"></a>
> 
>      → 멀티 쓰레드 지원

<details>
<summary>싱글 쓰레드</summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe180b79097cad06fdf48ab"></a>
> 
> 프로세스 안에서 하나의 쓰레드만 실행되는 것을 의미

- Java 프로그램의 경우 <code>main()</code> 메서드만 실행시켰을 때, 싱글 쓰레드 라고 한다&#46;
    - 예제로 학습했던 코드들은 모두 main 메서드만 실행했다&#46; <br>즉, 모두 싱글 쓰레드로 실행 됐다&#46;

    - Java 프로그램 <code>main()</code> 메서드의 쓰레드를 ‘메인 쓰레드’라고 부른다&#46;

    - JVM의 메인 쓰레드가 종료되면, JVM도 같이 종료된다&#46;

</details>

<details>
<summary>멀티 쓰레드 </summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe1808a8f74d2ef79a941e8"></a>
> 
> 프로세스 안에서 여러 개의 쓰레드가 실행되는 것을 의미한다&#46; 

- 하나의 프로세스는 여러 개의 실행 단위(쓰레드)를 가질 수 있으며, 해당 쓰레드들은 프로세스의 자원을 공유한다&#46;

- Java 프로그램은 메인 쓰레드 외 다른 작업 쓰레드들을 생서앟여 여러 개의 실행 흐름을 만들 수 있다&#46;  → 멀티 쓰레드

---

<details>
<summary>장점</summary>

- 여러 개의 쓰레드(실행 흐름)을 통해 여러 작업을 동시에 할 수  있기 때문에 성능이 좋아진다&#46; 

- 스택을 제외한 모든 영역에서 메모리를 공유하기 떄문에 자원을 보다 효율적으로 사용 가능하다&#46; 

- 응답 쓰레드와 작업 쓰레드를 분리하여 빠르게 응답응 줄 수 있다&#46; ( 비동기 )

</details>

<details>
<summary>단점</summary>

- 동기화 문제가 발생될 수 있다&#46;
    - 프로세스의 자원을 공유하면서 작업을 처리하기 때문에 자원을 서로 사용하려고 하는 충돌이 발생된다&#46;

- 교착 상태(데드락)이 발생할 수 있다&#46; 
    - 둘 이상의 쓰레드가 서로의 자원을 원하는 상태가 되었을 때 서로 작업이 종료되기만을 기다리며 더 이상 진행하지 못하게 되는 상태를 의미한다&#46; 

</details>

</details>
