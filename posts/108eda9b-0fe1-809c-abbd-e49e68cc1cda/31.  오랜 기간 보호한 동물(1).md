## 문제

<a id="10ceda9b0fe1808f9664ddafa9810e24"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="10ceda9b0fe18064b05df746b48c4dc7"></a>

<code>ANIMAL&#95;OUTS</code> 테이블은 동물 보호소에서 입양 보낸 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;OUTS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;OUTCOME</code>는 각각 동물의 아이디, 생물 종, 입양일, 이름, 성별 및 중성화 여부를 나타냅니다&#46; <code>ANIMAL&#95;OUTS</code> 테이블의 <code>ANIMAL&#95;ID</code>는 <code>ANIMAL&#95;INS</code>의 <code>ANIMAL&#95;ID</code>의 외래 키입니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;OUTCOME | VARCHAR(N) | FALSE |

<a id="10ceda9b0fe1801395fceb3213337b72"></a>

아직 입양을 못 간 동물 중, 가장 오래 보호소에 있었던 동물 3마리의 이름과 보호 시작일을 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 보호 시작일 순으로 조회해야 합니다&#46;

<a id="10ceda9b0fe1809a93ced8ec1e3e83a2"></a>

### 예시

<a id="10ceda9b0fe180a48f7dc402886b4968"></a>

예를 들어, <code>ANIMAL&#95;INS</code> 테이블과 <code>ANIMAL&#95;OUTS</code> 테이블이 다음과 같다면

<code>ANIMAL&#95;INS</code>

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A354597 | Cat | 2014&#45;05&#45;02 12&#58;16&#58;00 | Normal | Ariel | Spayed Female |
| A373687 | Dog | 2014&#45;03&#45;20 12&#58;31&#58;00 | Normal | Rosie | Spayed Female |
| A412697 | Dog | 2016&#45;01&#45;03 16&#58;25&#58;00 | Normal | Jackie | Neutered Male |
| A413789 | Dog | 2016&#45;04&#45;19 13&#58;28&#58;00 | Normal | Benji | Spayed Female |
| A414198 | Dog | 2015&#45;01&#45;29 15&#58;01&#58;00 | Normal | Shelly | Spayed Female |
| A368930 | Dog | 2014&#45;06&#45;08 13&#58;20&#58;00 | Normal |  | Spayed Female |

<a id="10ceda9b0fe180579702d38a4e3484d0"></a>

<code>ANIMAL&#95;OUTS</code>

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | NAME | SEX&#95;UPON&#95;OUTCOME |
| A354597 | Cat | 2014&#45;05&#45;02 12&#58;16&#58;00 | Ariel | Spayed Female |
| A373687 | Dog | 2014&#45;03&#45;20 12&#58;31&#58;00 | Rosie | Spayed Female |
| A368930 | Dog | 2014&#45;06&#45;13 15&#58;52&#58;00 |  | Spayed Female |

<a id="10ceda9b0fe18024bd8afd051acc66bb"></a>

SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| NAME | DATETIME |
| Shelly | 2015&#45;01&#45;29 15&#58;01&#58;00 |
| Jackie | 2016&#45;01&#45;03 16&#58;25&#58;00 |
| Benji | 2016&#45;04&#45;19 13&#58;28&#58;00 |

<a id="10ceda9b0fe18087a92dc067d2de4b58"></a>

※ 입양을 가지 못한 동물이 3마리 이상인 경우만 입력으로 주어집니다&#46;

<a id="fffeda9b0fe181d0aac7e4a87ad68964"></a>

## 풀이

- <code>not in</code>

- <code>subquery</code>

- <code>limit</code>

<a id="10ceda9b0fe180f78f46ca1ee94bbede"></a>

<strong>SQL Query</strong>

<a id="10ceda9b0fe180d9b3a3ca5fc6968cd8"></a>

```sql
SELECT NAME, DATETIME
FROM ANIMAL_INS
WHERE ANIMAL_ID NOT IN ( SELECT ANIMAL_ID FROM ANIMAL_OUTS)
ORDER BY DATETIME
LIMIT 3
```
