# 문제

<a id="1c3eda9b0fe181f291ede40bcf85512f"></a>

## <strong>5&#46; 중복 확인</strong>

---

<a id="1c3eda9b0fe18198a8d7e66ffb8299ca"></a>

### 설명

<a id="1c3eda9b0fe181c9a5b2f3fc6320d804"></a>

현수네 반에는 N명의 학생들이 있습니다&#46;

<a id="1c3eda9b0fe181e59e62fed61a62e895"></a>

선생님은 반 학생들에게 1부터 10,000,000까지의 자연수 중에서 각자가 좋아하는 숫자 하나 적어 내라고 했습니다&#46;

<a id="1c3eda9b0fe1818f9997cc413980671c"></a>

만약 N명의 학생들이 적어낸 숫자 중 중복된 숫자가 존재하면 D(duplication)를 출력하고,

<a id="1c3eda9b0fe181ed8735e990babeb679"></a>

N명이 모두 각자 다른 숫자를 적어냈다면 U(unique)를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1811e8935d7e922b208f6"></a>

### 입력

<a id="1c3eda9b0fe181f390b2f6c3aa0e21ef"></a>

첫 번째 줄에 자연수 N(5&#60;=N&#60;=100,000)이 주어진다&#46;

<a id="1c3eda9b0fe181218610dd44b1dfb883"></a>

두 번째 줄에 학생들이 적어 낸 N개의 자연수가 입력된다&#46;

<a id="1c3eda9b0fe18195843ffb1f19aba5f4"></a>

### 출력

<a id="1c3eda9b0fe181ce8543e2f67ce37e15"></a>

첫 번째 줄에 D 또는 U를 출력한다&#46;

---

<a id="1c3eda9b0fe1815da64ac6c90fb3257e"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181d28dd7eb1da77a2b16"></a>

```plaintext
8
20 25 52 30 39 33 43 33

```

<a id="1c3eda9b0fe18162ab26c98facec0971"></a>

### 예시 출력 1

<a id="1c3eda9b0fe1810e8e7bdfe9083301a5"></a>

```plaintext
D
```

<a id="1c3eda9b0fe181d49739d58ec8742d4a"></a>

# 풀이

<a id="1c3eda9b0fe18186bc18cede4bd7fae3"></a>

## 풀이1) <code>내 풀이</code>  문자열&#58; 중복 문자와  풀이 동일

<a id="1c3eda9b0fe181cf9cc5cf690cf46bf1"></a>

```java
import java.util.*;

public class Main {
    public String solution(int n, int[] arr) {
        ArrayList<Integer> include=new ArrayList<>();
        for(int x : arr){
            if(include.contains(x)) return "D";
            include.add(x);
        }
        return "U";
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        System.out.print(T.solution(n, arr));
    }
}
```

<a id="1c3eda9b0fe1815dbd7af3d4be5c1957"></a>

## 풀이2) <code>강의 풀이</code>  sort()

<a id="1c3eda9b0fe1815a94a4d4ae1b9ccbe9"></a>

```java
import java.util.*;

public class Main {
    public String solution(int n, int[] arr) {
        Arrays.sort(arr);
        for(int i=0; i<n-1; i++){
            if(arr[i]==arr[i+1]) return"D";
        }
        return "U";
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        System.out.print(T.solution(n, arr));
    }
}
```
