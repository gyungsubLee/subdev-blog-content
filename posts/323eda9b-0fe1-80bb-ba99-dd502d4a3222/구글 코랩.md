> 코랩 코드 실행 도중 interaction이 90분 없으면 런타임이 끊긴다&#46; 따라서 런타임 끊김 방지용 코드를 실행시키는 방식으로 연결을 유지한다&#46;

1. 브라우저의 개발자 도구 창을 켠다&#46; (맥 크롬 기준 우클릭&#45;&#62;검사 버튼 누르면 바로 뜬다)

1. 콘솔 창을 연다&#46;

1. 아래 코드를 입력한다&#46;

<a id="323eda9b0fe180e09c32f633a3f36545"></a>

```javascript
function ClickConnect(){
  colab.config
  console.log("Connnect Clicked - Start"); 
  document.querySelector("#top-toolbar > colab-connect-button").shadowRoot.querySelector("#connect").click();
  console.log("Connnect Clicked - End");
};
setInterval(ClickConnect, 60000)
```

- 60초마다 한번씩 코랩의 리소스 창 버튼을 클릭한다&#46; <br>그리고 콘솔 창에 클릭이 이루어졌을 때 출력을 보여줌

### 구글 드라이브 마운트

<a id="323eda9b0fe180119d68c9e16e06f243"></a>

```python
from google.colab import drive
import os

# 1. 드라이브 전체를 기본 경로에 마운트 (이 경로는 고정해서 쓰는 게 좋습니다)
drive.mount('/content/drive')

# 2. 내가 작업하고 싶은 특정 폴더로 경로 설정
path = '/content/drive/MyDrive/vectorDB/06.Fashion_rec/'

# 해당 경로가 진짜 있는지 확인 후 설정한 경로로 이동
if os.path.exists(path):
    os.chdir(path)
    print(f"현재 작업 경로: {os.getcwd()}")
else:
    print("경로를 찾을 수 없습니다. 폴더명이나 대소문자를 확인해주세요!")
```
