<a id="3b1eda9b0fe18075aa73c6558137b58c"></a>

###  요구사항 &#45; 해외 직구 쇼핑몰

- 해외 직구를 위한 <strong><u>원화 결제 준비 기능</u></strong> 개발

- <code>주문 번호</code>, <code>외국 통화 종류</code>, <code>외국 통화 기준 결제 금액</code>을 전달 받아서 아래 정보를 더해 Payment를 생성한다&#46; 
    - <code>적용 환율</code>
        - 원화 대비 환율 계산 금액

    - <code>원화 환산 금액</code>
        - 원화로 결제할 금액

    - <code> </code>
        - 원화로 환산한 금액 과 이 환율을 몇 분(초) 동안 유효한지 시간 설정

- <code>PaymentService&#46;prepare()</code> 메소드로 개발
    - Payment 오브젝트 리턴

<a id="3b1eda9b0fe18043a654c31a8ea1f942"></a>

###  개발 방법

> ✏️ 
> 
> <a id="3b1eda9b0fe180a097c3c85a563646a8"></a>
> 
> 한번에 <strong><u>모든 걸 개발</u></strong>하면 <strong>시스템이 정상 동작하기도 어렵</strong>고 이를 <strong>디버깅하는 것은 더 어렵</strong>다&#46; 
> 
> <a id="3b1eda9b0fe18000bcb0c7bc9ac66afa"></a>
> 
> 따라서 <strong><u>전체 작업을 쪼개 가장 단순한 작은 스텝부터 진행</u></strong>하는 것을 권장한다&#46; 
> 
> <a id="3b1eda9b0fe1806cb4f0ec41c007961f"></a>
> 
> 즉, 전체 기능 내에서 <strong><u>추적 및 검증 가능한 작업 단위로 나눠</u></strong> 개발을 진행하는 것 이다&#46; 

1. 한번에 너무 큰 단위로 개발을 하지 않는다&#46; 
    - 개발 요구사항을 작은 스텝으로 쪼갠다&#46; 
        <a id="3b1eda9b0fe180bb9dc3d17b23587deb"></a>

        → 개발 → 개선점 찾고 개선 

    - 다음 개발

1. 개발한 기능에 대해서 동작 검증
    - 서버 실행 후 API 테스트 

    - 테스트 코드 작성 후 테스트 실행

1. 조금씩 기능을 추가하고 다시 검증한다&#46; 

1. 코드를 한눈에 이해하기 힘들면 코멘트를 추가한다&#46; 
    - 평소에 많이 쓰지 않은 어려운 코드 작업 같은 경우 나중에 읽었을 때 빠르게 이해하기 위해서 주석을 더해서 설명을 추가한다&#46;
