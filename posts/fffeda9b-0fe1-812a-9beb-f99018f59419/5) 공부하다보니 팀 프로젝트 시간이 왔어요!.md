공부를 한 결과를 점검하기 위해 팀 프로젝트를 수행해야 합니다&#33; 이제, 아래와 같은 team&#95;projects(프로젝트) 테이블이 있습니다&#46; 

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| id | name | start&#95;date | end&#95;date | aws&#95;cost |
| 1 | 일조 | 2023&#45;01&#45;01 | 2023&#45;01&#45;07 | 30000 |
| 2 | 꿈꾸는이조 | 2023&#45;03&#45;15 | 2023&#45;03&#45;22 | 50000 |
| 3 | 보람삼조 | 2023&#45;11&#45;20 | 2023&#45;11&#45;30 | 80000 |
| 4 | 사조참치 | 2022&#45;07&#45;01 | 2022&#45;07&#45;30 | 75000 |

1. <strong><code>team&#95;projects</code></strong><strong> </strong>테이블에서 AWS 예산(aws&#95;cost)이 40000 이상 들어간 프로젝트들의 이름을 선택하는 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe180419740f0633a02cde7"></a>

    ```sql
    select name
    from team_projects
    where aws_cost >= 40000
    ```

1. <strong><code>team&#95;projects</code></strong><strong> </strong>테이블에서 2022년에 시작된 프로젝트를 선택하는 쿼리를 작성해주세요&#33; 단, <strong><u>start&#95;date &#60; ‘2023&#45;01&#45;01’</u></strong> 조건을 <strong>사용하지 말고</strong> 쿼리를 작성해주세요&#33;
    <a id="10ceda9b0fe1807d9916c481d9766661"></a>

    ```sql
    select *
    from team_projects
    where start_date like '2022%'
    ```

1. <strong><code>team&#95;projects</code></strong><strong> </strong>테이블에서 현재 진행중인 프로젝트를 선택하는 쿼리를 작성해주세요&#46; 단, 지금 시점의 날짜를 하드코딩해서 쿼리하지 말아주세요&#33;
    > 현재 진행 중 ⇒ 판단을 할 날짜 데이터가 주어지지 않음,  따라서 구할 수 없음

    <a id="10ceda9b0fe18013a08ed2acbf49bc5a"></a>

    아마 2023년에 만들어진 문제인 듯? 문제 오류임

1. <strong><code>team&#95;projects</code></strong><strong> </strong>테이블에서 각 프로젝트의 지속 기간을 일 수로 계산하는 쿼리를 작성해주세요&#33;
    <details>
    <summary>🧐 날짜 &#91; 시작 &#45; 끝 &#93;  지속 기간 구하기 &#58;  <code>DATEDIFF</code></summary>

    <a id="10ceda9b0fe180cbbf1bed5975bee78b"></a>

    ```sql
    DATEDIFF(end_date, start_date)
    ```

    </details>

    <a id="10ceda9b0fe18036b9d1c7cd24f2f537"></a>

    ```sql
    SELECT 
        id, 
        name, 
        start_date, 
        end_date, 
        DATEDIFF(end_date, start_date) AS project_duration
    FROM 
        team_projects;
    ```
