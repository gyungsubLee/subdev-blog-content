## application&#46;properties &#45; &#46;gitignore 등록

---

<a id="1c3eda9b0fe181c5b554dbe773e7ba08"></a>

처음 프로젝트 생성 시, 데이터베이스의 설정 정보를 저장하는  <code>application&#46;properties</code>가<strong> </strong><strong>git add 상태가 되어 스테이징 에리어에 올리가 있</strong>다&#46; 따라서 <strong>해당 파일을 git reset 을 통해 add 취소</strong>를 해줘야 한다&#46; 

<a id="1c3eda9b0fe1819bb659c417247b3884"></a>

```java
git reset HEAD src/main/resources/application.properties
```
