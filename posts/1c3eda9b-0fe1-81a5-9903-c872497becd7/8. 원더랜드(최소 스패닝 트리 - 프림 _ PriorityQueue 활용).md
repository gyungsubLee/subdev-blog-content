# 문제

<a id="1c3eda9b0fe1814da634cecab49055ee"></a>

## <strong>7&#46; 원더랜드(최소스패닝트리)</strong>

<a id="1c3eda9b0fe18133bc41c08155543937"></a>

### 설명

<a id="1c3eda9b0fe181039e20dc5f8825e8dc"></a>

원더랜드에 문제가 생겼다&#46; 원더랜드의 각 도로를 유지보수하는 재정이 바닥난 것이다&#46;

<a id="1c3eda9b0fe1814eb701da6ca85dfacf"></a>

원더랜드는 모든 도시를 서로 연결하면서 최소의 유지비용이 들도록 도로를 선택하고 나머지 도로는 폐쇄하려고 한다&#46;

<a id="1c3eda9b0fe181bbb245c2aa0aabbae6"></a>

아래의 그림은 그 한 예를 설명하는 그림이다&#46;

![](https://cote.inflearn.com/public/upload/7d06ee1336.jpg)

<a id="1c3eda9b0fe18141ab96e9d8c9c552db"></a>

위의 지도는 각 도시가 1부터 9로 표현되었고, 지도의 오른쪽은 최소비용 196으로 모든 도시를 연결하는 방법을 찾아낸 것이다&#46;

<a id="1c3eda9b0fe1819fa4a9dd19e8908483"></a>

### 입력

<a id="1c3eda9b0fe181d08239c68a7fe51da3"></a>

첫째 줄에 도시의 개수 V(1≤V≤100)와 도로의 개수 E(1≤E≤1,000)가 주어진다&#46;

<a id="1c3eda9b0fe1811b873ad339df8af39b"></a>

다음 E개의 줄에는 각 도로에 대한 정보를 나타내는 세 정수 A, B, C가 주어진다&#46;

<a id="1c3eda9b0fe181d09ce4dfe7d1175b2c"></a>

이는 A번 도시와 B번 도시가 유지비용이 C인 도로로 연결되어 있다는 의미이다&#46;

<a id="1c3eda9b0fe18171847de63529bdc5d7"></a>

### 출력

<a id="1c3eda9b0fe181678d16f4fe875d32e3"></a>

모든 도시를 연결하면서 드는 최소비용을 출려한다&#46;

# 풀이

<a id="1c3eda9b0fe1813482f7d6e0123e141e"></a>

## 풀이1)<strong><code>최소 스패닝 트리</code></strong><strong> , </strong><strong><code>priorityQueue</code></strong>

<a id="1c3eda9b0fe1819b95e8ece63780b35a"></a>

```java
import java.util.*;

class Edge implements Comparable<Edge>{
    int vex, cost;
    Edge(int vex, int cost){
        this.vex = vex;
        this.cost = cost;
    }

    @Override
    public int compareTo(Edge o){
        return this.cost - o.cost;
    }
}

public class Main {
    static int answer=0;
    static int[] ch;
    static ArrayList<ArrayList<Edge>> graph=new ArrayList<>();

    public void Solution(int v){
        PriorityQueue<Edge> pQ= new PriorityQueue<>();
        pQ.offer(new Edge(v, 0));
        while(!pQ.isEmpty()) {
            Edge tmp = pQ.poll();
            int ev=tmp.vex;
            if(ch[ev]==0){
                ch[ev]=1;
                answer += tmp.cost;
                for(Edge ob : graph.get(ev)) if(ch[ob.vex]!=1) pQ.offer(new Edge(ob.vex, ob.cost));
            }
        }
    }

    public static void main(String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        ch= new int[n+1];
        for(int i=0; i<=n; i++) graph.add(new ArrayList<>());
        for(int i=0; i<m; i++){
            int a = sc.nextInt();
            int b = sc.nextInt();
            int c = sc.nextInt();
            graph.get(a).add(new Edge(b, c));
            graph.get(b).add(new Edge(a, c));
        }
        T.Solution(1);
        System.out.println(answer);
    }
}
```
