IntStream.range(0, a.length).map(()-> ... )

### 스프링 &#45; Bean Validation ( <code>&#64;Valid</code> )

---

> <a href="#/post/138eda9b-0fe1-80e9-b72d-cef85dc88546">페이지</a> 

<a id="13beda9b0fe1802f8c68d9cd4365475e"></a>

이번 과제에서 추가 학습을  피드백 받은 개념이다&#46;<br> 과제 진행 시, <code>NullPointException</code>을 if 문으로 처리 했었다&#46; 그러나 해당 방법은 중복되는 로직이 많고, <strong>검증  로직이 각 계층에 분리</strong> 되어있어 로직을 추적하기 어렵게 하는 좋지 않은 방식이라고 한다&#46; 

<a id="13beda9b0fe180aaa658dd079c30949a"></a>

이를 스프링에서는 <u>Bean Validation(</u><u><code>&#64;Valid</code></u><u>)</u> 통해 <u>검증 로직을 통합</u>하고, <u>Layer에서 분리</u>함으로써 해결하는데, 이에 대한 내용을 정리했다&#46; 

<a id="13beda9b0fe180c385b9f4dc663133ef"></a>

전에 강의를 보면서 무지성으로 따라 쳐본적이 있는데 그래서 그런지 거의 내용을 몰랐다&#46; <br>이번 기회에 간단하게 튜터님이 추천해주신 자료를 참고해 <u>내부 동작 방식</u>이나 <u>사용법</u>에 대해서  정리를 하니 어느 정도  <code>&#64;Valid</code>를 활용한 검증 방법이 얼마나 코드의 유지보수성과 가독성에 도움이 되는지 이해할 수 있었다&#46; 

<a id="13beda9b0fe180ca9780d6d86fb4c7b6"></a>

→ 추가 학습 필요함
