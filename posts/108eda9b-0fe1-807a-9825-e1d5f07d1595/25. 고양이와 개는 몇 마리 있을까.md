## 문제

<a id="1d2eda9b0fe1809ab128d79adde55e2c"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe18038ba56faa491d356f8"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d2eda9b0fe1808a95cee366a912bb8d"></a>

동물 보호소에 들어온 동물 중 고양이와 개가 각각 몇 마리인지 조회하는 SQL문을 작성해주세요&#46; 이때 고양이를 개보다 먼저 조회해주세요&#46;

<a id="1d2eda9b0fe1804498c7dbd205c0f672"></a>

### 예시

<a id="1d2eda9b0fe180b3b470d86e8419e972"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A373219 | Cat | 2014&#45;07&#45;29 11&#58;43&#58;00 | Normal | Ella | Spayed Female |
| A377750 | Dog | 2017&#45;10&#45;25 17&#58;17&#58;00 | Normal | Lucy | Spayed Female |
| A354540 | Cat | 2014&#45;12&#45;11 11&#58;48&#58;00 | Normal | Tux | Neutered Male |

<a id="1d2eda9b0fe180ad8bedf2847fd8d817"></a>

고양이는 2마리, 개는 1마리 들어왔습니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| ANIMAL&#95;TYPE | count |
| Cat | 2 |
| Dog | 1 |

<a id="1d2eda9b0fe180769840f424351fdc97"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe18013adb9ec32d5117ea7"></a>
> 
> 조건
> 
> - 물 보호소에 들어온 동물 중 고양이와 개가 각각 몇 마리인지 조회
> 
> - 고양이를 개보다 먼저 조회

<a id="1d2eda9b0fe1805bb902c96dcca73625"></a>

```sql
SELECT 
    ANIMAL_TYPE,
    COUNT(*) count
FROM ANIMAL_INS
GROUP BY ANIMAL_TYPE
ORDER BY ANIMAL_TYPE;
```
