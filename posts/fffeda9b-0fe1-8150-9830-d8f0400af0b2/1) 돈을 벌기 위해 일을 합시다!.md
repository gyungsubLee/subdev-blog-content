> ⚡ <strong>실제 데이터 베이스를 연결하기 전, SQL 문법을 탄탄하게 다져봅시다&#46; </strong>

<a id="fffeda9b0fe181cf90fde56c051c6744"></a>

아래와 같은 sparta&#95;employees(직원) 테이블이 있습니다&#46;

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| id | name | position | salary | hire&#95;date |
| 1 | 르탄이 | 개발자 | 30000 | 2022&#45;05&#45;01 |
| 2 | 배캠이 | PM | 40000 | 2021&#45;09&#45;25 |
| 3 | 구구이 | 파트장 | 35000 | 2023&#45;06&#45;01 |
| 4 | 이션이 | 팀장 | 50000 | 2021&#45;07&#45;09 |

1. <strong><code>sparta&#95;employees</code></strong> 테이블에서 모든 직원의 이름(name)과 직급(position)을 선택하는 쿼리를 작성해주세요&#46;
    <a id="10ceda9b0fe18032bce6cfb85a34f0ed"></a>

    ```sql
    select name '이름', 
    			 position '직급'
    from sparta_employees
    ```

1. <strong><code>sparta&#95;employees</code></strong> 테이블에서 중복 없이 모든 직급(position)을 선택하는 쿼리를 작성해주세요&#46;
    <a id="fffeda9b0fe1810da737d5676975ef1d"></a>

    ```sql
    select distinct position '직급'
    from sparta_employees
    ```

1. <strong><code>sparta&#95;employees</code></strong> 테이블에서 연봉(salary)이 40000과 60000 사이인 직원들을 선택하는 쿼리를 작성해주세요&#46;
    <a id="10ceda9b0fe18033af42e9fad62b9454"></a>

    ```sql
    select name,
    			 salary
    from sparta_employees
    where salary between 40000 and 60000;
    ```

1. <strong><code>sparta&#95;employees</code></strong> 테이블에서 입사일(hire&#95;date)이 2023년 1월 1일 이전인 모든 직원들을 선택하는 쿼리를 작성해주세요&#46;
    <a id="10ceda9b0fe180709e6dfb415aaf2925"></a>

    ```sql
    select name,
    			 hire_date
    from sparta_employees
    where hire_date '2022%' or '2021%';
    ```
