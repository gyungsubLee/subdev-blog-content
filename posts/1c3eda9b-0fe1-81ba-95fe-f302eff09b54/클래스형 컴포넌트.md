## 클래스형 컴포넌트 

---

> 📖 
> 
> <a id="1c3eda9b0fe1811ea1e2ed2887cb8e7b"></a>
> 
> 클래스 문법으로 구현한 컴포넌트, 리액트 16&#46;8 버전 이전에는 기본으로 사용하였다&#46;

<details>
<summary>클래스형 컴포넌트</summary>

> 클래스 문법으로 구현한 컴포넌트

<a id="1c3eda9b0fe181d89fc5ee60f02c58eb"></a>

useState와 같은 Hooks는 React 버전 16&#46;8 부터 등장했다&#46;

<a id="1c3eda9b0fe181219174cc636fb52167"></a>

즉, <u>그 전에는 함수형 컴포넌트에서 state를 사용할 수 없</u>었고, <strong><u>클래스형 컴포넌트만 state를 가질 수 있</u></strong>었다&#46;

- 클래스의 멤버 변수로 state 정의

- render라는 멤버 함수에서 반환한 값(JSX)이 화면에 그려졌다&#46;

---

<details>
<summary>&#91; 코드 &#93; App&#46;js ( 이전 함수형 코드와 동일 </summary>

<a id="1c3eda9b0fe18141a06ad5f7aa67a5ae"></a>

```javascript
import React, { Component } from "react";

export default class App extends Component {
  state = {
    value: 0,
  };

  constructor(props) {
    super(props);
    this.state = {
      value: 1,
    };
  }

  resetValue() {
    this.setState({ value: 0 });
  }

  render() {
    return (
      <div>
        <h1>value: {this.state.value}</h1>
        <button
          onClick={() => {
            this.setState((state) => ({
              value: state.value + 1,
            }));
          }}
        >
          Increate value
        </button>
        <button onClick={this.resetValue.bind(this)}>Reset</button>
      </div>
    );
  }
}
```

</details>

</details>

<details>
<summary><strong>클래스형 컴포넌트의 문제점</strong></summary>

<a id="1c3eda9b0fe181f1a2fbd957b9e2914a"></a>

초기에는 클래스형 컴포넌트를 기본으로 사용하였으나, 몇가지 문제점이 있었다&#46;

- <u>규모가 커</u>지면 <u>복잡한 라이프 사이클</u>로 코드를 이해하기 어렵다&#46;

- <u>코드 재사용성</u>이 떨어진다&#46;

<a id="1c3eda9b0fe1819ca66eed1ecc2039ec"></a>

<u>위와 같은 문제점을 해결</u>하기 위해 나온 방식이 <strong><u>함수형 컴포넌트</u></strong> 이다&#46;

</details>
