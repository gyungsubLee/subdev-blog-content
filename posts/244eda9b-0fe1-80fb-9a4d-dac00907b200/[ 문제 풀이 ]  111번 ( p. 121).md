## 문제

<a id="244eda9b0fe18097a3abc65e11ee8fb4"></a>

<strong>&#91; 표 &#93;</strong>

| COL1 | COL2 |
| --- | --- |
| 1111 | AAAA |
| 1111 | AAAA |
| 1111 | AAAA |
| 1111 | BBBB |

<a id="244eda9b0fe1812e9eb4f580ab9abbbc"></a>

<strong>&#91; SQL &#93;</strong>

<a id="244eda9b0fe1805eb7b7e7d1ce34e2a7"></a>

```sql
SELECT 
	COUNT(COL1) AS CNT1, 
	COUNT(COL2) AS CNT2,
FROM (
	SELECT DISTINCT COL1, COL2
	FROM T1
)
```

<a id="244eda9b0fe18036a7e0c691b9001716"></a>

### 풀이

<a id="244eda9b0fe18034be8ee241cfb3bc36"></a>

```sql
WITH T1 AS (
	SELECT 1 col1, 'AAAA' col2 FROM dual UNION ALL
	SELECT 1, 'AAAA' FROM dual UNION ALL
	SELECT 1, 'AAAA' FROM dual UNION ALL
	SELECT 2, 'AAAA' FROM dual UNION ALL
)
SELECT COUNT(col1) AS CNT1, COUNT(col2) AS CNT2
FROM (
	SELECT DISTINCT col1, col2 FROM T1
)
```

> ✏️ 
> 
> <a id="244eda9b0fe18076bf01dce79c50b19a"></a>
> 
> <code>DISTINCT</code> 키워드는 뒤에 나열된 여러 열들의 값 전체를 하나의 조합으로 보고, <br>그 조합이 고유한 경우에만 해당 행을 결과로 포함시킨다&#46; 
> 
> <a id="244eda9b0fe1804d83bcf34138b83c7d"></a>
> 
> 따라서 위 문제의 경우,<code>1111, AAAA</code>,  <code>1111, BBBB</code>를 고유한 값으로 판단해 
> 
> <a id="244eda9b0fe180f4bbc3ef3e4326f0bc"></a>
> 
> 각각 2개의 카운팅이 발생된다&#46;
