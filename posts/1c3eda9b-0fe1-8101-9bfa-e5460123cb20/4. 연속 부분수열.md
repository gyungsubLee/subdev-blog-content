# 문제

<a id="1c3eda9b0fe181e8afebc9f1518b64fc"></a>

## 4&#46; 연속 부분수열

---

<a id="1c3eda9b0fe18107a3d6dde3222dd04c"></a>

### 설명

<a id="1c3eda9b0fe18181b4f8e656daadca4b"></a>

N개의 수로 이루어진 수열이 주어집니다&#46;

<a id="1c3eda9b0fe1815783a6f46689e86813"></a>

이 수열에서 연속부분수열의 합이 특정숫자 M이 되는 경우가 몇 번 있는지 구하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181949370c3217adba346"></a>

만약 N=8, M=6이고 수열이 다음과 같다면

<a id="1c3eda9b0fe181b8841efe89af566dcd"></a>

1 2 1 3 1 1 1 2

<a id="1c3eda9b0fe181dbad93c5ea290f405b"></a>

합이 6이 되는 연속부분수열은 {2, 1, 3}, {1, 3, 1, 1}, {3, 1, 1, 1}로 총 3가지입니다&#46;

<a id="1c3eda9b0fe1814c93c7e79acfbfe0e2"></a>

### 입력

<a id="1c3eda9b0fe181049014f10df9582ed5"></a>

첫째 줄에 N(1≤N≤100,000), M(1≤M≤100,000,000)이 주어진다&#46;

<a id="1c3eda9b0fe181678a69fcee00d5abdb"></a>

수열의 원소값은 1,000을 넘지 않는 자연수이다&#46;

<a id="1c3eda9b0fe1816e99b0fd127d43dbfc"></a>

### 출력

<a id="1c3eda9b0fe181b6af36d26a6f890ae7"></a>

첫째 줄에 경우의 수를 출력한다&#46;

---

<a id="1c3eda9b0fe1818d9ecedf7eca69330e"></a>

<a id="1c3eda9b0fe181f2bc7ec3b7e0f4eaf2"></a>

```plaintext
8 6
1 2 1 3 1 1 1 2

```

```java
    public int solution(int n, int t, int[] arr) {
```

### 풀이2) 강의 풀이&#58; 투포인터, for문 (더 깔끔한 풀이)

<a id="1c3eda9b0fe1813883cfce06926ea38c"></a>

```java
import java.lang.reflect.Array;
import java.util.*;
public class Main {

    public int solution(int n, int t, int[] arr) {
        int cnt=0, sum=0, lt=0;
        for(int rt=0; rt<n; rt++){
            sum+=arr[rt];
            if(sum==t) cnt++;
            while(sum>t){
                sum-=arr[lt++];
                if(sum==t) cnt++;
            }
        }
        return cnt;
    }


    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
         System.out.print( m.solution(n, t, arr));
    }
}
```
