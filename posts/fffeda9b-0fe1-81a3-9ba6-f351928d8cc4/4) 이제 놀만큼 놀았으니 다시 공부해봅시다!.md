아래와 같은 sparta&#95;students(학생) 테이블이 있습니다&#46;

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| id | name | track | grade | enrollment&#95;year |
| 1 | 르탄이 | Node&#46;js | A | 2023 |
| 2 | 배캠이 | Spring | B | 2022 |
| 3 | 구구이 | Unity | C | 2021 |
| 4 | 이션이 | Node&#46;js | B | 2022 |

1. <strong><code>sparta&#95;students</code></strong> 테이블에서 모든 학생의 이름(name)과 트랙(track)을 선택하는 쿼리를 작성해주세요&#33;

<a id="fffeda9b0fe181d8b908e615cd2637ed"></a>

```sql
select name, track
from sparta_students
```

1. <strong><code>sparta&#95;students</code></strong> 테이블에서 Unity 트랙 소속이 아닌 학생들을 선택하는 쿼리를 작성해주세요&#33;

<a id="10ceda9b0fe1802db211f686cf199a4f"></a>

```sql
select *
from sparta_students
where track not in ('Unity')
```

1. <strong><code>sparta&#95;students</code></strong> 테이블에서 입학년도(enrollment&#95;year)가 2021년인 학생과 2023년인 학생을 선택하는 쿼리를 작성해주세요&#33;

<a id="10ceda9b0fe180f3be5ce5757698cf30"></a>

```sql
select *
from sparta_students
where enrollment_year in (2021, 2023)
```

1. <strong><code>sparta&#95;students</code></strong> 테이블에서 Node&#46;js 트랙 소속이고 학점이 ‘A’인 학생의 입학년도를 선택하는 쿼리를 작성해주세요&#33;

<a id="10ceda9b0fe180978205e1acc9210461"></a>

```sql
select enrollment_year
from sparta_students
where track in ('Node.js') amd grade = 'A'
```
