## ‘객체 지향’ 이란

---

> 
> 
> <a id="3c4eda9b0fe180f98ecac21a8d348eb6"></a>
> 
> <strong>객체 지향 &#45; Golang</strong>
> 
> - 객체지향 프로그래밍(OOP)은 소프트웨어 개발 방법론 중 하나
> 
> - 현실 세계의 사물을 프로그램 안에서 객체로 모델링하는 것
> 
> - 대부분의 언어에서는 객체지향을 위해 클래스를 사용하지만 <br><code>Golang</code>은 <strong><u>구조체</u></strong><strong>와 </strong><strong><u>메서드</u></strong><strong>를 통해서 유사한 기능을 구현</strong>함

<a id="3bdeda9b0fe18009aae6e3d2bccddfa4"></a>

###  구조체

> ✏️ 
> 
> <a id="3c4eda9b0fe1805d8142dfe69c46b19c"></a>
> 
> 하나 이상의 변수를 묶어서 새로운 자료형을 정의하는 사용자 정의 타입

<details>
<summary>문법</summary>

<a id="3beeda9b0fe180eaa43ee02ec2d43075"></a>

```go
// 문법
type 타입명 {
		변수명 타입
		변수명 타입
		변수명 타입
}

자료형으로 사용
```

</details>

- ex)
    <a id="3beeda9b0fe180b0aae6d166d77d1458"></a>

    ```go
    // 구조체(클래스) 선언
    type person struct {
    		name string
    		age int
    		gender string
    }

    var p1 = person{} // p1 := person{}
    p1.name = "이경섭"
    p1.agge = 30
    p1.gender = "남자"
    ```

###  메소드

> ✏️ 
> 
> <a id="3c4eda9b0fe180e2b0a5c1fdd46c2851"></a>
> 
> 일반적으로 클래스 내에 선언된 함수를 메소드라고 하나, <br>고랭에서는 <strong>클래스가 존재하지 않</strong>기 떄문에 <strong><u>타입에 속한 함수를 메소드</u></strong>라고 한다&#46;

<details>
<summary>문법</summary>

<a id="3beeda9b0fe180ed8263de669a797415"></a>

```go
// 문법
func 리시버 메서드명(매개변수) 반환타입 {
		실행할 코드
}
```

</details>

<details>
<summary>🤔 메소드 선언 → <code>리시버 변수</code></summary>

<a id="3beeda9b0fe180fab6edcb6c33e11d9a"></a>

```go
// 구조
type person struct {
		name string
		age int
		gender string
}

// 메서드 - 리시버 변수로 구조체에 묶어 사용한다. 
func (p person) myInfo() String {
		return p.age + "살의 " + p.name + "입니다."
}
```

- 앞에서 나온 구조체에 엮어서 사용한다&#46; 이때, 리시버 변수를 통해 묶는다

</details>

- ex)
    <a id="3beeda9b0fe18085a36becf7b0fa91bd"></a>

    ```go
    // 구조체 생성
    var p1 = person{}

    // 메소드 선언 - 리시버 변수로 상위 구조체(클래스)를 정의한ㄴ다.
    func (p person) myInfo() String {
    		return p.age + "살의 " + p.name + "입니다."
    }

    p1.myInfo()
    ```

###  인터페이스 

> ✏️ 
> 
> <a id="3c4eda9b0fe180869e9fca002e4b35e7"></a>
> 
> 구조체(struct)가 필드들의 집합체라면, <strong><code>interface</code></strong>는 <strong><u>메소드들의 집합체 타입(type)</u></strong><strong><u>이 구현</u></strong>해야 하는 <strong><u>메서드 원형(prototype)들을 정의</u></strong>
> 
> - 이를 통해 <code>다형성</code>을 활용해 <strong><u>유연</u></strong>하게 구현 가능

<details>
<summary>문법</summary>

<a id="3beeda9b0fe180449c06cdecfdd011ca"></a>

```go
// 문법
type 타입명 interface {
		함수(매개변수)반환형
		함수(매개변수)반환형
}
```

</details>

- ex)
    <a id="3beeda9b0fe1802983ade840e3f74806"></a>

    ```go
    // 생성한 구조체-메서드와 동일한 인터페이스를 생성헤 타입으로 활용
    type behavior interface {
    		myinfo()
    }

    var b1 behavior
    b1 = p1
    b1.myInfo()
    ```

#### 실습 1 &#45; 구조체(struct)

> ✏️ 
> 
> - go언어에서는 객체지향을 위한 클래스(필드, 메소드) 와 객체 개념이 없다&#46; 
> 
> - <code>구조체</code>&#58; 필드, <del>메소드</del>
> 
> - <code>리시버</code>&#58; 
>     - 구조체 와 메소드 연결
> 
>     - 이러한 메소드는 구조체 인스턴스에 바인딩되어 동작 구현

<details>
<summary>전체 코드</summary>

<a id="3c4eda9b0fe180f99e83e6b992082c17"></a>

```go
package main

import "fmt"

type person struct {
	name string
	age int
	height float64
}

func (p person) myInfo() {
	fmt.Printf("그는 %v 이며, %v 살, 키는 %v 이다. \n", p.name, p.age, p.height)
}

func (p *person) setName(name string) {
	p.name = name
}

func main() {
	// ex 1 - 구조체 선언 
	var p1 person
	// 각 자료형의 초기값인 공백, 0으로 설정
	fmt.Println(p1) // { 0 0}

	// ex 2
	p1 = person{}
	p1.name = "LEE"
	p1.age = 30
	fmt.Println(p1) // {LEE 30 0}

	// ex 3
	p2 := person{name: "LEE2", age: 31}
	fmt.Println(p2) // {LEE2 31 0}

	p2.height = 176.7
	fmt.Printf("그는 %v 이며, %v 살, 키는 %v 이다. \n", p2.name, p2.age, p2.height)


	// ex 4 - 주소값 전달을 통한 포인터 생성
	p3 := &p2

	p3.name = "장보고"
	fmt.Println(p2, p3)

	fmt.Println("----------------------------")

	// ex 5 - 구조체 포인터 선언
	p4 := &person{name: "LEE3", age: 34}
	fmt.Println(p4)

	p5 := p4
	p5.name = "LEE5"
	fmt.Println(p5)
	fmt.Println(p4)

	// ex 6 - new 키워드 사용
	var p6 *person = new(person)
	p6.name = "김지우"
	fmt.Println(p6)

	fmt.Println("----------------------------")

	// ex7 - 익명 선언
	p7 := struct {
		brand string
		size int
	} {
		brand: "삼성",
		size: 53,
	}

	fmt.Println(p7)

	// ex 8 - 메소드 사용
	p8 := &person{}
	p8.name = "LEE8"
	p8.age = 38
	p8.height = 178.8
	p8.myInfo()

	// ex 9 - Setter
	p9 := &person{name: "LEE9", age: 39}
	p9.setName("김두식")
	fmt.Print(p9)	
}
```

</details>

#### 실습 2 &#45; 구조체(struct)

<details>
<summary>기본</summary>

<a id="3c4eda9b0fe18046926fc8c4e7a0bd3a"></a>

```go
package main

import "fmt"

type human struct{
	name string
	age int
}

func main() {
	var h1 *human = new(human)
	h1.name = "LEE"
	h1.age = 20
	fmt.Println(h1) // &{LEE 20}

	h2 := &human {
		name: "LEE2",
		age: 32,
	}
	fmt.Println(h2) // &{LEE2 32}
}

```

</details>

<details>
<summary><strong>구조체 생성자 패턴</strong></summary>

> ✏️ 
> 
> <a id="3c4eda9b0fe18084b9adc1ad3fe56ccf"></a>
> 
> 구조체의 값을 초기화하기 위한 메소드
> 
> <a id="3c4eda9b0fe180669731d7696e7be278"></a>
> 
> →  생성자, (팩토리 메서드 패턴 유사) 

<a id="3c4eda9b0fe180d7819fe86dce2ae39e"></a>

```go
package main

import "fmt"

type human struct{
	name string
	age int
}

// 구조체 생성자 패턴
func newHuman(name string, age int) *human {
	return &human{name, age}
}

func main() {

	/* 
	구조체 생성자 패턴
	- 구조체의 값을 초기화하기 위한 메소드 -> 생성자
	*/
	h3 := newHuman("LEE3", 33)
	h4 := newHuman("LEE4", 34)
	fmt.Println(h3) // &{LEE3 33}
	fmt.Println(h4) // &{LEE4 34}
}
```

</details>

<details>
<summary>구조체 임베딩 ( 상속 유사)</summary>

> ✏️ 
> 
> <a id="3c4eda9b0fe18001a734c52d5d9b600a"></a>
> 
> 구조체의 값을 초기화하기 위한 메소드
> 
> <a id="3c4eda9b0fe18023a19ad3f97b7bc866"></a>
> 
> →  생성자, (팩토리 메서드 패턴 유사) 

<a id="3c4eda9b0fe1804c9cb4e3ffd64e313b"></a>

```go
package main

import "fmt"

type human struct{
	name string
	age int
}

func (p *human) greeting() {
	fmt.Println("hello")
}

type student struct{
	human // 구조체 임베딩
	grade int
}

func main() {

	/*
	상속
	기존 클래스의 모든 필드와 메소드를 다른 클래스에서 사용 가능
	 ==> 구조체 임베딩 (상속과 같은 직접 연결은 아니지만, 유사하게 구현 가능)
	*/
	var s student
	s.name = "LEE5"
	s.age = 12
	s.grade = 5
	s.greeting()
	fmt.Println(s)
}

```

</details>

#### 실습 3 &#45; 인터페이스(interface)

> ✏️ 
> 
> <a id="3c4eda9b0fe18071b3a8d2756f55a025"></a>
> 
> Go의 인터페이스는 <strong><u>어떤 동작을 할 수 있는가</u></strong>를  정의한다&#46;
> 
> <a id="3c4eda9b0fe1808595bbd3bb2ba9ba88"></a>
> 
> 즉, <strong><u>메서드들만</u></strong>을 정의한다&#46;
> 
> <a id="3c4eda9b0fe1800ab1f5c314576459d1"></a>
> 
> <strong><u>정의된 인터페이스의 메서드들을 만족(이름, 매개변수, 반환타입)</u></strong>하는 <strong>구현체를 컴파일러가 암시적으로 해당 인터페이스를 구현/만족한다 판단</strong>한다&#46; 
> 
> - 구현 키워드(<code>implements</code>)는 따로 <strong><u>존재하지 않</u></strong>으며 암시적으로 처리된다&#46; 
> 
> <details>
> <summary>ex)</summary>
> 
> <a id="3c4eda9b0fe180ddbe0deda0bb48745f"></a>
> 
> ```go
> type shape interface {
> 	area() float64
> 	perimeter() float64
> }
> ```
> 
> - shape 인터페이스가 되려면 위 두 메서드 <code>area()</code>, <code>perimeter()</code>가 필요하다
> 
> <a id="3c4eda9b0fe1802391d2c0e1f2b34a16"></a>
> 
> ```go
> type rect struct {
> 	width, height float64
> }
> 
> func (r rect) area() float64 { return ... }
> func (r rect) perimeter() float64 { return ... }
> ```
> 
> - <code>rect</code>가 <u><code>shape</code></u><u>의 두 메서드</u>를 <strong><u>이름, 매개변수, 반환 타입까지 정확히</u></strong><u> </u><u>갖</u>고 있으므로, <strong><u>컴파일러</u></strong><strong><u>가 </u></strong><strong><u>자동(암시적)</u></strong><strong><u>으로 </u></strong><strong><u><code>rect</code></u></strong><strong><u>는 </u></strong><strong><u><code>shape</code></u></strong><strong><u>를 만족</u></strong><strong><u>한다고 판단</u></strong>한다&#46;
> 
> </details>

package main

import "fmt"

type shape interface{
	area() float64 // 면적
	perimeter() float64 
}

type rect struct{
	width, height float64
}

type circle struct{
	radius float64
}

func (r rect) area() float64 { return r.width * r.height }
func (r rect) perimeter() float64 { return 2 * (r.width + r.height) }

func (c circle) area() float64 { return c.radius * c.radius * 3.14 }
func (c circle) perimeter() float64 { return c.radius * 2 * 3.14 }

func main() {
	// 인터페이스 -> 메서드들의 집합체
	// 단순히 동작에 대한 방법만 표시

	var s1, s2 shape
	// 값을 할당해주지 않는 인터페이스는 nil을 리턴
	fmt.Println(s1, s2)

	s1 = rect{10, 10}
	fmt.Println("사각형 면적 : ", s1.area())
	fmt.Println("사각형 둘레 : ", s1.perimeter())

	s2 = circle{6}
	fmt.Println("원 면적 : ", s2.area())
	fmt.Println("원 둘레 : ", s2.perimeter())
}
```

package main

import "fmt"

type shape interface{
	area() float64 // 면적
	perimeter() float64 
}

type rect struct{
	width, height float64
}

type circle struct{
	radius float64
}

func (r rect) area() float64 { return r.width * r.height }
func (r rect) perimeter() float64 { return 2 * (r.width + r.height) }

func (c circle) area() float64 { return c.radius * c.radius * 3.14 }
func (c circle) perimeter() float64 { return c.radius * 2 * 3.14 }

func showShapeInfo(s shape) {
	fmt.Println("면적 : ", s.area())
	fmt.Println("둘레 : ", s.perimeter())
}

func main() {
	// 하나의 자료구조로 관리 가능
	shapes := []shape {
		rect{10, 10},
		rect{5, 10},
		circle{3.5},
		circle{4.1},
	}

	for _, s := range shapes {
		showShapeInfo(s)
		fmt.Println()
	}
}
```

package main

import "fmt"

type rect struct{
	width, height float64
}

type circle struct{
	radius float64
}

// 빈 인터페이스: 어떤 값이든 허용 가능 (유연성 극대화)
func showObject(s interface{}) {
	fmt.Println(s)
}

func main() {
	var s1, s2 shape

	s1 = rect{10, 10}
	s2 = circle{6}
	
	showObject(s1)  // {10, 10}
	showObject(s2)  // {6}
	showObject("circel")
}
