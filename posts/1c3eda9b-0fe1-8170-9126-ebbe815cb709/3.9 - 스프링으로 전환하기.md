<summary><strong>스프링 부트 3&#46;1 이상 로그 출력 안됨</strong></summary>

<a id="1c3eda9b0fe1817d9e77fb7ca222a43d"></a>

스프링 부트 3&#46;1부터는 기본 로그 레벨을 <strong><code>INFO</code></strong>로 빠르게 설정하기 때문에 로그 확인할  수 없음

<a id="1c3eda9b0fe181a3ae74d3489ea75c95"></a>

→ 아래 설정을 통해 로그 레벨 <code>DEBUG</code> 로 변경

<a id="1c3eda9b0fe181fdaaf1d545016a9df3"></a>

( 해당 내용은 <code>MemberApp</code> 과 <code>OrderApp</code> 처럼 <strong>ApplicationContext</strong> 를 직접 생성해서 사용할 때만 적용된다&#46;)

> <code>src/main/resources/logback&#46;xml</code>
> 
> <a id="1c3eda9b0fe181799a89cdf32f309433"></a>
> 
> ````xml
> <configuration>
>      <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender">
>          <encoder>
>              <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} -%kvp-
>  %msg%n</pattern>
>          </encoder>
>      </appender>
>      <root level="DEBUG">
>          <appender-ref ref="STDOUT" />
> </root>
> </configuration> ```
> ````

</details>

<a id="1c3eda9b0fe1817cb45ced2a070ca4fb"></a>

이전에는 순수 자바 코드로 직접 <strong><code>AppConfig</code></strong>를 이용하여 객체를 생성하고, DI 함<br>→  <code>스프링</code>을 통한 스프링 컨테이너, 빈 관리

> <strong>•</strong> 스프링 컨테이너는 <code>&#64;Configration</code> 이 붙은 <strong>AppConfig</strong>를 설정(구성) 정보로 사용한다&#46;<br>   여기서 <code>&#64;Bean</code> 을 명시한 메서드를 모두 호출해서 반환된 객체를 스프링 컨테이너에 등록한다&#46; (<strong>스프링 빈</strong>)<br><br><strong>•</strong> 스프링 빈은 <code>&#64;Bean</code>을 명시한 메서드의 명을 이름으로 사용한다&#46;  ex) memberService, orderService

<a id="1c3eda9b0fe181d99f21e38863a0576c"></a>

### AppConfig 스프링 기반으로 변경

> • <strong>Annotation 추가</strong><br><code>&#64;Configration</code> &#58;  <u>AppConfig에</u><strong><u> 컨테이너 설정을 구성</u></strong>한다는 뜻<br><code>&#64;Bean</code> &#58; 각 메서드에 붙여줌, 이렇게 하면 <strong>스프링컨테이너</strong>에 <strong><u>스프링 빈</u></strong>으로 등록됨

<a id="1c3eda9b0fe181fbaf40cdeb5fd301d6"></a>

```java
package hello.core;

import hello.core.discount.DiscountPolicy;
import hello.core.discount.RateDiscountPolicy;
import hello.core.repository.MemberRepository;
import hello.core.service.MemberService;
import hello.core.service.MemberServiceImpl;
import hello.core.order.OrderService;
import hello.core.order.OrderServiceImpl;
import hello.core.repository.MemoryMemberRepository;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AppConfig {

    @Bean
    public MemberService memberService() {
        return new MemberServiceImpl(MemberRepository());
    }

    @Bean
    public static MemberRepository MemberRepository() {
        return new MemoryMemberRepository();
    }

    @Bean
    public OrderService orderService() {
        return new OrderServiceImpl(MemberRepository(), discountPolicy());
    }

    @Bean
    public DiscountPolicy discountPolicy() {
        return new RateDiscountPolicy();
    }
}
```

### 기존 순수 자바 테스트 코드에 스프링 컨테이너 적용

> • <strong>스프링 컨테이너&#58; </strong><code>ApplicationContext</code><br>•  config를 기반으로 생성된 스프링 컨테이너 인스턴스&#58; <code>AnnotationConfigApplicationContext</code><br>• <strong>스프링 빈</strong> 불러오기&#58; appicationContext<code>&#46;getBean</code>

<details>
<summary>memberApp</summary>

<a id="1c3eda9b0fe18113b6cae70caa1a5427"></a>

```java
package hello.core;

import hello.core.member.Grade;
import hello.core.member.Member;

import hello.core.service.MemberService;
import hello.core.service.MemberServiceImpl;
import org.springframework.context.ApplicationContext;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;

public class MemberApp {

    public static void main(String[] args) {
//        AppConfig appConfig = new AppConfig();
//        MemberService memberService=appConfig.memberService();

        ApplicationContext appicationContext = new AnnotationConfigApplicationContext(AppConfig.class);
        MemberService memberService = appicationContext.getBean("memberService", MemberService.class);
        
        Member member = new Member(1L, "memberA", Grade.VIP);
        memberService.join(member);

        Member findMember = memberService.findMember(1L);
        System.out.println("new member = " + member.getName());
        System.out.println("find Member = " + findMember.getName());
    }
}
```

```java
package hello.core;

import hello.core.member.Grade;
import hello.core.member.Member;
import hello.core.service.MemberService;
import hello.core.service.MemberServiceImpl;
import hello.core.order.Order;
import hello.core.order.OrderService;
import hello.core.order.OrderServiceImpl;
import org.springframework.context.ApplicationContext;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;

public class OrderApp {
    public static void main(String[] args) {
//        AppConfig appConfig = new AppConfig();
//        MemberService memberService = appConfig.memberService();
//        OrderService orderService = appConfig.orderService();
        ApplicationContext applicationContext = new AnnotationConfigApplicationContext(AppConfig.class);
        MemberService memberService = applicationContext.getBean("memberService", MemberService.class);
        OrderService orderService = applicationContext.getBean("orderService", OrderService.class);

        long memberId = 1L;
        Member member = new Member(memberId, "memberA", Grade.VIP);
        memberService.join(member);

        Order order = orderService.createOrder(memberId, "itemA", 20000);
        System.out.println("order = " + order);

    }
}
```
