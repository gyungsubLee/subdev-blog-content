## <strong>7&#46; 좌표 정렬</strong>

---

<a id="1c3eda9b0fe181689dfaf365ba562c4f"></a>

### 설명

<a id="1c3eda9b0fe1810db1e5d5a50b98cb6e"></a>

N개의 평면상의 좌표(x, y)가 주어지면 모든 좌표를 오름차순으로 정렬하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181dc8e9df765093f8c5f"></a>

정렬기준은 먼저 x값의 의해서 정렬하고, x값이 같을 경우 y값에 의해 정렬합니다&#46;

<a id="1c3eda9b0fe1812b9e1aff02c8b165f1"></a>

### 입력

<a id="1c3eda9b0fe1819e8519def1e3b01b80"></a>

첫째 줄에 좌표의 개수인 N(3&#60;=N&#60;=100,000)이 주어집니다&#46;

<a id="1c3eda9b0fe181a8a615ff2b40c6449a"></a>

두 번째 줄부터 N개의 좌표가 x, y 순으로 주어집니다&#46; x, y값은 양수만 입력됩니다&#46;

<a id="1c3eda9b0fe18148bfbcfe44200618a7"></a>

### 출력

<a id="1c3eda9b0fe181c187e1edb86d5511ef"></a>

N개의 좌표를 정렬하여 출력하세요&#46;

## 풀이1) <code>내풀이</code>  클래스타입, 버블 정렬

```java
import java.util.*;

class Coordinate{
    int x;
    int y;
    public Coordinate(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    public Coordinate[] solution(int n, Coordinate[] arr) {
        for(int i=0; i<n-1; i++){
            for(int j=i+1; j<n; j++){
                if(arr[i].x > arr[j].x){
                    Coordinate tmp=arr[i];
                    arr[i]=arr[j];
                    arr[j]=tmp;
                }
                else if(arr[i].x==arr[j].x){
                    if(arr[i].y>arr[j].y){
                        Coordinate tmp=arr[i];
                        arr[i]=arr[j];
                        arr[j]=tmp;
                    }
                }
            }
        }
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        Coordinate[] arr = new Coordinate[n];
        for(int i=0; i<n; i++){
            int x=sc.nextInt();
            int y=sc.nextInt();
            arr[i] = new Coordinate(x, y);
        }
        for(Coordinate t : T.solution(n, arr)){
            System.out.println(t.x+" "+t.y);
        }
    }
} 
```

```java
import java.util.*;

class Coordinate {
    int x;
    int y;
    public Coordinate(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    public Coordinate[] solution(int n, Coordinate[] arr) {
        int i, j;
        for(i=1; i<n; i++){
            Coordinate tmp=arr[i];
            for(j=i-1; j>=0; j--) {
                if (arr[j].x > tmp.x) arr[j + 1] = arr[j];
                else if (arr[j].x == tmp.x) {
                    if (arr[j].y > tmp.y) arr[j+1] = arr[j];
                }
                else break;
            }
            arr[j+1]=tmp;
        }
        return arr;
    }

    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Coordinate[] arr= new Coordinate[n];
        for(int i=0; i<n; i++){
            arr[i]= new Coordinate(sc.nextInt(), sc.nextInt());
        }
        for(Coordinate c : T.solution(n, arr)){
            System.out.println(c.x+" "+c.y);
        }
    }
}
```

## 풀이3) <code>강의풀이</code> Collection  Override

<a id="1c3eda9b0fe181b2b7fcd1e211e92027"></a>

```java
import java.util.*;
class Point implements Comparable<Point> {
    public int x, y;
    Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
    @Override
    public int compareTo(Point o){
        if(this.x==o.x) return this.y-o.y;
        else return this.x-o.x;
    }
}

public class Main {
    public static void main (String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        ArrayList<Point> arr=new ArrayList<>();
        for(int i=0; i<n; i++){
            int x = sc.nextInt();
            int y = sc.nextInt();
            arr.add(new Point(x, y));
        }
        Collections.sort(arr);
        for(Point o : arr) System.out.println(o.x+ " "+o.y);
    }
}
```
