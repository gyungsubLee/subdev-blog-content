### 기본 MySQL  &#45; CLI

-  데이터베이스 생성
    <a id="1c3eda9b0fe18112ae9ec4dbc42cc77b"></a>

    ```shell
    CREATE DATABASE [데이터베이스 명];
    ```

- 데이터베이스 목록 확인
    <a id="1c3eda9b0fe1814aae47d7dc336b0b5b"></a>

    ```shell
    show databases;
    ```

- 데이터베이스 이동(사용)
    <a id="1c3eda9b0fe1813eb388da517117c856"></a>

    ```shell
    use [데이터베이스 명];
    ```

- 테이블 보기
    <a id="1c3eda9b0fe1814792d6ee4256038526"></a>

    ```java
    show tables;
    ```

- 테이블 조회(SQL&#45;select)
    <a id="1c3eda9b0fe181c4ad0dc71649bf1aec"></a>

    ```java
    select * from memo;
    ```
