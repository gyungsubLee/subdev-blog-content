## 문제

<a id="1c2eda9b0fe18092b97cdd4098a7984d"></a>

### <strong>문제 설명</strong>

<a id="1c2eda9b0fe180a98d46d0f5b4f2d0a9"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

| NAME | TYPE | NULLABLE |
| --- | --- | --- |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1c2eda9b0fe180dbb53cd77b355ecb37"></a>

동물 보호소에 들어온 동물 중, 이름이 있는 동물의 ID를 조회하는 SQL 문을 작성해주세요&#46; 단, ID는 오름차순 정렬되어야 합니다&#46;

<a id="1c2eda9b0fe180ccbcc4cd4babfdbdc0"></a>

### 예시

<a id="1c2eda9b0fe180419667d842ac07b8f9"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| --- | --- | --- | --- | --- | --- |
| A434523 | Cat | 2015&#45;11&#45;20 14&#58;18&#58;00 | Normal | NULL | Spayed Female |
| A562649 | Dog | 2014&#45;03&#45;20 18&#58;06&#58;00 | Sick | NULL | Spayed Female |
| A524634 | Dog | 2015&#45;01&#45;02 18&#58;54&#58;00 | Normal | &#42;Belle | Intact Female |
| A465637 | Dog | 2017&#45;06&#45;04 08&#58;17&#58;00 | Injured | &#42;Commander | Neutered Male |

<a id="1c2eda9b0fe18055bbded0863b67fe57"></a>

이름이 있는 동물의 ID는 A524634와 A465637입니다&#46; 따라서 SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

| ANIMAL&#95;ID |
| --- |
| A465637 |
| A524634 |

<a id="1c2eda9b0fe1802bad52e9312d5c63a4"></a>

## 풀이

- 컬럼&#58; <code>ANIMAL&#95;ID</code>, <code>NAME</code>

- 테이블&#58; <code>ANIMAL&#95;INS</code>

- 조건
    - 이름이 있는 동물의 ID 조회

    - ID를 기준으로 오름차순

<a id="1c2eda9b0fe18045af1cc0a3470e4ed4"></a>

```sql
SELECT ANIMAL_ID
FROM ANIMAL_INS
WHERE NAME IS NOT NULL
ORDER BY ANIMAL_ID ASC;
```
