## 문제

<a id="157eda9b0fe180d18c3ec98cff50a6f3"></a>

### 문제

<a id="157eda9b0fe180aa9fd3d2e1e4d90bf5"></a>

<code>2022년 1월</code>의 카테고리 별 도서 판매량을 합산하고, 카테고리(<code>CATEGORY</code>), 총 판매량(<code>TOTAL&#95;SALES</code>) 리스트를 출력하는 SQL문을 작성해주세요&#46;

<a id="157eda9b0fe1806e9f1af069c1d6c3fc"></a>

결과는 카테고리명을 기준으로 오름차순 정렬해주세요&#46;

---

<a id="157eda9b0fe180c2b8a7e680e1ccb19e"></a>

### 예시

<a id="157eda9b0fe180bdbcc9c4df919e104b"></a>

예를 들어 <code>BOOK</code> 테이블과 <code>BOOK&#95;SALES</code> 테이블이 다음과 같다면

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| BOOK&#95;ID | CATEGORY | AUTHOR&#95;ID | PRICE | PUBLISHED&#95;DATE |
| 1 | 인문 | 1 | 10000 | 2020&#45;01&#45;01 |
| 2 | 경제 | 1 | 9000 | 2021&#45;02&#45;05 |
| 3 | 경제 | 2 | 9000 | 2021&#45;03&#45;11 |

|  |  |  |
| --- | --- | --- |
| BOOK&#95;ID | SALES&#95;DATE | SALES |
| 1 | 2022&#45;01&#45;01 | 2 |
| 2 | 2022&#45;01&#45;02 | 3 |
| 1 | 2022&#45;01&#45;05 | 1 |
| 2 | 2022&#45;01&#45;20 | 5 |
| 2 | 2022&#45;01&#45;21 | 6 |
| 3 | 2022&#45;01&#45;22 | 2 |
| 2 | 2022&#45;02&#45;11 | 3 |

<a id="157eda9b0fe1804ea584e2e53b5b4de1"></a>

2022년 1월의 도서 별 총 판매량은 도서 ID 가 1 인 도서가 총 3권, 도서 ID 가 2 인 도서가 총 14권 이고, 도서 ID 가 3 인 도서가 총 2권 입니다&#46;

<a id="157eda9b0fe1805b84d5d908b07ca807"></a>

카테고리 별로 판매량을 집계한 결과는 다음과 같습니다&#46;

|  |  |
| --- | --- |
| CATEGORY | TOTAL&#95;SALES |
| 인문 | 3 |
| 경제 | 16 |

<a id="157eda9b0fe180f79144e20e782b9fb1"></a>

카테고리명을 오름차순으로 정렬하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| CATEGORY | TOTAL&#95;SALES |
| 경제 | 16 |
| 인문 | 3 |

<a id="157eda9b0fe181ba87abf93cbf155469"></a>

## 풀이

> ✏️ 
> 
> <a id="1d6eda9b0fe1804b8654e1d403889729"></a>
> 
> <strong>조건</strong>
> 
> - <code>2022년 1월</code>의 카테고리 별 도서 판매량을 합산
> 
> - 카테고리(<code>CATEGORY</code>), 총 판매량(<code>TOTAL&#95;SALES</code>) 리스트를 출력

<a id="1d6eda9b0fe180159d63df7642e245f4"></a>

풀이1 &#58; SUM &#43; JOIN &#43; BETWEEN 

<a id="157eda9b0fe18004af24ff2eb7875df9"></a>

```sql
SELECT 
    b.CATEGORY,
    SUM(bs.SALES) AS TOTAL_SALES
FROM BOOK_SALES bs
JOIN BOOK b ON bs.BOOK_ID = b.BOOK_ID
WHERE bs.SALES_DATE BETWEEN '2022-01-01' AND '2022-01-31'
GROUP BY b.CATEGORY
ORDER BY b.CATEGORY;
```

<a id="1d6eda9b0fe180549bf8cc8db4fdcd39"></a>

풀이2&#58; SUM &#43; Covering Index &#43; JOIN

<a id="1d6eda9b0fe18049bff4e20b501d8174"></a>

```sql
SELECT 
    b.CATEGORY,
    SUM(t.SALES) AS TOTAL_SALES
FROM (
    SELECT BOOK_ID, SALES
    FROM BOOK_SALES 
    WHERE SALES_DATE BETWEEN '2022-01-01' AND '2022-01-31'
) t
JOIN BOOK b ON t.BOOK_ID = b.BOOK_ID
GROUP BY b.CATEGORY
ORDER BY b.CATEGORY
```
