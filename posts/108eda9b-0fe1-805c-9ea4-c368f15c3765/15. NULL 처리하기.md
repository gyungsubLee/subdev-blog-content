## 문제

<a id="1d1eda9b0fe1806ea54bdde08b1cfcff"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d1eda9b0fe18019b24cec4d677245da"></a>

입양 게시판에 동물 정보를 게시하려 합니다&#46; 동물의 생물 종, 이름, 성별 및 중성화 여부를 아이디 순으로 조회하는 SQL문을 작성해주세요&#46; 이때 프로그래밍을 모르는 사람들은 NULL이라는 기호를 모르기 때문에, 이름이 없는 동물의 이름은 &#34;No name&#34;으로 표시해 주세요&#46;

<a id="1d1eda9b0fe1804dbec0ef40a531e963"></a>

### 예시

<a id="1d1eda9b0fe180d29783ee13e455deb9"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A350276 | Cat | 2017&#45;08&#45;13 13&#58;50&#58;00 | Normal | Jewel | Spayed Female |
| A350375 | Cat | 2017&#45;03&#45;06 15&#58;01&#58;00 | Normal | Meo | Neutered Male |
| A368930 | Dog | 2014&#45;06&#45;08 13&#58;20&#58;00 | Normal | NULL | Spayed Female |

<a id="1d1eda9b0fe1807fb347c06fd5645bbb"></a>

마지막 줄의 개는 이름이 없기 때문에, 이 개의 이름은 &#34;No name&#34;으로 표시합니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| ANIMAL&#95;TYPE | NAME | SEX&#95;UPON&#95;INTAKE |
| Cat | Jewel | Spayed Female |
| Cat | Meo | Neutered Male |
| Dog | No name | Spayed Female |

<a id="1d1eda9b0fe1806faed6eeb49cd1ad26"></a>

※ 컬럼 이름은 일치하지 않아도 됩니다&#46;

<a id="1d1eda9b0fe180948bb1e599a14e7fd8"></a>

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe18013839ad5e503e9c3f6"></a>
> 
> 조건
> 
> - 동물의 생물 종, 이름, 성별 및 중성화 여부를 아이디 순으로 조회
> 
> - 이름이 없는 동물의 이름은 &#34;No name&#34;으로 표시

<a id="1d1eda9b0fe180bcb7afc75823ad9554"></a>

```sql
SELECT 
    ANIMAL_TYPE, 
    IF(NAME IS NULL OR NAME = '', 'No name', name) AS NAME, 
    SEX_UPON_INTAKE
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```
