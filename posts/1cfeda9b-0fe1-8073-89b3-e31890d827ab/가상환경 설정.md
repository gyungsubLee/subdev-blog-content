### ✅ 방법 1&#46; <strong>가상환경(venv) 사용</strong>

<a id="1cfeda9b0fe1803593affb1b920f1d5b"></a>

```bash
# 1. 가상환경 만들기
python3 -m venv myenv

# 2. 가상환경 활성화
source myenv/bin/activate

# 3. pip 사용 가능!
pip install requests
```

<a id="1cfeda9b0fe1803283fae4f42203ba85"></a>

### <strong>✅ 방법 2&#58; pipx 사용 (CLI 앱 설치에 적합)</strong>

<a id="1cfeda9b0fe180629e7fcea6e7695ddb"></a>

```bash
brew install pipx
pipx install some-cli-tool
```

<a id="1cfeda9b0fe1809d8a56d0762ee62eb2"></a>

pipx는 파이썬 앱을 독립적인 가상환경에 설치해주는 툴

<a id="1cfeda9b0fe180b88267ea706ed1b7f1"></a>

 CLI 도구를 쓸 때 특히 좋다&#46;

<a id="1cfeda9b0fe180fdbc28fd713c3634c2"></a>

### 가상환경 활성화, 종료

> 🧐 
> 
> <a id="1cfeda9b0fe1807583cfd19f0c59499a"></a>
> 
> <strong>가상환경 (venv)</strong>
> 
> ---
> 
> <a id="1cfeda9b0fe180bc9450c09ba705720f"></a>
> 
> <strong>가상환경</strong>은 파이썬 <u>프로젝트별로 </u><strong><u>독립적인 패키지 설치 공간</u></strong>을 만들어 주는 도구 이다&#46;
> 
> <a id="1cfeda9b0fe1808192dbf6bad651324a"></a>
> 
> 전역 파이썬 설치에 영향을 주지 않고, 프로젝트마다 다른 패키지 버전을 쓸 수 있다&#46;<br>실무에서도 프로젝트 별로 &#46;venv 혹은 env를 만들어 관리한다&#46;

<a id="1cfeda9b0fe180699600d438381d1390"></a>

```bash
# 가상환경 활성화
source myenv/bin/activate

# pip 사용 가능!
pip install requests

# 가상환경 종료
deactivate
```

<a id="1cfeda9b0fe1807e9b87c2f5ca043ec5"></a>

```bash
myenv/
├── bin/
│   └── activate
├── lib/
├── include/
└── pyvenv.cfg
```

<a id="1cfeda9b0fe1805dadb4e3954dabb129"></a>

### 가상환경 실행 중 확인

| <strong>방법</strong> | <strong>명령어</strong> | <strong>의미</strong> |
| --- | --- | --- |
| 환경 변수 확인 | <code>echo &#36;VIRTUAL&#95;ENV</code> | 값이 있으면 가상환경 활성화 |
| 파이썬 코드 확인 | <code>sys&#46;prefix &#33;= sys&#46;base&#95;prefix</code> | True면 가상환경 |
| 실행 위치 확인 | <code>which python / which pip</code> | 경로가 venv 내부이면 활성화 |
