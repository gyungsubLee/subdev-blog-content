# 문제

<a id="1c3eda9b0fe181f19fb2c033678331e8"></a>

## <strong>5&#46; 연속된 자연수의 합</strong>

---

<a id="1c3eda9b0fe181c88a1deceb03d525c7"></a>

### 설명

<a id="1c3eda9b0fe181e282dbfc8e78616688"></a>

N입력으로 양의 정수 N이 입력되면 2개 이상의 연속된 자연수의 합으로 정수 N을 표현하는 방법의 가짓수를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181adb90fe5b457cdb68b"></a>

만약 N=15이면

<a id="1c3eda9b0fe181b8928bd540abafc094"></a>

7&#43;8=15

<a id="1c3eda9b0fe1816b93a5dcdc7d553a34"></a>

4&#43;5&#43;6=15

<a id="1c3eda9b0fe1819c8e2fce29c636eb74"></a>

1&#43;2&#43;3&#43;4&#43;5=15

<a id="1c3eda9b0fe181fe8a16f9131ced17d7"></a>

와 같이 총 3가지의 경우가 존재한다&#46;

<a id="1c3eda9b0fe18147af3cd0a847682753"></a>

### 입력

<a id="1c3eda9b0fe181fcb09de4cfa37591b0"></a>

첫 번째 줄에 양의 정수 N(7&#60;=N&#60;1000)이 주어집니다&#46;

<a id="1c3eda9b0fe181508029ca95508f4428"></a>

### 출력

<a id="1c3eda9b0fe1818abebcc0ef3ec02bea"></a>

첫 줄에 총 경우수를 출력합니다&#46;

---

<a id="1c3eda9b0fe1816c9c8fcfb654b9039e"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181a089d4f38e8af27676"></a>

```plaintext
15
```

### 풀이1)

<details>
<summary>오답</summary>

- for문으로 rt가 증가하는데 또 추가로 rt&#43;&#43; 로직을 넣어 2씩 증가됨&#46;

- value를 index&#43;1로 잡아 마지막 인덱스에 n값이 들어가 1이 추가로 카운트됨&#46; (조건에 2개 이상의 자연수라고 줌)

<a id="1c3eda9b0fe181ccb6c5ce14e3294c88"></a>

```java
public class Main {
    public int solution(int n, int[] arr) {
        int cnt=0, sum=0, lt=0;
        for(int rt=0; rt<n; rt++){
            sum+=arr[rt++];
            if(sum==n) cnt++;
            while(sum>n){
                sum-=arr[lt++];
                if(sum==n) cnt++;
            }
        }
        return cnt;
    }


    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=i+1;
        }
         System.out.print( m.solution(n, arr));
    }
}
```

</details>

### 풀이2) 강의풀이&#58; &#91;풀이1&#93; 최적화

<a id="1c3eda9b0fe18150bf6cc47353671b17"></a>

조건에 답을  2이상의 연속된 자연수의 합으로 구성하라고 주어짐&#46;

<a id="1c3eda9b0fe181debd28feeb513ff8c0"></a>

즉, 구하는 값이 n이라고 할때, n/2&#43;1 이상부터는 연속된 수의 합이 항상 n을 넘어가기 때문에, 해당 경우를 제외하고 경우의 수를 구성&#46;

> ex) n=19, n/2&#43;1=10 ⇒ 10이상의 연속된 자연수들은 항상 19를 넘어감&#46;
> 
> <a id="1c3eda9b0fe18121ba7cc6979607ca6b"></a>
> 
>        →  최솟값&#58; (10, 11)  &#46;  &#46;  &#46; 

<a id="1c3eda9b0fe181d686f6e2aa9d0e9bfe"></a>

```java
public class Main {
    public int solution(int n) {
        int cnt=0, sum=0, lt=0;
        // 연속된 2개의 수의 합 -> 구하려는 값의 나누기 2한 값(n/2) +1 이상부터는 연속된 자연수가 무조건 n을 넘어감.
        int m=n/2+1;
        int[] arr=new int[m];
        for(int i=0; i<m; i++) arr[i]=i+1;
        for(int rt=0; rt<m; rt++){
            sum+=arr[rt];
            if(sum==n) cnt++;
            while(sum>=n){
                sum-=arr[lt++];
                if(sum==n) cnt++;
            }
        }
        return cnt;
    }


    public static void main (String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
         System.out.print( m.solution(n));
    }
}
```

### 풀이3) &#91;2차 풀이&#93; 

<a id="1c3eda9b0fe1815b91d4d606f4b33897"></a>

가장 효율적인 듯? 굳굳

```java
import java.util.*;
public class Main {
    public int solution(int n) {
        int cnt=0, sum=0, lt=1;
        for(int rt=1; rt<=n/2+1; rt++){
            sum+=rt;
            if(sum==n) cnt++;
            while(sum>n){
                sum-=lt++;  // sum-=lt; lt++;
                if(sum==n) cnt++;
            }
        }
        return cnt;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.print(T.solution(n));
    }
}
```
