# 문제

<a id="1c3eda9b0fe1814cb05bd2d1c66c3aa8"></a>

## <strong>3&#46; 크레인 인형뽑기(카카오)</strong>

---

<a id="1c3eda9b0fe18117954de49eb3a2b866"></a>

### 설명

<a id="1c3eda9b0fe1817c8dd9d50b57e2d404"></a>

게임개발자인 죠르디는 크레인 인형뽑기 기계를 모바일 게임으로 만들려고 합니다&#46;

<a id="1c3eda9b0fe18154b214e83b4328b47d"></a>

죠르디는 게임의 재미를 높이기 위해 화면 구성과 규칙을 다음과 같이 게임 로직에 반영하려고 합니다&#46;

![](https://cote.inflearn.com/public/upload/d637c6aff5.jpg)

<a id="1c3eda9b0fe18117814df766c935ff09"></a>

게임 화면은 1 x 1 크기의 칸들로 이루어진 N x N 크기의 정사각 격자이며 위쪽에는 크레인이 있고 오른쪽에는 바구니가 있습니다&#46;

<a id="1c3eda9b0fe181fb9d27f63483265ea2"></a>

(위 그림은 5 x 5 크기의 예시입니다)&#46; 각 격자 칸에는 다양한 인형이 들어 있으며 인형이 없는 칸은 빈칸입니다&#46;

<a id="1c3eda9b0fe1819ebb4ef8505e2436dd"></a>

모든 인형은 1 x 1 크기의 격자 한 칸을 차지하며 격자의 가장 아래 칸부터 차곡차곡 쌓여 있습니다&#46;

<a id="1c3eda9b0fe18164a46adc54b990aaa8"></a>

게임 사용자는 크레인을 좌우로 움직여서 멈춘 위치에서 가장 위에 있는 인형을 집어 올릴 수 있습니다&#46; 집어 올린 인형은 바구니에 쌓이게 되는 데,

<a id="1c3eda9b0fe1817f90dec6dbdd00c328"></a>

이때 바구니의 가장 아래 칸부터 인형이 순서대로 쌓이게 됩니다&#46;

<a id="1c3eda9b0fe18126867adeb157494040"></a>

다음 그림은 &#91;1번, 5번, 3번&#93; 위치에서 순서대로 인형을 집어 올려 바구니에 담은 모습입니다&#46;

![](https://cote.inflearn.com/public/upload/e7f1732dc7.jpg)

<a id="1c3eda9b0fe181319d9ef5272d571fa3"></a>

만약 같은 모양의 인형 두 개가 바구니에 연속해서 쌓이게 되면 두 인형은 터뜨려지면서 바구니에서 사라지게 됩니다&#46;

<a id="1c3eda9b0fe18138bf43cf9311866ac9"></a>

위 상태에서 이어서 &#91;5번&#93; 위치에서 인형을 집어 바구니에 쌓으면 같은 모양 인형 두 개가 없어집니다&#46;

![](https://cote.inflearn.com/public/upload/437bd16905.jpg)

<a id="1c3eda9b0fe181f295aef79967857ab6"></a>

크레인 작동 시 인형이 집어지지 않는 경우는 없으나 만약 인형이 없는 곳에서 크레인을 작동시키는 경우에는 아무런 일도 일어나지 않습니다&#46;

<a id="1c3eda9b0fe1819fa8cbce7a0d81c19b"></a>

또한 바구니는 모든 인형이 들어갈 수 있을 만큼 충분히 크다고 가정합니다&#46; (그림에서는 화면표시 제약으로 5칸만으로 표현하였음)

<a id="1c3eda9b0fe1817dbeabc4ef3d26af9a"></a>

게임 화면의 격자의 상태가 담긴 2차원 배열 board와 인형을 집기 위해 크레인을 작동시킨 위치가 담긴 배열 moves가 매개변수로 주어질 때,

<a id="1c3eda9b0fe18122ab0ac14e96e66029"></a>

크레인을 모두 작동시킨 후 터트려져 사라진 인형의 개수를 구하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181aab9c9c7486aee95ff"></a>

### 입력

<a id="1c3eda9b0fe1815a8caafac6b45f98e6"></a>

첫 줄에 자연수 N(5&#60;=N&#60;=30)이 주어집니다&#46;

<a id="1c3eda9b0fe181ee84bce7e4cba3e687"></a>

두 번째 줄부터 N&#42;N board 배열이 주어집니다&#46;

<a id="1c3eda9b0fe1813daa17cfad73279d5a"></a>

board의 각 칸에는 0 이상 100 이하인 정수가 담겨있습니다&#46;

<a id="1c3eda9b0fe18134b78df05e1cf3d346"></a>

0은 빈 칸을 나타냅니다&#46;

<a id="1c3eda9b0fe181188974c1ffc656d697"></a>

1 &#126; 100의 각 숫자는 각기 다른 인형의 모양을 의미하며 같은 숫자는 같은 모양의 인형을 나타냅니다&#46;

<a id="1c3eda9b0fe1819fb195e1b54b16212d"></a>

board배열이 끝난 다음줄에 moves 배열의 길이 M이 주어집니다&#46;

<a id="1c3eda9b0fe181159718e3d304228d34"></a>

마지막 줄에는 moves 배열이 주어집니다&#46;

<a id="1c3eda9b0fe18128a7d3f3b27f2935d4"></a>

moves 배열의 크기는 1 이상 1,000 이하입니다&#46;

<a id="1c3eda9b0fe181919c15f97e08166557"></a>

moves 배열 각 원소들의 값은 1 이상이며 board 배열의 가로 크기 이하인 자연수입니다&#46;

<a id="1c3eda9b0fe181b1bd22c5264e081bbc"></a>

###  출력

<a id="1c3eda9b0fe181c7a046cc0ff13f38d5"></a>

첫 줄에 터트려져 사라진 인형의 개수를 출력합니다&#46;

---

# 풀이

<a id="1c3eda9b0fe181f6bcf0ca27e0b35c61"></a>

## 내 풀이1) 

<a id="1c3eda9b0fe18159a8accb20d1cad071"></a>

```java
import java.util.*;
public class Main {
    public int  solution(int n, int[][] arr, int m, int[] mvs){
        int answer=0;
        Stack<Integer> stack= new Stack<>();
        for(int x: mvs){
            int i=0;
            while(i<n&&arr[i][x]==0){
                i++;
            }
            if(!stack.isEmpty()&&stack.peek()==arr[i][x]){
                stack.pop();
                answer+=2;
                arr[i][x]=0;
                continue;
            }
            stack.add(arr[i][x]);
            arr[i][x]=0;
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[][] arr = new int[n+1][n+1];
        for(int i=1; i<n+1; i++){
            for(int j=1; j<n+1; j++){
                arr[i][j]=sc.nextInt();
            }
        }
        int m=sc.nextInt();
        int[] mvs=new int[m];
        for(int i=0; i<m; i++){
            mvs[i]=sc.nextInt();
        }
        System.out.println(T.solution(n, arr, m, mvs));
    }
}
```

## 풀이2) 강의풀이

<a id="1c3eda9b0fe181459cd0e6686d982c3a"></a>

```java
import java.util.*;
public class Main {
    public int  solution(int[][] board, int[] mvs){
        int answer=0;
        Stack<Integer> stack= new Stack<>();
        for(int pos: mvs){
            for(int i=0; i<board.length; i++){
                if(board[i][pos-1]!=0){
                    int tmp=board[i][pos-1];
                    board[i][pos-1]=0;
                    if(!stack.isEmpty() && tmp==stack.peek()){
                        stack.pop();
                        answer+=2;
                    }
                    else stack.add(tmp);
                    break;
                }
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[][] arr = new int[n][n];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                arr[i][j]=sc.nextInt();
            }
        }
        int m=sc.nextInt();
        int[] mvs=new int[m];
        for(int i=0; i<m; i++){
            mvs[i]=sc.nextInt();
        }
        System.out.println(T.solution(arr, mvs));
    }
}
```
