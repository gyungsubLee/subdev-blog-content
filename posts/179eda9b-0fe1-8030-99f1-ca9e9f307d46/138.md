## 문제

<a id="179eda9b0fe1804fb718fb9e9c6c572c"></a>

Query the list of <em>CITY</em> names starting with vowels (i&#46;e&#46;, <code>a</code>, <code>e</code>, <code>i</code>, <code>o</code>, or <code>u</code>) from <strong>STATION</strong>&#46; Your result <em>cannot</em> contain duplicates&#46;

<a id="179eda9b0fe180448768cefc2dc74cea"></a>

<strong>Input Format</strong>

<a id="179eda9b0fe180448437cbd69de49a73"></a>

The <strong>STATION</strong> table is described as follows&#58;

![](18d9a3a7dd65531f.webp)

<a id="179eda9b0fe180e5a7cbc87d1039baf0"></a>

where <em>LAT&#95;N</em> is the northern latitude and <em>LONG&#95;W</em> is the western longitude&#46;

<a id="ccafb1233e6d4515b5d8069fd7cb314d"></a>

## 풀이

<a id="179eda9b0fe1802b8923ea364b144ca4"></a>

```bash
SELECT DISTINCT CITY
FROM STATION
WHERE LOWER(LEFT(CITY, 1)) IN ('a', 'e', 'i', 'o', 'u');
```
