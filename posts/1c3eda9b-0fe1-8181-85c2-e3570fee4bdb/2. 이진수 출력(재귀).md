## 2&#46; 이진수 출력

---

<a id="1c3eda9b0fe18122be7cc8a0af85d711"></a>

### 설명

<a id="1c3eda9b0fe181378187f89c1b611efb"></a>

10진수 N이 입력되면 2진수로 변환하여 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe18155b838e27248d66b28"></a>

단&#46; 재귀함수를 이용해서 출력해야 합니다&#46; 

<a id="1c3eda9b0fe18115809fc6289072bb3a"></a>

### 입력 설명

<a id="1c3eda9b0fe181cfac83deed97ca6b3b"></a>

첫 번째 줄에 10진수 N(1≤N≤1,00)이 주어집니다&#46;

<a id="1c3eda9b0fe181d99122ede78e884c24"></a>

### 출력 설명

<a id="1c3eda9b0fe1814ea98bdbb484964086"></a>

첫 번째 줄에 이진수를 출력하세요&#46;

---

<a id="1c3eda9b0fe181aa8edefbc32e46747b"></a>

# 풀이

<a id="1c3eda9b0fe1813e984ee16caed74dec"></a>

## 풀이1)

<a id="1c3eda9b0fe1811b8dfedd6895cb5e6d"></a>

```java
import java.util.*;

public class Main {
    public void DFS(int n){
        if(n==0) return;
        else{
            DFS(n/2);
            System.out.print(n%2+" ");
        }
    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        T.DFS(n);
    }
}
```

## 풀이2) String 

<a id="1c3eda9b0fe1813e9a7eca7b62c7302c"></a>

```java
import java.util.*;

public class Main {
    static String answer="";
    public void DFS(int n){
        if(n==0) return;
        else {
            DFS(n/2);
            answer+=(n%2+" ");
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        T.DFS(n);
        System.out.println(answer);
    }
}
```
