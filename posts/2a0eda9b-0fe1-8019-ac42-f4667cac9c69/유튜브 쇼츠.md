- 사용하고 싶은 모델들을 옵션값으로 추가하로 API call 시 파라미터로 불러와 사용한다&#46;

### 카테고리별 프롬프트 예시

<details>
<summary><code>역사</code>&#58; 역사적 사실을 영화처럼 재구성</summary>

<a id="2a0eda9b0fe18067a8e8de8f98f2b1ae"></a>

```bash
■ 역사  
	- 전략: '역사적 사실'을 '한 편의 영화'처럼 재구성하십시오.  
	- 실행:  
	- 알려지지 않은 인물의 숨겨진 이야기나, 역사적 사건의 결정적 하루에 집중하세요.  
	- 건조한 사실 나열 대신, 당시 인물이 겪었을 감정(두려움, 결단, 환희 등)을 생생하게 묘사하여 시청자가 그 순간에 있는 것처럼 느끼게 만드십시오.  
	- 검증된 사실만을 기반으로 하되, 서술은 극적으로 구성해야 합니다. 허구는 절대 금지입니다.
```

</details>

<details>
<summary><code>과학</code>&#58; “왜?”로 시작, 직관적 비유와 아하 포인트 제공</summary>

<a id="2a0eda9b0fe1809cb7a0d45c3d79f101"></a>

```bash
■ 과학  
	- 전략: '어려운 과학 원리'를 '놀라운 마술쇼'처럼 보여주십시오.  
	- 실행:  
	- 복잡한 개념을 설명하기 위해, 우리 주변에서 바로 찾아볼 수 있는 직관적인 비유나 실생활 예시를 사용하세요. (예: 양자 얽힘을 '절대 헤어지지 않는 쌍둥이 양말'로 비유)  
	- "왜?"라는 질문으로 시작하여, 그 답을 찾아가는 과정을 짧고 흥미롭게 풀어내 시청자에게 '아하!'하는 순간(Aha! Moment)을 선사해야 합니다.  
	- 검증된 과학적 사실을 기반으로, 초등학생도 무릎을 탁 칠 만큼 쉽고 명쾌하게 설명해야 합니다.
```

</details>

    >     2. 보여주기, 말하지 않기 (Show, Don't Tell): '설명'을 '묘사'로, '주장'을 '스토리'로 치환하십시오. 시청자가 스스로 결론에 도달하게끔 장면을 그리듯 서술해야 합니다.
    >     3. 하나의 영상, 하나의 메시지 (One Video, One Message): 모든 Base 스토리는 단 하나의 핵심 메시지 또는 교훈으로 수렴해야 합니다. 군더더기 정보는 과감히 제거하십시오.
    >     4. 감성적 연결고리 (Emotional Hook): 시청자가 놀라움, 감동, 공감, 분노 등 특정 감정을 느끼도록 스토리를 설계하십시오. 감성적 동요는 콘텐츠 소비의 가장 강력한 동기입니다.
    >     5. 마지막 인상 (The Lasting Impression): CTA는 단순한 행동 유도가 아닙니다. 영상의 여운을 곱씹게 만드는 강력한 한마디 혹은 성찰적 질문이어야 합니다.
    > 
    >     ---------------------------------------
    > 
    >     [현재 카테고리]
    >     {{ $json.category }}
    > 
    >     [주제]
    >     {{ $('Get Reserved').item.json.keyword }}

    >     [주요 참고]
    >     {{ $('Get Reserved').item.json.reference }}
    > 
    >     ---------------------------------------
    > 
    >     [최종 목표: JSON 배열 스크립트 5개 창작]
    >     - 주어진 카테고리와 주제를 기반으로, 위의 핵심 원칙을 완벽하게 적용한 쇼츠 스크립트 5개를 작성하십시오.
    >     - 각 스크립트는 아래 JSON 형식을 따르는 하나의 오브젝트이며, 전체는 반드시 JSON 배열로 출력되어야 합니다.
