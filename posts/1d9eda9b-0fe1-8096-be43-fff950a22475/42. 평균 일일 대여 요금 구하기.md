## 문제

<a id="1d9eda9b0fe180029e52eab2830082b3"></a>

### <strong>문제 설명</strong>

<a id="1d9eda9b0fe180b1ba20ce70af8afd8d"></a>

다음은 어느 자동차 대여 회사에서 대여중인 자동차들의 정보를 담은 <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블입니다&#46; <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블은 아래와 같은 구조로 되어있으며, <code>CAR&#95;ID</code>, <code>CAR&#95;TYPE</code>, <code>DAILY&#95;FEE</code>, <code>OPTIONS</code> 는 각각 자동차 ID, 자동차 종류, 일일 대여 요금(원), 자동차 옵션 리스트를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| CAR&#95;ID | INTEGER | FALSE |
| CAR&#95;TYPE | VARCHAR(255) | FALSE |
| DAILY&#95;FEE | INTEGER | FALSE |
| OPTIONS | VARCHAR(255) | FALSE |

<a id="1d9eda9b0fe1801280e2fc1c212cf3ca"></a>

자동차 종류는 &#39;세단&#39;, &#39;SUV&#39;, &#39;승합차&#39;, &#39;트럭&#39;, &#39;리무진&#39; 이 있습니다&#46; 자동차 옵션 리스트는 콤마(&#39;,&#39;)로 구분된 키워드 리스트(예&#58; &#39;열선시트&#39;, &#39;스마트키&#39;, &#39;주차감지센서&#39;)로 되어있으며, 키워드 종류는 &#39;주차감지센서&#39;, &#39;스마트키&#39;, &#39;네비게이션&#39;, &#39;통풍시트&#39;, &#39;열선시트&#39;, &#39;후방카메라&#39;, &#39;가죽시트&#39; 가 있습니다&#46;

---

<a id="1d9eda9b0fe18095ad03f50e05462ab7"></a>

### 문제

<a id="1d9eda9b0fe180a791a9d12964336b86"></a>

<code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블에서 자동차 종류가 &#39;SUV&#39;인 자동차들의 평균 일일 대여 요금을 출력하는 SQL문을 작성해주세요&#46; 이때 평균 일일 대여 요금은 소수 첫 번째 자리에서 반올림하고, 컬럼명은 <code>AVERAGE&#95;FEE</code> 로 지정해주세요&#46;

---

<a id="1d9eda9b0fe1805eb187f45363e30ef3"></a>

### 예시

<a id="1d9eda9b0fe180aab805f3aaae084cf2"></a>

예를 들어 <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블이 다음과 같다면

|  |  |  |  |
| --- | --- | --- | --- |
| CAR&#95;ID | CAR&#95;TYPE | DAILY&#95;FEE | OPTIONS |
| 1 | 세단 | 16000 | 가죽시트,열선시트,후방카메라 |
| 2 | SUV | 14000 | 스마트키,네비게이션,열선시트 |
| 3 | SUV | 22000 | 주차감지센서,후방카메라,가죽시트 |

<a id="1d9eda9b0fe180d99de4c368c5a46f09"></a>

&#39;SUV&#39; 에 해당하는 자동차들의 평균 일일 대여 요금은 18,000 원 이므로, 다음과 같은 결과가 나와야 합니다&#46;

<a id="1d9eda9b0fe18058a30dc17fe2f3ab62"></a>

AVERAGE&#95;FEE

---

<a id="1d9eda9b0fe18028bf61e2bd522dde41"></a>

18000

---

<a id="1d9eda9b0fe180b2aa86c347908a7a4a"></a>

## 풀이

> ✏️ 
> 
> <a id="1d9eda9b0fe1809c9c31cb5ba51c9b3f"></a>
> 
> 조건
> 
> - 자동차 종류가 &#39;SUV&#39;인 자동차들의 평균 일일 대여 요금을 출력
> 
> - 평균 일일 대여 요금은 소수 첫 번째 자리에서 반올림하고, 컬럼명은 <code>AVERAGE&#95;FEE</code>

<a id="1d9eda9b0fe180ca99bafb58706cca12"></a>

```sql
SELECT ROUND(AVG(DAILY_FEE), 0) AS AVERAGE_FEE
FROM CAR_RENTAL_COMPANY_CAR
WHERE CAR_TYPE = 'SUV';
```
