# 문제

<a id="1c3eda9b0fe1813fb630fe4c3179a9b8"></a>

## <strong>14&#46; 피자 배달 거리(삼성 SW역량평가 기출문제 &#58; DFS활용)</strong>

<a id="1c3eda9b0fe18181b794ea5ead4131a2"></a>

### 설명

<a id="1c3eda9b0fe181798a8cdbf7a6fbdb79"></a>

N×N 크기의 도시지도가 있습니다&#46; 도시지도는 1×1크기의 격자칸으로 이루어져 있습니다&#46;

<a id="1c3eda9b0fe18189a176feb6e5c54bb7"></a>

각 격자칸에는 0은 빈칸, 1은 집, 2는 피자집으로 표현됩니다&#46; 각 격자칸은 좌표(행번호, 열 번호)로 표현됩니다&#46;

<a id="1c3eda9b0fe181fc940be9d15bcbabb9"></a>

행번호는 1번부터 N번까지이고, 열 번호도 1부터 N까지입니다&#46;

<a id="1c3eda9b0fe181559c67f14d4366009e"></a>

도시에는 각 집마다 “피자배달거리”가 았는데 각 집의 피자배달거리는 해당 집과 도시의 존재하는

<a id="1c3eda9b0fe181c290d4ed93ca1594e2"></a>

피자집들과의 거리 중 최소값을 해당 집의 “피자배달거리”라고 한다&#46;

<a id="1c3eda9b0fe18132a145d02ecbe8f719"></a>

집과 피자집의 피자배달거리는 &#124;x1&#45;x2&#124;&#43;&#124;y1&#45;y2&#124; 이다&#46;

<a id="1c3eda9b0fe18198a02af98ef3e20cb5"></a>

예를 들어, 도시의 지도가 아래와 같다면

![](https://cote.inflearn.com/public/upload/15230e4e41.jpg)

<a id="1c3eda9b0fe1817a8f26c68d825933c8"></a>

(1, 2)에 있는 집과 (2, 3)에 있는 피자집과의 피자 배달 거리는 &#124;1&#45;2&#124; &#43; &#124;2&#45;3&#124; = 2가 된다&#46;

<a id="1c3eda9b0fe181b19dabcb53c10b0909"></a>

최근 도시가 불경기에 접어들어 우후죽순 생겼던 피자집들이 파산하고 있습니다&#46;

<a id="1c3eda9b0fe18180821cf00bddb63530"></a>

도시 시장은 도시에 있는 피자집 중 M개만 살리고 나머지는 보조금을 주고 폐업시키려고 합니다&#46;

<a id="1c3eda9b0fe18166b34ce6738b48d133"></a>

시장은 살리고자 하는 피자집 M개를 선택하는 기준으로 도시의 피자배달거리가 최소가 되는 M개의 피자집을 선택하려고 합니다&#46;

<a id="1c3eda9b0fe181ba9704db2161a79695"></a>

도시의 피자 배달 거리는 각 집들의 피자 배달 거리를 합한 것을 말합니다&#46;

<a id="1c3eda9b0fe181f0a87ed536047f0e10"></a>

### 입력

<a id="1c3eda9b0fe181989eb3f0d6cc0f21f5"></a>

첫째 줄에 N(2 ≤ N ≤ 50)과 M(1 ≤ M ≤ 12)이 주어진다&#46;

<a id="1c3eda9b0fe181a396bdc276f3b09d62"></a>

둘째 줄부터 도시 정보가 입력된다&#46;

<a id="1c3eda9b0fe18151920fe85326526f58"></a>

### 출력

<a id="1c3eda9b0fe1813692ebd2afa3de716e"></a>

첫째 줄에 M개의 피자집이 선택되었을 때 도시의 최소 피자배달거리를 출력한다&#46;

---

# 풀이

## 풀이1) <code>내풀이</code> 

<a id="1c3eda9b0fe18115b484fde8fee18602"></a>

문제를 잘못 이해하여 오랜 시간이 걸림… 

> 하나의 피자 가게에서의 집들까지의 피자배달거리의 최솟값이 아닌,<br><strong><u>N개의 피자 가게 </u></strong>에서의 <strong><u>집들까지의 최소 피자 배달거리</u></strong>를 구하는 것임&#46;

<a id="1c3eda9b0fe181089bd9d70f4c8d1b79"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

class Point{
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n, m, len, minDistance=Integer.MAX_VALUE;
    static ArrayList<Point> home, pizzaStore;

    public void DFS(int L, int s, Point[] combiPizzaStorePoints){
        if(L==m) {
            setMinDistance(combiPizzaStorePoints);
        }
        else {
            for(int i=s; i<len; i++){
                combiPizzaStorePoints[L]=pizzaStore.get(i);
                DFS(L+1, i+1, combiPizzaStorePoints);
            }
        }
    }

    public void setMinDistance(Point[] combiPizzaStorePoints){
        int sum=0;
        for(Point homePoint : home){
            int dis=Integer.MAX_VALUE;
            for(Point pizzaPoint : combiPizzaStorePoints){
                dis=Math.min(dis, Math.abs(pizzaPoint.x-homePoint.x)+ Math.abs(pizzaPoint.y-homePoint.y));
            }
            sum+=dis;
        }
        minDistance=Math.min(minDistance, sum);
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        home=new ArrayList<>();
        pizzaStore=new ArrayList<>();
        int[][] board=new int[n][n];
        Point[] combiPizzaStorePoints=new Point[m];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                board[i][j]=sc.nextInt();
                if(board[i][j]==1) home.add(new Point(i, j));
                if(board[i][j]==2) pizzaStore.add(new Point(i, j));
            }
        }
        len=pizzaStore.size();
        T.DFS(0, 0, combiPizzaStorePoints);
        System.out.println(minDistance);
    }
}
```

## 풀이2) <code>강의풀이</code>  

<a id="1c3eda9b0fe181bba97ad315ba538235"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

class Point{
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n, m, len, answer=Integer.MAX_VALUE;
    static ArrayList<Point> hs=new ArrayList<>(), ps=new ArrayList<>();

    static int[] combi;
    public void DFS(int L, int s){
        if(L==m){
            int sum=0;
            for(Point h : hs){
                int dis=Integer.MAX_VALUE;
                for(int i : combi){
                    dis=Math.min(dis, Math.abs(h.x-ps.get(i).x)+Math.abs(h.y-ps.get(i).y));
                }
                sum+=dis;
            }
            answer=Math.min(answer, sum);
        }
        else {
            for(int i=s; i<len; i++){
                combi[L]=i;
                DFS(L+1, i+1);
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        combi=new int[m];
        int[][] board=new int[n][n];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                board[i][j]=sc.nextInt();
                if(board[i][j]==1) hs.add(new Point(i, j));
                if(board[i][j]==2) ps.add(new Point(i, j));
            }
        }
        len=ps.size();
        T.DFS(0, 0);
        System.out.println(answer);
    }
}
```
