# 문제

<a id="1c3eda9b0fe181e88228e7cb2a558613"></a>

## <strong>11&#46; 임시반장 정하기</strong>

---

<a id="1c3eda9b0fe1819e8e4ecf46715ffa9e"></a>

### 설명

<a id="1c3eda9b0fe181e7b732f191c8d2c4d2"></a>

김갑동 선생님은 올해 6학년 1반 담임을 맡게 되었다&#46;

<a id="1c3eda9b0fe1819ba1a4ee8af915ed1e"></a>

김갑동 선생님은 우선 임시로 반장을 정하고 학생들이 서로 친숙해진 후에 정식으로 선거를 통해 반장을 선출하려고 한다&#46;

<a id="1c3eda9b0fe1816d9246faec25569828"></a>

그는 자기반 학생 중에서 1학년부터 5학년까지 지내오면서 한번이라도 같은 반이었던 사람이 가장 많은 학생을 임시 반장으로 정하려 한다&#46;

<a id="1c3eda9b0fe1811ea7abf29300fd7217"></a>

그래서 김갑동 선생님은 각 학생들이 1학년부터 5학년까지 몇 반에 속했었는지를 나타내는 표를 만들었다&#46;

<a id="1c3eda9b0fe181938f9fef8e32352270"></a>

예를 들어 학생 수가 5명일 때의 표를 살펴보자&#46;

![](https://cote.inflearn.com/public/upload/f8a83920ca.jpg)

<a id="1c3eda9b0fe18178acd6ffad3cd0face"></a>

위 경우에 4번 학생을 보면 3번 학생과 2학년 때 같은 반이었고, 3번 학생 및 5번 학생과 3학년 때 같은 반이었으며,

<a id="1c3eda9b0fe181a1aa18c0030a4da39d"></a>

2번 학생과는 4학년 때 같은 반이었음을 알 수 있다&#46; 그러므로 이 학급에서 4번 학생과 한번이라도

<a id="1c3eda9b0fe181d3b994e535b9b1688d"></a>

같은 반이었던 사람은 2번 학생, 3번 학생과 5번 학생으로 모두 3명이다&#46;

<a id="1c3eda9b0fe181f885d6c92a0ea7ec32"></a>

이 예에서 4번 학생이 전체 학생 중에서 같은 반이었던 학생 수가 제일 많으므로 임시 반장이 된다&#46;

<a id="1c3eda9b0fe18146807bc13df83b08a6"></a>

각 학생들이 1학년부터 5학년까지 속했던 반이 주어질 때, 임시 반장을 정하는 프로그램을 작성하시오&#46;

---

<a id="1c3eda9b0fe181f4abc6cd5ffeadda62"></a>

### 입력

<a id="1c3eda9b0fe181d78b57c123e9d9f484"></a>

첫째 줄에는 반의 학생 수를 나타내는 정수가 주어진다&#46; 학생 수는 3 이상 1000 이하이다&#46;

<a id="1c3eda9b0fe18191bbe1fb54a28c6d05"></a>

둘째 줄부터는 1번 학생부터 차례대로 각 줄마다 1학년부터 5학년까지 몇 반에 속했었는지를 나타내는 5개의 정수가 빈칸 하나를 사이에 두고 주어진다&#46;

<a id="1c3eda9b0fe181a3ac31f43a81d5cd0e"></a>

주어지는 정수는 모두 1 이상 9 이하의 정수이다&#46;

<a id="1c3eda9b0fe1815e867aebfe665ab93f"></a>

### 출력

<a id="1c3eda9b0fe181349891cb8288e17303"></a>

첫 줄에 임시 반장으로 정해진 학생의 번호를 출력한다&#46;

<a id="1c3eda9b0fe1814d8998d831804b155e"></a>

단, 임시 반장이 될 수 있는 학생이 여러 명인 경우에는 그 중 가장 작은 번호만 출력한다&#46;

---

### 강의 풀이1) 삼중 for문 (’행’과 ‘열’을 헷갈렸음)

<a id="1c3eda9b0fe181d79e80fb8ecce471e4"></a>

조건을 잘못 이해함&#46; 

<a id="1c3eda9b0fe1812286c9c368e5789802"></a>

→ 한번이라도 같은 반인 경우를 찾는 것이라, 굳이 한번 같은 반인 경우 더 탐색을 진행할 이유가 없음&#46;

<a id="1c3eda9b0fe181b6922ffd09cf9a1be1"></a>

```java
import java.util.*;
public class Main {
    public int solution(int n, int[][] arr) {
        int answer=0, max=Integer.MIN_VALUE;
        for(int i=1; i<n+1; i++){
            int cnt=0;
            for(int j=1; j<n+1; j++) {
                if (i == j) continue;
                for (int k = 1; k < 6; k++) {
                    if (arr[i][k] == arr[j][k]) {
                        cnt++;
                        break;
                    }
                }
            }
            if(max<cnt){
                answer=i;
                max=cnt;
            }
        }
        return answer;
    }
    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] input = new int[n+1][6];
        for (int i = 1; i < n+1; i++) {
            for (int j = 1; j < 6; j++) {
                input[i][j] = sc.nextInt();
            }
        }
        System.out.println(T.solution(n, input));
    }
}
```

    public int solution(int n, int[][] arr) {
        int answer=0;
        //1. 배열 재작성
        //1-1) 이증배열 -> ArrayList로 작성
        ArrayList<Integer>[] arrList = new ArrayList[n];
        for(int i=0; i<n; i++){
            arrList[i]=new ArrayList<Integer>();
        }
        for(int i=1; i<n+1; i++){
            for(int k=1; k<6; k++){

<a id="1c3eda9b0fe1816cbb41ff4e6216dc58"></a>

따라서 max=Integer&#46;MIN&#95;VALUE;  로 초기화 하여, 위와 같이 겹치는 경우가 없어도 최초의 값으로 할당되게 처리해야 한다&#46;
