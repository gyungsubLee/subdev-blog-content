## 문제

<a id="1d2eda9b0fe180798781e33b7d0157ff"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe1806cb4e6ca4f9531a643"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d2eda9b0fe180ceafd1ee7263edf92c"></a>

동물 보호소에 들어온 동물 중, 이름이 없는 채로 들어온 동물의 ID를 조회하는 SQL 문을 작성해주세요&#46; 단, ID는 오름차순 정렬되어야 합니다&#46;

<a id="1d2eda9b0fe180309253d4548685b374"></a>

### 예시

<a id="1d2eda9b0fe1803fa842df05b9d1aebb"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A368930 | Dog | 2014&#45;06&#45;08 13&#58;20&#58;00 | Normal | NULL | Spayed Female |
| A524634 | Dog | 2015&#45;01&#45;02 18&#58;54&#58;00 | Normal | &#42;Belle | Intact Female |
| A465637 | Dog | 2017&#45;06&#45;04 08&#58;17&#58;00 | Injured | &#42;Commander | Neutered Male |

<a id="1d2eda9b0fe180a1bf8dfb9ac36eca5b"></a>

이름이 없는 채로 들어온 동물의 ID는 A368930입니다&#46; 따라서 SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

<a id="1d2eda9b0fe1808ab6ccc668326fdd0f"></a>

ANIMAL&#95;ID

---

<a id="1d2eda9b0fe1804eba02d63ea8bd3ff8"></a>

A368930

---

<a id="1d2eda9b0fe180c6bc48fc8fd9c6549d"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe180569c05f5b3d573570b"></a>
> 
> 조건
> 
> - 이름이 없는 채로 들어온 동물의 ID를 조회
> 
> - ID는 오름차순 정렬

<a id="1d2eda9b0fe180f9a101ff608a076d46"></a>

```sql
SELECT ANIMAL_ID
FROM ANIMAL_INS
WHERE NAME IS NULL
```
