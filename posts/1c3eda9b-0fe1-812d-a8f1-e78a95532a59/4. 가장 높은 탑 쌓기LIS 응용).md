# 문제

<a id="1c3eda9b0fe181d88c45d7c2f74a0723"></a>

## <strong>4&#46; 가장 높은 탑 쌓기</strong>

<a id="1c3eda9b0fe181cd929dc35085275692"></a>

### 설명

<a id="1c3eda9b0fe1815cbceceac87d25f6a6"></a>

밑면이 정사각형인 직육면체 벽돌들을 사용하여 탑을 쌓고자 한다&#46; 탑은 벽돌을 한 개씩 아래에서 위로 쌓으면서 만들어 간다&#46;

<a id="1c3eda9b0fe181ac9ca4e04aaa36e37a"></a>

아래의 조건을 만족하면서 가장 높은 탑을 쌓을 수 있는 프로그램을 작성하시오&#46;

<a id="1c3eda9b0fe18150b23cee0864294a93"></a>

(조건1) 벽돌은 회전시킬 수 없다&#46; 즉, 옆면을 밑면으로 사용할 수 없다&#46;

<a id="1c3eda9b0fe1816f91fad4698e837b10"></a>

(조건2) 밑면의 넓이가 같은 벽돌은 없으며, 또한 무게가 같은 벽돌도 없다&#46;

<a id="1c3eda9b0fe18169a630f5ba700c1544"></a>

(조건3) 벽돌들의 높이는 같을 수도 있다&#46;

<a id="1c3eda9b0fe181b5ab3afdeb36f154e3"></a>

(조건4) 탑을 쌓을 때 밑면이 좁은 벽돌 위에 밑면이 넓은 벽돌은 놓을 수 없다&#46;

<a id="1c3eda9b0fe181e88324d992b5102375"></a>

(조건5) 무게가 무거운 벽돌을 무게가 가벼운 벽돌 위에 놓을 수 없다&#46;

<a id="1c3eda9b0fe181ffbc69c15e5cf23ee0"></a>

### 입력

<a id="1c3eda9b0fe1812c82e0e25e33a2ca6a"></a>

입력 파일의 첫째 줄에는 입력될 벽돌의 수가 주어진다&#46; 입력으로 주어지는 벽돌의 수는 최대 100개이다&#46;

<a id="1c3eda9b0fe18134bc90cbb3504ef738"></a>

둘째 줄부터는 각 줄에 한 개의 벽돌에 관한 정보인 벽돌 밑면의 넓이, 벽돌의 높이 그리고 무게가 차례대로 양의 정수로 주어진다&#46;

<a id="1c3eda9b0fe1813b8608d8b5feca7dc7"></a>

각 벽돌은 입력되는 순서대로 1부터 연속적인 번호를 가진다&#46; 벽돌의 넓이, 높이 무게는 10,000보다 작거나 같은 자연수이다&#46;

<a id="1c3eda9b0fe18117b0b4cbaa23cd0a68"></a>

### 출력

<a id="1c3eda9b0fe181ca89b3c88fc880eab7"></a>

첫 번째 줄에 가장 높이 쌓을 수 있는 탑의 높이를 출력한다&#46;

---

## 풀이1) <code>내풀이</code> 

<a id="1c3eda9b0fe1812785ddd783acbc00d5"></a>

### 1차 시도, <code>그리디</code>   &#45;  <code>Fail</code> 

<a id="1c3eda9b0fe181ae8a3ae3fc8022112c"></a>

이전 챕터 &#45; 그리디알고리즘  풀이 이용 → 모든 케이스 오답

<a id="1c3eda9b0fe181608d69f8fb2f4bc7cd"></a>

 넓이를 기준으로 정렬을 진행했으나, 넓이가 작은데도, 높이 값이 커 더 큰 값을 경우의 수가 발생 

<details>
<summary>code</summary>

<a id="1c3eda9b0fe181c28227dd4650e7706e"></a>

```java
import java.util.*;

class Brick implements Comparable<Brick>{
    int area, height, weight;

    public Brick(int area, int height, int weight) {
        this.area = area;
        this.height = height;
        this.weight = weight;
    }

    @Override
    public int compareTo(Brick o){
        if(this.area == o.area) return o.weight - this.weight;
        else return o.area - this.area;
    }

}

public class Main {
    static ArrayList<Brick> arr = new ArrayList<>();
    public int solution(){
        int answer=0;
        int bA = Integer.MAX_VALUE, bW=Integer.MAX_VALUE;
        for(Brick ob : arr){
            if(bA > ob.area && bW > ob.weight){
                answer+=ob.height;
                bA=ob.area;
                bW=ob.weight;
            }
        }
        return answer;
    }

    public static void main(String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int  n= sc.nextInt();
        for(int i=0; i<n; i++){
            int a=sc.nextInt();;
            int h=sc.nextInt();
            int w=sc.nextInt();
            arr.add(new Brick(a, h, w));
        }
        System.out.println();
        Collections.sort(arr);
        System.out.println(T.solution());
    }
}
```

### 2차 시도,  <code>DFS</code>     &#45;  <code>success</code>

<a id="1c3eda9b0fe18177b3f9c64d1ecc32f1"></a>

모든 경우의 수를 찾아 최댓값을 도출하는 풀이

<a id="1c3eda9b0fe1815d842bc4cddc241d80"></a>

1차 시도에서 최대의 넓이 값이 아닌데도, 더큰 높이를 가지는 case가 존재 했으므로 첫번째 값을 <code>조합</code>으로 설계

<a id="1c3eda9b0fe181e3b53cfa9a64c329ef"></a>

이전 DFS 챕터의 ‘조합(8&#45;9)’ 풀이 참조하여 풀이 진행

> <strong><code>조건</code></strong><code><br></code> 위 쌓이는 벽돌은 밑의 벽돌보다 넓이와 무게가 작아야한다&#46; <br> → h, w ↓

<a id="1c3eda9b0fe18158922bc8dc01f9dd64"></a>

해당하는 조건을 만족하려면 <strong><u>밑에 쌓인 벽돌의 정보를 저장</u></strong>하여 현재의 벽돌과 비교해 판별해야한다&#46; 

<details>
<summary><strong>2&#45;1 차 시도  → </strong><strong><code>success</code></strong></summary>

<a id="1c3eda9b0fe181fc9580da96c53711f8"></a>

경우의 수는 도출하지만, 종료 조건을 잘못 설정함

<a id="1c3eda9b0fe181ebae60dd5d42bcabe1"></a>

<a id="1c3eda9b0fe181429457de9080fd06a7"></a>

그러나 <strong>조건</strong>에 의해 <strong><u>깊이 n 까지 탐색을 진행하지 못함</u></strong>

## 풀이2) <code>강의풀이</code> 

<a id="1c3eda9b0fe1815abf5cc1faa3cc36c8"></a>

이전 문제 와 풀이 로직 동일

<a id="1c3eda9b0fe1817c94b2fcc9b875b663"></a>

```java
 import java.util.*;

class Brick implements Comparable<Brick>{
    int area, height, weight;

    public Brick(int area, int height, int weight) {
        this.area = area;
        this.height = height;
        this.weight = weight;
    }

    @Override
    public int compareTo(Brick o){
        return o.area - this.area;
    }

}

public class Main {
    static int[] dy;
    public int  solution(ArrayList<Brick> arr){
        int answer=0;
        Collections.sort(arr);
        dy[0]=arr.get(0).height;
        for(int i=1; i<arr.size(); i++){
            int max_h=0;
            for(int j=i-1; j>=0; j--){
                if(arr.get(j).weight>arr.get(i).weight && dy[j]>max_h){
                    max_h=dy[j];
                }
            }
            dy[i]=max_h + arr.get(i).height;
            answer=Math.max(answer, dy[i]);
        }
        return answer;
    }

    public static void main(String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n= sc.nextInt();
        dy=new int[n+1];
        ArrayList<Brick> arr = new ArrayList<>();
        for(int i=0; i<n; i++){
            int a=sc.nextInt();;
            int h=sc.nextInt();
            int w=sc.nextInt();
            arr.add(new Brick(a, h, w));
        }
       
        System.out.println(T.solution(arr));
    }
}
```
