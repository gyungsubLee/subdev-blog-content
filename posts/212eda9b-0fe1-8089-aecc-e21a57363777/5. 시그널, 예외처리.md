## Signal 과 에러처리

---

> 📖 
> 
> <a id="219eda9b0fe180e9a72accd04e469329"></a>
> 
> <strong>시그널 ( Signal )</strong>
> 
> ---
> 
> <a id="219eda9b0fe18098b9cfc0a883836688"></a>
> 
> 리액티브 프로그래밍에서 <code>시그널(Signal)</code>은 <strong><u>데이터 흐름(stream) 상에서 발생하는 </u></strong><strong><u>이벤트의 종류</u></strong>를 의미한다&#46; 
> 
> <a id="219eda9b0fe1809fae57c53470b70f5b"></a>
> 
> 해당 시그널들은 모두 <strong><u>비동기</u></strong>적으로 발생하며<strong> Subscriber(구독자</strong>) 쪽에서 <u>해당 이벤트들을 받</u>아 처리한다&#46; 

<details>
<summary><strong>핵심 시그널 3가지</strong></summary>

> ✏️ 
> 
> <a id="219eda9b0fe18083ab0df030b9c31cf3"></a>
> 
> <code>Reactor</code>나 <code>Spring WebFlux</code>에서의 <strong>Flux, Mono</strong> 같은 <strong>Publisher</strong>에서 발생하는<strong> </strong><strong><u>3가지 핵심 시그널</u></strong>은 아래와 같다&#46;

- <code>onNext</code>
    - 의미&#58; <strong><u>새로운 데이터가 발행</u></strong>될 때 발생

    - 사용&#58; <code>doOnNext(T data)</code>

- <code>onComplete</code>
    - 의미&#58; <strong><u>모든 데이터 발행 완료</u></strong> 됐을 때 발생 (스트림 완료)

    - 사용&#58; <code>doOnComplete()</code>

- <code>onError</code>
    - 의미&#58; <strong><u>스트림 처리 중 에러가 발생</u></strong> 됐을 때 발생

    - 사용&#58; <code>doOnError(Throwable e)</code>

</details>

> <strong>동작 흐름</strong>
>

> <a id="219eda9b0fe180e69597c1375005a396"></a>

> ```xml
>     클라이언트 요청
>          ↓
>  ┌────────────────┐
>  │ Flux.range(1,5)│
>  └────────────────┘
>          ↓
> 		[onNext: 1]
> 		[onNext: 2]
> 		[onNext: 3]
> 		[onNext: 4]
> 		[onNext: 5]
> 		     ↓
> 	  [onComplete]
> ```
> 
> 1. 클라이언트 <code>/numbers/flux</code> 호출
> 
> 1. Flux&#46;range(1, 5) →  onNext 시그널이 5번 발생 ( 1 &#126; 5 )
> 
> 1. 각 데이터마다 doNext(…)로 로그 출력
> 
> 1. 마지막 숫자 발행 후 → onComplete 시그널 발생
> 
> 1. 에러가 없기 때문에 onError는 발생하지 않음

<details>
<summary>&#91; 코드 &#93; Flux &#45; doOnNext()</summary>

<a id="219eda9b0fe18025b23cc47087ecf374"></a>

```java
@RestController
@RequestMapping("/numbers")
public class NumberController {

    @GetMapping("/flux")
    public Flux<Integer> streamNumbers() {
        return Flux.range(1, 5)
                   .delayElements(Duration.ofSeconds(1)) // 1초 간격으로 데이터 발행
                   .doOnNext(data -> System.out.println("🔹 onNext: " + data))
                   .doOnComplete(() -> System.out.println("✅ onComplete"))
                   .doOnError(err -> System.err.println("❌ onError: " + err.getMessage()));
    }
}
```
