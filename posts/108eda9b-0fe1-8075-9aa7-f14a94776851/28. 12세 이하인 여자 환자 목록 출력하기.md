## 문제

<a id="1aa017b980964ed182b89a41ef357927"></a>

### <strong>문제 설명</strong>

---

<a id="3be9af7d500547ef9d039824ebb86db1"></a>

다음은 종합병원에 등록된 환자정보를 담은 <code>PATIENT</code> 테이블입니다&#46; <code>PATIENT</code> 테이블은 다음과 같으며 <code>PT&#95;NO</code>, <code>PT&#95;NAME</code>, <code>GEND&#95;CD</code>, <code>AGE</code>, <code>TLNO</code>는 각각 환자번호, 환자이름, 성별코드, 나이, 전화번호를 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PT&#95;NO | VARCHAR(10) | FALSE |
| PT&#95;NAME | VARCHAR(20) | FALSE |
| GEND&#95;CD | VARCHAR(1) | FALSE |
| AGE | INTEGER | FALSE |
| TLNO | VARCHAR(50) | TRUE |

<a id="a79bf84f897f4ed19facb20ec36b2d02"></a>

### 문제

---

<a id="6b375d646e3f4f3cbb8eb78c7de09a32"></a>

<code>PATIENT</code> 테이블에서 12세 이하인 여자환자의 환자이름, 환자번호, 성별코드, 나이, 전화번호를 조회하는 SQL문을 작성해주세요&#46; 이때 전화번호가 없는 경우, &#39;NONE&#39;으로 출력시켜 주시고 결과는 나이를 기준으로 내림차순 정렬하고, 나이 같다면 환자이름을 기준으로 오름차순 정렬해주세요&#46;

<a id="77a43fd9518547c7a07ea28008c1cd4c"></a>

### 예시

---

<code>PATIENT</code> 테이블이 다음과 같을 때

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| PT&#95;NAME | PT&#95;NO | GEND&#95;CD | AGE | TLNO |

<a id="109eda9b0fe18083bdeecef06ff3e62e"></a>

## 풀이

<a id="109eda9b0fe1809da4b5cfc427995738"></a>

 문제는 <strong>12세 이하의 여자 환자</strong>를 조회하는 SQL 쿼리를 작성하는 것과, 조건에 맞게 데이터를 정렬하고 NULL 값을 ‘NONE’으로 출력하는 기능을 구현하는 문제이다&#46;

<a id="109eda9b0fe1805e9a28e2f9cdff58c8"></a>

### 요구사항 분석

---

- <strong>12세 이하의 여자 환자</strong>만을 조회해야 한다&#46; 
    - 여자 환자는 GEND&#95;CD가 ‘W’인 환자이다&#46; 

    - 나이는 AGE &#60;= 12 인 환자이다&#46; 

- <strong>출력할 컬럼<br></strong><code>PT&#95;NAME</code>, <code>PT&#95;NO</code>, <code>GEND&#95;CD</code>, <code>AGE</code>, <code>TLNO</code> 조회

- <strong>전화번호가 없는 경우</strong> (TLNO가 NULL인 경우) ⇒  <code>‘NONE’</code>
    -  COALESCE 함수를 사용
        - NULL  →  ‘NONE’

- <strong>결과 정렬</strong>
    - 나이를 기준으로 내림차순(DESC)으로 정렬

    - 만약 나이가 같다면 환자 이름(PT&#95;NAME)을 오름차순(ASC)으로 정렬

---

- SELECT<strong> 구문</strong>
    - <code>PT&#95;NAME</code>, <code>PT&#95;NO</code>, <code>GEND&#95;CD</code>, <code>AGE</code>, <code>TLNO</code> 컬럼 선택

    - <code>COALESCE(TLNO, &#39;NONE&#39;) AS TLNO</code>
        <a id="109eda9b0fe18068a62ace4cfc5edbfb"></a>

        <code>TLNO</code> 컬럼에서 <code>NULL</code>을 <strong><code>‘NONE’</code></strong>으로 <strong><u>대체</u></strong>해준다&#46; 

        > <strong>COALESCE 함수</strong>는 <strong><u>첫 번째 인자</u></strong>가 <code>NULL</code>이면 <strong><u>두 번째 인자를 반환</u></strong>한다&#46; 

- FROM<strong> 구문</strong>
    - PATIENT 테이블에서 데이터를 조회

- WHERE<strong> 구문</strong>
    - 성별이 여자(GEND&#95;CD = &#39;W&#39;)인 환자만 조회

    - 나이가 12세 이하(AGE &#60;= 12)인 환자만 필터링

- ORDER BY<strong> 구문</strong>
    - 나이를 기준으로 내림차순(DESC)으로 정렬하고&#46;

    - 나이가 같다면 환자 이름을 오름차순(ASC)으로 정렬함

<a id="013dd17d5719474783f89473d95aa7a0"></a>

### 풀이

<a id="1d5eda9b0fe180d697efe325c1d76342"></a>

<strong>풀이 1&#58; </strong><strong><code>IF</code></strong><strong> 문</strong>

<a id="1d5eda9b0fe180fc8e4ee1cb438d6f9b"></a>

```java
SELECT 
    PT_NAME, 
    PT_NO, 
    GEND_CD, 
    AGE, 
    IF(TLNO IS NULL, 'NONE', TLNO) AS TLNO
FROM PATIENT
WHERE AGE < 13 AND GEND_CD = 'W'
ORDER BY AGE DESC, PT_NAME ASC;
```

<a id="1d5eda9b0fe180d49b5bd7a1a02bef07"></a>

<strong>풀이2&#58;</strong> <code>COALESCE</code> 문

<a id="109eda9b0fe18055bc28f674475e2216"></a>

```sql
SELECT 
    PT_NAME, 
    PT_NO, 
    GEND_CD, 
    AGE, 
    COALESCE(TLNO, 'NONE') AS TLNO
FROM 
    PATIENT
WHERE 
    GEND_CD = 'W'    -- 여자 환자
    AND AGE <= 12    -- 나이가 12세 이하
ORDER BY 
    AGE DESC,        -- 나이 내림차순
    PT_NAME ASC;     -- 나이가 같을 경우 이름 오름차순
```
