### 회원가입 / 로그인

---

- 회원가입
    - 아이디
        - 아이디는 이메일 형식입니다

    - 비밀번호
        - 비밀번호는 Bcrypt 로 인코딩합니다

        - 비밀번호는 대소문자 포함 영문 &#43; 숫자 &#43; 특수문자를 최소 1글자씩 포함합니다&#46;

        - 비밀번호는 최소 8글자 이상입니다&#46;

    - 주소
        - 주소는 주소값과 위도, 경도를 포함합니다&#46;

        - 한 계정 당 3개의 주소를 가질 수 있습니다&#46;

    - 권한
        - 회원가입시 일반 유저(USER) 또는 관리자(ADMIN)로 가입할 수 있습니다&#46;

        - 관리자 페이지 기능은 관리자만 사용 가능합니다&#46;

- 로그인
    - 아이디 비밀번호로 로그인 합니다&#46;

    - 로그인 시 accessToken, refreshToke 이 발급됩니다&#46;

    - 로그인이 필요한 로직에서 accessToken 을 사용합니다&#46;

    - accessToken 만료 시 클라이언트는 refreshToken 을 사용해 accessToken 을 재발급 받을 수 있습니다&#46;

- <strong>⚠️ </strong><strong>예외 처리</strong>
    - 중복 유저 아이디

    - 아이디/비밀번호 오류

<a id="b8f1aeb7c502476d8d63957261373f3e"></a>

### 유저

---

- 이름, 나이, 성별, 주소, 이메일, 패스워드, 프로필 사진, 등급(결제) &#43; admin

- client → s3 이미지 저장 후 url 서버 전송

- 유저 CRUD

- 매칭 활성화/비활성화

- 유저의 상태는 normal, rejected 로 관리됩니다&#46;

- 유저 수정
    - 주소, 프로필사진, 매칭 허용 여부를 수정할 수 있습니다&#46;

    - status 는 관리자만 수정 가능합니다&#46;

- 회원 탈퇴
    - 회원 탈퇴는 비밀번호 확인요청 처리 후 받은 cookie 가 있어야 가능합니다&#46;

<a id="5ef755d4dd9141b287f1839273b3c084"></a>

### 일정

---

- CRUD

- 컨텐츠 나열 (순서 상관 x)

- userId

- 특정 이벤트 데이에 대한 일정을 생성할 수 있습니다&#46;

- 일정에 대한 간단한 설명과 카테고리로 분류된 컨텐츠들을 다수 담을 수 있습니다&#46;

- 한 이벤트 데이에 하나의 일정만 생성 가능합니다&#46;

- 하나의 일정에 최대 10개의 sub&#95;category 가 들어갈 수 있습니다&#46;

<a id="5faf8fdb6f1a44ceb1bc67705200b15d"></a>

### 매칭

---

- 사용자는 일정에서 매칭을 돌려 가장 유사한 사람과 매칭될 수 있다&#46;

- 정책
    - 한개의 일정에 대해 5개의 무료 매칭을 제공한다&#46;

    - 매칭 1회당 50P가 사용 된다&#46;

    - 쿠폰으로 인한 무료 횟수가 존재할 경우 무료 횟수 먼저 소진된 후 포인트가 소진된다&#46;

- <strong>매칭 로직 &#58; (추후 추가 예정)</strong>

- 유사도는 각 일정의 지역, 성별, 나이, 컨텐츠를 기준으로 계산된다&#46;

- 매칭 신청을 통해 요청을 보낼 수 있으며 PENDING을 default로 한다&#46; 
    - status&#58; PENDING(대기), APPROVE(승인), REJECT(거절)

    - 거절한 경우 같은 일정내에서 매칭으로 노출되지 않는다&#46;

- <strong>⚠️ </strong><strong>예외 처리</strong>
    - 포인트가 모두 소진되었을 경우 매칭 요청은 불가능 하다&#46;

    - 매칭이 완료 됐을경우 매칭 요청이 불가능하다&#46;

<a id="f5d46a0b20ce41569c3c39644279dd5c"></a>

### 카테고리

---

- 카테고리를 등록, 조회, 수정, 삭제 할 수 있습니다&#46;

- 등록, 수정, 삭제는 관리자만 가능합니다&#46;

- 카테고리에는 이름과 사진 정보가 필요합니다&#46;

<a id="e148fb72742c4c2a868dda0c07278af2"></a>

### 서브 카테고리

---

- 서브 카테고리를 등록, 조회, 수정, 삭제 할 수 있습니다&#46;

- 등록, 수정, 삭제는 관리자만 가능합니다&#46;

- 서브 카테고리에는 이름과 사진 정보가 필요합니다&#46;

- 카테고리 탑10은 일정에 등록된 상위 10개의 서브 카테고리를 보여줍니다&#46;

- 일정은 createdAt을 기준으로 최근 일주일 이내의 레코드만 참고합니다&#46;

<a id="f63511b823c0497481b219578e07deb8"></a>

### 신고

---

- 사용자
    - 사용자는 신고 접수와 취소가 가능하고, 본인이 신고 한 내역을 조회할 수 있습니다&#46;

    - 사용자는 신고 당하는 사람과 매칭 정보를 통해 신고를 접수할 수 있습니다&#46;

    - 신고할 때에는 신고 내용이 있어야 합니다&#46;

    - 신고 취소는 6개월 이내에 가능합니다&#46;

    - 한 매칭 내에서 신고는 한 번만 가능합니다&#46;

- 관리자
    - 관리자는 모든 신고 내역 조회가 가능합니다&#46;

    - 신고의 타당성이 의심될 경우, 신고 내역을 삭제할 수 있습니다&#46;

    - 신고를 5회 이상 받은 유저는 블랙리스트로 처리합니다&#46;

<a id="0d4f1b7386c34fbfbdd64b27e7dfc624"></a>

### 포인트

---

- 사용자는 포인트를 충전하고 사용하여 매칭을 돌릴 수 있다&#46;

- 정책
    - 매칭 1회당 사용 포인트&#58; 50P (임시)

    - 포인트는 결제 금액의 10%가 지급된다&#46;

    - 포인트는 1년간의 유효기간을 가진다&#46;

- <strong>⚠️ </strong><strong>예외 처리</strong>
    - 백엔드
        - 유효기간 만료된 포인트는 차감된다&#46;

    - 프론트
        - 유효기간 소멸 임박 포인트를 확인 할 수 있다&#46;(30일 이내 소멸)

<a id="211a1dc90830413fb356522be76ed728"></a>

### 쿠폰

---

- 사용자는 쿠폰을 사용하여 매칭 횟수 충전이 가능하다&#46;

- 정책
    - 자동 지급 쿠폰
        - 가입 축하 쿠폰 (5회 무료 쿠폰)

        - 생일자 쿠폰 (5회 무료 쿠폰)

    - 쿠폰은 선착순과 전체 지급 두가지 경우만 존재한다&#46;

- 사용자
    - 쿠폰을 사용버튼을 눌러 무료 매칭 횟수를 충천할 수 있다&#46;

    - 쿠폰 발급 페이지를 통해 쿠폰을 선착순으로 받을 수 있다&#46; 

    - 받은 쿠폰은 쿠폰함에 저장 된다&#46;

- 관리자
    - 사용자에게 쿠폰을 지급할 수 있다&#46;
        - 쿠폰 지급은 모든 유저에게 또는 배너를 통해 선착순으로 지급 가능하다&#46;

    - 쿠폰 입력 내용
        - 이름, 무료 횟수, 내용, 소멸 기한(한달 기준으로 입력 가능)
            - 소멸기한의 경우 저장 되는 데이터는 생성일  &#43; 소멸기한 개월 수로 계산된 일자

- <strong>⚠️ </strong><strong>예외 처리</strong>
    - 백엔드
        - 사용자는 소멸기한이 지난 쿠폰을 사용할 수 없다&#46;

        - 본인이 가진 쿠폰만 사용 가능하다&#46;

        - <del>생일자 쿠폰을 1년 이내에 가지고 있는 상태에서 사용자가 생일을 변경할 경우 지급 되지 않는다&#46;</del>

    - 프론트
        - 사용자는 소멸기한이 지난 쿠폰을 볼 수 없다&#46;

        - 사용자는 사용한 쿠폰을 확인 가능하다&#46;

### 멤버쉽

---

<a id="335eda9b0fe180289b83c243b3b02973"></a>

결제를 통해 NOMAL, PREMIUM 멤버십으로 변경 가능하며 각 등급에 따라 매칭 시 필터 및 포인트 사용이 차등 적용됨

<a id="335eda9b0fe1803cb16bceef5a44f27e"></a>

### 관리자 페이지

---

<a id="335eda9b0fe18083bfa7f9cd5c3bb841"></a>

각 도메인별로 관리자 내용도 정리 되어있음

- 베너 관리

- 유저 관리 (등급, 블랙리스트 등)

- 매출 통계

- 쿠폰 관련 내용

- 결제 내역

<a id="764f28aeea3b473bb92650f61743b3d9"></a>

### 채팅

---

- 1&#58;1 채팅
    - 특정 사용자와 개인 채팅 기능

    - 채팅방 입장을 소캣 통신의 커넥션 연결로 판단

- 실시간 메세지 전송
    - 사용자가 메시지를 입력하면, 실시간으로 다른 사용자에게 전달

- 메세지 기록
    - 채팅 내역이 저장되어야 하며, 사용자는 이전 메세지를 확인 가능

    - DB

- 오프라인 상태에서도 메시지 확인 가능(예&#58; 캐싱)

- 사용자가 오프라인일 때 보낸 메시지를 나중에 수신
    - 메세지 큐 &#45; redis  사용

<a id="e24c83f3abe142d3aa269d4a2cca70a4"></a>

### 알림

---

- <strong>알람 알림</strong>
    - 해당되는 이벤트 발생 시, 사용자에게 알림 전송
        - 푸시 알림, 이메일, SMS 등

- <strong>알람 활성화/비활성화</strong>
    - 사용자가 알람을 활성화 또는 비활성화할 수 있도록 토글 기능 제공

- 매칭
    - 매칭 성공, 실패 시 알림 

- 메세지 수신 알림
    - 새 메시지 도착 시 브라우저 푸시알림

<a id="1dfe47683096409892c737376f381596"></a>

### 결제

---

- 구독과 포인트 충전이 가능하다&#46;

- 정책
    - 포인트 결제
        - 포인트를 결제할 경우 결제 금액의 10%를 사용자에게 포인트로 제공한다&#46;

- 결제&#58; 포트원 api 사용

- 결제 / 결제 취소 가능

- <strong>⚠️ </strong><strong>예외 처리</strong>
    - 백엔드
        - 결제한 금액 중 포인트 사용이 발생했을 경우 결제 취소가 불가능 하다&#46;

    - 프론트
        - 결제한 금액중 포인트 사용이 발생했을 경우 문자는 &#35;B1B1B1(임시)로 표시 된다&#46;

<a id="e176d87e217c46658248df4a03e94e3e"></a>

### 리뷰

---

- 1점 &#126; 5점 사이의 별점 형태로 매칭에 대한 리뷰를 남길 수 있음

- 매칭된 상대방의 리뷰(별점 평균) 확인 가능
