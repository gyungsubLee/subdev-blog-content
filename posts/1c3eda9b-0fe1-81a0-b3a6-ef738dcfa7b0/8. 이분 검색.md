# 문제

<a id="1c3eda9b0fe181e981d4d2571f2aeaf3"></a>

## <strong>8&#46; 이분검색</strong>

---

<a id="1c3eda9b0fe181548d6bc7c6bd73b3dc"></a>

### 설명

<a id="1c3eda9b0fe181e98103ecfdf17e1e2b"></a>

임의의 N개의 숫자가 입력으로 주어집니다&#46; N개의 수를 오름차순으로 정렬한 다음 N개의 수 중 한 개의 수인 M이 주어지면

<a id="1c3eda9b0fe181719e07e760239548c2"></a>

이분검색으로 M이 정렬된 상태에서 몇 번째에 있는지 구하는 프로그램을 작성하세요&#46; 단 중복값은 존재하지 않습니다&#46;

<a id="1c3eda9b0fe181efb415dcdc03947de3"></a>

### 입력

<a id="1c3eda9b0fe18105a599f097e47753ee"></a>

첫 줄에 한 줄에 자연수 N(3&#60;=N&#60;=1,000,000)과 M이 주어집니다&#46;

<a id="1c3eda9b0fe181a9a347e991debc63e6"></a>

두 번째 줄에 N개의 수가 공백을 사이에 두고 주어집니다&#46;

<a id="1c3eda9b0fe18180abf1d99bf504dd01"></a>

### 출력

<a id="1c3eda9b0fe1810eaaa0e0012ebc6827"></a>

첫 줄에 정렬 후 M의 값의 위치 번호를 출력한다&#46;

---

<a id="1c3eda9b0fe1813ca88cc4480baea015"></a>

### 예시 입력 1

<a id="1c3eda9b0fe18129b430ff1920b426df"></a>

```plaintext
8 32
23 87 65 12 57 32 99 81

```

# 풀이

<a id="1c3eda9b0fe181f4bf2ccfcbcac88e9c"></a>

## 풀이1) <code>내 풀이</code> 이분 검색 아님…

<a id="1c3eda9b0fe181d8ba01ec8864e01c41"></a>

```java
import java.util.*;

public class Main {
    public int solution(int n, int t, int[] arr) {
        int answer=0;
        Arrays.sort(arr);
        for(int i=0; i<n; i++){
            if(arr[i]==t) answer=i+1;
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int t=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        System.out.print(T.solution(n, t, arr));
    }
}
```

## 풀이2) <code>강의 풀이</code>  이분 검색

<a id="1c3eda9b0fe181c1a61ff5c5ea9bccf6"></a>

투포인터, 정렬 , 절반 값을 기준으로 줄여나감&#46;

<a id="1c3eda9b0fe181c9af3afbb247c15864"></a>

```java
import java.util.*;

public class Main {
    public int solution(int n, int t, int[] arr) {
        int answer=0;
        Arrays.sort(arr);
        int lt=0, rt=n-1;
        while(lt<=rt){
            int mid=(lt+rt)/2;   // '( )' 없으면 계산 처라 안됨.
            if(arr[mid]==t) {
                answer=mid+1;
                break;
            }
            else if(arr[mid]>t) rt=mid-1;
            else lt=mid+1;
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int t=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        System.out.print(T.solution(n, t, arr));
    }
}
```
