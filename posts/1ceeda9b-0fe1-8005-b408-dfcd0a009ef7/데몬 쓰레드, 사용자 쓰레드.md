## 데몬 쓰레드, 사용자 쓰레드

---

> 📖 
> 
> - <code>데몬 쓰레드</code>&#58; 보이지 않는 곳(background)에서 실행되는 낮은 우선순위를 가진 쓰레드 
> 
> - <code>사용자 쓰레드</code>&#58; 보이는 곳(foreground)에서 실행되는 높은 우선순위를 가진 쓰레드 

<details>
<summary>데몬 쓰레드 </summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe180ff8b9fd508f8e24e5d"></a>
> 
> 보이지 않는 곳(background)에서 실행되는 낮은 우선순위를 가진 쓰레드를 말한다&#46;
> 
> - 보조적인 역할을 담당하며 대표적인 데몬 쓰레드로는 메모리 영역을 정리해주는 가비지 컬렉터(GC)가 있다&#46;

<details>
<summary>데몬 쓰레드 설정 방법&#58; <code>setDaemon(true)</code></summary>

<a id="1ceeda9b0fe180ceab9ad663f0ce48b2"></a>

```java
public class Main {
    public static void main(String[] args) {
        Runnable demon = () -> {
            for (int i = 0; i < 1000000; i++) {
                System.out.println("demon");
            }
        };

        Thread thread = new Thread(demon);
        thread.setDaemon(true); // true 로 설정시 데몬스레드로 실행됨

        thread.start();

        for (int i = 0; i < 100; i++) {
            System.out.println("task");
        }
    }
```

- emon 쓰레드는 우선순위가 낮고 다른 쓰레드가 모두 종료되면 강제 종료 당한다

- 따라서  <code>main()</code> 쓰레드의 task가 100번이 먼저 찍히면 종료된다&#46;
    - 1000000번 수행이 되지 않고 종료

</details>

</details>

<details>
<summary>사용자 쓰레드 </summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe180098e18e4bb593b0b04"></a>
> 
> 보이는 곳(foreground)에서 실행되는 높은 우선순위를 가진 쓰레드를 말한다&#46;
> 
> <a id="1ceeda9b0fe1804989f6d2f0caf9e8d8"></a>
> 
> 프로그램 기능을 담당하며 대표적인 사용자 쓰레드로 메인 쓰레드가 있다&#46; 
> 
> - 기존 코드 예제들을 실행한 쓰레드들이  모두 사용자 쓰레드이다&#46; ( 자바 메인 쓰레드 )

> ⚠️  JVM은 사용자 쓰레드의 작업이 끝나면 데몬 쓰레드도 자동으로 종료시킨다&#46;

</details>
