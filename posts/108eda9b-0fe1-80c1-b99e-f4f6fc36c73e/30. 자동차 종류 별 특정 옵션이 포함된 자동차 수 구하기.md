## 문제

<a id="7f63fb78d9d94d9a9284469267f0ff0c"></a>

### 설명

<a id="10aeda9b0fe18043aa84c5c45db0f43e"></a>

다음은 어느 자동차 대여 회사에서 대여 중인 자동차들의 정보를 담은 <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블입니다&#46; <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블은 아래와 같은 구조로 되어있으며, <code>CAR&#95;ID</code>, <code>CAR&#95;TYPE</code>, <code>DAILY&#95;FEE</code>, <code>OPTIONS</code>는 각각 자동차 ID, 자동차 종류, 일일 대여 요금(원), 자동차 옵션 리스트를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| CAR&#95;ID | INTEGER | FALSE |
| CAR&#95;TYPE | VARCHAR(255) | FALSE |
| DAILY&#95;FEE | INTEGER | FALSE |
| OPTIONS | VARCHAR(255) | FALSE |

- 자동차 종류는 &#39;세단&#39;, &#39;SUV&#39;, &#39;승합차&#39;, &#39;트럭&#39;, &#39;리무진&#39;이 있습니다&#46;

- 자동차 옵션 리스트는 콤마(&#39;,&#39;)로 구분된 키워드 리스트(옵션 리스트 값 예시&#58; &#39;열선시트&#39;, &#39;스마트키&#39;, &#39;주차감지센서&#39;)로 되어있으며, 키워드 종류는 &#39;주차감지센서&#39;, &#39;스마트키&#39;, &#39;네비게이션&#39;, &#39;통풍시트&#39;, &#39;열선시트&#39;, &#39;후방카메라&#39;, &#39;가죽시트&#39;가 있습니다&#46;

---

<a id="10aeda9b0fe18050a0acde5ef31dd666"></a>

### 문제

<a id="10aeda9b0fe18013bf93cd7dc43f3527"></a>

<code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블에서 &#39;통풍시트&#39;, &#39;열선시트&#39;, &#39;가죽시트&#39; 중 하나 이상의 옵션이 포함된 자동차가 자동차 종류 별로 몇 대인지 출력하는 SQL문을 작성해주세요&#46; 이때 자동차 수에 대한 컬럼명은 <code>CARS</code>로 지정하고, 결과는 자동차 종류를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="10aeda9b0fe1802bb2abcfdfc6b44e58"></a>

### 예시

<a id="10aeda9b0fe180319c6fde4df39062a3"></a>

예를 들어 <code>CAR&#95;RENTAL&#95;COMPANY&#95;CAR</code> 테이블이 다음과 같다면&#58;

|  |  |  |  |
| --- | --- | --- | --- |
| CAR&#95;ID | CAR&#95;TYPE | DAILY&#95;FEE | OPTIONS |
| 1 | 세단 | 16000 | 가죽시트,열선시트,후방카메라 |
| 2 | SUV | 14000 | 스마트키,네비게이션,열선시트 |
| 3 | SUV | 22000 | 주차감지센서,후방카메라 |
| 4 | 트럭 | 35000 | 주차감지센서,네비게이션,열선시트 |
| 5 | SUV | 16000 | 가죽시트,네비게이션,열선시트,후방카메라,주차감지센서 |

<a id="10aeda9b0fe1803b93a3e7af9637cdc1"></a>

&#39;통풍시트&#39;, &#39;열선시트&#39;, &#39;가죽시트&#39; 중 하나 이상의 옵션이 포함된 자동차는 자동차 ID가 1, 2, 4, 5인 자동차이고, 자동차 종류 별로 몇 대인지 구하고 자동차 종류를 기준으로 오름차순 정렬하면 다음과 같은 결과가 나와야 합니다&#46;

|  |  |
| --- | --- |
| CAR&#95;TYPE | CARS |
| SUV | 2 |
| 세단 | 1 |
| 트럭 | 1 |

<a id="10aeda9b0fe18026a1bfc4915ccf92cf"></a>

## 풀이

<details>
<summary>🧐 Where 절을 통해 집계함수(count, avg, sum …) 연산에 조건을 부여할 수 있다&#46; </summary>

<a id="10aeda9b0fe1807ab41cff5e4b411845"></a>

```sql
SELECT CAR_TYPE, COUNT(*) CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE 
OPTIONS LIKE('%통풍시트%') OR 
OPTIONS LIKE('%열선시트%') OR 
OPTIONS LIKE('%가죽시트%') 
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE
```

<a id="10aeda9b0fe1809487b2d0bed3de4e5b"></a>

<br> 1&#46;   Car&#95;type의 타입 값 for문 (<code>group by</code>)

1. 집계함수 연산 (<code>count()</code>)

1. where 절 조건에 맞는 경우만 카운팅 처리됨&#46;

</details>

<a id="10aeda9b0fe180e6a080e31971fc5ca0"></a>

문제의 조건은 OPTIONS 컬럼에 ‘통풍시트’, ‘열선시트’, ‘가죽시트’ 중 하나라도 포함된 자동차를 자동차 종류별로 그룹화하여 그 개수를 출력하는 것 이다&#46;

<a id="10aeda9b0fe180f5ae2de4f1731877d3"></a>

### 풀이1 &#45; REGEXP ( 정규식 )

<a id="323c2195206849a1aeb9db9e6f017ad9"></a>

```sql
SELECT CAR_TYPE, COUNT(*) CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE 
OPTIONS REGEXP '통풍시트|열선시트|가죽시트'
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE
```

<a id="4020ddc77b2a42528e09950e598831be"></a>

### 풀이 2 &#45; LIKE

<a id="10aeda9b0fe180da82a0ca5e054db93f"></a>

```sql
SELECT CAR_TYPE, COUNT(*) CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE 
OPTIONS LIKE('%통풍시트%') OR 
OPTIONS LIKE('%열선시트%') OR 
OPTIONS LIKE('%가죽시트%') 
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE
```

<a id="10aeda9b0fe180b895baee549d10105f"></a>

### 풀이3 &#45; INSTR

<a id="0ae670beb9274f068daced044eb58025"></a>

```sql
SELECT CAR_TYPE, COUNT(*) CARS
FROM CAR_RENTAL_COMPANY_CAR
WHERE 
INSTR(OPTIONS, '통풍시트') > 0 OR
INSTR(OPTIONS, '열선시트') > 0 OR
INSTR(OPTIONS, '가죽시트') > 0 
GROUP BY CAR_TYPE
ORDER BY CAR_TYPE
```
