### 자바에서의 예외처리

---

<a id="146eda9b0fe180cfa8fbea25319ae6a0"></a>

자바에서의 예외는 크게 2가지로 나뉜다&#46;

<a id="146eda9b0fe180949de1f62e811b0534"></a>

<u>예외 자체를 의미</u>하는 <code>Exception</code> 클래스, 그리고 <u>예외를 핸들링</u>하기 위한 <code>try&#45;catch</code>가 있다&#46;

<a id="146eda9b0fe18042a620d4dbe31cbfe8"></a>

다 못외운다&#46; 

![](a58935ff083189b0.webp)

<a id="146eda9b0fe180fbbb1af2fecaef334e"></a>

자바에서 Exception은 다시 2가지로 나뉜다&#46;

- Checked Exception

- UnChecked Exception

<a id="146eda9b0fe180738b45e3cf50a196b3"></a>

Checked Exception은 반드시 try&#45;catch나 상위 메소드로 throws 처리를 해야하는 예외를 말한다&#46; 

<a id="146eda9b0fe180949122d9741b72d16e"></a>

처리를 하지 않고 컴파일을 시, 오류가 발생되어 실패한다&#46;

<a id="146eda9b0fe1803a85abf7748ccc7ccd"></a>

왜 2종류는 나누는가?

<a id="146eda9b0fe18048a3abfff88e31dfaa"></a>

Checked Exception은 예외에 반드시 어떻게 처리할 지를 구현해야 한다&#46;

<a id="146eda9b0fe180aa8b41da0d3d63d276"></a>

내가 작성한 모든 코드에 대해서 100% 예외를 처리해야 된다는 얘기이다&#46; 

<a id="146eda9b0fe1800998cac78511612970"></a>

과연 이게 가능한가? 가능하더라도 그 코드를 읽는 것이 쉬운가? 

<a id="146eda9b0fe18013a5e9f5a417bab30e"></a>

예시

<a id="146eda9b0fe1800487d1ccb624695065"></a>

try&#45;cath문을 계속 사용하면, 어떻게 

<a id="146eda9b0fe180f9933df8f4e96cb34e"></a>

→ 모든 것을 checked Exception 처리를 하면 가독성이 해친다&#46;

<a id="146eda9b0fe18036bf70c733a3159766"></a>

굳이 중요하지 않거나 필요가 없는 경우는 unchecked Exception으로 정의 해서 예외를 처리해야되는 경우를 제외하여 가독성을 높인다 &#46;

<a id="146eda9b0fe18034a53fc4b97da9fd2c"></a>

예외상황에 대한 처리를 강제함으로써 프로그램의 안정성을 향상 시킨다&#46;

<a id="146eda9b0fe18088bd1bce3b700c2ff3"></a>

checked Exception

<a id="146eda9b0fe180718107eeca83b8ab1d"></a>

예외처리 강제, 코드 안정성 향상

<a id="146eda9b0fe18070a5c3cecada4ddad9"></a>

예외 발생 가능성을 명확히 문서화

<a id="146eda9b0fe18044a347c1e548f69aee"></a>

가독성 떨어짐, 코드 생산성 하락

<a id="146eda9b0fe180c68babd7a5c3ab4d29"></a>

불필요한 예외 처리로 코드 복잡성 증가

<a id="146eda9b0fe180a7abd0cf5a24915569"></a>

unchecked Exception 

<a id="146eda9b0fe1808a95e9c2d1b6efc1ab"></a>

단순하고 가독성 높은 코드 작성 가능

<a id="146eda9b0fe180e990dfe4250972a95f"></a>

필요한ㄹ때만 예외 처리

<a id="146eda9b0fe18041a1bdf79f94baf0bd"></a>

예외 누락할 가능성이  있음, 시스템 신뢰도 하락
