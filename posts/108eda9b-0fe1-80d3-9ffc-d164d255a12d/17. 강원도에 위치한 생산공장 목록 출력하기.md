## 문제

<a id="1d2eda9b0fe180df9073d9fddbae912c"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180328393d61fc2fe6ce9"></a>

다음은 식품공장의 정보를 담은 <code>FOOD&#95;FACTORY</code> 테이블입니다&#46; <code>FOOD&#95;FACTORY</code> 테이블은 다음과 같으며 <code>FACTORY&#95;ID</code>, <code>FACTORY&#95;NAME</code>, <code>ADDRESS</code>, <code>TLNO</code>는 각각 공장 ID, 공장 이름, 주소, 전화번호를 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| FACTORY&#95;ID | VARCHAR(10) | FALSE |
| FACTORY&#95;NAME | VARCHAR(50) | FALSE |
| ADDRESS | VARCHAR(100) | FALSE |
| TLNO | VARCHAR(20) | TRUE |

---

<a id="1d2eda9b0fe180e0a94dc82e3b93aaab"></a>

### 문제

<a id="1d2eda9b0fe18006836ec455a30cedb7"></a>

<code>FOOD&#95;FACTORY</code> 테이블에서 강원도에 위치한 식품공장의 공장 ID, 공장 이름, 주소를 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 공장 ID를 기준으로 오름차순 정렬해주세요&#46;

---

SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| FACTORY&#95;ID | FACTORY&#95;NAME | ADDRESS |
| FT19980003 | (주)맛있는라면 | 강원도 정선군 남면 칠현로 679 |
| FT20100003 | (주)맛있는음료 | 강원도 원주시 문막읍 문막공단길 154 |
| FT20100004 | (주)맛있는국 | 강원도 평창군 봉평면 진조길 227&#45;35 |

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe1802187f2e435083fcaf1"></a>
> 
> 조건
> 
> - 강원도에 위치한 식품공장의 공장 ID, 공장 이름, 주소를 조회
> 
> - 공장 ID를 기준으로 오름차순 정렬

<a id="1d2eda9b0fe180af804df4e882472f09"></a>

```sql
SELECT FACTORY_ID, FACTORY_NAME, ADDRESS
FROM FOOD_FACTORY
WHERE ADDRESS LIKE '강원도%'
ORDER BY FACTORY_ID
```
