## 문제

<a id="1d2eda9b0fe180838f57eb75ec5348ff"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180dc8a2adceaa461e3f4"></a>

<code>ANIMAL&#95;OUTS</code> 테이블은 동물 보호소에서 입양 보낸 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;OUTS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;OUTCOME</code>는 각각 동물의 아이디, 생물 종, 입양일, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;OUTCOME | VARCHAR(N) | FALSE |

<a id="1d2eda9b0fe1808491c3feccf7be1994"></a>

보호소에서는 몇 시에 입양이 가장 활발하게 일어나는지 알아보려 합니다&#46; 09&#58;00부터 19&#58;59까지, 각 시간대별로 입양이 몇 건이나 발생했는지 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 시간대 순으로 정렬해야 합니다&#46;

<a id="1d2eda9b0fe1809a9de5c4f1e388491f"></a>

### 예시

<a id="1d2eda9b0fe180fdabc9fd671a2939aa"></a>

SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| HOUR | COUNT |
| 9 | 1 |
| 10 | 2 |
| 11 | 13 |
| 12 | 10 |
| 13 | 14 |
| 14 | 9 |
| 15 | 7 |
| 16 | 10 |
| 17 | 12 |
| 18 | 16 |
| 19 | 2 |

<a id="1d2eda9b0fe180e9bcb3df0f2de82908"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe180b48eb1c36bf01266ea"></a>
> 
> 조건
> 
> - 09&#58;00부터 19&#58;59까지, 각 시간대별로 입양이 몇 건이나 발생했는지 조회
> 
> -  결과는 시간대 순으로 정렬

<a id="1d2eda9b0fe1803eb30fd4b313353bbf"></a>

### 1차 풀이

<a id="1d2eda9b0fe18031aa2bdf3b0fb22b65"></a>

```sql
SELECT 
    CASE
        WHEN HOUR BETWEEN 9 AND 10 THEN '9'
        WHEN HOUR BETWEEN 10 AND 11 THEN '10'
        WHEN HOUR BETWEEN 11 AND 12 THEN '11'
        WHEN HOUR BETWEEN 12 AND 13 THEN '12'
        WHEN HOUR BETWEEN 13 AND 14 THEN '13'
        WHEN HOUR BETWEEN 14 AND 15 THEN '14'
        WHEN HOUR BETWEEN 15 AND 16 THEN '15'
        WHEN HOUR BETWEEN 16 AND 17 THEN '16'
        WHEN HOUR BETWEEN 17 AND 18 THEN '17'
        WHEN HOUR BETWEEN 18 AND 19 THEN '18'
        WHEN HOUR BETWEEN 19 AND 20 THEN '19'
        END AS 'HOUR',
    COUNT(*) COUNT
FROM (
    SELECT DATE_FORMAT(DATETIME, '%H') HOUR
    FROM ANIMAL_OUTS
) 
GROUP BY HOUR 
ORDER BY HOUR
```

- 문법 오류 

<a id="1d2eda9b0fe180689cb0da4c01194f54"></a>

```sql
SELECT 
    CASE HOUR(DATETIME)
        WHEN 9 THEN '9'
        WHEN 10 THEN '10'
        WHEN 11 THEN '11'
        WHEN 12 THEN '12'
        WHEN 13 THEN '13'
        WHEN 14 THEN '14'
        WHEN 15 THEN '15'
        WHEN 16 THEN '16'
        WHEN 17 THEN '17'
        WHEN 18 THEN '18'
        WHEN 19 THEN '19'
    END AS HOUR,
    COUNT(*) AS COUNT
FROM ANIMAL_OUTS
WHERE HOUR(DATETIME) BETWEEN 9 AND 19
GROUP BY HOUR
ORDER BY CAST(HOUR AS UNSIGNED);
```

<a id="1d2eda9b0fe180c4bb31db6712a711e3"></a>

### 풀이1 ) <strong> 인덱스 활용 &#43; 서브쿼리</strong>

<a id="1d2eda9b0fe180589acfef25ed52671f"></a>

```sql
SELECT 
    HOUR,
    COUNT(*) AS COUNT
FROM (
    SELECT 
        CAST(DATE_FORMAT(DATETIME, '%H') AS UNSIGNED) AS HOUR
    FROM ANIMAL_OUTS
    WHERE DATETIME >= '0000-00-00 09:00:00'
      AND DATETIME <  '9999-12-31 20:00:00'
) AS hour_table
WHERE HOUR BETWEEN 9 AND 19
GROUP BY HOUR
ORDER BY HOUR;
```

<a id="1d2eda9b0fe180229a9cfa32a50a05a1"></a>

### 풀이 2)  HOUR()

<a id="1d2eda9b0fe18086a33cdd51b6b98a14"></a>

```sql
SELECT 
    HOUR(DATETIME) AS HOUR,
    COUNT(*) AS COUNT
FROM ANIMAL_OUTS
WHERE HOUR(DATETIME) BETWEEN 9 AND 19
GROUP BY HOUR 
ORDER BY HOUR
```

<a id="1d2eda9b0fe180b6932fe37dc735ba8e"></a>

### 풀이 3) WHERE 절에서 <code>HOUR()</code> 제거

> MySQL에서 인덱스를 사용하려면 <strong>WHERE 조건에서 컬럼 자체가 가공되지 않아야 한다&#46;</strong>

<a id="1d2eda9b0fe1807ba768f83299c45b0b"></a>

```sql
SELECT HOUR(DATETIME) AS HOUR, COUNT(*) AS COUNT
FROM ANIMAL_OUTS
WHERE DATETIME >= '2021-01-01'  -- 가능한 최소 범위로 잡기
  AND DATETIME <  '2022-01-01'  -- 최대한 인덱스가 효율적이게
  AND HOUR(DATETIME) BETWEEN 9 AND 19
GROUP BY HOUR
ORDER BY HOUR;
```
