> 
> ---
> 
> - <strong>배열이란 무엇인가요?</strong>
>     - 배열은 동일한 데이터 타입의 여러 값을 저장할 수 있는 자료구조입니다&#46;
>         <a id="fffeda9b0fe1819c8368c2294b93903d"></a>
> 
>         ```java
>         int[] numbers = {1, 2, 3, 4, 5};
>         ```
> 
> - <strong>사용자 입력 받기</strong>
>     - <code>Scanner</code> 클래스를 사용하여 사용자로부터 데이터를 입력받을 수 있습니다&#46;
>         <a id="fffeda9b0fe18188bf6ef06b0ec4f6c3"></a>
> 
>         ```java
>         Scanner scanner = new Scanner(System.in);
>         System.out.print("숫자를 입력해주세요.");
>         int number = scanner.nextInt();
>         ```
> 
> - <strong>반복문으로 배열 순회</strong>
>     - 반복문을 사용하여 배열의 각 요소를 하나씩 검사할 수 있습니다&#46;
>         <a id="fffeda9b0fe181fc9024f733691468b1"></a>
> 
>         ```java
>         for (int i = 0; i < numbers.length; i++) {
>             System.out.println(numbers[i]);
>         }
>         ```
