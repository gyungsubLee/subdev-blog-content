# 문제

<a id="1c3eda9b0fe181ab9624f9b6e6976b6c"></a>

## <strong>7&#46; 교육과정 설계</strong>

---

<a id="1c3eda9b0fe1815daf54d8bffe607716"></a>

### 설명

<a id="1c3eda9b0fe1818796aafa24445b3f63"></a>

현수는 1년 과정의 수업계획을 짜야 합니다&#46;

<a id="1c3eda9b0fe18100ad8dcfcea78bc90b"></a>

수업중에는 필수과목이 있습니다&#46; 이 필수과목은 반드시 이수해야 하며, 그 순서도 정해져 있습니다&#46;

<a id="1c3eda9b0fe181169387f83b621963e6"></a>

만약 총 과목이 A, B, C, D, E, F, G가 있고, 여기서 필수과목이 CBA로 주어지면 필수과목은 C, B, A과목이며 이 순서대로 꼭 수업계획을 짜야 합니다&#46;

<a id="1c3eda9b0fe181b7bb20f2a8b832b516"></a>

여기서 순서란 B과목은 C과목을 이수한 후에 들어야 하고, A과목은 C와 B를 이수한 후에 들어야 한다는 것입니다&#46;

<a id="1c3eda9b0fe1812f9f5ccdd61f77ce08"></a>

현수가 C, B, D, A, G, E로 수업계획을 짜면 제대로 된 설계이지만

<a id="1c3eda9b0fe181369c35f1585ff1e316"></a>

C, G, E, A, D, B 순서로 짰다면 잘 못 설계된 수업계획이 됩니다&#46;

<a id="1c3eda9b0fe18138ad38e6452b584740"></a>

수업계획은 그 순서대로 앞에 수업이 이수되면 다음 수업을 시작하다는 것으로 해석합니다&#46;

<a id="1c3eda9b0fe18120aa18e678127b5f71"></a>

수업계획서상의 각 과목은 무조건 이수된다고 가정합니다&#46;

<a id="1c3eda9b0fe1817d9d72fb6425e0c29f"></a>

필수과목순서가 주어지면 현수가 짠 N개의 수업설계가 잘된 것이면 “YES&#34;, 잘못된 것이면 ”NO“를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1814aa52bfacb1342a0d9"></a>

### 입력

<a id="1c3eda9b0fe18180a4fce33834c226f8"></a>

첫 줄에 한 줄에 필수과목의 순서가 주어집니다&#46; 모든 과목은 영문 대문자입니다&#46;

<a id="1c3eda9b0fe181bab190c1e1f79c8ea5"></a>

두 번 째 줄부터 현수가 짠 수업설계가 주어집니다&#46;(수업설계의 길이는 30이하이다)

<a id="1c3eda9b0fe181ebae88c060bf4746ba"></a>

### 출력

<a id="1c3eda9b0fe1811db60dd9d460731a75"></a>

첫 줄에 수업설계가 잘된 것이면 “YES&#34;, 잘못된 것이면 ”NO“를 출력합니다&#46;

---

<a id="1c3eda9b0fe18116b136c757d06094a0"></a>

<a id="1c3eda9b0fe181688aa9dc0aac521571"></a>

CBA
CBDAGE

```

### 예시 출력 1

YES
```

# 풀이

## 풀이1)

<a id="1c3eda9b0fe181208038f48b127e48f7"></a>

```java
import java.util.*;
public class Main {
    public String  solution(String n, String m){
        Queue<Character> Q = new LinkedList<>();
        for(char x: n.toCharArray()) Q.offer(x);
        for(char x: m.toCharArray()){
            if(Q.contains(x)){
                if(x!=Q.poll()) return "NO";
            }
        }
        if(!Q.isEmpty()) return "NO";
        return "YES";
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String n = sc.next();
        String m = sc.next();
        System.out.println(T.solution(n, m));
    }
}
```
