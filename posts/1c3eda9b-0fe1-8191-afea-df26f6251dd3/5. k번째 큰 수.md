# 문제

<a id="1c3eda9b0fe181c3a848d6a27bf12fda"></a>

## <strong>5&#46; K번째 큰 수</strong>

---

<a id="1c3eda9b0fe181879424cff62f71eecf"></a>

### 설명

<a id="1c3eda9b0fe1810f9da8e0f6079f46c9"></a>

현수는 1부터 100사이의 자연수가 적힌 N장의 카드를 가지고 있습니다&#46; 같은 숫자의 카드가 여러장 있을 수 있습니다&#46;

<a id="1c3eda9b0fe181b28429f5e38fec5115"></a>

현수는 이 중 3장을 뽑아 각 카드에 적힌 수를 합한 값을 기록하려고 합니다&#46; 3장을 뽑을 수 있는 모든 경우를 기록합니다&#46;

<a id="1c3eda9b0fe181d69afcefce3830f7c1"></a>

기록한 값 중 K번째로 큰 수를 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181cbb875e6f642e7abbd"></a>

만약 큰 수부터 만들어진 수가 25 25 23 23 22 20 19&#46;&#46;&#46;&#46;&#46;&#46;이고 K값이 3이라면 K번째 큰 값은 22입니다&#46;

<a id="1c3eda9b0fe1813aa6b8eff1715d640d"></a>

### 입력

<a id="1c3eda9b0fe181aeb2baede3db40856c"></a>

첫 줄에 자연수 N(3&#60;=N&#60;=100)과 K(1&#60;=K&#60;=50) 입력되고, 그 다음 줄에 N개의 카드값이 입력된다&#46;

<a id="1c3eda9b0fe18143b5e6f10610b9ab97"></a>

### 출력

<a id="1c3eda9b0fe181cda59afa03f2f18d35"></a>

첫 줄에 K번째 수를 출력합니다&#46; K번째 수가 존재하지 않으면 &#45;1를 출력합니다&#46;

---

<a id="1c3eda9b0fe181119aebcbabb0c88928"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181ef846ec56f802f6b6a"></a>

```plaintext
10 3
13 15 34 23 45 65 33 11 26 42

```

<a id="1c3eda9b0fe181588751f456d5ce6d43"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181b2af8be1d7ce2d6452"></a>

```plaintext
143
```

## 풀이1)

<a id="1c3eda9b0fe1813b9d01d4b3337c7fdb"></a>

```java
import java.util.*;
public class Main {
    public int  solution(int n, int m, int[] arr){
        TreeSet<Integer> Tset = new TreeSet<>(Collections.reverseOrder());
        for(int i=0; i<n; i++){
            for(int j=i+1; j<n; j++){
                for(int k=j+1; k<n; k++){
                    int sum=arr[i]+arr[j]+arr[k];
                    Tset.add(sum);
                }
            }
        }

        int cnt=0, answer=-1;
        for(int x: Tset){
            cnt++;
            if(cnt==m) {
                answer=x;
                break;
            }
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n= sc.nextInt();
        int m=sc.nextInt();
        int[] arr =new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.println(T.solution(n, m, arr));
    }
}
```
