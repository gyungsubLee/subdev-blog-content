## 문제

<a id="1d9eda9b0fe180f69360d2a62a1d432b"></a>

### <strong>문제 설명</strong>

<a id="1d9eda9b0fe180d180cef0f8319d8229"></a>

다음은 중고 거래 게시판 정보를 담은 <code>USED&#95;GOODS&#95;BOARD</code> 테이블과 중고 거래 게시판 사용자 정보를 담은 <code>USED&#95;GOODS&#95;USER</code> 테이블입니다&#46; <code>USED&#95;GOODS&#95;BOARD</code> 테이블은 다음과 같으며 <code>BOARD&#95;ID</code>, <code>WRITER&#95;ID</code>, <code>TITLE</code>, <code>CONTENTS</code>, <code>PRICE</code>, <code>CREATED&#95;DATE</code>, <code>STATUS</code>, <code>VIEWS</code>는 게시글 ID, 작성자 ID, 게시글 제목, 게시글 내용, 가격, 작성일, 거래상태, 조회수를 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| BOARD&#95;ID | VARCHAR(5) | FALSE |
| WRITER&#95;ID | VARCHAR(50) | FALSE |
| TITLE | VARCHAR(100) | FALSE |
| CONTENTS | VARCHAR(1000) | FALSE |
| PRICE | NUMBER | FALSE |
| CREATED&#95;DATE | DATE | FALSE |
| STATUS | VARCHAR(10) | FALSE |
| VIEWS | NUMBER | FALSE |

<a id="1d9eda9b0fe180709e50fc675bf39823"></a>

<code>USED&#95;GOODS&#95;USER</code> 테이블은 다음과 같으며 <code>USER&#95;ID</code>, <code>NICKNAME</code>, <code>CITY</code>, <code>STREET&#95;ADDRESS1</code>, <code>STREET&#95;ADDRESS2</code>, <code>TLNO</code>는 각각 회원 ID, 닉네임, 시, 도로명 주소, 상세 주소, 전화번호를 를 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| USER&#95;ID | VARCHAR(50) | FALSE |
| NICKNAME | VARCHAR(100) | FALSE |
| CITY | VARCHAR(100) | FALSE |
| STREET&#95;ADDRESS1 | VARCHAR(100) | FALSE |
| STREET&#95;ADDRESS2 | VARCHAR(100) | TRUE |
| TLNO | VARCHAR(20) | FALSE |

### 문제

<a id="1d9eda9b0fe1804c8e60c4fc200982f9"></a>

<code>USED&#95;GOODS&#95;BOARD</code>와 <code>USED&#95;GOODS&#95;USER</code> 테이블에서 완료된 중고 거래의 총금액이 70만 원 이상인 사람의 회원 ID, 닉네임, 총거래금액을 조회하는 SQL문을 작성해주세요&#46; 결과는 총거래금액을 기준으로 오름차순 정렬해주세요&#46;

## 풀이

<details>
<summary>🧐 <code>WHERE</code> vs <code>HAVING</code></summary>

| <strong>구분</strong> | <strong>WHERE</strong> | <strong>HAVING</strong> |
| --- | --- | --- |
| 시점 | <strong>GROUP BY</strong> 전에 필터링 | <strong>GROUP BY</strong> 후에 집계 결과를 필터링 |
| 대상 | <strong>개별 행(레코드)</strong> | <strong>집계된 결과</strong> (ex&#58; SUM, AVG 등) |
| 사용 가능한 컬럼 | 테이블에 존재하는 “원래” 컬럼 | 집계함수(SUM, AVG 등)도 사용 가능 |
| 대표 예시 | 가격이 5000 이상인 상품만 조회 | 합계가 10만 이상인 사람만 조회 |

</details>

> ✏️ 
> 
> <a id="1d9eda9b0fe180ea87b1f5b6293f5b3c"></a>
> 
> 조건
> 
> - 완료된 중고 거래의 총금액이 70만 원 이상인 사람의 회원 ID, 닉네임, 총거래금액을 조회
> 
> - 총거래금액을 기준으로 오름차순 정렬

<a id="1d9eda9b0fe180029762c4482b4b80b0"></a>

```sql
SELECT 
    U.USER_ID, 
    U.NICKNAME, 
    SUM(B.PRICE) AS TOTAL_SALES
FROM USED_GOODS_BOARD B
JOIN USED_GOODS_USER U ON U.USER_ID = B.WRITER_ID
WHERE B.STATUS = 'DONE'
GROUP BY  U.USER_ID, U.NICKNAME
HAVING TOTAL_SALES >= 700000
ORDER BY TOTAL_SALES;
```
