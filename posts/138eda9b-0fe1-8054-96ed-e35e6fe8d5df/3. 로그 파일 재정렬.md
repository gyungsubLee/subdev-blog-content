## 문제

<a id="138eda9b0fe180f4b057eaa1a773f80c"></a>

# <strong><a href="https://leetcode.com/problems/reorder-data-in-log-files/">37&#46; Reorder Data in Log Files</a></strong>

<a id="138eda9b0fe180a88360c0e071a8c401"></a>

You are given an array of <code>logs</code>&#46; Each log is a space&#45;delimited string of words, where the first word is the <strong>identifier</strong>&#46;

<a id="138eda9b0fe180cbb1a7e6bac6b45cab"></a>

There are two types of logs&#58;

- <strong>Letter&#45;logs</strong>&#58; All words (except the identifier) consist of lowercase English letters&#46;

- <strong>Digit&#45;logs</strong>&#58; All words (except the identifier) consist of digits&#46;

<a id="138eda9b0fe180bcaa79dd6b91610671"></a>

Reorder these logs so that&#58;

1. The <strong>letter&#45;logs</strong> come before all <strong>digit&#45;logs</strong>&#46;

1. The <strong>letter&#45;logs</strong> are sorted lexicographically by their contents&#46; If their contents are the same, then sort them lexicographically by their identifiers&#46;

1. The <strong>digit&#45;logs</strong> maintain their relative ordering&#46;

<a id="138eda9b0fe180b68b14e58e9e85c417"></a>

Return <em>the final order of the logs</em>&#46;

<a id="138eda9b0fe180398849df7b18dcc140"></a>

<strong>Example 1&#58;</strong>

<a id="138eda9b0fe180dca664e38f5945cafd"></a>

```plaintext
Input: logs = ["dig1 8 1 5 1","let1 art can","dig2 3 6","let2 own kit dig","let3 art zero"]
Output: ["let1 art can","let3 art zero","let2 own kit dig","dig1 8 1 5 1","dig2 3 6"]
Explanation:
The letter-log contents are all different, so their ordering is "art can", "art zero", "own kit dig".
The digit-logs have a relative order of "dig1 8 1 5 1", "dig2 3 6".

```

<a id="138eda9b0fe180e2afadd67d4ac9ccbe"></a>

<strong>Example 2&#58;</strong>

<a id="138eda9b0fe180c3b0e7c8ad0eb40d78"></a>

```plaintext
Input: logs = ["a1 9 2 3 1","g1 act car","zo4 4 7","ab1 off key dog","a8 act zoo"]
Output: ["g1 act car","a8 act zoo","ab1 off key dog","a1 9 2 3 1","zo4 4 7"]

```

<a id="138eda9b0fe180edb48fed72d15779ef"></a>

<strong>Constraints&#58;</strong>

- <code>1 &#60;= logs&#46;length &#60;= 100</code>

- <code>3 &#60;= logs&#91;i&#93;&#46;length &#60;= 100</code>

- All the tokens of <code>logs&#91;i&#93;</code> are separated by a <strong>single</strong> space&#46;

- <code>logs&#91;i&#93;</code> is guaranteed to have an identifier and at least one word after the identifier&#46;

<a id="138eda9b0fe18191b691f921c8768af0"></a>

## 풀이

> 실무에서도 이와 같은 로직을 많이 쓴다

- 정렬 조건
    1. 맨 앞 식별자는 순서에 영향을 주지 않음

    1. 문자로 구성된 로그가 숫자로 구성된 로그보다 앞에 온다&#46; 

    1.  문자 로그는 사전순으로 정렬한다&#46; 

    1. 문자가 동일한 경우 식별자 순으로 정렬한다&#46; 

    1. 숫자 로그는 입력 순서대로 정렬한다&#46;

<a id="138eda9b0fe180899a4feb32b8beb0f9"></a>

### 풀이1  &#45;  문자 분할, 정렬 ( 정렬 조건 )

<summary>🧐 <code>compareTo()</code></summary>

    - 0&#58; 두 객체가 같다는 의미

    - 음수&#58; 현재 객체가 비교 대상 객체보다 작다는 의미

- sort() 는 반환값에 따라 요소들의 위치를 바꾼다&#46; 
    - 음수인 경우 위치를 유지

    - 양수인 경우 두 요소의 위치를 교환

</details>

    -  List(리스트) → Array(배열

    - Object 배열을 반환하기 때문에,특정 타입으로 생성 시,  아래와 같이 빈 객체를 생성해 제공해야 한다&#46;

- <code>new String&#91;0&#93;</code>
    - <em>단순히 빈 배열을 제공 </em>하여 <code>toArray()</code> 메서드가<u> 원하는 타입의 배열을 생성</u>할 수 있도록 하는 관용적인 방법이다,

    -  JVM이 내부적으로 최적화를 할 수 있게 해준다,<br>즉, 새로운 배열을 할당할 때 타입 추론이 가능해지므로 보다 효율적인 메모리 할당을 할 수 있다&#46;

</details>

<a id="138eda9b0fe180bd8f1dd3b87f3f1aa4"></a>

```java
class Solution {
    public String[] reorderLogFiles(String[] logs) {
		    // 문자 로그를 저장할 list
        List<String> letterList = new ArrayList<>();
		    // 숫자 로그를 저장할 list
        List<String> digitList = new ArrayList<>();

        for(String log : logs){
		        // log의 2번째 요소가 숫자인지 판별
            if( Character.isDigit(log.split(" ")[1].charAt(0))){
                digitList.add(log);
            } else {
                letterList.add(log);
            }
        }

        // 문자 리스트 정렬 진행
        letterList.sort((s1, s2) -> {
            // 식별자, 실별자 외 나머지 부분으로 split
            String[] s1x = s1.split(" ", 2);  // 2 번쨰 파라미터 값을 통해 나눠지는 개수 설정 가능
            String[] s2x = s2.split(" ", 2);

            // 문자 로그 사전순 비교
            int compared = s1x[1].compareTo(s2x[1]);

            // 믄지기 동일한 경우(compared=0), 식별자 비교
            if (compared == 0) {
                return s1x[0].compareTo(s2x[0]);
            } else {
                return compared;
            } // 비교 대상 동일: 0, 순서가 앞인 경우: 1. 순서가 뒤인 경우: -1
        });

        // 문자 리스트에 숫자 리스트 붙임
        letterList.addAll(digitList);

        // 리스트를 String 배열로 반환
        return letterList.toArray(new String[0]);
    }
}
```
