<a id="203eda9b0fe1803ca7daf3162a885b2e"></a>

### 📐 아키텍처

<a id="203eda9b0fe180e9b323c646ce1579e3"></a>

```yaml
[ GitHub Push ] 
	→ Webhook 
	→ Nginx (443/80) 
	→ Jenkins (Docker, HTTPS) 
	→ Unity 빌드 
	→ Firebase 배포 
	→ Slack 알림
```

## 🧩 Jenkinsfile 예시

<a id="203eda9b0fe1803a9d2fd520d3c56eda"></a>

```yaml
pipeline {  
    agent any  
    environment {  
        SLACK_CHANNEL = "#cicd"  
        UNITY_PROJECT_PATH = "unity-project"  
        BUILD_OUTPUT_PATH = "build/output.apk"  
        FIREBASE_APP_ID = credentials('firebase_app_id')  
        FIREBASE_TOKEN = credentials('firebase_token')  
        SLACK_WEBHOOK = credentials('slack_webhook')  
    }  
    triggers {  
        githubPush()  
    }  
    stages {  
        stage('Checkout') {  
            steps {  
                git url: 'https://github.com/your-org/unity-game-repo.git', branch: 'main'  
            }  
        }  
        stage('Unity Build') {  
            steps {  
                sh "chmod +x ./scripts/build.sh"  
                sh "./scripts/build.sh $UNITY_PROJECT_PATH"  
            }  
        }  
        stage('Distribute to Firebase') {  
            steps {  
                sh "chmod +x ./scripts/deploy.sh"  
                sh "./scripts/deploy.sh $FIREBASE_APP_ID $BUILD_OUTPUT_PATH $FIREBASE_TOKEN"  
            }  
        }  
    }  
    post {  
        success {  
            sh "scripts/notify.sh success"  
        }  
        failure {  
            sh "scripts/notify.sh failure"  
        }  
    }  
}
```

<summary>build&#46;sh</summary>

<a id="203eda9b0fe1809d80c8f386328672f9"></a>

```shell
#!/bin/bash  
UNITY_PATH="/opt/Unity/Editor/Unity"  
PROJECT_PATH=$1  
BUILD_PATH="build/output.apk"  
BUILD_TARGET="Android"  
BUILD_METHOD="BuildScript.BuildAndroid"  
$UNITY_PATH \  
  -batchmode \  
  -nographics \  
  -silent-crashes \  
  -logFile /dev/stdout \  
  -projectPath "$PROJECT_PATH" \  
  -executeMethod "$BUILD_METHOD" \  
  -buildTarget "$BUILD_TARGET" \  
  -quit  
echo "✅ Unity Build 완료: $BUILD_PATH"
```

<summary>deploy&#46;sh</summary>

<a id="203eda9b0fe180e78260c80d4a4823e3"></a>

```shell
#!/bin/bash  
FIREBASE_APP_ID=$1  
APK_PATH=$2  
TOKEN=$3  
firebase appdistribution:distribute "$APK_PATH" \  
  --app "$FIREBASE_APP_ID" \  
  --token "$TOKEN" \  
  --groups "testers"
```

<summary>notify&#46;sh</summary>

<a id="203eda9b0fe180a5a2f4c2caa404af66"></a>

```shell

#!/bin/bash  
STATUS=$1  
WEBHOOK=$(cat /run/secrets/slack_webhook)  
if [ "$STATUS" = "success" ]; then  
  COLOR="#36a64f"  
  TEXT="✅ Unity Build & Deploy 성공"  
else  
  COLOR="#ff0000"  
  TEXT="❌ Unity Build or Deploy 실패"  
fi  
curl -X POST -H 'Content-type: application/json' --data "{
  \"attachments\": [{
    \"color\": \"$COLOR\",
    \"text\": \"$TEXT\"
  }]
}" "$WEBHOOK"
```

using UnityEditor;  
using System.IO;  
public class BuildScript {  
    public static void BuildAndroid() {  
        string path = "build/output.apk";  
        BuildPipeline.BuildPlayer(  
            new[] { "Assets/Scenes/MainScene.unity" },  
            path,  
            BuildTarget.Android,  
            BuildOptions.None  
        );  
        Debug.Log("✅ Android APK 생성 완료: " + path);  
    }  
}

### 🔐 Jenkins Credentials 설정

<a id="203eda9b0fe180289de3db1719f67ea7"></a>

```shell
firebase_app_id: Secret Text, Firebase App ID
firebase_token: Secret Text, Firebase CLI 로그인 토큰
slack_webhook: Secret Text, Slack Webhook URL
```

### ✅ 실행 절차 요약

1. &#46;env 작성

1. <a href="http://init-letsencrypt.sh/">init&#45;letsencrypt&#46;sh</a> 실행 → 인증서 발급
