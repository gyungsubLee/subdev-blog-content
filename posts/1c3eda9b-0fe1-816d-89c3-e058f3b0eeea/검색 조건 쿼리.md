## 검색 조건 쿼리

---

> 📖 
> 
> <a id="1c3eda9b0fe18108854ae1201e17e113"></a>
> 
> QueryDSL에서 제공하는 메서드를 통해 체이닝 형태로 SQL 조건문(<code>WHERE</code>) 작성이 가능하다&#46; 
> 
> - <code>=</code>&#58; <code>Q클래스&#46;필드명&#46;eq(value)</code>
>     - username = &#39;member1&#39;
>         - <code>member&#46;username&#46;eq(&#34;member1&#34;)</code>
> 
> - <code>&#33;=</code> &#58; <code>Q클래스&#46;필드명&#46;ne(value)</code>
>     - username &#33;= &#39;member1&#39;
>         - <code>member&#46;username&#46;eq(&#34;member1&#34;)&#46;not() </code>
> 
>         - <code>member&#46;username&#46;ne(&#34;member1&#34;)</code>
> 
> - 비교 연산자(And, or)&#58;  <code>&#46;and()</code> , <code>&#46;or()</code>

<details>
<summary>기본 검색 쿼리 </summary>

-  <code>&#46;and()</code> , <code>&#46;or()</code> 를 메서드 체인으로 연결 가능

<a id="1c3eda9b0fe181a99724cd8a5f7c3c53"></a>

```java
@Test
public void search() {
		
		QMember member = QMember.member;

    Member findMember = queryFactory
            .selectFrom(member)
            .where(
		            member.username.eq("member1")
		            .and(member.age.eq(10))
            )
            .fetchOne();
           
    assertThat(findMember.getUsername()).isEqualTo("member1");
}

```

</details>

<details>
<summary>JPQL<strong>이 제공하는 모든 검색 조건</strong></summary>

<a id="1c3eda9b0fe1816dbf2eea16ddd19414"></a>

```java
member.username.eq("member1") // username = 'member1'
member.username.ne("member1") //username != 'member1'
member.username.eq("member1").not() // username != 'member1'

member.username.isNotNull() //이름이 is not null

member.age.in(10, 20) // age in (10,20)
member.age.notIn(10, 20) // age not in (10, 20)
member.age.between(10,30) //between 10, 30

member.age.goe(30) // age >= 30
member.age.gt(30) // age > 30
member.age.loe(30) // age <= 30
member.age.lt(30) // age < 30

member.username.like("member%") //like 검색 
member.username.contains("member") // like ‘%member%’ 검색 
member.username.startsWith("member") //like ‘member%’ 검색
```

</details>

<summary>AND 조건 파라미터 처리</summary>

<a id="1c3eda9b0fe18157a940c66ecd7564f4"></a>

```java

@Test
public void searchAndParam() {
	   List<Member> result1 = queryFactory
           .selectFrom(member)
           .where(
		           member.username.eq("member1"), 
		           member.age.eq(10)
           )
           .fetch();
             
     assertThat(result1.size()).isEqualTo(1);
 }
```

- <code>where()</code>에 파라미터로 검색 조건을 추가하면 <code>AND</code> 조건이 추가된다&#46;

- 이 경우 <u><code>null</code></u><u> 값은 무시</u>되며<u> 메서드 추출을 활용</u>해서 <u>동적 쿼리를 깔끔하게 만</u>들 수 있다&#46;
