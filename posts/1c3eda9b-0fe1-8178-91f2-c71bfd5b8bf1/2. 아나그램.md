# 문제

<a id="1c3eda9b0fe181bcbe76e1a3ee97799e"></a>

## <strong>2&#46; 아나그램(해쉬)</strong>

---

<a id="1c3eda9b0fe181fc842df901970fb2c3"></a>

### 설명

<a id="1c3eda9b0fe1811a916dd40018a5849b"></a>

Anagram이란 두 문자열이 알파벳의 나열 순서를 다르지만 그 구성이 일치하면 두 단어는 아나그램이라고 합니다&#46;

<a id="1c3eda9b0fe181d89afeed0a08861091"></a>

예를 들면 AbaAeCe 와 baeeACA 는 알파벳을 나열 순서는 다르지만 그 구성을 살펴보면 A(2), a(1), b(1), C(1), e(2)로

<a id="1c3eda9b0fe181e3b704f1c7c9fac9fe"></a>

알파벳과 그 개수가 모두 일치합니다&#46; 즉 어느 한 단어를 재 배열하면 상대편 단어가 될 수 있는 것을 아나그램이라 합니다&#46;

<a id="1c3eda9b0fe181c2b0c3e389a16ac46f"></a>

길이가 같은 두 개의 단어가 주어지면 두 단어가 아나그램인지 판별하는 프로그램을 작성하세요&#46; 아나그램 판별시 대소문자가 구분됩니다&#46;

<a id="1c3eda9b0fe1816f9b46e110c22d764b"></a>

### 입력

<a id="1c3eda9b0fe181e781e7ecbd02a36ab0"></a>

첫 줄에 첫 번째 단어가 입력되고, 두 번째 줄에 두 번째 단어가 입력됩니다&#46;

<a id="1c3eda9b0fe18111ae0ac759564da22e"></a>

단어의 길이는 100을 넘지 않습니다&#46;

<a id="1c3eda9b0fe181b089a4d1aa1c891446"></a>

### 출력

<a id="1c3eda9b0fe181238138d647053ac450"></a>

두 단어가 아나그램이면 “YES&#34;를 출력하고, 아니면 ”NO&#34;를 출력합니다&#46;

---

<a id="1c3eda9b0fe18123a689e336c6ee7ef2"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181209578d90eb74654ec"></a>

```plaintext
AbaAeCe
baeeACA

```

<a id="1c3eda9b0fe181f7a2d9f8bed5609ec4"></a>

### 예시 출력 1

<a id="1c3eda9b0fe1817eb461d63edbbc87fb"></a>

```plaintext
YES
```

<a id="1c3eda9b0fe1813fac7df251fd34305e"></a>

# 풀이

<a id="1c3eda9b0fe181f293ffd65dfb491d66"></a>

## 풀이1)

<a id="1c3eda9b0fe18127bfc1f94a451a7ffb"></a>

```java
import java.util.*;
public class Main {
    public String solution(String s1, String s2){
        HashMap<Character, Integer> map = new HashMap<>();
        for(char x : s1.toCharArray()){
            map.put(x, map.getOrDefault(x, 0)+1);
        }
        for(char x : s2.toCharArray()){
            if(!map.containsKey(x) || map.get(x)==0) return "NO";
            map.put(x, map.get(x)-1);
        }
        return "YES";
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str1= sc.next();
        String str2= sc.next();
        System.out.print(T.solution(str1, str2));
    }
}
```
