## 요청 응답 예시

---

> 해당하는 값이 없는 경우,  테이블 삭제 후 <code>None</code> 명시

<a id="797eda9b0fe1823e88e401f0315fcc52"></a>

### 요청 

- Path Variable&#58; <code>None</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | toId | Long | false | 신고 당한 사람 ID |
    | 2 | matchingId | Long | false | 매칭 ID |
    | 3 | content | String | false | 신고 내용 |

- HTTP 요청
    <a id="f73eda9b0fe1823390c6010209bf0f09"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) POST  /api/reports  HTTP1.1
    ```

    <a id="466eda9b0fe18213bfd681be03077971"></a>

    ```json
    {
    		"toId" : 1,
    		"matchingId" : 1,
    		"content" : "종교 강요함" 
    }
    ```

    </details>

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    |  | data | ReportResDto | None | 응답 Dto |

    <details>
    <summary>응답 예시 </summary>

    <a id="331eda9b0fe183248b3c019551b0b206"></a>

    ```json
    {
        "message": "신고 접수 완료.",
        "data": {
            "id": 2,
            "fromId": 1,
            "toId": 8,
            "toName": "name5",
            "scheduleId": 8,
            "scheduleTitle": "운동",
            "scheduleDate": "2025-02-28",
            "matchingId": 2,
            "content": "종교 강요함",
            "createdAt": "2025-02-03T02:42:58.161124",
            "updatedAt": "2025-02-03T02:42:58.161124"
        }
    }
    ```

    </details>

    <details>
    <summary>DTO&#58; <code>ReportResDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None | 신고 ID |
    | 2 | fromID | Long | None | 신고자 ID |
    | 3 | toId | Long | None | 신고 당한 사람 ID |
    | 4 | matchingId | Long | None | 매칭 ID |
    | 5 | content | String | None | 신고 내용 |
    | 6 | createdAt | timestamp | None | 신고 요청 날짜 |
    | 7 | updatedAt | timestamp | None | 신고 수정 날짜 |

    </details>

- HTTP Status
    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
    | --- | --- | --- | --- |
    | 1 | <code>200</code> | <code>OK</code> | 성공 |
    | 2 | <code>400</code> | <code>Bad Request</code> | 잘못된 요청 |
    | 3 | <code>401</code> | <code>Unauthorized</code> | 인가되지 않은 요청 |
    | 4 | <code>404</code> | <code>Not Found</code> | 해당 정보 찾을 수 없음 |
