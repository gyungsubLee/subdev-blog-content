## 문제

<a id="1d2eda9b0fe18035a72bc0d8b21bd311"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180388bfef04341d36bca"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d2eda9b0fe1805bab38f93b8cd81705"></a>

<code>ANIMAL&#95;INS</code> 테이블에 등록된 모든 레코드에 대해, 각 동물의 아이디와 이름, 들어온 날짜<a href="https://school.programmers.co.kr/learn/courses/30/lessons/59414#fn1">1</a>를 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 아이디 순으로 조회해야 합니다&#46;

<a id="1d2eda9b0fe1801e8283ecfbae3beae2"></a>

### 예시

<a id="1d2eda9b0fe18001b104f88e4a31b96a"></a>

예를 들어, <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

<a id="1d2eda9b0fe180179c6ff65191c988d0"></a>

<code>ANIMAL&#95;INS</code>

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |

|  |  |  |
| --- | --- | --- |
| ANIMAL&#95;ID | NAME | 날짜 |
| A349996 | Sugar | 2018&#45;01&#45;22 |
| A350276 | Jewel | 2017&#45;08&#45;13 |
| A350375 | Meo | 2017&#45;03&#45;06 |
| A352555 | Harley | 2014&#45;08&#45;08 |
| A352713 | Gia | 2017&#45;04&#45;13 |

<a id="1d2eda9b0fe180e69da2fd405ab12d44"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe1802cb176e89a25c75aef"></a>
> 
> 조건
> 
> - 각 동물의 아이디와 이름, 들어온 날짜를 조회
> 
> -  아이디 순으로 조회

<a id="1d2eda9b0fe18075a298dd494e7e695e"></a>

```sql
SELECT ANIMAL_ID, NAME, DATE_FORMAT(DATETIME, '%Y-%m-%d')
FROM ANIMAL_INS
ORDER BY ANIMAL_ID
```

<a id="1d2eda9b0fe1800d9015d1233e4eaa08"></a>

### <strong>DATE&#95;FORMAT (MySQL 기준)</strong>

<a id="1d2eda9b0fe180beb349cb724461e8bf"></a>

```java
// 문법
SELECT DATE_FORMAT(컬럼명, '포맷') AS 별칭
FROM 테이블명;

// ex)
SELECT DATE_FORMAT(created_at, '%Y/%m/%d') AS formatted_date
FROM orders;
```

| <strong>포맷 코드</strong> | <strong>설명</strong> |
| --- | --- |
| %Y | 4자리 연도 |
| %y | 2자리 연도 |
| %m | 2자리 월 |
| %d | 2자리 일 |
| %H | 시 (00–23) |
| %i | 분 (00–59) |
| %s | 초 (00–59) |
