## 3&#46; 팩토리얼

---

<a id="1c3eda9b0fe181abb196f423c5e1bd10"></a>

### 설명

<a id="1c3eda9b0fe181438cade293dffc7e8c"></a>

자연수 N이 입력되면 N&#33;를 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181bab038f522dbfc4230"></a>

예를 들어 5&#33; = 5&#42;4&#42;3&#42;2&#42;1 = 120 입니다&#46;

<a id="1c3eda9b0fe181298a65c805838e008a"></a>

### 입력 설명

<a id="1c3eda9b0fe181ed8811f35a8bac5167"></a>

첫 번째 줄에 자연수 N(1≤N≤100)이 주어집니다&#46;

<a id="1c3eda9b0fe18199900cebdd46d7d54b"></a>

### 출력 설명

<a id="1c3eda9b0fe181e1bf9bd319bfc9b6ed"></a>

첫 번째 줄에 N팩토리얼 값을 출력합니다&#46;

---

<a id="1c3eda9b0fe1811fb692ee73dca1d5f3"></a>

### <br>입력 예제1

```plaintext
5
```

# 풀이

<a id="1c3eda9b0fe18121b896c3a8d6519fce"></a>

## 풀이1)  🧐 &#91;Error&#93; 내부 재귀 함수에서 얻은 값을 외부 재귀 함수로 가져올 수 없음

<a id="1c3eda9b0fe18103a389d9aaf1e03904"></a>

파라미터로 값을 전달하는 것은 가능하나 내부 재귀 함수에서의 결과값 인출이 안됨&#46;

<a id="1c3eda9b0fe1810cb6f3e7cff75a31bf"></a>

 <strong>⇒ 값을 받아오는 것은 </strong><strong><code>return</code></strong><strong>  값을 통해 가능함&#46;</strong>

<details>
<summary>오류 코드 </summary>

<a id="1c3eda9b0fe18103a405d59035a2ceb3"></a>

```java
import java.util.*;

public class Main {
    public int DFS(int n, int sum){
        if(n==0) return sum;
        else{
            sum*=n;
            n--;
            DFS(n, sum);
        }
    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int sum=1;
        System.out.print(T.DFS(n, sum));
    }
}
```

</details>

```java
import java.util.*;
```
