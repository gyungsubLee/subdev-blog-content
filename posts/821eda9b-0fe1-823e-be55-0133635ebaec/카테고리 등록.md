### 요청 

- Path Variable&#58; <code>Non</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | name | String | false |  |
    | 2 | imageUrl | String | false |  |

- HTTP 요청
    <a id="6dfeda9b0fe183cdab4c013b216429fe"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) POST  /api/admin/categories  HTTP1.1
    ```

### 응답

- Header&#58; <code>None</code>

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None |  |
    | 2 | name | String | None |  |
    | 3 | imageUrl | String | None |  |
    | 4 | createdAt | Timestamp | None |  |
    | 5 | updatedAt | Timestamp | None |  |

    <details>
    <summary>응답 예시 </summary>

    <a id="c25eda9b0fe182dca76d813641afe7fa"></a>

        "message": "카테고리 생성 완료.",

            "id": 2,
            "name": "name",
