# 문제

<a id="1c3eda9b0fe1812fa870c788fd4f653d"></a>

## <strong>9&#46; 격자판 최대합</strong>

---

<a id="1c3eda9b0fe181b8acdeda2e42d5f48a"></a>

### 설명

<a id="1c3eda9b0fe18172a269e91be8ac0734"></a>

5&#42;5 격자판에 아래롸 같이 숫자가 적혀있습니다&#46;

![](https://cote.inflearn.com/public/upload/4897574b00.jpg)

<a id="1c3eda9b0fe181c7bbe5e1cc04482d10"></a>

N&#42;N의 격자판이 주어지면 각 행의 합, 각 열의 합, 두 대각선의 합 중 가 장 큰 합을 출력합니다&#46;

---

<a id="1c3eda9b0fe1812b8d36c88e0ccf2014"></a>

### 입력

<a id="1c3eda9b0fe18195959ff6d8c6ceed92"></a>

첫 줄에 자연수 N이 주어진다&#46;(2&#60;=N&#60;=50)

<a id="1c3eda9b0fe181588377d80b611cf5db"></a>

두 번째 줄부터 N줄에 걸쳐 각 줄에 N개의 자연수가 주어진다&#46; 각 자연수는 100을 넘지 않는다&#46;

<a id="1c3eda9b0fe181a6b7ddc8a2ffb01f88"></a>

### 출력

<a id="1c3eda9b0fe181eeb598e6b3c787c9ff"></a>

최대합을 출력합니다&#46;

---

```java
import java.util.Scanner;

public class Main {
    public int solution(int n, int[][] arr) {
        int max=0;
        // 행의 합
        for(int i=0; i<n; i++) {
            int sum = 0;
            for (int j = 0; j < n; j++) {
                sum+=arr[i][j];
            }
            if(sum>max) max=sum;
        }
        // 열의 합
        for (int j = 0; j < n; j++) {
            int sum = 0;
            for (int i = 0; i < n; i++) {
                sum+=arr[i][j];
            }
            if(sum>max) max=sum;
        }
        // 대각선의 합
        int sum=0;
        for(int i=0; i<n; i++) {
            int j= i;
            sum+=arr[i][j];
        }
        if(sum>max) max=sum;

        sum=0;
        for(int i=n-1; i>=0; i--) {
            int j= n-1-i;
            sum+=arr[i][j];
        }
        if(sum>max) max=sum;
        return max;
    }
    public static void main (String[]args) {
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] arr = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                arr[i][j] = sc.nextInt();
            }
        }
        System.out.println(m.solution(n, arr));
    }
}
```

### 강의 &#91;풀이2&#93; ) 최적화 → 행, 열 연산 합침, 대각선 오른쪽, 왼쪽 연산 합침

<a id="1c3eda9b0fe181ac83cfcd30c488c91c"></a>

```java
import java.util.Scanner;

public class Main {
    public int solution(int n, int[][] arr) {
        int answer = Integer.MIN_VALUE;
        int sum1, sum2;
        // 행의 합, 열의 합
        for(int i=0; i<n; i++) {
            sum1=sum2=0;  // 오 자바 중복할당 가능함. 오 왠일?
            for (int j = 0; j < n; j++) {
                sum1+=arr[i][j];
                sum2+=arr[j][i];
            }
            answer=Math.max(answer, sum1);
            answer=Math.max(answer, sum2);
        }
        // 대각선의 합
        sum1=sum2=0;
        for(int i=0; i<n; i++){
            int j = n-1-i;
            sum1+=arr[i][i];
            sum2+=arr[i][j];
        }
        answer=Math.max(answer, sum1);
        answer=Math.max(answer, sum2);
        return answer;
    }
    public static void main (String[]args) {
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] arr = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                arr[i][j] = sc.nextInt();
            }
        }
        System.out.println(m.solution(n, arr));
    }
}
```
