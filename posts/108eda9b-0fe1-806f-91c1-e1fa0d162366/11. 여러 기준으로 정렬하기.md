## 문제

<a id="1d1eda9b0fe180f19909e337d7984ce4"></a>

### <strong>문제 설명</strong>

<a id="1d1eda9b0fe18093b5fbeca2e405f0a1"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d1eda9b0fe180309043cf0ef3dd071e"></a>

동물 보호소에 들어온 모든 동물의 아이디와 이름, 보호 시작일을 이름 순으로 조회하는 SQL문을 작성해주세요&#46; 단, 이름이 같은 동물 중에서는 보호를 나중에 시작한 동물을 먼저 보여줘야 합니다&#46;

<a id="1d1eda9b0fe18014a998e827f4f3cb76"></a>

### 예시

<a id="1d1eda9b0fe1804396c9d65e2b9a9f4d"></a>

예를 들어, <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A349996 | Cat | 2018&#45;01&#45;22 14&#58;32&#58;00 | Normal | Sugar | Neutered Male |
| A350276 | Cat | 2017&#45;08&#45;13 13&#58;50&#58;00 | Normal | Jewel | Spayed Female |
| A396810 | Dog | 2016&#45;08&#45;22 16&#58;13&#58;00 | Injured | Raven | Spayed Female |
| A410668 | Cat | 2015&#45;11&#45;19 13&#58;41&#58;00 | Normal | Raven | Spayed Female |

1. 이름을 사전 순으로 정렬하면 다음과 같으며, &#39;Jewel&#39;, &#39;Raven&#39;, &#39;Sugar&#39;

1. &#39;Raven&#39;이라는 이름을 가진 개와 고양이가 있으므로, 이 중에서는 보호를 나중에 시작한 개를 먼저 조회합니다&#46;

<a id="1d1eda9b0fe18094b3c4dcdb766871a1"></a>

따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| ANIMAL&#95;ID | NAME | DATETIME |
| A350276 | Jewel | 2017&#45;08&#45;13 13&#58;50&#58;00 |
| A396810 | Raven | 2016&#45;08&#45;22 16&#58;13&#58;00 |
| A410668 | Raven | 2015&#45;11&#45;19 13&#58;41&#58;00 |
| A349996 | Sugar | 2018&#45;01&#45;22 14&#58;32&#58;00 |

<a id="1d1eda9b0fe180519bc3cda959b1988b"></a>

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe180c28893c7f6af24e981"></a>
> 
> 조건
> 
> - 동물 보호소에 들어온 모든 동물의 아이디와 이름, 보호 시작일을 이름 순으로 조회하는 SQL문을 작성
> 
> - 단, 이름이 같은 동물 중에서는 보호를 나중에 시작한 동물을 먼저 보여줘야 한다&#46;

<a id="1d1eda9b0fe1805eb7a2cd1ff18372e8"></a>

```sql
SELECT ANIMAL_ID, NAME, DATETIME
FROM ANIMAL_INS
ORDER BY NAME ASC, DATETIME DESC
```
