## 문제

<a id="1d2eda9b0fe180999ca6ef9b8e7003c0"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe18002b00fd1a0cd6b5b0f"></a>

다음은 어느 의류 쇼핑몰에서 판매중인 상품들의 정보를 담은 <code>PRODUCT</code> 테이블입니다&#46; <code>PRODUCT</code> 테이블은 아래와 같은 구조로 되어있으며, <code>PRODUCT&#95;ID</code>, <code>PRODUCT&#95;CODE</code>, <code>PRICE</code>는 각각 상품 ID, 상품코드, 판매가를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PRODUCT&#95;ID | INTEGER | FALSE |
| PRODUCT&#95;CODE | VARCHAR(8) | FALSE |
| PRICE | INTEGER | FALSE |

<a id="1d2eda9b0fe1801ba8eeeda8a122fc05"></a>

상품 별로 중복되지 않는 8자리 상품코드 값을 가지며, 앞 2자리는 카테고리 코드를 의미합니다&#46;

---

<a id="1d2eda9b0fe18088a825e224f1f6e5aa"></a>

### 문제

<a id="1d2eda9b0fe180228a77c032b7a5cc0e"></a>

<code>PRODUCT</code> 테이블에서 상품 카테고리 코드(<code>PRODUCT&#95;CODE</code> 앞 2자리) 별 상품 개수를 출력하는 SQL문을 작성해주세요&#46; 결과는 상품 카테고리 코드를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="1d2eda9b0fe18056a6bcc70039778381"></a>

### 예시

<a id="1d2eda9b0fe180fd8e17c6800a058c98"></a>

예를 들어 <code>PRODUCT</code> 테이블이 다음과 같다면

|  |  |  |
| --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;CODE | PRICE |
| 1 | A1000011 | 10000 |
| 2 | A1000045 | 9000 |
| 3 | C3000002 | 22000 |
| 4 | C3000006 | 15000 |
| 5 | C3000010 | 30000 |
| 6 | K1000023 | 17000 |

<a id="1d2eda9b0fe180d199f2f3b18a7ff295"></a>

상품 카테고리 코드 별 상품은 아래와 같으므로,

- <code>A1</code>&#58; <code>PRODUCT&#95;ID</code>가 1, 2 인 상품

- <code>C3</code>&#58; <code>PRODUCT&#95;ID</code>가 3, 4, 5 인 상품

- <code>K1</code>&#58; <code>PRODUCT&#95;ID</code>가 6 인 상품

<a id="1d2eda9b0fe180d99b0dfae6190d5210"></a>

다음과 같은 결과가 나와야 합니다&#46;

|  |  |
| --- | --- |
| CATEGORY | PRODUCTS |
| A1 | 2 |
| C3 | 3 |
| K1 | 1 |

<a id="1d2eda9b0fe1801db681cf2ded0bd822"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe1808e8fbde176d8f7ffad"></a>
> 
> 조건
> 
> - <code>PRODUCT</code> 테이블에서 상품 카테고리 코드(<code>PRODUCT&#95;CODE</code> 앞 2자리) 별 상품 개수를 출력
> 
> -  상품 카테고리 코드를 기준으로 오름차순

<a id="1d2eda9b0fe18081b90de68cf420de0b"></a>

```sql
SELECT 
    SUBSTR(PRODUCT_CODE, 1, 2) AS CATEGORY, 
    COUNT(*) AS PRODUCTS
FROM PRODUCT
GROUP BY CATEGORY
ORDER BY CATEGORY;
```
