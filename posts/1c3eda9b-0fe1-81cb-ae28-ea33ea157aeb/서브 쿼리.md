## 서브 쿼리

---

> 📖 
> 
> <a id="1c3eda9b0fe181e6b89eeacc989f9423"></a>
> 
> QueryDSL에서는 <code>JPAExpressions</code>( <code>com&#46;querydsl&#46;jpa&#46;JPAExpressions</code> )을 통해 서브 쿼리를 사용한다&#46;

<details>
<summary><code>eq</code></summary>

<a id="1c3eda9b0fe181a583b1fba92fdd347d"></a>

```java
/**
* 나이가 가장 많은 회원 조회 
*/
@Test
public void subQuery() throws Exception {
	
		QMember memberSub = new QMember("memberSub");
		
		List<Member> result = queryFactory
									.selectFrom(member)
									.where(member.age.eq(
											     JPAExpressions
											             .select(memberSub.age.max())
											             .from(memberSub)
									)) 
									.fetch();
									
		assertThat(result).extracting("age")
		     .containsExactly(40);
}
```

</details>

<details>
<summary><code>goe</code></summary>

<a id="1c3eda9b0fe181b0abb0db8b6117c299"></a>

```java
/**
* 나이가 평균 나이 이상인 회원 
*/
@Test
public void subQueryGoe() throws Exception {
	
		QMember memberSub = new QMember("memberSub");
		
		List<Member> result = queryFactory
									.selectFrom(member)
									.where(member.age.goe(
											     JPAExpressions
											             .select(memberSub.age.avg())
											             .from(memberSub)
									)) 
									.fetch();
									
		assertThat(result).extracting("age")
		     .containsExactly(30, 40);
}
```

</details>

<details>
<summary> <code>in</code> &#45; 여러 건  처리</summary>

<a id="1c3eda9b0fe18168803bd6dda7b34bc4"></a>

```java
/**
* 서브쿼리 여러 건 처리, in 사용
*/
@Test
public void subQueryIn() throws Exception {
	
		QMember memberSub = new QMember("memberSub");
		
		List<Member> result = queryFactory
									.selectFrom(member)
									.where(member.age.in(
											     JPAExpressions
											             .select(memberSub.age)
											             .from(memberSub)
											             .where(memberSub.age.gt(10))
									)) 
									.fetch();
									
		assertThat(result).extracting("age")
		     .containsExactly((20, 30, 40);
}
```

</details>

List<Tuple> fetch = queryFactory
     .select(member.username,
             JPAExpressions
                     .select(memberSub.age.avg())
                     .from(memberSub)
     ).from(member)
     .fetch();
         
         
for (Tuple tuple : fetch) {
	   System.out.println("username = " + tuple.get(member.username));
	   System.out.println("age = " + tuple.get(JPAExpressions.select(memberSub.age.avg())
																		             .from(memberSub)));
}

> 
> <strong>from 절의 서브쿼리 한계 및 해결 방안</strong>
> 
> <details>
> <summary>한계</summary>
> 
> <a id="293eda9b0fe18051bf14ef263d2a80f1"></a>
> 
> JPA JPQL 서브쿼리의 한계점으로 from 절의 서브쿼리(인라인 뷰)는 지원하지 않는다&#46; 
> 
> <a id="293eda9b0fe18091bdcfeeeab3804b6a"></a>
> 
> 당연히 Querydsl도 지원하지 않는다&#46; 
> 
> <a id="293eda9b0fe1805daa5cd949fc8cb519"></a>
> 
> 하이버네이트 구현체를 사용하면 select 절의 서브쿼리는 지원한다
> 
> <a id="293eda9b0fe180439cc8dc9b2370c5f0"></a>
> 
> Querydsl도 하이버네이트 구현체를 사용 하면 select 절의 서브쿼리를 지원한다&#46;
> 
> </details>
> 
> <details>
> <summary>해결 방안</summary>
> 
> 1. 서브쿼리를 join으로 변경한다&#46; ( 불가능한 상황 존재)
> 
> 1. 애플리케이션에서 쿼리를 2번 분리해서 실행한다&#46; 
> 
> 1. native SQL을 사용한다&#46;
