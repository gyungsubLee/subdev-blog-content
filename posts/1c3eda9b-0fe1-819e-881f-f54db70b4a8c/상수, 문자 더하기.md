## <strong>상수</strong>, <strong>문자 더하기</strong>

---

<details>
<summary>상수 &#45;  <code>Expressions&#46;constant(xxx)</code></summary>

- 상수가 필요하면 <code>Expressions&#46;constant(xxx)</code> 사용

<a id="1c3eda9b0fe181e1a2c7e840e459e8d6"></a>

```java
 Tuple result = queryFactory
         .select(
		         member.username, 
		         Expressions.constant("A")
         )
         .from(member)
         .fetchFirst();
```

> ☝🏻 
> 
> <a id="1c3eda9b0fe1816c9542dd7dc05ab494"></a>
> 
> 위와 같이 최적화가 가능하면 SQL에 constant 값을 넘기지 않는다&#46; <br>상수를 더하는 것 처럼 최적화가 어려 우면 SQL에 constant 값을 넘긴다&#46;

</details>

<details>
<summary><strong>문자 더하기 &#45; </strong><code>concat</code></summary>

<a id="1c3eda9b0fe18123bb97fd57bb2a932d"></a>

```java
String result = queryFactory
         .select(member.username.concat("_").concat(member.age.stringValue()))
         .from(member)
         .where(member.username.eq("member1"))
         .fetchOne();
 
// 결과: member1_10
```

> ✏️ 
> 
> <a id="1c3eda9b0fe181a998dfeee5a6c5a083"></a>
> 
> <code>member&#46;age&#46;stringValue()</code> 
> 
> <a id="1c3eda9b0fe18117a123eb75604349e3"></a>
> 
>  <u>문자가 아닌 다른 타입들은 </u><u><code>stringValue()</code></u><u>로  </u><u><code>String</code></u><u>으로 변환</u><u>할 수 있</u>다&#46; <br>이 방법은 <strong><u>ENUM을 처리</u></strong>할 때도 자주 사용한다&#46;

</details>
