### 웹소캣 프로토콜 연결

---

- <strong>WebSocket 연결 요청</strong>
    - 연결 요청&#58; <code>ws&#58;//localhost&#58;8080/ws</code>

    - HTTP 요청  메세지
        <a id="7cceda9b0fe1823ba3e081cdabfc7d01"></a>

        ```java
        GET /ws HTTP/1.1
        Host: localhost:8080
        Upgrade: websocket
        Connection: Upgrade
        Sec-WebSocket-Key: dGhlIHNhbXBsZSBub25jZQ==
        Sec-WebSocket-Version: 13
        Origin: http://localhost:8080
        ```

- <strong>WebSocket 연결 응답</strong>
    - HTTP 응답 메세지
        <a id="cf0eda9b0fe18283b96801f076203abe"></a>

        ```java
        HTTP/1.1 101 Switching Protocols
        Upgrade: websocket
        Connection: Upgrade
        Sec-WebSocket-Accept: s3pPLMBiTxaQ9kYGzzhZRbK+xOo=
        ```

<a id="debeda9b0fe18374856e81ee3c33a7b1"></a>

### 메세지 송신

---

- URL&#58; <code>pub//chats/room/{roomId</code>

- Body
    - DTO&#58; <code>ChatReqDto</code>
        | 번호 | 이름 | 타입 | Nullable | 설명 |
        | --- | --- | --- | --- | --- |
        | 1 | senderId | Long | None | 채팅 작성자 ID |
        | 2 | name | String | None | 채팅 작성자 이름 |
        | 3 | profileUrl | String | None | 채팅 작성자 프로필 URL |
        | 4 | message | String | None | 채팅 메시지 |

- 송신 예시
    <a id="62ceda9b0fe182088b5501b8aa678000"></a>

    ```java
    {
      "senderId": 123,
      "name": "John Doe",
      "profileUrl": "http://example.com/profile.jpg",
      "message": "Hello, WebSocket!"
    }
    ```

### 메세지 수신

---

- URL&#58; <code>/sub/chats/room/{roomId</code>

- Body
    - DTO&#58; <code>ChatRabbimqRestDto</code>
        | 번호 | 이름 | 타입 | Nullable | 설명 |
        | --- | --- | --- | --- | --- |
        | 1 | chatroomId | Long | None | 채팅방 ID |
        | 2 | senderId | Long | None | 채팅 작성자 ID |
        | 3 | name | String | None | 채팅 작성자 이름 |
        | 4 | profileUrl | String | None | 채팅 작성자 프로필 URL |
        | 5 | message | String | None | 채팅 메시지 |
        | 6 | createdAt | LocalDateTime | None | 메시지 생성 일시 |

- 수신 예시 
    <a id="308eda9b0fe18206b13e0105ffb9ccd8"></a>
