## 문제

<a id="15beda9b0fe180d29a8ffd337345e630"></a>

### <strong>문제 설명</strong>

<a id="15beda9b0fe180e5b5ecf8ef3b23b739"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="15beda9b0fe180caa578f743b3c9bbf9"></a>

동물 보호소에 들어온 동물 중 이름이 Lucy, Ella, Pickle, Rogan, Sabrina, Mitty인 동물의 아이디와 이름, 성별 및 중성화 여부를 조회하는 SQL 문을 작성해주세요&#46;

<a id="15beda9b0fe1803ab973c483b239bfdc"></a>

### 예시

<a id="15beda9b0fe180128e93c7b35634d772"></a>

이때 결과는 아이디 순으로 조회해주세요&#46; 예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A373219 | Cat | 2014&#45;07&#45;29 11&#58;43&#58;00 | Normal | Ella | Spayed Female |
| A377750 | Dog | 2017&#45;10&#45;25 17&#58;17&#58;00 | Normal | Lucy | Spayed Female |
| A353259 | Dog | 2016&#45;05&#45;08 12&#58;57&#58;00 | Injured | Bj | Neutered Male |
| A354540 | Cat | 2014&#45;12&#45;11 11&#58;48&#58;00 | Normal | Tux | Neutered Male |
| A354597 | Cat | 2014&#45;05&#45;02 12&#58;16&#58;00 | Normal | Ariel | Spayed Female |

<a id="15beda9b0fe180fa90bade2b8987d7e9"></a>

SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| ANIMAL&#95;ID | NAME | SEX&#95;UPON&#95;INTAKE |
| A373219 | Ella | Spayed Female |
| A377750 | Lucy | Spayed Female |

<a id="0deca6c299a8480180a2f064a3465d9f"></a>

## 풀이

<a id="15beda9b0fe1808998d4c1f9e9cf0091"></a>

```sql
SELECT
    ANIMAL_ID,
    NAME,
    SEX_UPON_INTAKE
FROM ANIMAL_INS
WHERE NAME IN ('Lucy', 'Ella', 'Pickle', 'Rogan', 'Sabrina', 'Mitty');
```
