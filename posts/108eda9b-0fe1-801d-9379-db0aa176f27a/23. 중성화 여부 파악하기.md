## 문제

<a id="1d2eda9b0fe1804db90bdd71cf80d164"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180f4be9cc0be2ee6b25f"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d2eda9b0fe180a0a3f9ca8fb8eb3bfe"></a>

보호소의 동물이 중성화되었는지 아닌지 파악하려 합니다&#46; 중성화된 동물은 <code>SEX&#95;UPON&#95;INTAKE</code> 컬럼에 &#39;Neutered&#39; 또는 &#39;Spayed&#39;라는 단어가 들어있습니다&#46; 동물의 아이디와 이름, 중성화 여부를 아이디 순으로 조회하는 SQL문을 작성해주세요&#46; 이때 중성화가 되어있다면 &#39;O&#39;, 아니라면 &#39;X&#39;라고 표시해주세요&#46;

<a id="1d2eda9b0fe18038b5b2f4d8e5497cd6"></a>

### 예시

<a id="1d2eda9b0fe1800381c0fa4d847a417a"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A355753 | Dog | 2015&#45;09&#45;10 13&#58;14&#58;00 | Normal | Elijah | Neutered Male |
| A373219 | Cat | 2014&#45;07&#45;29 11&#58;43&#58;00 | Normal | Ella | Spayed Female |
| A382192 | Dog | 2015&#45;03&#45;13 13&#58;14&#58;00 | Normal | Maxwell 2 | Intact Male |

- 중성화한 동물&#58; Elijah, Ella

- 중성화하지 않은 동물&#58; Maxwell 2

<a id="1d2eda9b0fe1808986e1e22ab7330fd6"></a>

따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |  |
| --- | --- | --- |
| ANIMAL&#95;ID | NAME | 중성화 |
| A355753 | Elijah | O |
| A373219 | Ella | O |
| A382192 | Maxwell 2 | X |

<a id="1d2eda9b0fe180bc9924da208b91d1bd"></a>

※ 컬럼 이름은 일치하지 않아도 됩니다&#46;

<a id="1d2eda9b0fe1808aa543d9556cd66838"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe180fc8b9bc96e7dd76de1"></a>
> 
> 조건
> 
> - 동물의 아이디와 이름, 중성화 여부를 아이디 순으로 조회
> 
> - 중성화가 되어있다면 &#39;O&#39;, 아니라면 &#39;X&#39;라고 표시
>     - 중성화된 동물은 <code>SEX&#95;UPON&#95;INTAKE</code> 컬럼에 &#39;Neutered&#39; 또는 &#39;Spayed&#39;라는 단어가 들어있다&#46;

<a id="1d2eda9b0fe18001bc8bfaed11a78cb1"></a>

### 풀이1) IF &#43;  LIKE

<a id="1d2eda9b0fe18091a5dceebf27c98498"></a>

```sql
-- 코드를 입력하세요
SELECT 
    ANIMAL_ID, 
    NAME, 
    IF(SEX_UPON_INTAKE LIKE 'Neutered%' 
		    OR SEX_UPON_INTAKE LIKE 'Spayed%',
		    'O', 'X') AS 중성화
FROM ANIMAL_INS
```

<a id="1d2eda9b0fe180d6bf46fa3a759c47c6"></a>

### 풀이2) REGEXP 

<a id="1d2eda9b0fe1805c8390f442c2124b9f"></a>

```sql
SELECT 
    ANIMAL_ID, 
    NAME, 
    IF(SEX_UPON_INTAKE REGEXP '^Neutered|^Spayed', 'O', 'X') AS 중성화
FROM ANIMAL_INS
```

- ✅ 간결한 코드
