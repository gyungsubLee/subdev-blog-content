# 문제

<a id="1c3eda9b0fe1816caae6ca21c26051e8"></a>

## <strong>9&#46; 뮤직비디오(결정알고리즘)</strong>

---

<a id="1c3eda9b0fe18157a4e0d7fc95b15d4d"></a>

### 설명

<a id="1c3eda9b0fe181438dc1c737e4841159"></a>

지니레코드에서는 불세출의 가수 조영필의 라이브 동영상을 DVD로 만들어 판매하려 한다&#46;

<a id="1c3eda9b0fe181a28e91e5b3109daa60"></a>

DVD에는 총 N개의 곡이 들어가는데, DVD에 녹화할 때에는 라이브에서의 순서가 그대로 유지되어야 한다&#46;

<a id="1c3eda9b0fe18182956bfda98c699b61"></a>

순서가 바뀌는 것을 우리의 가수 조영필씨가 매우 싫어한다&#46; 즉, 1번 노래와 5번 노래를 같은 DVD에 녹화하기 위해서는

<a id="1c3eda9b0fe181cb8546c42533d1f511"></a>

1번과 5번 사이의 모든 노래도 같은 DVD에 녹화해야 한다&#46; 또한 한 노래를 쪼개서 두 개의 DVD에 녹화하면 안된다&#46;

<a id="1c3eda9b0fe1810d85bbc49614689cf8"></a>

지니레코드 입장에서는 이 DVD가 팔릴 것인지 확신할 수 없기 때문에 이 사업에 낭비되는 DVD를 가급적 줄이려고 한다&#46;

<a id="1c3eda9b0fe1819abfb0dfe2094d7cae"></a>

고민 끝에 지니레코드는 M개의 DVD에 모든 동영상을 녹화하기로 하였다&#46; 이 때 DVD의 크기(녹화 가능한 길이)를 최소로 하려고 한다&#46;

<a id="1c3eda9b0fe181eb8dc8ebd5def5e01d"></a>

그리고 M개의 DVD는 모두 같은 크기여야 제조원가가 적게 들기 때문에 꼭 같은 크기로 해야 한다&#46;

<a id="1c3eda9b0fe18146bebee88e8bee4c45"></a>

### 입력

<a id="1c3eda9b0fe181e69b9adef11e7d0687"></a>

첫째 줄에 자연수 N(1≤N≤1,000), M(1≤M≤N)이 주어진다&#46;

<a id="1c3eda9b0fe18155b065d355eb044755"></a>

다음 줄에는 조영필이 라이브에서 부른 순서대로 부른 곡의 길이가 분 단위로(자연수) 주어진다&#46;

<a id="1c3eda9b0fe18142986cee3118e91187"></a>

부른 곡의 길이는 10,000분을 넘지 않는다고 가정하자&#46;

<a id="1c3eda9b0fe181938007e18d73a4cad7"></a>

### 출력

<a id="1c3eda9b0fe1815191e2fbc2d609464c"></a>

첫 번째 줄부터 DVD의 최소 용량 크기를 출력하세요&#46;

---

<a id="1c3eda9b0fe1811eacddfea4172f8fea"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181a7a163f4583c304471"></a>

```plaintext
9 3
1 2 3 4 5 6 7 8 9
```

<a id="1c3eda9b0fe181fe8d41e729ee225889"></a>

### 예시 출력 1

<a id="1c3eda9b0fe1814cb946d477d1e5a762"></a>

```plaintext
17
```

<a id="1c3eda9b0fe18188a03bd2f90f24c950"></a>

### 힌트

> 설명 &#58; 3개의 DVD용량이 17분짜리이면 (1, 2, 3, 4, 5) (6, 7), (8, 9) 이렇게 3개의 DVD로 녹음을 할 수 있다&#46;

<a id="1c3eda9b0fe18175a5b3f763698fd00d"></a>

# 풀이

<a id="1c3eda9b0fe181cf95adcb79bfbd2f3e"></a>

## 풀이1) 

<a id="1c3eda9b0fe18125bc0dea75d7c311e0"></a>

```java
import java.util.*;

public class Main {
    public  int count(int[] arr, int capacity){
        int cnt=1, sum=0;
        for(int x : arr){
            sum+=x;
            if(sum>capacity){
                cnt++;
                sum=x;
            }
        }
        return cnt;
    }

    public int solution(int n, int t, int[] arr){
        int answer=0;
        int lt = Arrays.stream(arr).max().getAsInt();
        int rt = Arrays.stream(arr).sum();
        while(lt<=rt){
            int mid=(lt+rt)/2;
            if(count(arr, mid)<=t) {
                answer=mid;
                rt=mid-1;
            }
            else lt=mid+1;
        }
        return answer;
    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.println(T.solution(n, t, arr));
    }
}
```
