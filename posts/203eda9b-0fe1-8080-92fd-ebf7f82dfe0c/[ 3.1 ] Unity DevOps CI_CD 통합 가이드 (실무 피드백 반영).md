> 🗒️ 
> 
> <a id="203eda9b0fe180c292e3f8db837ef81c"></a>
> 
> 실무 피드백 요약
> 
> - <code>보안</code>&#58; Docker&#45;in&#45;Docker(DIND) 또는 별도 에이전트 사용, 시크릿 디렉토리/Vault 연동, Least Privilege 원칙 적용
> 
> - <code>피드백 루프</code>&#58; 테스트 단계 추가, Slack 알림에 빌드/로그 링크 포함, 모니터링 연동
> 
> - <code>모니터링</code>&#58; Prometheus/Grafana 연동(선택)
> 
> - <code>자동화</code>&#58; 인증서 갱신, 빌드/테스트/배포/알림 완전 자동화<br>이렇게 실무 피드백을 반영하면, 보안과 자동화, 피드백 루프까지 모두 강화된 CI/CD 파이프라인을 구축 가능하다&#46;
> 
> - Unity CLI, Jenkins, Docker, Nginx, Firebase, Slack, 모니터링까지 실무에 최적화된 구조

> 🗒️ 
> 
> <a id="203eda9b0fe180408048ce73bd02fa49"></a>
> 
> 실행 절차 요약 (실무 반영)
> 
> 1. &#46;env 및 secrets 디렉토리 설정
> 
> 1. <a href="http://init-letsencrypt.sh/">init&#45;letsencrypt&#46;sh</a> 실행 (인증서 발급)
> 
> 1. docker&#45;compose up &#45;d
> 
> 1. Jenkins 웹 UI 접속 → 플러그인 설치 (GitHub, Slack, Prometheus 등)
> 
> 1. Jenkins Credentials 또는 Vault 연동
> 
> 1. GitHub에 Jenkinsfile 커밋
> 
> 1. GitHub Webhook 자동 트리거
> 
> 1. Firebase 배포 &#43; Slack 알림 &#43; 모니터링 확인
> 
> 1. 정기적 보안 점검 및 접근 권한 관리

> ✅ 
> 
> <a id="203eda9b0fe1807dab03d750e8215f80"></a>
> 
> 전체 아키텍처 흐름
> 
> <a id="203eda9b0fe1803c9ee7c07f9ebee8d9"></a>
> 
> GitHub → Webhook → Nginx (443/80) → Jenkins (내부 8080) → Unity Build &#38; Test → APK 생성 → Firebase 배포 → Slack 알림 &#43; 테스터 관리
> 
> - <code>Nginx</code>&#58; 외부 SSL 종료, 내부 트래픽 암호화 필요 시 추가 설정
> 
> - <code>Jenkins</code>&#58; 내부 네트워크 전용, Docker&#45;in&#45;Docker(DIND) 또는 별도 에이전트 권장
> 
> - <code>모니터링</code>&#58; Prometheus/Grafana 연동(선택)
> 
> - <code>시크릿 관리</code>&#58; Jenkins Credentials 또는 Vault 연동

<summary>docker&#45;compose&#46;yml (보안/실무 반영)</summary>

<a id="203eda9b0fe180968b27cc423db2c9d1"></a>

```yaml
version: '3.8'

services:
  jenkins:
    image: jenkins/jenkins:2.504.2-lts
    container_name: jenkins
    restart: unless-stopped
    expose:
      - "8080"
    networks:
      - backend
    volumes:
      - ./jenkins/jenkins_home:/var/jenkins_home
      # Docker-in-Docker(DIND) 또는 별도 에이전트 사용 권장
      # - /var/run/docker.sock:/var/run/docker.sock  # 보안 주의! 필요시만 사용
      - ./secrets:/secrets:ro  # NEW: 시크릿 마운트

  nginx:
    image: nginx:stable
    container_name: nginx
    restart: unless-stopped
    depends_on:
      - jenkins
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/nginx.conf:ro
      - ./nginx/healthcheck.conf:/etc/nginx/conf.d/healthcheck.conf
      - ./nginx/ssl:/etc/letsencrypt
      - ./nginx/ssl:/var/www/certbot
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 10s
      retries: 5
    networks:
      - backend

  certbot:
    image: certbot/certbot
    container_name: certbot
    entrypoint: "/bin/sh -c 'trap exit TERM; while :; do sleep 6h & wait $${!}; certbot renew --webroot -w /var/www/certbot --quiet; nginx -s reload; done'"
    volumes:
      - ./nginx/ssl:/etc/letsencrypt
      - ./nginx/ssl:/var/www/certbot
    networks:
      - backend

networks:
  backend:
    driver: bridge
```

<summary>Jenkinsfile (피드백 루프/모니터링 반영)</summary>

<a id="203eda9b0fe180c18847fdc44b2d620e"></a>

```groovy
pipeline {
  agent {
    docker {
      image 'unityci/editor:2022.3.12f1-android'
      args '-v /var/run/docker.sock:/var/run/docker.sock' // 보안 주의! 필요시만 사용
    }
  }
  environment {
    UNITY_PROJECT_PATH = 'unity-project'
    BUILD_OUTPUT_PATH = 'build/output.apk'
    FIREBASE_APP_ID = credentials('firebase_app_id')
    FIREBASE_TOKEN = credentials('firebase_token') // 또는 /secrets/firebase_token
    SLACK_WEBHOOK = credentials('slack_webhook')  // 또는 /secrets/slack_webhook
    TESTER_GROUP = 'testers'
  }
  triggers {
    githubPush()
  }
  stages {
    stage('Checkout') {
      steps {
        git url: 'https://github.com/your-org/unity-game-repo.git', branch: 'main'
      }
    }
    stage('Build') {
      steps {
        sh './scripts/build.sh $UNITY_PROJECT_PATH'
        archiveArtifacts artifacts: 'build/output.apk', fingerprint: true
      }
    }
    stage('Test') { // NEW: 테스트 단계 추가
      steps {
        sh './scripts/test.sh $UNITY_PROJECT_PATH'
      }
    }
    stage('Deploy') {
      steps {
        sh './scripts/deploy.sh $FIREBASE_APP_ID $BUILD_OUTPUT_PATH $FIREBASE_TOKEN $TESTER_GROUP'
        sh './scripts/manage-testers.sh $FIREBASE_APP_ID $FIREBASE_TOKEN $TESTER_GROUP'
      }
    }
  }
  post {
    success { 
      sh './scripts/notify.sh success'
      // Prometheus/Grafana 메트릭 전송 예시
      sh 'curl -X POST -d "pipeline=success" http://monitoring:9090/metrics'
    }
    failure { 
      sh './scripts/notify.sh failure'
      sh 'curl -X POST -d "pipeline=failure" http://monitoring:9090/metrics'
    }
  }
}
```

```bash
#!/bin/bash
UNITY_PROJECT_PATH=$1
BUILD_PATH="build/output.apk"
/opt/unity/Editor/Unity \
  -batchmode \
  -nographics \
  -silent-crashes \
  -logFile /dev/stdout \
  -projectPath "$UNITY_PROJECT_PATH" \
  -executeMethod "BuildScript.BuildAndroid" \
  -buildTarget Android \
  -quit
```

<summary>manage&#45;testers&#46;sh</summary>

<a id="203eda9b0fe1809c9caceeadb0bb85cc"></a>

```bash
#!/bin/bash

FIREBASE_APP_ID=$1
TOKEN=$2
CSV_PATH="./testers.csv"

while IFS=, read -r email
do
  echo "테스터 등록 중: $email"
  firebase appdistribution:testers:add "$email" \
    --app "$FIREBASE_APP_ID" \
    --token "$TOKEN"
done < <(tail -n +2 "$CSV_PATH") # 첫 줄은 헤더니까 제외하고 읽기
```
