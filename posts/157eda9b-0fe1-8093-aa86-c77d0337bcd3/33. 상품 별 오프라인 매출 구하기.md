## 문제

<a id="157eda9b0fe180a69f5fef2c202ac004"></a>

### <strong>문제 설명</strong>

<a id="157eda9b0fe1807491e2ea0d34e92a4f"></a>

다음은 어느 의류 쇼핑몰에서 판매중인 상품들의 상품 정보를 담은 <code>PRODUCT</code> 테이블과 오프라인 상품 판매 정보를 담은 <code>OFFLINE&#95;SALE</code> 테이블 입니다&#46; <code>PRODUCT</code> 테이블은 아래와 같은 구조로 <code>PRODUCT&#95;ID</code>, <code>PRODUCT&#95;CODE</code>, <code>PRICE</code>는 각각 상품 ID, 상품코드, 판매가를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PRODUCT&#95;ID | INTEGER | FALSE |
| PRODUCT&#95;CODE | VARCHAR(8) | FALSE |
| PRICE | INTEGER | FALSE |

<a id="157eda9b0fe1807c8568c1c109015999"></a>

상품 별로 중복되지 않는 8자리 상품코드 값을 가지며, 앞 2자리는 카테고리 코드를 의미합니다&#46;

<a id="157eda9b0fe1806eabc9dd076c8e23fc"></a>

<code>OFFLINE&#95;SALE</code> 테이블은 아래와 같은 구조로 되어있으며 <code>OFFLINE&#95;SALE&#95;ID</code>, <code>PRODUCT&#95;ID</code>, <code>SALES&#95;AMOUNT</code>, <code>SALES&#95;DATE</code>는 각각 오프라인 상품 판매 ID, 상품 ID, 판매량, 판매일을 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| OFFLINE&#95;SALE&#95;ID | INTEGER | FALSE |
| PRODUCT&#95;ID | INTEGER | FALSE |
| SALES&#95;AMOUNT | INTEGER | FALSE |
| SALES&#95;DATE | DATE | FALSE |

<a id="157eda9b0fe18027ae70d2bb6afb84ac"></a>

동일한 날짜, 상품 ID 조합에 대해서는 하나의 판매 데이터만 존재합니다&#46;

---

<a id="157eda9b0fe180ba9103ca8bb3a47302"></a>

### 문제

<a id="157eda9b0fe180d9aaa5dc6b0d643c0a"></a>

<code>PRODUCT</code> 테이블과 <code>OFFLINE&#95;SALE</code> 테이블에서 상품코드 별 매출액(판매가 &#42; 판매량) 합계를 출력하는 SQL문을 작성해주세요&#46; 결과는 매출액을 기준으로 내림차순 정렬해주시고 매출액이 같다면 상품코드를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="157eda9b0fe1804e912fff0bad43b2c3"></a>

### 예시

<a id="157eda9b0fe180938a2bd5ab229baaa4"></a>

예를 들어 <code>PRODUCT</code> 테이블이 다음과 같고

|  |  |  |
| --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;CODE | PRICE |
| 1 | A1000011 | 15000 |
| 2 | A1000045 | 8000 |
| 3 | C3000002 | 42000 |

<a id="157eda9b0fe180caa182c939812d7494"></a>

<code>OFFLINE&#95;SALE</code> 테이블이 다음과 같다면

|  |  |  |  |
| --- | --- | --- | --- |
| OFFLINE&#95;SALE&#95;ID | PRODUCT&#95;ID | SALES&#95;AMOUNT | SALES&#95;DATE |
| 1 | 1 | 2 | 2022&#45;02&#45;21 |
| 2 | 1 | 2 | 2022&#45;03&#45;02 |
| 3 | 3 | 3 | 2022&#45;05&#45;01 |
| 4 | 2 | 1 | 2022&#45;05&#45;24 |
| 5 | 1 | 2 | 2022&#45;07&#45;14 |
| 6 | 2 | 1 | 2022&#45;09&#45;22 |

<a id="157eda9b0fe180798a21efe69a80a2ba"></a>

각 상품 별 총 판매량과 판매가는 다음과 같습니다&#46;

- <code>PRODUCT&#95;CODE</code> 가 <code>A1000011</code>인 상품은 총 판매량이 6개, 판매가가 15,000원

- <code>PRODUCT&#95;CODE</code> 가 <code>A1000045</code>인 상품은 총 판매량이 2개, 판매가가 8,000원

- <code>PRODUCT&#95;CODE</code> 가 <code>C3000002</code>인 상품은 총 판매량이 3개, 판매가가 42,000원

<a id="157eda9b0fe180b098e2d0300184e89f"></a>

그러므로 각 상품 별 매출액을 계산하고 정렬하면 결과가 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| PRODUCT&#95;CODE | SALES |
| C3000002 | 126000 |
| A1000011 | 90000 |
| A1000045 | 16000 |

<a id="157eda9b0fe18157a349e63974b255c7"></a>

## 풀이

<a id="157eda9b0fe180658478ce5124ebe667"></a>

```sql
SELECT
    p.PRODUCT_CODE,
    SUM(p.PRICE * os.SALES_AMOUNT) AS SALES
FROM PRODUCT p
JOIN OFFLINE_SALE os ON p.PRODUCT_ID = os.PRODUCT_ID
GROUP BY p.PRODUCT_ID
ORDER BY SALES DESC, p.PRODUCT_CODE
```
