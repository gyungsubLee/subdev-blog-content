### 요청 

- Path Variable&#58; <code>None</code>

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; <code>None</code>


- HTTP 요청

    [ Method ] [ URI ] [ HTTP Version ]

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | List&#60;<code>ChatroomResDto</code>&#62; | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>ChatroomResDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | chatroomId | Long | None | 채팅방 ID |
    | 2 | matchingId | Long | None | 매칭 ID |
    | 3 | date | LocalDate | None | 일정 날짜 |
    | 4 | title | String | None | 일정 제목 |
    | 5 | detail | String | None | 일정 제목 |
    | 6 | address | String | None | 주소 |
    | 7 | partnerName | String | None | 상대방 이름 |
    | 8 | partnerGender | String | None | 상대방 성별 |

    </details>
