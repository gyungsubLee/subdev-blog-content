# 문제

<a id="1c3eda9b0fe1814b8507cc2dc36a9c29"></a>

## 4&#46; 피보나치 수열

<a id="1c3eda9b0fe1817ba4d1f8d6ae914c4d"></a>

### 설명

<a id="1c3eda9b0fe181e4bd0ae2c8738c3d05"></a>

1) 피보나치 수열을 출력한다&#46; 피보나치 수열이란 앞의 2개의 수를 합하여 다음 숫자가 되는 수열이다&#46; 

<a id="1c3eda9b0fe1816bb0f0ca1fab3b3228"></a>

2) 입력은 피보나치 수열의 총 항의 수 이다&#46; 만약 7이 입력이되면 1 1 2 3 5 8 13을 출력하면 된다&#46; 

<a id="1c3eda9b0fe1818f9e23e8db2e807303"></a>

### 입력

<a id="1c3eda9b0fe181948fe5e3cee51b455e"></a>

첫 줄에 총 항수 N(3≤N≤45)이 입력된다&#46;

<a id="1c3eda9b0fe181f5a60ace156738db04"></a>

### 출력

<a id="1c3eda9b0fe181da8806f1dac5b14fc4"></a>

첫 줄에 피보나치 수열을 출력합니다&#46;

---

<a id="1c3eda9b0fe18198857bd3ecd78be8b9"></a>

# 풀이

<a id="1c3eda9b0fe1814e9384f99b6a4528ba"></a>

## 풀이1) <code>내 풀이</code>

<a id="1c3eda9b0fe1819cb785d241250e7e00"></a>

```java
import java.util.*;

public class Main {
    public ArrayList<Integer> DFS(int n, int a, int b, ArrayList<Integer> arr ){
        int c = a + b;
        arr.add(c);
        if(n==arr.size()) return arr;
        return DFS(n, b, c, arr);
    }

    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        ArrayList<Integer> arr = new ArrayList<>();
        int a=1, b=1;
        arr.add(a);
        arr.add(b);
        for(int x : T.DFS(n, a, b, arr)){
            System.out.print(x+" ");
        }
    }
}
```

## 풀이2) <code>강의 풀이</code>  메모제이션 

<a id="1c3eda9b0fe181d9874fd73015bdc62d"></a>

메모제이션&#58; 이전에 계산한 값을 저장하여 다시 불러옴 → 시간복잡도↓

<a id="1c3eda9b0fe1818da20fdf5a0fa8a3bd"></a>

```java
import java.util.*;

public class Main {
    static int[] fibo;
    public int DFS(int n){
				// 메모제이션
        if(fibo[n]>0) return fibo[n];
        if(n==1) return fibo[n]=1;
        else if(n==2) return fibo[n]=1;
        else return fibo[n]=DFS(n-2)+DFS(n-1);
    }

    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        fibo= new int[n+1];
				T.DFS(n);
        for(int i=1; i<=n; i++) System.out.print(fibo[i]+" ");
    }
}
```

## 풀이3) <code>2차 풀이</code> 

<a id="1c3eda9b0fe181aaaf38c468e24a1ac0"></a>

```java
import java.util.*;

public class Main {
    public void DFS(int a, int b, int L ){
        if(L==0) return;
        else {
            int c = a + b;
            System.out.print(c + " ");
            DFS(b, c, L-1);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        System.out.print(1 +" " + 1+" ");
        T.DFS(1, 1, n-2);
    }
}
```
