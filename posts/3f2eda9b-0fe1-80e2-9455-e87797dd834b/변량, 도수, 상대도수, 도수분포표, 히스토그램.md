## 변량, 도수, 상대도수, 도수분포표, 히스토그램

---

![  • 예시 - 100면의 키를 임의로 추출한 데이터 ( 대략 150 ~ 190 사이 )](7be708f5a4d9d3b2.webp)

<a id="3f2eda9b0fe180578678d1a7089cfaeb"></a>

### <code>변량</code>

> ✏️ 
> 
> <a id="3f2eda9b0fe1805f84edfe5f673de70a"></a>
> 
> <strong>변량</strong>
> 
> <a id="3f2eda9b0fe18048b105d34316b69d0b"></a>
> 
> 자료의 수치, 즉 데이터의 값을 의미하는 용어

> 🤔 
> 
> <a id="3f2eda9b0fe1808998a3da250d2bd6a0"></a>
> 
> 변량은 키, 나이(숫자)뿐만 아니라 혈액형, MBTI 등 <strong><u>특정 타입에 관계없이 데이터의 값</u></strong>을 의미한다&#46;

![  • 100면의 키를 임의로 추출한 데이터 ( 대략 150 ~ 190 사이 )](7be708f5a4d9d3b2.webp)

- 위와  같은 데이터들의 각 값들을 <code>변량</code>이라 한다&#46; 

<a id="3f2eda9b0fe1801391acf4aac6f7348b"></a>

### <code>계급</code>

> ✏️ 
> 
> <a id="3f2eda9b0fe1805eb2c2dbc0869a2ef4"></a>
> 
> 어느 정도 구간을 가지고 데이터를 묶어야 할지에 대한 기준
> 
> - 변량을 일정한 간격으로 나눈 구간
> 
> - 계급을 정할 때 변량의 최소, 최대를 고려

> 🤔 
> 
> <a id="3f2eda9b0fe1802ca2b4f4180c1a6a8e"></a>
> 
> 데이터 전체의 개형을 파악할 수 있는 적당한 수치로 계급(구간)을 나눠 도수를 구해야 한다&#46;
> 
> - 적당한? 굉장히 애매한 표현
> 
> - 구간을 너무 크게 잡거나, 너무 작게 잡지 않고 적당한 구간을 잡아야 전체 개형 파악이 가능하다&#46;
>     - 도수 분포의 목적 
> 
> ---
>

### <code>상대 도수</code>

> ✏️ 
> 
> <a id="3f2eda9b0fe180a8b26cfdb525997f82"></a>
> 
> 각 계급에 속하는 변량의 비율
> 
> > <code class="language-math">&#92;frac{도수(해당 계급의 개수)}{전체 개수}</code>

![](82a8b6e2d1a94bdc.webp)

<a id="3f2eda9b0fe180d7a1e9c76b1647af71"></a>

### <code>도수 분포표</code>

> ✏️ 
> 
> <a id="3f2eda9b0fe18007b104d2120c02a3f8"></a>
> 
> 주어진 자료를 계급에 따라 나눈 표
> 
> <a id="3f2eda9b0fe180868d39e9a59051bd2e"></a>
> 
> 아래의 표와 같이 <code>계급</code>, <code>도수</code>, <code>상대 도수</code>를 보기 쉽게 표현한다&#46;

> 💬 
> 
> <a id="3f2eda9b0fe180fba0fce61ab9394d3e"></a>
> 
> 정렬 기준
> 
> - 순서가 있는 경우, 순서대로 요약
> 
> - 순서가 없는 경우, 도수가 큰 값이나 강조하고 싶은 계급을 더 위에 정렬

> 💬 
> 
> - 장점
>     - 구간별 분포를 한눈에 알아보기 좋다&#46; 
> 
> - 단점
>     - 각 변량의 정확한 값 생략
>         - 계급 구간 안에 존재하는 실제 값에 대해서 파악 불가능

![](eeee23affbee73e9.webp)

<a id="3f2eda9b0fe18064a726cabcc0b36421"></a>

### <code>히스토그램</code>

> ✏️ 
> 
> <a id="3f2eda9b0fe1800e93ced48d4f21e7ef"></a>
> 
> <strong>도수분포표</strong>를 <code>시각화</code>해서 보는 <strong><u>가장 기본</u></strong>적인 방법
> 
> ![](e46033a02283a9ab.webp)
> 
> - Pivot chart와 비슷한형태
> 
> <a id="3f2eda9b0fe18079a1e2c1c4890c31b1"></a>
> 
> 데이터가 많아지고 구간이 넓어지며 세분화 되어 쪼개지는 상황들이 많이 발생되는 경우, 표 보다는 차트 형태가 전체적인 개형을 파악하는 데 용이하다&#46;

![](81ad143e04d38891.webp)

- 위와 같이 히스토그램으로 각 계급의 변량을 시각화하여 한눈에 전체 데이터의 개형을 파악할 수 있다&#46;
