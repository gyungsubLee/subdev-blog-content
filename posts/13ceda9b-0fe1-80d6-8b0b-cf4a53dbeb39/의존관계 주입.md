## 의존관계 주입

> 📖 
> 
> <a id="342c308fb68b418a8b373ba25488b415"></a>
> 
> 의존관계를 주입하는 방법으로는 <code>생성자 주입</code>, <code>setter 주입</code>, <code>필드 주입</code>, <code>메서드 주입</code> 총 4가지 방법이 있다&#46;

> ✏️ 
> 
> <a id="fdbd6ee819ca4aa78ec9d827d0040f79"></a>
> 
> <code>&#64;Autowired</code>
> 
> - 의존성을 자동으로 주입할 때 사용하는 Annotation
> 
> - 기본적으로 주입할 대상이 없으면 오류가 발생된다&#46; ( <code>required = true</code> ) 
> 
> -  의존관계를 자동으로 주입할 객체가 Spring Bean으로 등록되어 있어야 <code>&#64;Autowired</code> 로 주입이 가능

<details>
<summary>생성자 주입</summary>

- 생성자를 통해 의존성을 주입하는 방법

- 최초에 한번 생성된 후 값을 수정하지 못한다&#46; ( 불변, 필수 )

---

<details>
<summary>&#91; 코드 &#93; 빈 등록</summary>

<a id="141eda9b0fe180b1a895d554e743f298"></a>

```java
// Spring Bean으로 등록
@Service
public class MyServiceImpl implements MyService {
    @Override
    public void doSomething() {
        System.out.println("MyServiceImpl 메서드 호출");
    }
}
```

</details>

<details>
<summary>&#91; 코드 &#93; 생성자 주입</summary>

<a id="4b29426f8d134c57b4b02a9ee7ebfd98"></a>

```java
// 생성자 주입 방식
@Component
public class MyApp {
		// 필드에 final 키워드 필수! 무조건 값이 있도록 만들어준다.(필수)
    private final MyService myService;

		// 생성자 주입
				// 생성자 1개 시, @Autowired 생략 가능
    @Autowired
    public MyApp(MyService myService) {
        this.myService = myService;
    }

    public void run() {
        myService.doSomething();
    }
    
}

```

</details>

<details>
<summary>&#91; 코드 &#93;  테스트 &#45; Main</summary>

<a id="6940367a531143849bfa0882cc080193"></a>

```java

@ComponentScan(basePackages = "com.example.springdependency.test")
public class Main {
    public static void main(String[] args) {

        ApplicationContext context = new AnnotationConfigApplicationContext(Main.class);

        // 등록된 MyApp 빈 가져오기
        MyApp myApp = context.getBean(MyApp.class);

        // 빈 메서드 호출
        myApp.run();
    }
}

```

</details>

> ☝🏻 
> 
> <a id="a399a1aecf95415d972c701b55eb539b"></a>
> 
> 생성자가 하나인 경우 <code>&#64;Autowired</code> 생략 가능하다&#46;

<details>
<summary>🤬 Error &#45; 생성자가 2개 이상인 경우 <code>&#64;Autowired</code> 생략</summary>

- 아래와 같이 생성자가 2개인 경우, <code>&#64;Autowired</code> 생략 시 둘 중 어떤 생성자를 사용하여 주입해야 하는지 spring이 인식할 수 없다&#46; 

<a id="141eda9b0fe180c4bee7d6a2783f29ed"></a>

```java
// 생성자가 두개인 경우 생략이 불가능하다.
@Component
public class MyApp {
		// 필드에 final 키워드 필수! 무조건 값이 있도록 만들어준다.(필수)
    private final MyService myService;
    
    
    public MyApp(MyService myService, String myRepository) {
        this.myService = myService;
    }

		// 생성자를 통해 의존성 주입
    // @Autowired를 생략하기 위해서는 생성자가 하나여야 한다.
    public MyApp(MyService myService) {
        this.myService = myService;
    }

    public void run() {
        service.doSomething();
    }
}
```

</details>

> 🥸 
> 
> <a id="ddd5a45a938546d380524290f81cabdd"></a>
> 
> 롬복 &#45; <code>&#64;RequiredArgsContructor</code>
> 
> - lombok 라이브러리의 Annotation으로  <br><code>final</code>로 선언한 필드들의 값을 동으로  생성자 생성 및  주입을 해준다&#46;
> 
> - 일일이 생성자를 입력하지 않아도 돼서 개발 생산성을 향상 시켜준다&#46;

## 생성자 주입

> 📖 
> 
> <a id="3ace0986e7d944738b7be711f12ed9c9"></a>
> 
>  DI를 가지고 있는 대부분의 Framework가 <strong><u>생성자 주입 방식을 권장</u></strong>한다&#46;

- 생성자 주입을 선택하는 이유
    - 불변 <strong>( immutable )</strong>
        - 객체를 생성할 때 최초 한번만 호출된다 ( 불변 )

        - setter 주입을 사용하면 접근제어자가 <code>public</code> 으로 설정되어 누구나 수정할 수 있게된다&#46;

        <details>
        <summary>🧐 생성 메서드 &#45; <code>private</code> Setter </summary>

        - setter를 <code>private</code>으로 변경 선언 후 생성 메서드 통해 객체 생성 및 필드 초기화를 하여 불변성을 지킬 수 있다&#46;
            - JPA 사용 시, 객체 생성 할 때 필드 초기화와 연관관계를 동시에 설정할 수 있다&#46;

            - 기본 생성자를 protected로 선언하여 외부에서 객체가 생성되는 것을 막아야 한다&#46; 

        <details>
        <summary>ex) </summary>

        <details>
        <summary>1&#46; 기본생성자 protected 선언</summary>

        <a id="1cb885eea6ac4116b1c13e98d6ea0279"></a>

        ```java
        @NoArgsConstructor(access = AccessLevel.PROTECTED)
        ```

        </details>

        <details>
        <summary>2&#46; 연관관계 메서드 privat 선언</summary>

        <a id="f27cb95e8f304068a0bcf40e0cc09c87"></a>

        ```java
        // 연관관계 메서드, private 선언
        private void setMember ( Member member ){
            this.member = member;
            member.getScheduleList().add(this);
        }
        ```

        </details>

        <details>
        <summary>3&#46; 생성 메서드 </summary>

        <a id="184b5c75b49d475b9b1093078d9f05ab"></a>

        ```java
        // 생성 메서드
        public static Schedule createSchedule(String title, String descriptiom, Member member){
            Schedule schedule = new Schedule();
            schedule.title = title;
            schedule.descriptiom = descriptiom;
            schedule.setMember(member);
            return schedule;
        }
        ```

        </details>

        </details>

        </details>

    - 실수 방지
        - 생상자를 통해 설정하면, <u>인스턴스 생성</u> 시 <u>해당 필드 값 입력이 필수</u>가 된다&#46; 
            <details>
            <summary><u>입력이 안될 시 컴퍼일 오류로 잡</u>아준다&#46;</summary>

            <a id="13ceda9b0fe18097a879ca8654c8d783"></a>

            ```java
            / 생성자 주입 방식
            @Component
            public class MyApp {
            		// 필드에 final 키워드 필수! 무조건 값이 있도록 만들어준다.(필수)
                private final MyService myService;

            		// 생성자를 통해 의존성 주입, 생략 가능
                @Autowired
                public MyApp(MyService myService) {
                    this.myService = myService;
                }

                public void run() {
                    myService.doSomething();
                }
                
            }

            public class Main {
                public static void main(String[] args) {
            		    // MyService가 매개변수로 꼭 들어가야 한다.
                    MyApp myApp = new MyApp(); // 컴파일 오류 발생, 생성자 필드 값 누락
                    myApp.run();
                }
            }
            ```

            </details>

        - 테스트 코드(순수 자바 코드)에서 <u>생성자의 필드를 필수로 입력</u> 가능하도록하여 <u>NPE 방지</u>할 수 있다&#46;

## &#64;RequiredArgsConstructor

> 📖 
> 
> <a id="025ef2ee0887439998ee9fe7876524c2"></a>
> 
> Lombok의  <code>&#64;RequiredArgsConstructor</code>을 통해 불<u>변 객체( </u><u><code>final</code></u><u> ) 및 생성자 주입</u>을 간편하게 처리할 수 있다&#46; 

> <code>final</code> 필드로 선언된 변수들을 자동으로 생성자 주입 방식으로 만들어 준다&#46; 

<details>
<summary>생성자 주입 ( <code>&#64;RequiredArgsConstructor</code> 사용 전 )</summary>

<a id="13ceda9b0fe1804f85c1f91895caaa4b"></a>

```java
@Component
public class MyApp {
	
    private final MyService myService;
    
    // 생성자를 통한 의존성 주입
    // 생성자 1개 -> @Autowired 생략 가능
    public MyApp(MyService myService) {
         this.myService = myService;
    }

    public void run() {
        myService.doSomething();
    }
    
}
```

</details>

<details>
<summary><code>&#64;RequiredArgsConstructor</code> 사용</summary>

<a id="13ceda9b0fe180fd9fbecf9926f837f9"></a>

```java
@Component
@RequiredArgsConstructor
public class MyApp {
	
		// 생성자 주입 자동으로 처리
		// 불변 객체에 대한 처리이기 때문에, final(상수) 선언 필수
    private final MyService myService;

    public void run() {
        myService.doSomething();
    }
    
}
```

</details>
