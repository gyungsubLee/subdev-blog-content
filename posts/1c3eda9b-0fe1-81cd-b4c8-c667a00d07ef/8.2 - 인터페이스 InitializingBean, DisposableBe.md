## <strong>인터페이스 </strong>InitializingBean, DisposableBean

---

<a id="1c3eda9b0fe181cba326faecd27ad1ea"></a>

### <strong>인터페이스 </strong>InitializingBean, DisposableBean 상속 및 오버라이드

<a id="1c3eda9b0fe18102bb12d8eba4dbb572"></a>

```java
package hello.core.lifecycle;

import org.springframework.beans.factory.DisposableBean;
import org.springframework.beans.factory.InitializingBean;

public class NetworkClient implements InitializingBean, DisposableBean  {
    private String url;

    public NetworkClient() {
        System.out.println("생성자 호출, url = " + url);
    }

    public void setUrl(String url) {
        this.url = url;
    }

    // 서비스 시작 시 호출
    public void connect() {
        System.out.println("connect: " + url);
    }

    public void call(String message) {
        System.out.println("call = " + url + " message = " + message);
    }

    // 서비스 종료 시 호출
    public void disConnect() {
        System.out.println("close + " + url);
    }

    @Override
    public void afterPropertiesSet() throws Exception {
        connect();
        call("초기화 연결 메시지");
    }

    @Override
    public void destroy() throws Exception {
        disConnect();
    }

}
```

> <code>InitializingBean</code> 은 <code>afterPropertiesSet()</code> 메서드로 초기화를 지원한다&#46; <br><code>DisposableBean</code> 은 <code>destroy()</code> 메서드로 소멸을 지원한다&#46;

<a id="1c3eda9b0fe181e68467d872c8f65a96"></a>

<a id="1c3eda9b0fe1815baa9ed9d5226a4dea"></a>

```plaintext

NetworkClient.afterPropertiesSet

call: http://hello-spring.dev message = 초기화 연결 메시지
13:24:49.043 [main] DEBUG

```

> 출력 결과를 보면 초기화 메서드가 주입 완료 후에 적절하게 호출 된 것을 확인할 수 있다&#46; <br>그리고 스프링 컨테이너의 종료가 호출되자 소멸 메서드가 호출 된 것도 확인할 수 있다&#46;

<a id="1c3eda9b0fe18186b879dc6d1c5ffc47"></a>

### 초기화, 소멸 인터페이스 단점

<a id="1c3eda9b0fe181dd9d2ff2c05adb3552"></a>

해당 인터페이스(<code>InitializingBean</code>, <code>DisposableBean</code>)는 스프링 전용 인터페이스이다&#46; 해당 코드가 스프링 전용 인터페이스에 의존한다&#46;<br>→ 초기화, 소멸 메서드의 이름을 변경할 수 없다&#46;<br>→ 스스로 코드를 수정할수 없는 외부 라이브러이에 적용할 수없다&#46;
