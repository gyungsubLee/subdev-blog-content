## 문제

<a id="1d2eda9b0fe18045b816e0fc6a93f4da"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe1805f87bddbe44f18bc9d"></a>

다음은 종합병원에 속한 의사 정보를 담은<code>DOCTOR</code> 테이블입니다&#46; <code>DOCTOR</code> 테이블은 다음과 같으며 <code>DR&#95;NAME</code>, <code>DR&#95;ID</code>, <code>LCNS&#95;NO</code>, <code>HIRE&#95;YMD</code>, <code>MCDP&#95;CD</code>, <code>TLNO</code>는 각각 의사이름, 의사ID, 면허번호, 고용일자, 진료과코드, 전화번호를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| DR&#95;NAME | VARCHAR(20) | FALSE |
| DR&#95;ID | VARCHAR(10) | FALSE |
| LCNS&#95;NO | VARCHAR(30) | FALSE |
| HIRE&#95;YMD | DATE | FALSE |
| MCDP&#95;CD | VARCHAR(6) | TRUE |
| TLNO | VARCHAR(50) | TRUE |

---

<a id="1d2eda9b0fe18009a402ea517a19a560"></a>

### 문제

<a id="1d2eda9b0fe18035b164e47d080a553f"></a>

<code>DOCTOR</code> 테이블에서 진료과가 흉부외과(CS)이거나 일반외과(GS)인 의사의 이름, 의사ID, 진료과, 고용일자를 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 고용일자를 기준으로 내림차순 정렬하고, 고용일자가 같다면 이름을 기준으로 오름차순 정렬해주세요&#46;

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe180b9bfccd16a85f67163"></a>
> 
> 조건
> 
> - 진료과가 흉부외과(CS)이거나 일반외과(GS)인 의사의 이름, 의사ID, 진료과, 고용일자를 조회
> 
> - 고용일자를 기준으로 내림차순 정렬하고, 고용일자가 같다면 이름을 기준으로 오름차순 정렬

<a id="1d2eda9b0fe180cb927be2dff7776767"></a>

```sql
SELECT 
    DR_NAME, 
    DR_ID, 
    MCDP_CD, 
    DATE_FORMAT(HIRE_YMD, '%Y-%m-%d')
FROM DOCTOR
WHERE MCDP_CD IN('CS', 'GS')
ORDER BY HIRE_YMD DESC, DR_NAME;
```
