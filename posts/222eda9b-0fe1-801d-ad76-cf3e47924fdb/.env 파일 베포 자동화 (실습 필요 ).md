>

> 따라서 베포 시 베포 서버에 <code>&#46;env</code> 파일 따로 세팅해야 하는 번거로움이 있다&#46;
> 
> <a id="222eda9b0fe180269c6fc608778eb278"></a>
> 
> 이를 <code>&#46;env</code> 파일 github secret 값으로 등록하여 Github Actions에서 불러와 자동으로 EC2에 베포할 수 있다&#46;

1. <strong>Gitbub Actions 코드 수정</strong>
    <a id="222eda9b0fe180b6a9a5f0ec4d1a911e"></a>

    <strong><code>&#46;github/workflows/deploy&#46;yml</code></strong>

    <a id="222eda9b0fe180dbb453d89da3e10878"></a>

    ```yaml
    name: Deploy To EC2

    on:
      push:
        branches:
          - main

    jobs:
      deploy:
        runs-on: ubuntu-latest
        steps:
          - name: SSH로 EC2에 접속하기
            uses: appleboy/ssh-action@v1.0.3
            env:
              ENV: ${{ secrets.ENV }}
            with:
              host: ${{ secrets.EC2_HOST }}
              username: ${{ secrets.EC2_USERNAME }}
              key: ${{ secrets.EC2_PRIVATE_KEY }}
              envs: ENV
              script_stop: true
              script: |
                cd /home/ubuntu/cicd-nest-test
                rm -rf .env
                git pull origin main
                echo "$ENV" > .env
                npm i
                npm run build
                pm2 kill
                pm2 start dist/main.js --name "backend-server"
    ```
