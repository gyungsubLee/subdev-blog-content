# 문제

<a id="1c3eda9b0fe18182a618f03e35813f6c"></a>

## <strong>1&#46; 선택 정렬</strong>

---

<a id="1c3eda9b0fe18127abece5a5c70d46c9"></a>

### 설명

<a id="1c3eda9b0fe181cdb830d0232926d0b1"></a>

N개이 숫자가 입력되면 오름차순으로 정렬하여 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181bfad35db57efe8e3c3"></a>

정렬하는 방법은 선택정렬입니다&#46;

<a id="1c3eda9b0fe181d0a8f0f7f984827744"></a>

### 입력

<a id="1c3eda9b0fe1812ab233fe9a71ac508d"></a>

첫 번째 줄에 자연수 N(1&#60;=N&#60;=100)이 주어집니다&#46;

<a id="1c3eda9b0fe181839fb5da80d26f844d"></a>

두 번째 줄에 N개의 자연수가 공백을 사이에 두고 입력됩니다&#46; 각 자연수는 정수형 범위 안에 있습니다&#46;

<a id="1c3eda9b0fe181208cfecf90183db41c"></a>

### 출력

<a id="1c3eda9b0fe181669b64c158f4ff8637"></a>

오름차순으로 정렬된 수열을 출력합니다&#46;

---

<a id="1c3eda9b0fe1814899ccd2ca38fe84e6"></a>

### 예시 입력 1

<a id="1c3eda9b0fe18145b082ed2ed9361e37"></a>

```plaintext
6
13 5 11 7 23 15
```

<a id="1c3eda9b0fe181aa9bd8e8aec00316f6"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181ef8b13d54f16ab30cb"></a>

```plaintext
5 7 11 13 15 23
```

## 풀이1) sort()

<a id="1c3eda9b0fe181fb84a0e03753e59fca"></a>

```java
import java.util.*;

public class Main {
public int[] solution(int n, int[] arr){
        Arrays.sort(arr);
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(n, arr)){
            System.out.print(x+" ");
        }
    }
}
```

## 풀이2)  선택 정렬 알고리즘

<a id="1c3eda9b0fe18101bb38ffb2b0129af6"></a>

```java
import java.util.*;

public class Main {
public int[] solution(int n, int[] arr){
        for(int i=0; i<n-1; i++){
            int idx=i;
            for(int j=i+1; j<n; j++){
                if(arr[j]<arr[idx]) idx=j;
            }
            int tmp=arr[i];
            arr[i]=arr[idx];
            arr[idx]=tmp;
        }
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(n, arr)){
            System.out.print(x+" ");
        }
    }
} 
```
