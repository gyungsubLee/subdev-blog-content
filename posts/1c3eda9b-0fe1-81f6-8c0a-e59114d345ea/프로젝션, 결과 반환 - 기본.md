## 프로젝션

---

> 📖 
> 
> <a id="1c3eda9b0fe1815d8305edf31bda3837"></a>
> 
> 프로젝션은 조회(<code>SELECT</code>) 시 가져오는 컬럼(들)을 말한다&#46; 
> 
> - 프로젝션 1개&#58; 해당 컬럼 타입 명시
> 
> - 프로젝션 2개 이상&#58; <code>Tuple</code>, <code>DTO</code>

<details>
<summary>프로젝션</summary>

- SELECT 에서 가져오는 대상을 말한다&#46; 
    - SELECT에서 명시하는 컬럼들

<details>
<summary>프로젝션 대상이 <u>하나</u>면 <u>타입을 명확하게 지정</u> 가능하다&#46; </summary>

<a id="1c3eda9b0fe18160921ccee9c7648b63"></a>

```java
 List<String> result = queryFactory
         .select(member.username)
     .from(member)
     .fetch();
```

</details>

- 프로젝션 대상이 <u>둘 이상</u>이면 <code>튜플</code>이나 <code>DTO</code>로 조회한다&#46; 

</details>

<details>
<summary>튜플 조회</summary>

- 프로젝션 <u>대상이 둘 이상일 때</u> 사용한다&#46;
    > <code>com&#46;querydsl&#46;core&#46;Tuple</code>

    <a id="1c3eda9b0fe181cc8466f20fe310ecd8"></a>

    ```java
    List<Tuple> result = queryFactory
           .select(member.username, member.age)
           .from(member)
           .fetch();
           
    for (Tuple tuple : result) {
       String username = tuple.get(member.username);
       Integer age = tuple.get(member.age);
       System.out.println("username=" + username);
       System.out.println("age=" + age);
    }
    ```

</details>

> ☝🏻 
> 
> <a id="1c3eda9b0fe181959e5cd199df8de0e5"></a>
> 
> <u>튜플</u>은<u> Querydls에서 제공하는 기술</u>이다&#46; ( <code>com&#46;querydsl&#46;core&#46;Tuple</code>)
> 
> <a id="1c3eda9b0fe1819f939ed40e8a5946a2"></a>
> 
>  따라서 <u>repository 계층을 넘</u>어서 <u>service, controller 계층에서 사용하는 것은 권장하지 않</u>는다&#46; 
> 
> - service, controller 계층에서 JPA나 Querydsl을 의존하게 된다&#46; 
> 
> - 이렇게 종속적인 설계는 이후 하부 기술 변경 및 확장 시 비용을 증가시킨다&#46; 
> 
> <a id="1c3eda9b0fe1814faa11d42517e5137f"></a>
> 
> ⇒ <u>튜플 데이터는 </u><u>리포지토리 계층에서만 처리</u>하고 <u>반환 시 DTO로 변환</u>해서 처리한다&#46;
