## 문제

<a id="1d2eda9b0fe1806cab7cce8f4c0eb7f9"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180728d89c9eb6ea6bc5d"></a>

다음은 식품창고의 정보를 담은 <code>FOOD&#95;WAREHOUSE</code> 테이블입니다&#46; <code>FOOD&#95;WAREHOUSE</code> 테이블은 다음과 같으며 <code>WAREHOUSE&#95;ID</code>, <code>WAREHOUSE&#95;NAME</code>, <code>ADDRESS</code>, <code>TLNO</code>, <code>FREEZER&#95;YN</code>는 창고 ID, 창고 이름, 창고 주소, 전화번호, 냉동시설 여부를 의미합니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| WAREHOUSE&#95;ID | VARCHAR(10) | FALSE |
| WAREHOUSE&#95;NAME | VARCHAR(20) | FALSE |
| ADDRESS | VARCHAR(100) | TRUE |
| TLNO | VARCHAR(20) | TRUE |
| FREEZER&#95;YN | VARCHAR(1) | TRUE |

---

<a id="1d2eda9b0fe180e48fc6e79f6bb81008"></a>

### 문제

<a id="1d2eda9b0fe18055ba24eab8e7032c3c"></a>

<code>FOOD&#95;WAREHOUSE</code> 테이블에서 경기도에 위치한 창고의 ID, 이름, 주소, 냉동시설 여부를 조회하는 SQL문을 작성해주세요&#46; 이때 냉동시설 여부가 NULL인 경우, &#39;N&#39;으로 출력시켜 주시고 결과는 창고 ID를 기준으로 오름차순 정렬해주세요&#46;

---

<a id="1d2eda9b0fe180d2afb3d08571de074a"></a>

### 예시

<a id="1d2eda9b0fe1807aa9ced89a253aa321"></a>

<code>FOOD&#95;WAREHOUSE</code> 테이블이 다음과 같을 때

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| WAREHOUSE&#95;ID | WAREHOUSE&#95;NAME | ADDRESS | TLNO | FREEZER&#95;YN |
| WH0001 | 창고&#95;경기1 | 경기도 안산시 상록구 용담로 141 | 031&#45;152&#45;1332 | Y |
| WH0002 | 창고&#95;충북1 | 충청북도 진천군 진천읍 씨제이로 110 | 043&#45;623&#45;9900 | Y |
| WH0003 | 창고&#95;경기2 | 경기도 이천시 마장면 덕평로 811 | 031&#45;221&#45;7241 | NULL |
| WH0004 | 창고&#95;경기3 | 경기도 김포시 대곶면 율생중앙로205번길 | 031&#45;671&#45;1900 | N |
| WH0005 | 창고&#95;충남1 | 충청남도 천안시 동남구 광덕면 신덕리1길 9 | 041&#45;876&#45;5421 | Y |

<a id="1d2eda9b0fe1806693fdd15e33673f4e"></a>

SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

|  |  |  |  |
| --- | --- | --- | --- |
| WAREHOUSE&#95;ID | WAREHOUSE&#95;NAME | ADDRESS | FREEZER&#95;YN |
| WH0001 | 창고&#95;경기1 | 경기도 안산시 상록구 용담로 141 | Y |
| WH0003 | 창고&#95;경기2 | 경기도 이천시 마장면 덕평로 811 | N |
| WH0004 | 창고&#95;경기3 | 경기도 김포시 대곶면 율생중앙로205번길 | N |

<a id="1d1eda9b0fe1805fade3ff471835256d"></a>

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe1805e84d5f387398876bb"></a>
> 
> 조건
> 
> - 경기도에 위치한 창고의 ID, 이름, 주소, 냉동시설 여부를 조회
> 
> - 냉동시설 여부가 NULL인 경우, &#39;N&#39;으로 출력
> 
> -  창고 ID를 기준으로 오름차순 정렬

<a id="1d1eda9b0fe180058a9bf1a1b97a5420"></a>

```sql
SELECT 
    WAREHOUSE_ID,
    WAREHOUSE_NAME, 
    ADDRESS, 
    IF(FREEZER_YN IS NULL, 'N', FREEZER_YN)
FROM FOOD_WAREHOUSE
WHERE ADDRESS LIKE '경기도%'
```
