# 문제

<a id="1c3eda9b0fe181908b70cdcfacaf2444"></a>

## <strong>14&#46; 섬나라 아일랜드(BFS)</strong>

---

<a id="1c3eda9b0fe1811d8a18d554e440855c"></a>

### 설명

<a id="1c3eda9b0fe1815da1c0f8c4d45904f3"></a>

N&#42;N의 섬나라 아일랜드의 지도가 격자판의 정보로 주어집니다&#46;

<a id="1c3eda9b0fe18163875cf76b957f5eac"></a>

각 섬은 1로 표시되어<strong> 상하좌우와 대각선</strong>으로 연결되어 있으며, 0은 바다입니다&#46;

<a id="1c3eda9b0fe181578cb0d084887bfd1b"></a>

섬나라 아일랜드에 몇 개의 섬이 있는지 구하는 프로그램을 작성하세요&#46;

![](https://cote.inflearn.com/public/upload/7c81fe29cd.jpg)

<a id="1c3eda9b0fe1817b84f0fc9c9a865ee2"></a>

만약 위와 같다면 섬의 개수는 5개입니다&#46;

<a id="1c3eda9b0fe181e480ecca45de641805"></a>

### 입력

<a id="1c3eda9b0fe18103866fc50afc65592f"></a>

첫 번째 줄에 자연수 N(3&#60;=N&#60;=20)이 주어집니다&#46;

<a id="1c3eda9b0fe181dd9c60ffed5cacdda9"></a>

두 번째 줄부터 격자판 정보가 주어진다&#46;

<a id="1c3eda9b0fe18124b707cc5c5c75af57"></a>

### 출력

<a id="1c3eda9b0fe18156a642f6335a36fa07"></a>

첫 번째 줄에 섬의 개수를 출력한다&#46;

# 풀이

<a id="1c3eda9b0fe18162b2d7ca078254eb0e"></a>

## 풀이1) <code>내풀이</code> BFS

<a id="1c3eda9b0fe1817f9aebf385a352f30f"></a>

```java
import java.util.*;

class Point{
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n;
    static int[] dx={1, -1, 0, 0, 1, 1, -1, -1};
    static int[] dy={0, 0, 1, -1, 1, -1, 1, -1};
    static int[][] board;

    public void BFS(int x, int y){
        Queue<Point> Q=new LinkedList<>();
        Q.offer(new Point(x, y));
        board[x][y]=0;
        while(!Q.isEmpty()){
            Point cur=Q.poll();
            for(int i=0; i<8; i++){
                int nx=cur.x+dx[i];
                int ny=cur.y+dy[i];
                if((nx>=0 && ny>=0 && nx<n && ny<n) && board[nx][ny]==1){
                    board[nx][ny]=0;
                    Q.offer(new Point(nx, ny));
                }
            }
        }
    }

    public int solution(){
        int cnt=0;
        for(int i=0; i<n; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 1){
                    BFS(i, j);
                    cnt++;
                }
            }
        }
        return cnt;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        board=new int[n][n];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                board[i][j]=sc.nextInt();
            }
        }

        System.out.println(T.solution());
    }
}
```
