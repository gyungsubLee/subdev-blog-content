### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | <code>MatchingResDto</code> | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>MatchingResDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long | None | — 식별자 |
    | 2 | status | String | None | 매칭 상태 |
    | 3 | createdAt | Timestamp | None | 생성 일자 |
    | 4 | updatedAt | Timestamp | None | 수정 일자 |

    </details>

    <details>
    <summary>응답 예시 </summary>

    }

    </details>

    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
