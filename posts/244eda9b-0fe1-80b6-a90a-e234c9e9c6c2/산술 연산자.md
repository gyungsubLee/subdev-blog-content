> <strong>산술 연산자 ( 수학 &#45; 사칙연산 )</strong>
> 
> - <strong>종류&#58; </strong><code>&#43;</code>, <code>&#45;</code>, <code>/</code>, <code>&#42;</code>
> 
> - <code>NUMBER</code>, <code>DATE</code> 에 적용 가능
> 
> - 우선 순위
>     1. <code>(&#46;&#46;&#46;)</code>
> 
>     1. <code>&#42;</code>, <code>/</code>
> 
>     1. <code>&#43;</code>, <code>&#45;</code>

- ex 1)
    <a id="244eda9b0fe180139cabed0c6101bfd3"></a>

    ```sql
    SELECT
    		sal,
    		sal * 0.3,
    		100 + 300,
    		sal - deptno
    FROM emp;
    ```

- ex 2) <code>NULL</code> &#43; <code>&#42;</code>, <code>/</code>, <code>&#43;</code>, <code>&#45;</code>  = <code>NULL</code>
    <a id="244eda9b0fe18048a90af9d979a2e503"></a>

    ```sql
    SELECT
    		sal,
    		comm,
    		sal + NULL,
    		sal - NULL,
    		sal * NULL,
    		sal / NULL,
    FROM emp;
    ```
