## 문제

<a id="1cfeda9b0fe1802fbe4ada6b90e90c00"></a>

### <strong>문제 설명</strong>

<a id="1cfeda9b0fe180ceb635d6885d91e945"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1cfeda9b0fe180d1b5ccfaa9de362e34"></a>

동물 보호소에 가장 먼저 들어온 동물의 이름을 조회하는 SQL 문을 작성해주세요&#46;

<a id="1cfeda9b0fe180c484d3ff897879776b"></a>

### 예시

<a id="1cfeda9b0fe180b692edd154feb344ca"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A399552 | Dog | 2013&#45;10&#45;14 15&#58;38&#58;00 | Normal | Jack | Neutered Male |
| A379998 | Dog | 2013&#45;10&#45;23 11&#58;42&#58;00 | Normal | Disciple | Intact Male |
| A370852 | Dog | 2013&#45;11&#45;03 15&#58;04&#58;00 | Normal | Katie | Spayed Female |
| A403564 | Dog | 2013&#45;11&#45;18 17&#58;03&#58;00 | Normal | Anna | Spayed Female |

<a id="1cfeda9b0fe1806f96f5fb9b6fc48391"></a>

이 중 가장 보호소에 먼저 들어온 동물은 Jack입니다&#46; 따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

<a id="1cfeda9b0fe180e0b6b0fcf2c3096318"></a>

NAME

---

<a id="1cfeda9b0fe18068b4eeed20dc586a6b"></a>

Jack

---

<a id="1cfeda9b0fe18040beb5e2c18f3b03d1"></a>

※ 보호소에 가장 먼저 들어온 동물은 한 마리인 경우만 테스트 케이스로 주어집니다&#46;

<a id="1cfeda9b0fe1800ea8f4d9c607f9372c"></a>

## 풀이

> ✏️ 
> 
> <a id="1cfeda9b0fe180f180c6f3209a498dd9"></a>
> 
> 조건
> 
> - 가장 먼저 들어온 동물의 이름을 조회

<a id="1cfeda9b0fe1804baf40cc881dc0c27f"></a>

### 풀이1&#58; ORDER BY &#43; LIMIT

<a id="1cfeda9b0fe18052b33dce77c6bc8efe"></a>

```sql
SELECT NAME
FROM ANIMAL_INS
ORDER BY DATETIME  # default: ASC
LIMIT 1
```

<a id="1cfeda9b0fe180b285d9f2b9ce323ef8"></a>

### 풀이2&#58; 서브쿼리 &#43; MIN()

<a id="1cfeda9b0fe180348a4cec3bf00365b7"></a>

```sql
SELECT NAME
FROM ANIMAL_INS
WHERE DATETIME = ( SELECT MIN(DATETIME) FROM ANIMAL_INS);
```
