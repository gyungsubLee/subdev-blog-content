## 문제

<a id="1d1eda9b0fe18062ace6eff2a6acd26c"></a>

### <strong>문제 설명</strong>

<a id="1d1eda9b0fe1807a9c09ebc089728413"></a>

다음은 어느 의류 쇼핑몰에서 판매 중인 상품들의 정보를 담은 <code>PRODUCT</code> 테이블입니다&#46; <code>PRODUCT</code> 테이블은 아래와 같은 구조로 되어있으며, <code>PRODUCT&#95;ID</code>, <code>PRODUCT&#95;CODE</code>, <code>PRICE</code>는 각각 상품 ID, 상품코드, 판매가를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| PRODUCT&#95;ID | INTEGER | FALSE |
| PRODUCT&#95;CODE | VARCHAR(8) | FALSE |
| PRICE | INTEGER | FALSE |

<a id="1d1eda9b0fe180ddb39fe631729af694"></a>

상품 별로 중복되지 않는 8자리 상품코드 값을 가지며, 앞 2자리는 카테고리 코드를 의미합니다&#46;

---

<a id="1d1eda9b0fe1807a80d4fa90d6bd320e"></a>

### 문제

<a id="1d1eda9b0fe18067a91ffa49f9581512"></a>

<code>PRODUCT</code> 테이블에서 판매 중인 상품 중 가장 높은 판매가를 출력하는 SQL문을 작성해주세요&#46; 이때 컬럼명은 MAX&#95;PRICE로 지정해주세요&#46;

---

<a id="1d1eda9b0fe180d28173e09e489b6e59"></a>

### 예시

<a id="1d1eda9b0fe1803d802fe5e8b8a6613a"></a>

예를 들어 <code>PRODUCT</code> 테이블이 다음과 같다면

|  |  |  |
| --- | --- | --- |
| PRODUCT&#95;ID | PRODUCT&#95;CODE | PRICE |
| 1 | A1000001 | 10000 |
| 2 | A2000005 | 9000 |
| 3 | C1000006 | 22000 |

<a id="1d1eda9b0fe180be8a86eaad5242ca56"></a>

가장 높은 판매가는 22,000 원 이므로, 다음과 같은 결과가 나와야 합니다&#46;

<a id="1d1eda9b0fe1801f95e3db65a63ed168"></a>

MAX&#95;PRICE

---

<a id="1d1eda9b0fe1801992e0d884587663a0"></a>

22000

---

<a id="1d1eda9b0fe18039a305ea282f1d3e78"></a>

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe1806cbd70cdc2306f2525"></a>
> 
> 조건
> 
> - <code>PRODUCT</code> 테이블에서 판매 중인 상품 중 가장 높은 판매가를 출력

<a id="1d1eda9b0fe18027b540fd243f704efd"></a>

```sql
SELECT MAX(PRICE) AS MAX_PRICE
FROM PRODUCT
LIMIT 1
```
