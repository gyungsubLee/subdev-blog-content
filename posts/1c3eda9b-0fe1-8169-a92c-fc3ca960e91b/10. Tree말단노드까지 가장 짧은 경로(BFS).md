# 문제

<a id="1c3eda9b0fe1814982b1e1db7b5d4e5b"></a>

## 10&#46; Tree 말단 노드까지 가장 짧은 경로(BFS)

<a id="1c3eda9b0fe1814fa449eb45b8be1f86"></a>

### 설명

<a id="1c3eda9b0fe18126bafced2609102528"></a>

아래 그림과 같은 이진트리에서 루트 노드 1에서 말단노드까지의 길이 중 가장 짧은 길이를 구하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1812eab02ead1cadc5c8f"></a>

각 경로의 길이는 루트 노드에서 말단 노드까지 가는데 이동한 횟수를 즉, 간선(에지)의 개수의 길이로 하겠습니다&#46; 

![](d3a600fcd40e4224.webp)

<a id="1c3eda9b0fe181a99cc9ff13579cc800"></a>

### 출력

<a id="1c3eda9b0fe1819399dff2afc78cf1eb"></a>

가장 짧은 길이는 3번 노드까지의 길이인 1이다&#46;

<a id="1c3eda9b0fe181af8f4fe5a5ba66a0ab"></a>

```plaintext
1
```

<a id="1c3eda9b0fe181698649ccfbda6f1c17"></a>

# 풀이

<a id="1c3eda9b0fe18193bfe8d9c9b8b0d79c"></a>

## 풀이1) <code>내 풀이</code> ,  &#91;강의 풀이&#93; 동일

<a id="1c3eda9b0fe181acbb22d1bb4633513c"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

class Node{
    int data;
    Node lt, rt;
    Node(int val){
        data=val;
        lt=rt=null;
    }
}

public class Main {
    Node root;
    public int BFS(Node root){
        int L=0;
        Queue<Node> Q;=new LinkedList<>();
        Q.offer(root);
        while(!Q.isEmpty()){
            int len=Q.size();
            for(int i=0; i<len; i++){
                Node cur=Q.poll();
                if(cur.lt==null&&cur.rt==null) return L;
                if(cur.lt!=null) Q.offer(cur.lt);
                if(cur.rt!=null) Q.offer(cur.rt);
            }
            L++;
        }
        return 0;
    }

    public static void main(String args[]) {
        Main tree=new Main();
        tree.root=new Node(1);
        tree.root.lt=new Node(2);
        tree.root.rt=new Node(3);
        tree.root.lt.lt=new Node(4);
        tree.root.lt.rt=new Node(5);
       System.out.println(tree.BFS(tree.root));
    }
}
```
