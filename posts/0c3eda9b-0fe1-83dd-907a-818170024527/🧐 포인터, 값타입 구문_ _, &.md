## 1&#46; <code>&#42;</code>

<a id="3d0eda9b0fe1807dae99db7f3ad2d708"></a>

```go
// 위치 A: 타입 선언
var p *Node   

// 위치 B: 표현식(값 사용)
v := *p
```

| 위치 | 코드 | 의미 |
| --- | --- | --- |
| A&#46; 타입 선언 | <code>&#42;Node</code> |   • <code>포인터 타입</code> 이라는 뜻<br>  • <code>p</code> 라는 변수의 타입을 정의 |
| B&#46; 표현식 | <code>&#42;p</code> |   • <code>역참조</code> 연산<br>  • p가 가리키는 곳의 값을 꺼내 |
