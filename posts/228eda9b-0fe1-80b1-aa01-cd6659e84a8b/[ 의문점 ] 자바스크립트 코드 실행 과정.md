<a id="228eda9b0fe1802e9b7bfed3477bb8c5"></a>

### 1&#46; <strong>호이스팅(Hoisting)</strong>

<a id="228eda9b0fe180979887deabcaba71c8"></a>

자<strong>바스크립트 인터프리터</strong>는 코드 실행 전에 <strong>변수 선언(var), 함수 선언(function)</strong> 등을 <strong>최상단으로 끌어올리는 동작</strong>을 수행합니다&#46;

<a id="228eda9b0fe180b9ab4ad403d8a438c3"></a>

이는 <strong>“스코프 내 선언들을 먼저 처리”</strong> 하는 동작이며, 이 과정을 <strong>Hoisting(끌어올림)</strong> 이라고 합니다&#46;

<a id="228eda9b0fe180ed8bffd190a76b01dd"></a>

```javascript
console.log(a); // undefined
var a = 10;
```

<a id="228eda9b0fe18049b83ddaf39983823d"></a>

위 코드는 내부적으로 아래처럼 동작한다&#46;

<a id="228eda9b0fe180bc97e6e6470c312f51"></a>

```javascript
var a;         // 선언이 먼저 올라감
console.log(a); // undefined
a = 10;   
```

<a id="228eda9b0fe1806a985cf15b13a7f4db"></a>

### 2&#46; <strong>실행 컨텍스트(Execution Context) 생성</strong>

<a id="228eda9b0fe18074ad68f672347bcba5"></a>

자바스크립트 엔진은 코드를 실행할 때 <strong>“실행 컨텍스트”</strong>를 생성하고, <strong>Call Stack</strong>에 쌓아 올리며 위에서 아래로 코드를 <strong>순차적으로 실행한다&#46;</strong>

1. <strong><code>Global Execution Context</code></strong>
    - 자바스크립트 프로그램이 시작되면 가장 먼저 생성되는 컨텍스트

1. <strong><code>Function Execution Context</code></strong>
    - 함수가 호출될 때마다 생성

1. <strong><code>Eval Execution Context</code></strong>
    -  eval()이 실행될 때 생성, 사용이 권장되지 않음

<a id="228eda9b0fe180ceb122c83c89789e7b"></a>

### <strong>3&#46; 자바스크립트 코드 실행 시 내부 동작 순서</strong>

<a id="228eda9b0fe18086badff3f00e396e1f"></a>

```javascript
[Global Execution Context 생성]
↓
[Hoisting 수행]
↓
[코드 한 줄씩 순차적으로 실행]
↓
[함수 호출 시 새로운 Execution Context 생성 → Call Stack에 push]
↓
[함수 종료 시 pop]
↓
[프로그램 종료]
```

<a id="228eda9b0fe180e6890cd7aced0d8d9a"></a>

### 4&#46; 용어 정리

| <strong>일반 표현</strong> | <strong>전문 용어</strong> | <strong>설명</strong> |
| --- | --- | --- |
| 위에서 아래로 실행 | <strong>Sequential Execution</strong> | 명령어를 작성된 순서대로 실행 |
| 변수/함수 선언이 끌어올려짐 | <strong>Hoisting</strong> | 스코프 내 선언을 코드 위로 끌어올림 |
| 코드 실행을 담당하는 구조 | <strong>Execution Context</strong> | 코드 실행 정보를 담은 객체 |
| 실행 순서 추적 구조 | <strong>Call Stack</strong> | 어떤 코드(함수 등)가 실행되고 있는지 추적 |
