- jquery 문법
    - 선택자 = <code>document&#46;getElement&#46;&#46;&#46;()</code>
        - <strong>ID 선택</strong>&#58; <code>&#36;(&#39;&#35;id&#39;)</code>

        - <strong>클래스 선택</strong>&#58; <code>&#36;(&#39;&#46;class&#39;)</code>

        - <strong>태그 선택</strong>&#58; <code>&#36;(&#39;tag&#39;)</code>

        - <strong>속성 선택</strong>&#58; <code>&#36;(&#39;&#91;attribute=&#34;value&#34;&#93;&#39;)</code>

    - 메서드 
        - &#46;text()&#58; 요소의 텍스트를 가져오거나 설정합니다&#46;

        - &#46;html()&#58; 요소의 HTML 내용을 가져오거나 설정합니다&#46;

        - &#46;css()&#58; CSS 속성을 가져오거나 설정합니다&#46;

        - &#46;attr()&#58; 속성을 가져오거나 설정합니다&#46;

        - &#46;addClass()<strong>, </strong>&#46;removeClass()&#58; 클래스를 추가하거나 제거합니다&#46;

        - &#46;show()<strong>, </strong>&#46;hide()&#58; 요소를 보이게 하거나 숨깁니다&#46;
            - toggle()

        - &#46;fadeIn()<strong>, </strong>&#46;fadeOut()&#58; 서서히 나타나거나 사라지게 합니다&#46;

    - 이벤트 처리

        ```css
        $('#button-id').click(function() {
        		// 버튼 클릭 시 실행할 코드
        });
        ```

    - AJAX
        <a id="b0e3aaefbeae4419b7fef75b679d20e1"></a>

        ```css
        $.ajax({
            url: 'https://api.example.com/data',
            type: 'GET',
            success: function(data) {
                console.log(data);
            },
            error: function(error) {
                console.error('에러 발생:', error);
            }
        });
        ```
