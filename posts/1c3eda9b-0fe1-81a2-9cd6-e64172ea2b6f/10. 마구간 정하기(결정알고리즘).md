# 문제

<a id="1c3eda9b0fe181bd9ee7c6d9f061d850"></a>

## <strong>10&#46; 마구간 정하기(결정알고리즘)</strong>

---

<a id="1c3eda9b0fe1815cbe58df9e07f7fc2c"></a>

### 설명

<a id="1c3eda9b0fe1817e9ecade3c4252d7af"></a>

N개의 마구간이 수직선상에 있습니다&#46; 각 마구간은 x1, x2, x3, &#46;&#46;&#46;&#46;&#46;&#46;, xN의 좌표를 가지며, 마구간간에 좌표가 중복되는 일은 없습니다&#46;

<a id="1c3eda9b0fe181ac8c4df507d3aba58c"></a>

현수는 C마리의 말을 가지고 있는데, 이 말들은 서로 가까이 있는 것을 좋아하지 않습니다&#46; 각 마구간에는 한 마리의 말만 넣을 수 있고,

<a id="1c3eda9b0fe1819b85a6c6ab50676656"></a>

가장 가까운 두 말의 거리가 최대가 되게 말을 마구간에 배치하고 싶습니다&#46;

<a id="1c3eda9b0fe1818ea63ef79f5171581b"></a>

C마리의 말을 N개의 마구간에 배치했을 때 가장 가까운 두 말의 거리가 최대가 되는 그 최대값을 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe18123b7a4c1d5404a3417"></a>

### 입력

<a id="1c3eda9b0fe1813995c8e73ac3c64564"></a>

첫 줄에 자연수 N(3&#60;=N&#60;=200,000)과 C(2&#60;=C&#60;=N)이 공백을 사이에 두고 주어집니다&#46;

<a id="1c3eda9b0fe18100ac44d05e816712ef"></a>

둘째 줄에 마구간의 좌표 xi(0&#60;=xi&#60;=1,000,000,000)가 차례로 주어집니다&#46;

<a id="1c3eda9b0fe181faba96f593c7ec229f"></a>

### 출력

<a id="1c3eda9b0fe181e39715c71007113675"></a>

첫 줄에 가장 가까운 두 말의 최대 거리를 출력하세요&#46;

---

<a id="1c3eda9b0fe181d88877c766000e2540"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1818ca212eea1bcc707af"></a>

```plaintext
5 3
1 2 8 4 9

```

3

# 풀이

<a id="1c3eda9b0fe181059245ea733e340a90"></a>

## 풀이1) <code>강의풀이</code>

<a id="1c3eda9b0fe18111a5e5c779fc15059a"></a>

```java
import java.util.*;

public class Main {
    public int count(int[] arr, int dist){
        int cnt=1;
        int ep=arr[0];
        for(int i=1; i<arr.length; i++){
            if(arr[i]-ep>=dist){
                cnt++;
                ep=arr[i];
            }
        }
        return cnt;
    }
    public int solution(int n, int t, int[] arr){
        int answer=0;
        Arrays.sort(arr);
        int lt=1;
        int rt=arr[n-1];
        while(lt<=rt){
            int mid=(lt+rt)/2;
            if(count(arr, mid)>=t){
                answer=mid;
                lt=mid+1;
            }
            else rt=mid-1;
        }
        return answer;
    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int t = sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        System.out.println(T.solution(n, t, arr));
    }
}
```
