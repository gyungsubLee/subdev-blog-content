<a id="2a1eda9b0fe180ffb3c7f6b7bb306cc7"></a>

```bash
python-tools/
├── main.py              # 검색 로직 (SearchManager 클래스)
```

## API 키 발급 및 설정

<a id="2a1eda9b0fe180f68169c3b34247cb96"></a>

### 네이버 API 키 발급

1. <strong>네이버 개발자 센터 접속</strong>
    - URL&#58; <code>https&#58;//developers&#46;naver&#46;com/apps/&#35;/register</code><br>

1. <strong>애플리케이션 등록</strong>
    - 애플리케이션 이름 입력 (예&#58; &#34;통합검색API&#34;)

    - 사용 API 선택&#58; <strong>검색</strong> 체크<br>

1. <strong>검색 API 활성화</strong>
    - 블로그 검색 API 활성화

    - 뉴스 검색 API 활성화<br>

1. <strong>인증 정보 확인</strong>
    - Client ID 복사

- Client Secret 복사

<a id="2a1eda9b0fe180c28573e0be67f8d7db"></a>

### 구글 Custom Search API 키 발급

<details>
<summary> Google Cloud Console에서 API 키 생성</summary>

1.  <strong>Google Cloud Console 접속</strong>
    - URL&#58; <code>https&#58;//console&#46;cloud&#46;google&#46;com/</code><br>

1.  <strong>프로젝트 생성</strong><br>   &#45; &#34;프로젝트 선택&#34; → &#34;새 프로젝트&#34;<br>   &#45; 프로젝트 이름 입력 (예&#58; &#34;search&#45;api&#45;project&#34;)<br>

1. <strong>Custom Search API 활성화</strong><br>   &#45; &#34;API 및 서비스&#34; → &#34;라이브러리&#34;<br>   &#45; &#34;Custom Search API&#34; 검색 및 활성화<br>

1. <strong>API 키 생성</strong><br>   &#45; &#34;사용자 인증 정보&#34; → &#34;사용자 인증 정보 만들기&#34; → &#34;API 키&#34;<br>   &#45; 생성된 API 키 복사<br>

</details>

<details>
<summary>Programmable Search Engine 생성</summary>

1.  <strong>Programmable Search Engine 접속</strong><br>   &#45; URL&#58; https&#58;//programmablesearchengine&#46;google&#46;com/<br>

1. <strong>새 검색엔진 생성</strong><br>   &#45; &#34;새 검색엔진 만들기&#34; 클릭<br>   &#45; 검색할 사이트&#58; &#34;전체 웹 검색&#34; 선택<br>   &#45; 검색엔진 이름 입력 (예&#58; &#34;통합검색엔진&#34;)<br>

1. <strong>검색엔진 ID 복사</strong><br>   &#45; 생성 완료 후 &#34;검색엔진 ID&#34; (cx 값) 복사<br>

</details>

##  API 사용법

<a id="2a1eda9b0fe180789cb0c2d98fc96a8a"></a>

### 인증 방식

> ✏️ 
> 
> <a id="2a1eda9b0fe1800eab27da65bd599139"></a>
> 
> 모든 검색 API는 <strong>헤더 인증</strong>이 필요합니다&#58;
> 
> - <strong>API 키 변경</strong>&#58; <code>app&#46;py</code> 파일의 35번째 줄에서 <code>API&#95;KEY</code> 값을 변경할 수 있습니다&#46;
> 
> ---
> 
> <details>
> <summary>&#91; 코드 &#93; app&#46;py</summary>
> 
> <a id="2a1eda9b0fe180db8058ed7c28c15f43"></a>
> 
> ```bash
> # FastAPI를 사용한 통합 검색 API 서버
> # n8n의 HTTP Request 노드에서 사용할 수 있는 REST API 제공
> 
> # 필요한 라이브러리들을 가져오기 (import)
> from fastapi import FastAPI, HTTPException, Depends, Header  # FastAPI 웹 프레임워크와 HTTP 예외 처리, 의존성 주입, 헤더 처리
> from fastapi.middleware.cors import CORSMiddleware  # CORS(다른 도메인에서 접근) 허용
> from pydantic import BaseModel  # 데이터 검증을 위한 모델 정의
> from typing import Optional, List, Annotated  # 타입 힌트용 (선택적 매개변수, 리스트 타입, 어노테이션)
> import uvicorn  # FastAPI 서버 실행용
> 
> # 우리가 만든 검색 관리자 클래스 가져오기
> from main import SearchManager
> 
> # FastAPI 앱 인스턴스 생성
> # title, description, version은 API 문서에 표시되는 정보
> app = FastAPI(
>     title="통합 검색 API",
>     description="네이버 블로그, 네이버 뉴스, 구글 검색을 통합해서 수행하는 API",
>     version="1.0.0"
> )
> 
> # CORS 설정 - 다른 도메인(n8n 등)에서 이 API에 접근할 수 있도록 허용
> app.add_middleware(
>     CORSMiddleware,
>     allow_origins=["*"],  # 모든 도메인에서 접근 허용 (보안상 필요에 따라 제한 가능)
