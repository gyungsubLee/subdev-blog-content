---

<a id="1c3eda9b0fe181afac26e1bd5f85b787"></a>

### 설명

<a id="1c3eda9b0fe181d68be0d8ddae11cbc7"></a>

1부터 N까지 번호가 적힌 구슬이 있습니다&#46; 이 중 중복을 허락하여 M번을 뽑아 일렬로 나열하는 방법을 모두 출력시오&#46;

<a id="1c3eda9b0fe1811f8219e320378fb52a"></a>

### 휴리스틱)   <code>내 풀이</code> 불필요한 로직 제거

<details>
<summary><strong>1) 백트래킹(</strong><strong><code>ch&#91;L&#93;=0;</code></strong><strong>) 은 불필요한 로직이다&#46;</strong></summary>

<a id="1c3eda9b0fe181d88012e1758d261b63"></a>

이전 문제 풀이와 같게 <code>ch(int&#91;&#93;)</code>를 통해 원소를 <u>출력해야하는 값을 저장,/  백트래킹 후 초기화 </u><u><code>ch&#91;L&#93;=0;</code></u> 를 하는 것으로 로직을 작성하였다&#46; 

<a id="1c3eda9b0fe18161876bc2af5c7f3196"></a>

그러나 초기화가 아닌 <strong>값을 덮어쓰면</strong>은 해당 로직은(<u><code>ch&#91;L&#93;=0;</code></u><u>)은 불필요하다&#46;</u>

</details>

<details>
<summary><strong>2) 이전 </strong><strong><code>ch 배열</code></strong><strong> 설계부터 잘못했다&#46; </strong></summary>

<a id="1c3eda9b0fe18160beb2d3fc96b22559"></a>

<a id="1c3eda9b0fe181d9b448d5a9a7840b0e"></a>

그러나 저장과 체크를 같이하는 배열로 ch배열을 설계하였다&#46;<br>

</details>

## 풀이1) <code>내풀이</code> DFS, 메모제이션, 백트래킹

<a id="1c3eda9b0fe18128a022e4e11083aa5c"></a>

<del>이게 2시간 걸리네…</del>  → 이것만 이해해도 DFS는 다 이해했다&#46; 

<a id="1c3eda9b0fe181d79cd6c9d9e15061f0"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int[] ch;
    static int m, n;
    public void DFS(int L){
        if(L==n) {
            for(int i=0; i<n; i++){
                System.out.print(ch[i]+" ");
            }
            System.out.println();
        }
        else {
            for(int i=1; i<=m; i++){
                ch[L]=i;
                DFS(L+1);
                ch[L]=0;
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        m=sc.nextInt();
        n=sc.nextInt();
        ch=new int[n];
        T.DFS(0);
    }
}
```

## 풀이3) <code>2차풀이</code>  

<a id="1c3eda9b0fe18141b66fe8e88840b4e1"></a>

### 1) 오류) ch 배열로 결과값 출력하기 

<details>
<summary>출력값 </summary>

<a id="1c3eda9b0fe181b8a0fbe4453f260df6"></a>

```java
1 
2 
3 
1 2 
2 
3 
1 3 
2 3 
3
```

</details>

<a id="1c3eda9b0fe18130b5a0e64ff3730f25"></a>

해당 문제는 중복을 허용하기 때문에, 값이 중복되는 경우 1개의 경우만 check 되어 출력 오류 발생

<a id="1c3eda9b0fe18130becbc5db0c159c9f"></a>

또한, check로 값을 출력하는 경우 순서가 구분되지 않는 오류 발생

<a id="1c3eda9b0fe18191ae3bd3c14b64098c"></a>

```java
import java.util.*;

public class Main {
     static int n, m;
     static int[] ch;
    public void DFS( int L){
        if(L==m){
            String answer="";
            for(int i=1; i<=n; i++){
                if(ch[i]==1) answer += i+" ";
            }
            System.out.println(answer);
        }
        else {
            for(int i=1; i<=n; i++){
                ch[i]=1;
                DFS(L+1);
                ch[i]=0;
            }
        }

    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc = new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        ch= new int[n+1];
        T.DFS(0);
    }
}
```

### 2) 해결) 인자 값으로 추가

<a id="1c3eda9b0fe18121a298dc44d030fabe"></a>

ch 배열을 제거하고 인자 값에 answer(String)을 추가하여 재귀로 구함&#46;

<a id="1c3eda9b0fe1813d86cbe28e48826bf0"></a>

```javascript
import java.util.*;

public class Main {
     static int n, m;
    public void DFS( int L, String answer){
        if(L==m){
            System.out.println(answer);
        }
        else {
            for(int i=1; i<=n; i++){
                DFS(L+1, answer+i+" ");
            }
        }

    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc = new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        T.DFS(0, "");
    }
} 
```
