# 문제

<a id="1c3eda9b0fe18137a327de9ae45e5bfc"></a>

## 6&#46; 순열 구하기

<a id="1c3eda9b0fe181c19607ed8c291c7467"></a>

### 설명

<a id="1c3eda9b0fe1810d8233ed565c3199d8"></a>

10이하의 M개의 자연수가 주어지면 이 중 N개를 뽑아 일렬로 나열하는 방법을 모두 출력합니다&#46; 

<a id="1c3eda9b0fe1813cae9ee638f6f028dd"></a>

### 입력

<a id="1c3eda9b0fe181398d96ce020b3e45e2"></a>

첫번째 줄에 자연수 N(3≤N≤10)과 M(2≤M≤N)이 주어집니다&#46;

<a id="1c3eda9b0fe1819298e0c0cc37420d16"></a>

두번째 줄에 N개의 자연수가 오름차순으로 주어집니다&#46;

---

<a id="1c3eda9b0fe18138871cfb2aed41f25b"></a>

### 입력 예제1

<a id="1c3eda9b0fe1811180c0eeb4a1d8097a"></a>

```java
3 2
3 6 9
```

<a id="1c3eda9b0fe18166b295ee95e15e7dbc"></a>

<a id="1c3eda9b0fe181ceaac3c5cfcbe04bd0"></a>

9 6

import java.util.*;

public class Main {
    static int n, m;
    static int[] numTypes, pm, ch;
    public void DFS(int L) {
        if(L==m){
            for(int x : pm) System.out.print(x+" ");
            System.out.println();
        }
        else {
            for(int i=0; i<n; i++){
                if(ch[i]==0){
                    ch[i]=1;
                    pm[L]=numTypes[i];
                    DFS(L+1);
                    ch[i]=0;
                }
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        numTypes=new int[n];
        for(int i=0; i<n; i++){
            numTypes[i]=sc.nextInt();
        }
        ch=new int[n];
        pm=new int[m];
        T.DFS(0);
    }
}
