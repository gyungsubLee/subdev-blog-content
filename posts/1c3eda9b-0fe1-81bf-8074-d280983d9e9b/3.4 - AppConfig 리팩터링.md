### AppConfig 리펙토링

> 기존의 AppConfig는 <strong>중복 코드</strong>도 있고,<strong> 역할에 따른 구현 코드가 잘 보이지 않</strong>는다&#46; <br>→ 중복 제거, 역할에 따른 구현이 잘 보이도록 리펙토링 

> • 중복 코드(<code>new MemoryMemberRepository()</code>)  → 함수로 추출<strong>(external method)</strong><br>→ 다른 구현체로 변경 시, <code>MemberRepository()</code> 내부 구현체만 변경하면 됨<br><br>• 레이아웃 분리(<code>discountPolicy()</code>) <br> → 구현 클래스가 한눈에 들어옴<br> → 애플리케이션 전체 구성을 빠르게 파악 가능

<a id="1c3eda9b0fe18120bf79cce4b35a1bd8"></a>

```java
package hello.core;

import hello.core.discount.DiscountPolicy;
import hello.core.discount.FixDiscountPolicy;
import hello.core.service.MemberService;
import hello.core.service.MemberServiceImpl;
import hello.core.order.OrderService;
import hello.core.order.OrderServiceImpl;
import hello.core.repository.MemoryMemberRepository;

public class AppConfig {

    public MemberService memberService() {
        return new MemberServiceImpl(MemberRepository());
    }

  
    public OrderService orderService() {
        return new OrderServiceImpl(MemberRepository(), discountPolicy());
    }

	   public static MemberRepository MemberRepository() {
        return new MemoryMemberRepository();
    }

    public DiscountPolicy discountPolicy() {
        return new FixDiscountPolicy();
    }
}
```
