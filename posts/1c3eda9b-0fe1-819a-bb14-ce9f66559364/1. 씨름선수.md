# 문제

<a id="1c3eda9b0fe18177b425f23df8e40ff3"></a>

## <strong>1&#46; 씨름 선수</strong>

<a id="1c3eda9b0fe18196baf7e939e194b636"></a>

### 설명

<a id="1c3eda9b0fe1816e995ecbb7ba565af3"></a>

현수는 씨름 감독입니다&#46; 현수는 씨름 선수를 선발공고를 냈고, N명의 지원자가 지원을 했습니다&#46;

<a id="1c3eda9b0fe181db9890e236dd7cf214"></a>

현수는 각 지원자의 키와 몸무게 정보를 알고 있습니다&#46;

<a id="1c3eda9b0fe1811b923bf1213c8712dc"></a>

현수는 씨름 선수 선발 원칙을 다음과 같이 정했습니다&#46;

<a id="1c3eda9b0fe181b2991cc6f0c57c130a"></a>

“A라는 지원자를 다른 모든 지원자와 일대일 비교해서 키와 몸무게 모두 A지원자 보다 높은(크고, 무겁다) 지원자가

<a id="1c3eda9b0fe181019169e7b5fae32a5d"></a>

존재하면 A지원자는 탈락하고, 그렇지 않으면 선발된다&#46;”

<a id="1c3eda9b0fe181bda9a9f53677c02c72"></a>

N명의 지원자가 주어지면 위의 선발원칙으로 최대 몇 명의 선수를 선발할 수 있는지 알아내는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181f5a080ce5c45aacaa4"></a>

### 입력

<a id="1c3eda9b0fe181e388b4c8da22edba6b"></a>

첫째 줄에 지원자의 수 N(5&#60;=N&#60;=30,000)이 주어집니다&#46;

<a id="1c3eda9b0fe181adbe98c7d26b8bab20"></a>

두 번째 줄부터 N명의 흰돌 능력치와 검은돌 능력치 정보가 차례로 주어집니다&#46;

<a id="1c3eda9b0fe18175b1ead5b73c6739cd"></a>

각 선수의 흰돌능력치가 모두 다르고, 검은돌 능력치도 모두 다릅니다&#46; 능력치 값은 1,000,000이하의 자연수입니다&#46;

<a id="1c3eda9b0fe18155b07ed7fc278453b6"></a>

### 출력

<a id="1c3eda9b0fe18199910ede2946ad28cf"></a>

첫째 줄에 바둑 선수로 뽑히는 최대 인원을 출력하세요&#46;

---

<a id="1c3eda9b0fe181d1ab7ec86032b8fdd2"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181349339d40f7e38129f"></a>

```plaintext
5
172 67
183 65
180 70
170 72
181 60

```

<a id="1c3eda9b0fe181dba3f1d6989545b3be"></a>

### 예시 출력 1

<a id="1c3eda9b0fe18171983cdf67e3126558"></a>

```plaintext
3
```

---

<a id="1c3eda9b0fe181028600d9514e58bafa"></a>

### 힌트

> 출력설명<br>(183, 65), (180, 70), (170, 72) 가 선발됩니다&#46; (181, 60)은 (183, 65)보다 키와 몸무게 모두 낮기 때문에 탈락이고, (172, 67)은 (180, 70) 때문에 탈락입니다&#46;

## 풀이1) <code>내풀이</code>

<a id="1c3eda9b0fe1815899f9d69bbe6fd0bc"></a>

```java
import java.util.*;

class Person{
    int height, weight;
    Person(int height, int weight){
        this.height=height;
        this.weight=weight;
    }
}

public class Main {
    static int n;
    static Person[] pList;
    public int solution(){
        int answer=n;
        for(Person a : pList){
            for(Person b : pList){
                if(a==b) continue;
                if(a.height<b.height && a.weight<b.weight){
                    answer--;
                    break;
                }
            }
        }
        return answer;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        pList=new Person[n];
        for(int i=0; i<n; i++){
            int height=sc.nextInt();
            int weight=sc.nextInt();
            pList[i]=new Person(height, weight);
        }
        System.out.println(T.solution());
    }
}
```

## 풀이2) <code>강의풀이</code>   인터페이스, 오버라이드

<a id="1c3eda9b0fe18156a7b9ca370d89999b"></a>

좌표정렬 → <strong>인터페이스, 오버라이드</strong>

<a id="1c3eda9b0fe181b7991efdc4ad98c32a"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

class Body implements Comparable<Body>{
    public int h, w;
    Body(int h, int w){
        this.h=h;
        this.w=w;
    }
    @Override
    public int compareTo(Body o){
        return o.h-this.h;
    }
}

public class Main {
    public int solution(int n, ArrayList<Body> arr){
        int cnt=0;
        Collections.sort(arr);
        int max=Integer.MIN_VALUE;
        for(Body ob : arr){
            if(ob.w>max){
                max=ob.w;
                cnt++;
            }
        }
        return cnt;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        ArrayList<Body> arr=new ArrayList<>();
        for(int i=0; i<n; i++){
            int height=sc.nextInt();
            int weight=sc.nextInt();
            arr.add(new Body(height, weight));
        }
        System.out.println(T.solution(n, arr));
    }
}
```
