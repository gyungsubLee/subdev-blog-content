# 문제

<a id="1c3eda9b0fe181939e25cd6a49c1ce47"></a>

## 1&#46; 재귀함수

---

<a id="1c3eda9b0fe18180bbb1dc3ec6fa1733"></a>

### 내용

<a id="1c3eda9b0fe181a39305f919c1c6a919"></a>

자연수 N이 입력되면 재귀함수를 이용하여 1부터 N까지 출력하는 프로그램을 작성하시요&#46;

<a id="1c3eda9b0fe1814aa0c9e6a4a02a9b5e"></a>

### 입력 설명

<a id="1c3eda9b0fe1811ea57cda9b4d77b7bb"></a>

첫 번째 줄은 정수 N((3≤N≤10)이 입력된다&#46;

<a id="1c3eda9b0fe181798d52e9f63ed4b68f"></a>

### 출력 설명

<a id="1c3eda9b0fe181079b5ee166abe59ab2"></a>

첫째 줄에 출력한다&#46;

---

<a id="1c3eda9b0fe1816d82e9dc33f5e91e85"></a>

### 입력예제 1 

<a id="1c3eda9b0fe18139ac39c4bb69831ddc"></a>

```plaintext
3
```

<a id="1c3eda9b0fe1812ab41cf582a71b50d5"></a>

### 출력예제 1

<a id="1c3eda9b0fe181a79eb0fe48dbaeb778"></a>

```plaintext
1 2 3
```

# 풀이

<a id="1c3eda9b0fe181e98c88fb3a050a889a"></a>

## 풀이1) 

<a id="1c3eda9b0fe1812392aae9d9e8e136cc"></a>

```java
import java.util.*;

public class Main {
    public void DFS(int n){
        if(n>1) DFS(n-1);
        System.out.print(n+" ");

    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        T.DFS(n);
    }
}
```

## 풀이2) 

<a id="1c3eda9b0fe181a58084c26189fdfa3e"></a>

```java
import java.util.*;

public class Main {
    public void DFS(int n){
        if(n==0) return;
        else {
            DFS(n-1);
            System.out.print(n+" ");
        }
    }
    public static void main (String[] args) {
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        T.DFS(n);
    }
}
```
