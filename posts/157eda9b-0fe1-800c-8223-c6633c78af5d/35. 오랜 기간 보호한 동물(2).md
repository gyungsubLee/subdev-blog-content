<summary>🧐 <code>TIMESTAMPDIFF()</code></summary>

- TIMESTAMPDIFF()는 <code>MySQL</code>에서 <u>날짜와 시간 사이의 차이를 계산</u>할 때 사용하는 함수이다&#46;

- DATETIME, DATE, 또는 TIMESTAMP 값 간의 차이를 특정 단위로 반환한다&#46;

<a id="157eda9b0fe1806c9089c98859871b4c"></a>

```sql
TIMESTAMPDIFF(unit, datetime_expr1, datetime_expr2)
```

- <code>unit</code>&#58; 차이를 반환할 단위입니다&#46; 예를 들어, 초, 분, 시간, 일, 월, 연도 등이 가능

- <code>datetime&#95;expr1</code>&#58; 기준이 되는 첫 번째 날짜 또는 시간 값

- <code>datetime&#95;expr2</code>&#58; 비교할 두 번째 날짜 또는 시간 값

- 결과
    - <code>datetime&#95;expr2 &#45; datetime&#95;expr1</code>에 해당하는 차이를<u> unit 단위로 반환</u>한다&#46; 

- unit 옵션
    | 단위(Unit) | 설명 |
    | --- | --- |
    | SECOND | 초 단위로 차이를 계산 |
    | MINUTE | 분 단위로 차이를 계산 |
    | HOUR | 시간 단위로 차이를 계산 |
    | DAY | 일 단위로 차이를 계산 |
    | WEEK | 주 단위로 차이를 계산 |
    | MONTH | 월  단위로 차이를 계산 |
    | YEAR | 연 단위로 차이를 계산 |

</details>

## 문제

<a id="157eda9b0fe180b29de2cad1caa59c21"></a>

### <strong>문제 설명</strong>

<a id="157eda9b0fe1800f9cf6e7dbc7921518"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="157eda9b0fe180068585ebdfad34af8e"></a>

<code>ANIMAL&#95;OUTS</code> 테이블은 동물 보호소에서 입양 보낸 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;OUTS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;OUTCOME</code>는 각각 동물의 아이디, 생물 종, 입양일, 이름, 성별 및 중성화 여부를 나타냅니다&#46; <code>ANIMAL&#95;OUTS</code> 테이블의 <code>ANIMAL&#95;ID</code>는 <code>ANIMAL&#95;INS</code>의 <code>ANIMAL&#95;ID</code>의 외래 키입니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;OUTCOME | VARCHAR(N) | FALSE |

<a id="157eda9b0fe1809da8f2c6076f4a637e"></a>

입양을 간 동물 중, 보호 기간이 가장 길었던 동물 두 마리의 아이디와 이름을 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 보호 기간이 긴 순으로 조회해야 합니다&#46;

<a id="157eda9b0fe18070ac54d222344ea713"></a>

## 풀이

> ✏️ 
> 
> <a id="1d6eda9b0fe1808f9665f0700f324407"></a>
> 
> 조건
> 
> - 보호 기간이 가장 길었던 동물 두 마리의 아이디와 이름을 조회
> 
> - 결과는 보호 기간이 긴 순으로 조회

<a id="157eda9b0fe1804daa45c5e220b4530b"></a>

```sql
SELECT I.ANIMAL_ID, I.NAME
FROM ANIMAL_OUTS O
JOIN ANIMAL_INS I ON I.ANIMAL_ID = O.ANIMAL_ID
ORDER BY O.DATETIME -I.DATETIME DESC
LIMIT 2
```

<a id="1d6eda9b0fe18026b1d2fec079ed7c00"></a>

```sql
SELECT
    ins.ANIMAL_ID,
    ins.NAME
FROM ANIMAL_INS ins
JOIN ANIMAL_OUTS outs ON ins.ANIMAL_ID = outs.ANIMAL_ID
ORDER BY TIMESTAMPDIFF(SECOND, ins.DATETIME, outs.DATETIME) DESC
LIMIT 2;
```

- <code>TIMESTAMPDIFF(SECOND, ins&#46;DATETIME, outs&#46;DATETIME)</code>
    - <strong>초 단위 보호 기간</strong>을 계산

    - 초 단위로 하면 정렬이 더 정확해 진다&#46;
        -  DATEDIFF()도 가능하지만 일 단위라서 정확도가 떨어질 수 있다&#46;<br><br><br><br><br>
