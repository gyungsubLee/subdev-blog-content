# 시스템 설계

---

> 📖 
> 
> <a id="32eeda9b0fe18177a0c7e6486dedca36"></a>
> 
> 본 실습은 <strong><u>대규모 트래픽 환경에서 안정적으로 동작하는 프로모션 시스템을 구현</u></strong>하는 것을 목표한다&#46;
> 
> - 마이크로서비스 아키텍처를 기반으로 하여 확장성과 유연성을 확보하고, <br>다양한 동시성 제어 방식을 통해 성능을 최적화한다&#46;

<a id="339eda9b0fe180f5af12cd0fddeb62af"></a>

## 시스템 아키텍처

---

![  • 아키텍처](c85f3783975b451e.webp)

<a id="339eda9b0fe1807ea8b7cfdd65afdf76"></a>

### 핵심 기능

<details>
<summary>1&#46; 쿠폰 발급 시스템</summary>

- 동시성 제어를 통한 수량 관리

- 다양한 발급 전략 구현
    - 선착순, 지정 대상

</details>

<details>
<summary>2&#46; 사용자 관리</summary>

- 회원 가입 / 로그인

- 권한 관리

</details>

<details>
<summary>3&#46; 주문 처리</summary>

- 쿠폰 적용 주문

- 주문 상태 관리

- 결제 연동

</details>

<details>
<summary>4&#46; 상품 관리</summary>

- 상품 등록/수정

- 재고 관리

- 상품별 쿠폰 정책

</details>

<details>
<summary>5&#46; 포인트 시스템</summary>

- 포인트 적립/사용

- 포인트 내역 관리

</details>

<details>
<summary>6&#46; 타임 세일 </summary>

- 특정 시간대 할인

- 수량 제한 판매

- 실시간 재고 관리

</details>

<a id="339eda9b0fe180ecb23fd936806d15d6"></a>

### 핵심 컴포넌트 

<details>
<summary>1&#46; API Gateway (Spring Cloud Gateway)</summary>

- 인증/인가 처리

- 요청 라우팅

- 로드밸런싱

- 속도 제한

</details>

<details>
<summary>2&#46; Service Discovery (Eureka)</summary>

- 서비스 등록 / 발견

- 상태 모니터링

- 로드벨런싱 지원

</details>

<details>
<summary>3&#46; 마이크로서비스</summary>

- User Service&#58; 사용자 관리

- Coupon Service&#58; 쿠폰 발급/관리

- Order Service&#58; 주문 처리

- Point Service&#58; 포인트 관리

- Product Service&#58; 상품 관리

- Time Sale Service&#58; 타입세일 관리

</details>

## 기술 스택 

---

<a id="339eda9b0fe180258c23da6883cb68c6"></a>

### 공통 기술 스택

- Java 17

- Spring Boot 4&#46;x

- Spring Cloud

- Gradle

- JUnit 5

- H2(in&#45;memory DB) / MySQL 8&#46;ㅌ

- Redis 7&#46;x

- Docker

<a id="339eda9b0fe1805881f1c009e1380c71"></a>

### 컴포넌트 주요 기술

<details>
<summary>1&#46; API Gateway</summary>

- Spring Cloud Gateway

- Spring Security

- JWT

- Rate Limiter

</details>

<details>
<summary>2&#46; Service Discovery</summary>

- Spring Cloud Netflix Eureka

- Spring Cloud LoadBalancer

</details>

<details>
<summary>3&#46; 마이크로서비스 공통</summary>

- Spring Boot

- Spring Data JPA

- Spring Data Redis

- Sping Kafka

- Resilience4j

</details>

## 구현 전략

---

<a id="339eda9b0fe180cb80d3cec48a3e58c7"></a>

### 동시성 제어

<details>
<summary>분산 락</summary>

- Redisson을 활용한 분산 락 구현

- 쿠폰 발급, 재고 관리 등에 적용

- 데드락 방지를 위한 타임아웃 설정

</details>

<details>
<summary>대기열 시스템</summary>

- Redis를 활용한 대기열 구현

- 트래픽 부하 분산

- 공정한 처리 순서 보장

</details>

<a id="339eda9b0fe180d9bab8d348ceacf361"></a>

### 확장성

<details>
<summary>수평적 확장</summary>

- 서비스별 독립적인 확장

- 로드밸런서를 통한 부하 분산

- 컨테이너 기반 자동 스케일링

</details>

<details>
<summary>데이터 분산</summary>

- 서비스별 독립 데이터베이스

- 캐시 계층 활용

- 데이터 정합성 관리

</details>

<a id="339eda9b0fe180d7bd79fe8332f2e7de"></a>

### 장애 대응

<details>
<summary>서킷 브레이커</summary>

- Resilience4j를 활용한 장애 격리

- 폴백 메커니즘 구현

- 장애 전파 방지

</details>

<details>
<summary>모니터링</summary>

- Spring Boot Actuator

- 실시간 시스템 상태 모니터링

</details>

<a id="339eda9b0fe180688b6ef9f9ace0f6e9"></a>

### 성능 최적화

<details>
<summary>캐싱 전략</summary>

- Redis를 활용한 캐싱

- 캐시 정합성 관리

- 캐시 갱신 전략

</details>

<details>
<summary>비동기 처리</summary>

- 이벤트 기반 아키텍처

- Kafka를 활용한 메시지 큐

- 비동기 작업 처리

</details>
