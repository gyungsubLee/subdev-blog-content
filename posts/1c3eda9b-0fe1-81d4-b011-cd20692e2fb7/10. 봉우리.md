# 문제

<a id="1c3eda9b0fe1814388dcd733855c2f5d"></a>

## <strong>10&#46; 봉우리</strong>

---

<a id="1c3eda9b0fe18176ba68c783aec4c905"></a>

### 설명

<a id="1c3eda9b0fe18113be59ea24f115e8e2"></a>

지도 정보가 N&#42;N 격자판에 주어집니다&#46; 각 격자에는 그 지역의 높이가 쓰여있습니다&#46;

<a id="1c3eda9b0fe1812bb3cfc9bf30907127"></a>

각 격자판의 숫자 중 자신의 상하좌우 숫자보다 큰 숫자는 봉우리 지역입니다&#46; 봉우리 지역이 몇 개 있는 지 알아내는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe18164bccaf94e8ae4f9f7"></a>

격자의 가장자리는 0으로 초기화 되었다고 가정한다&#46;

<a id="1c3eda9b0fe18118a082fc6d173e80bc"></a>

만약 N=5 이고, 격자판의 숫자가 다음과 같다면 봉우리의 개수는 10개입니다&#46;

![](https://cote.inflearn.com/public/upload/d0a3fd4667.jpg)

---

<a id="1c3eda9b0fe18120b78cfdb25ff24f0a"></a>

### 입력

<a id="1c3eda9b0fe181668994df7e5e196f76"></a>

첫 줄에 자연수 N이 주어진다&#46;(2&#60;=N&#60;=50)

<a id="1c3eda9b0fe181bf844cc3e12c4b79a8"></a>

두 번째 줄부터 N줄에 걸쳐 각 줄에 N개의 자연수가 주어진다&#46; 각 자연수는 100을 넘지 않는다&#46;

<a id="1c3eda9b0fe181448b99e0772bb10840"></a>

### 출력

<a id="1c3eda9b0fe181c39cd2d9f5196064e6"></a>

봉우리의 개수를 출력하세요&#46;

---

## 풀이

<a id="1c3eda9b0fe181f0971bf1f5ee224ebd"></a>

### 풀이1)

- 첫 풀이 &#45; 오답

<a id="1c3eda9b0fe181d2b61de24faeb7766a"></a>

```java
import java.util.Scanner;

public class Main {
    public int solution(int n, int[][] arr) {
        int cnt = 0;
        for(int i=0; i<n+1; i++){
            for(int j=0; j<n+1; j++){
                if(arr[i][j]!=0) {
                    int t = arr[i][j];
                    if(arr[i-1][j]<t && arr[i+1][j]<t && arr[i][j-1]<t && arr[i][j+1]<t) cnt++;
                }
            }
        }
        return cnt;
    }
    public static void main (String[]args) {
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] arr = new int[n+1][n+1];
        for (int i = 1; i < n+1; i++) {
            for (int j = 1; j < n+1; j++) {
                arr[i][j] = sc.nextInt();
            }
        }
        System.out.println(m.solution(n, arr));
    }
}
```

### 강의 &#91;풀이 2&#93;)  디버깅 찍어보기

<a id="1c3eda9b0fe1810ebee2dc0fd566374c"></a>

```java
import java.util.*;
public class Main {
    int[] dx={-1, 0, 1, 0};
    int[] dy={0, 1, 0, -1};
    public int solution(int n, int[][] arr) {
        int cnt = 0;
        for (int i=0; i<n; i++) {
            for (int j=0; j<n; j++) {
                boolean flag = true;
                for (int k=0; k<4; k++) {
                    int nx = i + dx[k];
                    int ny = j + dy[k];
										// 조건도 앞에서 부터 참조한다. 따라서 범위를 앞에 조건에 써야 한다.  
										// 부호가 없는 경우 오답 케이스 발생함 ->  디버깅 찍어보기
                    if (nx >= 0 && nx < n && ny >= 0 && ny < n && arr[nx][ny] >= arr[i][j]) {
                        flag = false;
                        break;
                    }
                }
                if (flag) cnt++;
            }
        }
        return cnt;
    }
    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] input = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                input[i][j] = sc.nextInt();
            }
        }
        System.out.println(T.solution(n, input));
    }
}
```
