### SQL 문의 기본 구조

<a id="8823464743714bc7aa36e68f3439ca21"></a>

```sql
select # '데이터 조회' 의 명령어로 필수 구문
from   # '어디에서 데이터를 조회할까' 의 명령어로 필수 구문 
where  # 조건을 지정해주는 구문
```

<a id="39cc2997298141f1999056768f9c0ee0"></a>

### 조건을 지정하는 방법

- 비교연산자 &#58; <code>&#60;</code>, <code>&#62;</code>, <code>=</code>, <code>&#60;&#62;</code>

- 다양한 구문 &#58; <code>IN</code>, <code>BETWEEN</code>, <code>LIKE</code>

- 여러가지 조건의 적용 &#58; <code>AND</code>, <code>OR</code>, <code>NOT</code>
