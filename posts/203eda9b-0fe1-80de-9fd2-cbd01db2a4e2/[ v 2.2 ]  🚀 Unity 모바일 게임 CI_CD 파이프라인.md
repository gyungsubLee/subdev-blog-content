> EC2 &#43; Docker 기반 Jenkins, Nginx, Certbot, Unity CLI, Firebase App Distribution, Slack 알림 자동화

> ✅ 
> 
> <a id="203eda9b0fe1802c8b38f3e47cfca575"></a>
> 
> 실행 절차
> 
> 1. &#46;env 작성 (필요시)
> 
> 1. <a href="http://init-letsencrypt.sh/">init&#45;letsencrypt&#46;sh</a> 실행 → 인증서 발급
> 
> 1. docker&#45;compose up &#45;d
> 
> 1. Jenkins 접속 → 플러그인 설치 (GitHub, Slack)
> 
> 1. Jenkinsfile → GitHub Push → 자동 빌드 실행

> ☝🏻 
> 
> <a id="203eda9b0fe180bcb492e65401b94193"></a>
> 
> <strong>실무 기준 보완 사항</strong>
> 
> - Jenkins 8080 포트 외부 비공개, Nginx만 노출
> 
> - 인증서 자동 갱신 → certbot renew &#43; nginx reload
> 
> - Slack Webhook, Firebase CLI 인증은 Jenkins Credentials에 저장
> 
> - Unity 빌드는 GameCI 도커 이미지 활용 (빌드 속도, 확장성 향상)
> 
> - 빌드 결과물(APK) Jenkins 아티팩트로 저장
> 
> - 테스터 관리 자동화 (<a href="http://manage-testers.sh/">manage&#45;testers&#46;sh</a>)
> 
> - 에러 핸들링 및 상세 Slack 알림

<summary><strong>🧩 Jenkinsfile</strong></summary>

<a id="203eda9b0fe180c88c7ce0c31f21f56d"></a>

```groovy
pipeline {
    agent {
        docker {
            image 'unityci/editor:2022.3.12f1-android'
            args '-v /var/run/docker.sock:/var/run/docker.sock'
        }
    }
    environment {
        SLACK_CHANNEL = "#cicd"
        UNITY_PROJECT_PATH = "unity-project"
        BUILD_OUTPUT_PATH = "build/output.apk"
        FIREBASE_APP_ID = credentials('firebase_app_id')
        FIREBASE_TOKEN = credentials('firebase_token')
        SLACK_WEBHOOK = credentials('slack_webhook')
        TESTER_GROUP = "testers"
    }
    triggers {
        pollSCM('H/5 * * * *') // 또는 GitHub Webhook
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/your-org/unity-game-repo.git', branch: 'main'
            }
        }
        stage('Unity Build') {
            steps {
                sh "chmod +x ./scripts/build.sh"
                sh "./scripts/build.sh $UNITY_PROJECT_PATH"
                archiveArtifacts artifacts: 'build/output.apk', fingerprint: true
            }
        }
        stage('Distribute to Firebase') {
            steps {
                sh "chmod +x ./scripts/deploy.sh"
                sh "./scripts/deploy.sh $FIREBASE_APP_ID $BUILD_OUTPUT_PATH $FIREBASE_TOKEN $TESTER_GROUP"
                sh "chmod +x ./scripts/manage-testers.sh"
                sh "./scripts/manage-testers.sh $FIREBASE_APP_ID $FIREBASE_TOKEN $TESTER_GROUP"
            }
        }
    }
    post {
        success {
            sh "scripts/notify.sh success"
        }
        failure {
            sh "scripts/notify.sh failure"
        }
    }
}
```

<summary>build&#46;sh</summary>

<a id="203eda9b0fe180d88d6adfcce79f3936"></a>

```groovy
#!/bin/bash
UNITY_PROJECT_PATH=$1
BUILD_PATH="build/output.apk"
echo "🔨 Unity 프로젝트 빌드 시작: $UNITY_PROJECT_PATH"
/opt/unity/Editor/Unity \
  -batchmode \
  -nographics \
  -silent-crashes \
  -logFile /dev/stdout \
  -projectPath "$UNITY_PROJECT_PATH" \
  -executeMethod "BuildScript.BuildAndroid" \
  -buildTarget Android \
  -quit
if [ -f "$BUILD_PATH" ]; then
  echo "✅ Unity Build 완료: $BUILD_PATH"
else
  echo "❌ Unity Build 실패"
  exit 1
fi
```

```groovy
#!/bin/bash
FIREBASE_APP_ID=$1
APK_PATH=$2
TOKEN=$3
GROUP=$4
echo "🚀 Firebase에 배포 시작: $APK_PATH"
firebase appdistribution:distribute "$APK_PATH" \
  --app "$FIREBASE_APP_ID" \
  --token "$TOKEN" \
  --groups "$GROUP"
if [ $? -eq 0 ]; then
  echo "✅ Firebase 배포 성공"
else
  echo "❌ Firebase 배포 실패"
  exit 1
fi
```

```c#
using UnityEditor;
using UnityEngine;

public class BuildScript {
    public static void BuildAndroid() {
        string path = "build/output.apk";
        BuildPipeline.BuildPlayer(
            new[] { "Assets/Scenes/MainScene.unity" },
            path,
            BuildTarget.Android,
            BuildOptions.None
        );
        Debug.Log("✅ Android APK 생성 완료: " + path);
    }
}
```
