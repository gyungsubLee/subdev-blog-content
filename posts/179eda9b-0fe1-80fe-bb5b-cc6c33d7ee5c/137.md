## 문제

<a id="179eda9b0fe18059b78bc598fd6af450"></a>

Query the two cities in <strong>STATION</strong> with the shortest and longest <em>CITY</em> names, as well as their respective lengths (i&#46;e&#46;&#58; number of characters in the name)&#46; If there is more than one smallest or largest city, choose the one that comes first when ordered alphabetically&#46;

<a id="179eda9b0fe180f3972dc99121c72d20"></a>

The <strong>STATION</strong> table is described as follows&#58;

![](18d9a3a7dd65531f.webp)

<a id="179eda9b0fe18032aee5c0f9e4c0bc81"></a>

where <strong>LAT&#95;N</strong> is the northern latitude and <strong>LONG&#95;W</strong> is the western longitude&#46;

<a id="179eda9b0fe180048855d8e2c75edd96"></a>

<strong>Sample Input</strong>

<a id="179eda9b0fe1800a8616c30bec3a4752"></a>

For example, <strong>CITY</strong> has four entries&#58; <strong>DEF, ABC, PQRS</strong> and <strong>WXY</strong>&#46;

<a id="179eda9b0fe18076a0fbccaf48b7cc34"></a>

<strong>Sample Output</strong>

<a id="179eda9b0fe1808c9567e919b154822b"></a>

<code>ABC 3<br>PQRS 4</code>

<a id="179eda9b0fe18001b4ecd8ba8f7e5f86"></a>

<strong>Explanation</strong>

<a id="179eda9b0fe1801c9481fd9bbe2c9db2"></a>

When ordered alphabetically, the <strong>CITY</strong> names are listed as <strong>ABC, DEF, PQRS,</strong> and <strong>WXY</strong>, with lengths  and &#46; The longest name is <strong>PQRS</strong>, but there are  options for shortest named city&#46; Choose <strong>ABC</strong>, because it comes first alphabetically&#46;

<a id="179eda9b0fe180c3bcf7fc17d94b8e55"></a>

<strong>Note</strong>

<a id="179eda9b0fe180fbb66bde198418a611"></a>

You can write two separate queries to get the desired output&#46; It need not be a single query&#46;

<a id="ea14d1412bbf445eb30f30010cc6036c"></a>

## 풀이

<a id="179eda9b0fe180a98efac2aca2d79dda"></a>

```sql
(
    SELECT CITY, LENGTH(CITY) AS LENGTH
    FROM STATION
    ORDER BY LENGTH(CITY), CITY
    LIMIT 1
)
UNION ALL
(
    SELECT CITY, LENGTH(CITY) AS LENGTH
    FROM STATION
    ORDER BY LENGTH(CITY) DESC, CITY
    LIMIT 1
);
```
