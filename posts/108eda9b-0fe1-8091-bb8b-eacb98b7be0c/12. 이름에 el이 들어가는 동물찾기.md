## 문제

<a id="1d1eda9b0fe180568201c46c9a35e4ab"></a>

### <strong>문제 설명</strong>

<a id="1d1eda9b0fe180a5a821fbc576c0d8a7"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1d1eda9b0fe180c9b082ec1c641e3481"></a>

보호소에 돌아가신 할머니가 기르던 개를 찾는 사람이 찾아왔습니다&#46; 이 사람이 말하길 할머니가 기르던 개는 이름에 &#39;el&#39;이 들어간다고 합니다&#46; 동물 보호소에 들어온 동물 이름 중, 이름에 &#34;EL&#34;이 들어가는 개의 아이디와 이름을 조회하는 SQL문을 작성해주세요&#46; 이때 결과는 이름 순으로 조회해주세요&#46; 단, 이름의 대소문자는 구분하지 않습니다&#46;

<a id="1d1eda9b0fe18091a380d2c95cf0d51e"></a>

### 예시

<a id="1d1eda9b0fe18057bc6edacfdf53182e"></a>

예를 들어 <code>ANIMAL&#95;INS</code> 테이블이 다음과 같다면

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ANIMAL&#95;ID | ANIMAL&#95;TYPE | DATETIME | INTAKE&#95;CONDITION | NAME | SEX&#95;UPON&#95;INTAKE |
| A355753 | Dog | 2015&#45;09&#45;10 13&#58;14&#58;00 | Normal | Elijah | Neutered Male |
| A352872 | Dog | 2015&#45;07&#45;09 17&#58;51&#58;00 | Aged | Peanutbutter | Neutered Male |
| A353259 | Dog | 2016&#45;05&#45;08 12&#58;57&#58;00 | Injured | Bj | Neutered Male |
| A373219 | Cat | 2014&#45;07&#45;29 11&#58;43&#58;00 | Normal | Ella | Spayed Female |
| A382192 | Dog | 2015&#45;03&#45;13 13&#58;14&#58;00 | Normal | Maxwell 2 | Intact Male |

- 이름에 &#39;el&#39;이 들어가는 동물은 Elijah, Ella, Maxwell 2입니다&#46;

- 이 중, 개는 Elijah, Maxwell 2입니다&#46;

<a id="1d1eda9b0fe180a1941de47bedc290a5"></a>

따라서 SQL문을 실행하면 다음과 같이 나와야 합니다&#46;

|  |  |
| --- | --- |
| ANIMAL&#95;ID | NAME |
| A355753 | Elijah |
| A382192 | Maxwell 2 |

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe180419a64f56452596b99"></a>
> 
> 조건
> 
> - 동물 이름 중, 이름에 &#34;EL&#34;이 들어가는 개의 아이디와 이름을 조회
> 
> -  결과는 이름 순으로 조회
> 
> - 이름의 대소문자는 구분하지 않음

<a id="1d1eda9b0fe1808ea887c91c03f37fed"></a>

```sql
SELECT ANIMAL_ID, NAME
FROM ANIMAL_INS
WHERE ANIMAL_TYPE = "Dog" AND NAME LIKE '%el%'
ORDER BY NAME ASC
```
