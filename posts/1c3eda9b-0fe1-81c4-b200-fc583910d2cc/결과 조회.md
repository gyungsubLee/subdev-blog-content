## 결과 조회

---

> 📖 

<details>
<summary>결과 조회 설정 메서드 </summary>

- <code>fetch()</code> &#58; 리스트 조회, 데이터 없으면 빈 리스트 반환

- <code>fetchOne()</code> &#58; 단 건 조회
    - 결과가 없으면 &#58; <code>null</code>

    - 결과가 둘 이상이면 &#58; <code>com&#46;querydsl&#46;core&#46;NonUniqueResultException</code>

- <code>fetchFirst()</code>&#58; <code>limit(1)&#46;fetchOne()</code>

- <code>fetchResults()</code> &#58; 페이징 정보 포함, total count 쿼리 추가 실행

- <code>fetchCount()</code> &#58; count 쿼리로 변경해서 count 수 조회

</details>

<details>
<summary>예시 </summary>

<a id="1c3eda9b0fe181a5b29ecb9fffbaaed7"></a>

```java
//List
List<Member> fetch = queryFactory
        .selectFrom(member)
				.fetch();

//단 건
Member findMember1 = queryFactory
        .selectFrom(member)
        .fetchOne();
        
//처음 한 건 조회
Member findMember2 = queryFactory
        .selectFrom(member)
        .fetchFirst();
        
//페이징에서 사용
QueryResults<Member> results = queryFactory
        .selectFrom(member)
        .fetchResults();

//count 쿼리로 변경
long count = queryFactory
         .selectFrom(member)
         .fetchCount();
```

</details>
