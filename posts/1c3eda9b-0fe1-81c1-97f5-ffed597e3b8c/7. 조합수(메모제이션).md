### 1) 1차 풀이 

<a id="1c3eda9b0fe18108bee3dbe0f64cecb0"></a>

&#91; <strong>예제 입력 1 &#93;</strong>을 기준으로 구현

![](d4244238e7ffe556.webp)

<a id="1c3eda9b0fe181b1ac78db6256cd99cd"></a>

```java
public class Main {
    static int cnt;
    public void DFS(int n, int m){
        if(n<0) return;
        if(m==0) cnt++;
        else {
            DFS(n-1, m-1);
            DFS(n-1, m);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        T.DFS(n, m);
        System.out.println(cnt);
    }
}
```

### 3) 3차 풀이, 백트래킹 개선

```java
import java.util.*;

public class Main {
    static int cnt;
    public void DFS(int n, int m){
        if(n<m) return;
        if(n==m) {
            cnt++;
            return;
        }
        if(m==1) cnt+=n;
        else {
            DFS(n-1, m-1);
            DFS(n-1, m);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        T.DFS(n, m);
        System.out.println(cnt);
    }
}
```

## 풀이2 )<code>강의풀이</code>  DFS, 메모제이션

<a id="1c3eda9b0fe1815f9962d9b49600b495"></a>

```java
import java.util.*;

public class Main {
    //  n값 범위: 3 <= n <= 33
    int[][] dy=new int[35][35];
    public int DFS(int n, int r){
        if(dy[n][r]>0) return dy[n][r]; // 메모제이션
        if(n==r || r==0) return 1;
        else return dy[n][r]=dy[n][n-r]=DFS(n-1, r-1) + DFS(n-1, r);
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int r=sc.nextInt();
        System.out.println(T.DFS(n, r));
    }
}
```

## 풀이3) 2차 풀이(복습)

```java
import java.util.*;

public class Main {
    static int[][] memo;

    // combi = combination(조합)
    public int combi(int n, int r) {
        if(memo[n][r]>0) return memo[n][r];
        if(n==r || r==0) return 1;
        else return memo[n][r]=memo[n][n-r]=combi(n-1, r-1)+combi(n-1, r);
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        int r=sc.nextInt();
        memo=new int[n+1][n+1];
        System.out.println(T.combi(n, r));
    }
}
```
