# 문제

<a id="1c3eda9b0fe18189b12ad30605b455d1"></a>

## <strong>2&#46; 바둑이 승차(DFS)</strong>

---

<a id="1c3eda9b0fe181d9a121f16d6b760231"></a>

### 설명

<a id="1c3eda9b0fe1811585c3df9892f251eb"></a>

철수는 그의 바둑이들을 데리고 시장에 가려고 한다&#46; 그런데 그의 트럭은 C킬로그램 넘게 태울수가 없다&#46;

<a id="1c3eda9b0fe1813a9bdcf4186cbd62ed"></a>

철수는 C를 넘지 않으면서 그의 바둑이들을 가장 무겁게 태우고 싶다&#46;

<a id="1c3eda9b0fe181bfb3f5dd19f77f1341"></a>

N마리의 바둑이와 각 바둑이의 무게 W가 주어지면, 철수가 트럭에 태울 수 있는 가장 무거운 무게를 구하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181178067f321985d25b5"></a>

### 입력

<a id="1c3eda9b0fe181ef9adec88afc15bf13"></a>

첫 번째 줄에 자연수 C(1&#60;=C&#60;=100,000,000)와 N(1&#60;=N&#60;=30)이 주어집니다&#46;

<a id="1c3eda9b0fe181aaac06e2adf1f913bb"></a>

둘째 줄부터 N마리 바둑이의 무게가 주어진다&#46;

<a id="1c3eda9b0fe18167ad79fd292877557e"></a>

### 출력

<a id="1c3eda9b0fe18133893cccd47151c306"></a>

첫 번째 줄에 가장 무거운 무게를 출력한다&#46;

---

## 풀이1) <code>내 풀이</code> DFS

<a id="1c3eda9b0fe1810495a2c99101f7f66b"></a>

<del>겁나 바보짓함…</del> code ← 필요없는 부분(풀이2)

<a id="1c3eda9b0fe18155be8ff84dde2e4446"></a>

```java
import java.util.*;

public class Main {
    static int weight, n;
    static int[] arr;
    static ArrayList<Integer> answer=new ArrayList<>();
    public void DFS(int L, int sum){
        if(L<n && sum>weight) {
            int x=sum-arr[L-1];
            if(!answer.contains(x))answer.add(x);
            return;
        }
        if(L==n) {
            if(sum<weight){
                answer.add(sum);
            }
        }
        else{
            DFS(L+1, sum+arr[L]);
            DFS(L+1, sum);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        weight=sc.nextInt();
        n=sc.nextInt();
        arr=new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        T.DFS(0, 0);
        int max=0;
        for(int i=0; i<answer.size(); i++){
            max=Math.max(max, answer.get(i));
        }
        System.out.print(max);
    }
}
```

## 풀이2) <code>강의 풀이</code>  최적화

<a id="1c3eda9b0fe1819ca938e47eab340683"></a>

```java
import java.util.*;

public class Main {
    static int answer=Integer.MIN_VALUE, c, n;
    public void DFS(int L, int sum, int[] arr){
        if(sum>c) return;
        if(L==n) {
            answer=Math.max(answer, sum);
        }
        else{
            DFS(L+1, sum+arr[L], arr);
            DFS(L+1, sum, arr);
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        c=sc.nextInt();
        n=sc.nextInt();
        int[] arr=new int[n];
        for(int i=0; i<n; i++){
            arr[i]=sc.nextInt();
        }
        T.DFS(0, 0, arr);
        System.out.print(answer);
    }
}
```
