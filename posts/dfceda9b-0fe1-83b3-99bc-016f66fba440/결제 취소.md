## 요청 응답 예시

---

> 해당하는 값이 없는 경우,  테이블 삭제 후 <code>None</code> 명시

<a id="e3ceda9b0fe182b9a65d8133a519b41b"></a>

### 요청 

- Path Variable&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | id | Long |  | 결제 식별 번호 |

- Parameter&#58; <code>None</code>

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Authorization  | String | Bearer token, 토큰 헤더 |
    | 2 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | paymentId | Long |  | DB 결제 ID |
    | 2 | amount | Decimal |  | 결제 금액 |
    | 3 | reason | String |  | 결제 취소 사유<br>details 로 들어감 |

- HTTP 요청
    <a id="cb3eda9b0fe1826a808a810802479f6f"></a>

    ```plaintext
    [ Method ] [ URI ] [ HTTP Version ] 

    ex) GET  /search?user_id=1&card_title=작업  HTTP1.1
    ```

    <details>
    <summary>요청 예시 </summary>

    <a id="9a0eda9b0fe1834ea51c81a2abd73a58"></a>

    ```json
    {
        "paymentId": 2,
        "amount": 1000,
        "reason": "포인트 쓸 일이 없음으로 환불 요청"
    }
    ```

    </details>

<a id="057eda9b0fe183dabfb7015ac7af65b7"></a>

### 응답

- Header&#58;
    | &#45; | 이름 | 타입 | 설명 |
    | --- | --- | --- | --- |
    | 1 | Content&#45;Type | application/json | 컨텐츠 타입 |

- Body&#58; 
    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | message | String | None | 응답 메세지 |
    | 2 | data | <code>PaymentResDto</code> | None | 응답 Dto |

    <details>
    <summary>DTO&#58; <code>PaymentResDto</code></summary>

    | &#45; | 이름 | 타입 | Nullable | 설명 |
    | --- | --- | --- | --- | --- |
    | 1 | payUid | String |  | 내부 결제 ID |
    | 2 | portoneUid | String |  | 포트원 결제 ID |
    | 3 | amount | Decimal |  | 결제금액 |
    | 4 | details | String |  | 결제 내용 |
    | 5 | type | String |  | 결제 타입<br>POINT, SUBSCRIBR |
    | 6 | status | String |  | 결제 상태<br>CANCELLED, FAILED, PAID, PAY&#95;PENDING, READY |

    </details>

    <details>
    <summary>응답 예시 </summary>

    <a id="b4deda9b0fe183d39e02010c38d05f9b"></a>

    ```json
    {
    		"message": "결제가 취소되었습니다.",
    		"data": {
    		    "payUid": "pay-be359e46-da01-41",
    		    "portoneUid": "01944682-e79a-e86d-a44e-793f1a554c95",
    		    "amount": 1000.00,
    		    "details": "포인트 쓸 일이 없음으로 환불 요청",
    		    "type": "POINT",
    		    "status": "CANCELLED"
    		}
    }
    ```

    </details>

- HTTP Status
    |  &#45; | 상태코드  | 상태 메세지 | 설명 |
    | --- | --- | --- | --- |
    | 1 | <code>200 </code> | <code>OK</code> | 성공 |
    | 2 | <code>400</code> | <code>Bad Request</code> | 잘못된 요청 |
    | 3 | <code>401</code> | <code>Unauthorized</code> | 인가되지 않은 요청 |
    | 4 | <code>404</code> | <code>Not Found</code> | 해당 정보 찾을 수 없음 |
