## 문제

<a id="1d1eda9b0fe1804e87b8ff45cb3596ca"></a>

### <strong>문제 설명</strong>

<a id="1d1eda9b0fe1802ba8d5f3d50ad035eb"></a>

다음은 어느 의류 쇼핑몰에 가입한 회원 정보를 담은 <code>USER&#95;INFO</code> 테이블입니다&#46; <code>USER&#95;INFO</code> 테이블은 아래와 같은 구조로 되어있으며, <code>USER&#95;ID</code>, <code>GENDER</code>, <code>AGE</code>, <code>JOINED</code>는 각각 회원 ID, 성별, 나이, 가입일을 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| USER&#95;ID | INTEGER | FALSE |
| GENDER | TINYINT(1) | TRUE |
| AGE | INTEGER | TRUE |
| JOINED | DATE | FALSE |

<a id="1d1eda9b0fe1800c897ada26297a6715"></a>

<code>GENDER</code> 컬럼은 비어있거나 0 또는 1의 값을 가지며 0인 경우 남자를, 1인 경우는 여자를 나타냅니다&#46;

---

<a id="1d1eda9b0fe18046aff4e13d1fc2bd28"></a>

### 문제

<a id="1d1eda9b0fe18017bda7d678e2c74053"></a>

<code>USER&#95;INFO</code> 테이블에서 나이 정보가 없는 회원이 몇 명인지 출력하는 SQL문을 작성해주세요&#46; 이때 컬럼명은 USERS로 지정해주세요&#46;

---

<a id="1d1eda9b0fe180ac9fb4decbc3a47fe8"></a>

### 예시

<a id="1d1eda9b0fe1805e8f1ae40436542e59"></a>

예를 들어 <code>USER&#95;INFO</code> 테이블이 다음과 같다면

|  |  |  |  |
| --- | --- | --- | --- |
| USER&#95;ID | GENDER | AGE | JOINED |
| 1 | 1 | 26 | 2021&#45;06&#45;01 |
| 2 | NULL | NULL | 2021&#45;07&#45;25 |
| 3 | 1 | NULL | 2021&#45;07&#45;30 |
| 4 | 0 | 31 | 2021&#45;08&#45;03 |

<a id="1d1eda9b0fe180859524ee30fefd78c2"></a>

나이 정보가 없는 회원은 2명 이므로, 다음과 같은 결과가 나와야 합니다&#46;

<a id="1d1eda9b0fe180278127d006c58b5508"></a>

USERS

---

<a id="1d1eda9b0fe1807fa139c1d106d453c6"></a>

2

---

<a id="1d1eda9b0fe180cfad39dea7614d2ebe"></a>

## 풀이

> ✏️ 
> 
> <a id="1d1eda9b0fe1809ba70df13c74707618"></a>
> 
> 조건
> 
> - <code>USER&#95;INFO</code> 테이블에서 나이 정보가 없는 회원이 몇 명인지 출력
> 
> - 컬럼명 USERS

<a id="1d1eda9b0fe180798e5cc50d02b0db93"></a>

```sql
SELECT COUNT(*) AS USERS
FROM USER_INFO
WHERE AGE IS NULL
```
