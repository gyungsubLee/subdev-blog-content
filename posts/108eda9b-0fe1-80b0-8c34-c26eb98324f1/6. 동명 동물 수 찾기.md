## 문제

<a id="1cfeda9b0fe180268fc8db99389843db"></a>

## 풀이

> ✏️ 
> 
> <a id="1cfeda9b0fe18071a8d5fb10583d2d5c"></a>
> 
> 조건
> 
> - 동물 보호소에 들어온 동물 이름 중 두 번 이상 쓰인 이름, 해당 이름이 쓰인 횟수를 조회
> 
> - 이름이 없는 동물은 집계에서 제외
> 
> - 결과는 이름 순으로 조회

<a id="1cfeda9b0fe18099b0e2e9f2510623bb"></a>

### 1차 시도&#58; fail

<a id="1cfeda9b0fe1808bb174fcf1ed4a803a"></a>

```sql
SELECT NAME, COUNT(*) AS count
FROM ANIMAL_INS
WHERE NAME IS NOT NULL AND count > 1 
GROUP BY NAME
```

<a id="1cfeda9b0fe1800a9b86db90acf9fab4"></a>

오류 메세지

<a id="1cfeda9b0fe18059bce4c0956463f2ad"></a>

```plaintext
SQL 실행 중 오류가 발생하였습니다.
Unknown column 'count' in 'where clause'
```

<a id="1cfeda9b0fe18017b5e1cf2b11ea7ded"></a>

오류 원인

- <code>WHERE</code>절에서 별칭을 사용하여 조건을 줬다&#46; 그러나 <code>WHERE</code>에서 별칭을 사용할 수 없다&#46;
    <a id="1cfeda9b0fe1804eb46ccff328fa9c3c"></a>

    ```sql
    WHERE ... AND count > 1   <- ❌ 별칭 사용 불가능
    ```

- 그룹핑 이후 조건에 대해서는 <code>HAVING</code> 절을 사용해야 한다&#46;

<a id="1cfeda9b0fe1807eab86d50f97d873eb"></a>

### 2차 시도&#58; Success

<a id="1cfeda9b0fe18037b592f96f095c9b54"></a>

```sql
SELECT NAME, COUNT(*) AS count
FROM ANIMAL_INS
WHERE NAME IS NOT NULL
GROUP BY NAME
HAVING count > 1
ORDER BY NAME
```
