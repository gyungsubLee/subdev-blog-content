# 문제

<a id="1c3eda9b0fe181078356e5523774fdeb"></a>

## <strong>3&#46; 삽입 정렬</strong>

---

<a id="1c3eda9b0fe181a997d7cb1d8b23fee3"></a>

### 설명

<a id="1c3eda9b0fe1813bbbf4d701fd27ffd1"></a>

N개이 숫자가 입력되면 오름차순으로 정렬하여 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1816fb734f9b8c369b0ea"></a>

정렬하는 방법은 삽입정렬입니다&#46;

<a id="1c3eda9b0fe181279466ee8c40d889df"></a>

### 입력

<a id="1c3eda9b0fe181d39806e1171faf43ef"></a>

첫 번째 줄에 자연수 N(1&#60;=N&#60;=100)이 주어집니다&#46;

<a id="1c3eda9b0fe181e6ba14ecbd6807a3fb"></a>

두 번째 줄에 N개의 자연수가 공백을 사이에 두고 입력됩니다&#46; 각 자연수는 정수형 범위 안에 있습니다&#46;

<a id="1c3eda9b0fe181bfa0baf9b585d5f72d"></a>

### 출력

<a id="1c3eda9b0fe181a19e09f1167662afcc"></a>

오름차순으로 정렬된 수열을 출력합니다&#46;

---

# 풀이

<a id="1c3eda9b0fe181deaa8cc7939b64fa62"></a>

## 풀이1)

<a id="1c3eda9b0fe18142b28ada0de1249fd9"></a>

```java
import java.util.*;

public class Main {
public int[] solution(int n, int[] arr){
        int i, j, tmp;
        for(i=1; i<n; i++){
            tmp=arr[i];
            for(j=i-1; j>=0; j--){
                if(arr[j]>tmp) arr[j+1]=arr[j];
                else break;
            }
            arr[j+1]=tmp;
        }
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(n, arr)){
            System.out.print(x+" ");
        }
    }
}
```
