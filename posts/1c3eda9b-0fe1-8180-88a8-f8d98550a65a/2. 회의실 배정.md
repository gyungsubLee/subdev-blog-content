## <strong>2&#46; 회의실 배정</strong>

<a id="1c3eda9b0fe181789731fe1573720e09"></a>

### 설명

<a id="1c3eda9b0fe18182910ddf49f965436c"></a>

한 개의 회의실이 있는데 이를 사용하고자 하는 n개의 회의들에 대하여 회의실 사용표를 만들려고 한다&#46;

<a id="1c3eda9b0fe181e39c15e3eb219b7ea0"></a>

각 회의에 대해 시작시간과 끝나는 시간이 주어져 있고, 각 회의가 겹치지 않게 하면서 회의실을 사용할 수 있는 최대수의 회의를 찾아라&#46;

<a id="1c3eda9b0fe181779006df6846c740d2"></a>

단, 회의는 한번 시작하면 중간에 중단될 수 없으며 한 회의가 끝나는 것과 동시에 다음 회의가 시작될 수 있다&#46;

<a id="1c3eda9b0fe1814f85e8fb236488e509"></a>

### 입력

<a id="1c3eda9b0fe181478b4bc0ddf9b3f1c6"></a>

첫째 줄에 회의의 수 n(1&#60;=n&#60;=100,000)이 주어진다&#46; 둘째 줄부터 n&#43;1 줄까지 각 회의의 정보가 주어지는데

<a id="1c3eda9b0fe181c1964cd9473aade026"></a>

이것은 공백을 사이에 두고 회의의 시작시간과 끝나는 시간이 주어진다&#46; 회의시간은 0시부터 시작한다&#46;

<a id="1c3eda9b0fe181cdbd3ed9b2dce0167a"></a>

회의의 시작시간과 끝나는 시간의 조건은 (시작시간 &#60;= 끝나는 시간)입니다&#46;

<a id="1c3eda9b0fe1817eab75c0b647bb87c6"></a>

### 출력

<a id="1c3eda9b0fe181f197d4f79ec1f3a3b1"></a>

첫째 줄에 최대 사용할 수 있는 회의 수를 출력하여라&#46;

## 풀이1) <code>강의풀이</code>

<a id="1c3eda9b0fe181c8874ce87b76fcdab4"></a>

```java
import java.util.*;

class Time implements Comparable<Time>{
    public int start, end;
    Time(int start, int end){
        this.start=start;
        this.end=end;
    }
    @Override
    public int compareTo(Time o) {
        if (this.end == o.end) return this.start - o.start;
        else return this.end - o.end;
    }


public class Main {
    public int solution(int n, ArrayList<Time> arr){
        int answer =0;
        Collections.sort(arr);
        int endTime=0;
        for(Time ob: arr){
            if(ob.start>=endTime){
                answer++;
                endTime=ob.end;
            }
        }
        return answer;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        int n=sc.nextInt();
        ArrayList<Time> arr=new ArrayList<>();
        for(int i=0; i<n; i++){
            int start=sc.nextInt();
            int end=sc.nextInt();
            arr.add(new Time(start, end));
        }
        System.out.println(T.solution(n, arr));
    }
}
```
