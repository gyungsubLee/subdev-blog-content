> 개발을 하다 보면, 대부분(99%)가 불변이다&#46; 따라서 거의 <code>final</code> 키워드를 사용하여 처리한다&#46; <br>따라서 생성자를 만들어줘야 하는데… 귀찮다? → 필드 주입처럼 처리…

> 의존관계 주입을 자동으로 처리할 때, 생성자 주입은 다 좋은데 코드가 많다&#46;&#46;<br> → 롬복 라이브러리를 통해, 생성자 주입을 필드 주입처럼 편리하게 사용

<a id="1c3eda9b0fe181579168e8bcca224e23"></a>

###  롬복 라이브러리가 제공하는 <code>&#64;RequiredArgsConstructor</code>  → <code>final</code>이 붙은 필드를 모아서 생성자를 자동으로 만듬

<a id="1c3eda9b0fe18106bb37c3426ed20958"></a>

### 기본코드

<a id="1c3eda9b0fe181aa91d4cf1ac0e18ef3"></a>

```java
@Component
public class OrderServiceImpl implements OrderService {
     private final MemberRepository memberRepository;
     private final DiscountPolicy discountPolicy;

		 @Autowired
     public OrderServiceImpl(MemberRepository memberRepository, DiscountPolicy discountPolicy) {
         this.memberRepository = memberRepository;
         this.discountPolicy = discountPolicy;
     }
}
```

<a id="1c3eda9b0fe1819fa7d0e155146e5e61"></a>

### &#64;Autowired 생략

> 생성자가 딱 1개만 있는 경우, &#64;Autowired 생략 할 수 있다&#46; 

<a id="1c3eda9b0fe181a1acd4d72aafcab985"></a>

```java
@Component
public class OrderServiceImpl implements OrderService {
     private final MemberRepository memberRepository;
     private final DiscountPolicy discountPolicy;

     public OrderServiceImpl(MemberRepository memberRepository, DiscountPolicy discountPolicy) {
         this.memberRepository = memberRepository;
         this.discountPolicy = discountPolicy;
     }
}
```

<a id="1c3eda9b0fe181c79524c4807d6cc082"></a>

### 롬복 라이브러리를 사용한 코드 최적화

> 롬복 라이브러리가 제공하는 <code>&#64;RequiredArgsConstructor</code> 기능을 사용하면 <code>final</code>이 붙은 필드를 모아서 생성자를 자동으로 만들어 준다&#46;

<a id="1c3eda9b0fe181df8e75e0bd081cc5c8"></a>

```java
@Component
@RequiredArgsConstructor
public class OrderServiceImpl implements OrderService {
     private final MemberRepository memberRepository;
     private final DiscountPolicy discountPolicy;
}
```

<a id="1c3eda9b0fe181b3a8dac30a4f7cc219"></a>

롬복이 자바의 애노테이션 프로세서라는 기능을 사용하여, 컴파일 시점에서 생성자 코드를 자동으로 생성해준다&#46; 

<a id="1c3eda9b0fe1815aa12dd0da007d0c21"></a>

<br>실제 class 를 열어보면 다음 코드가 추가된것을 확인 할 수 있다&#46;

<a id="1c3eda9b0fe1818c9945ca9af8ee0339"></a>

```java
public OrderServiceImpl(MemberRepository memberRepository, DiscountPolicy
 discountPolicy) {
     this.memberRepository = memberRepository;
     this.discountPolicy = discountPolicy;
 }
```
