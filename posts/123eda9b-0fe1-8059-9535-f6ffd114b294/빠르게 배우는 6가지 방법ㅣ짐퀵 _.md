# 빠르게 학습하는 ‘6가지 방법( 6 R)’

<a id="fb6584c6fd634eefbcbd122b3a42cca7"></a>

→ 어떤 것을 일고 깊게 생각해서 개인적인 정의를 가진 다음, 그것을 기록하고 다른 사람에게 설명하며, 능독적인 인출을 후 주기적으로 복습하여 장기 기억화

<a id="4d1cd256151846b786c94468e2480ecc"></a>

## 1&#46;  학습하기 (Read)

<a id="78257b45fcb747c492e78aec256cf155"></a>

‘읽다’는 자료를 학습한다는 의미이다&#46; 

<a id="3d88208e6ef341a198c98de52578bda8"></a>

이것은 텍스트를 읽는 다는 것 뿐만 아닌 오디오 북을 보거나 강의를 듣는 것, 누군가와 대화를 하는 것 등 내가 학습하고자 하는 정보들을 받아들이는 모든 것을 뜻한다&#46; 

<a id="41180f5942334033bb2e8db95c49fb13"></a>

적극적으로 열정적으로 임해야한다&#46; 

<a id="04a2fc6a051d4ba38e48d6c637725c20"></a>

## 2&#46;  깊게 생각하기 (Reflect)

<a id="40126c5b46534c738ab185a4a2f4184d"></a>

일종의 메타인지와 같다&#46;

<a id="cf15816169d642d8974dd9c10ae9a7a0"></a>

‘읽기’를 통해 학습한 내용을 단지 생각해보는 것이다&#46; 

<a id="dc723d355729441f87c37c57c14f45c7"></a>

이렇게 얻은 정보를 깊게 생각함으로써 새로운 의미를 얻고 새로운 수준의 이해력을 배우고,  새로운 수준의 지식을 얻을 수 있다&#46; 

<a id="09c2ea3d8dfc4d3aa2b9b87392b6df82"></a>

## 3&#46; 기록하기 (Record)

<a id="ba6a58c8e47c4c38af50ea20f518be9e"></a>

그냥 2분 정도 시간을 내어 배운 것을 일기나 노트 등에 기록하는 것

<a id="cad0edcedce9444c9454917f1f32896b"></a>

이를 통해 그 정보가 머리에 들어온다&#46; 

<a id="1ff820d5a1044d0ea647d73ad937547d"></a>

정보를 글의 형태로 표현하기 위해서는, 내가 이해한 지식을 한층 더 깊이 생각해야 한다&#46; 해당 정보를 새로운 수준에서 이해할 수 있어야 한다&#46; 

<a id="b46aba67717b48878dbe93fe3a9f0448"></a>

정보를 이해하고 학습하고 정리해야한다&#46; 이는 학습 과정의 일부이다&#46; 

<a id="4453dbc2fb504fe89b731f06e73ba5b7"></a>

## 4&#46; 설명하기 (Relate) 

<a id="ab753f03df5e4eba9bee8d281098836f"></a>

혼자보다 다른 사람과 학습하는 것이 더 효과적일 수 있다&#46;

<a id="8868fb8a187e48e58c6d76e4f58bb6b1"></a>

그 중 하나가 다른 누군가에게 어떤 정보를 설명하는 것이다&#46; 

<a id="f2e410a206aa4e31bfde5fdf50831d20"></a>

### 무언가를 가르치면서, 2번 학습한다&#46; 

<a id="bc0e331b9fb14e0ea2a7e56812ff0f64"></a>

## 5&#46; 질문하고 테스트하기 (Retrieval)

<a id="a60d853e77dc4180a711a7d58980e64c"></a>

다른 사람들에게 내가 배운걸 테스트 하는 단계

<a id="d189c6ed666f4d4c962aa285c728c3aa"></a>

ex) 내가 배운 내용을 다른 사람에게 설명 → 그리고 그 사람이 나에게 문제를 내는 것  

<a id="311d3b0b1cf24ca7bcda0e430eb1cb1b"></a>

나에게  스스로 질문을 던지는 것 

<a id="307fe7bdb3e14e4683bc06f0d480bba0"></a>

예를 들어, 책을 덮고 스스로 문제를 내는 것 , 노트를 보지 않고 얼마나 많은 것을 기억하는지 테스트 하는 것

> 짐 퀵, 그는 2번 읽는 것 보다 이 ‘능동적 인출’ 한번이 더 높은 학습 효과를 발휘한다고 함&#46; <br>왜냐하면 머리 속으로 들어가 정보를 빼내는 행위가 그 정보를 가지고 있는가에 대한 여부를 확인하는 순수한 테스트이기  때문이다&#46; 

<a id="1a5299d3d01d43ccaadf1b6d2c53b1fe"></a>

### 스스로에게 질문하고 테스트하는 것 → 어느 정도의 정보가 들어있는지 확인 

<a id="43f24ee089de4a19a9a294089bdaafd2"></a>

## 6&#46; 복습하기(Review)

<a id="0523ee1a152d4c4eae790deae946022b"></a>

### 복습은 일정 간격을 두고 반복하는 힘이다&#46; 

<a id="bb67a775f265416990cc49defa78a539"></a>

전날 했던 것을 복습해야 한다&#46; 

<a id="bfe75841528345f1b476af0046617c0f"></a>

복습 주기&#58; 1시간, 하루, 일주일, 한달  →  단기 기억을 통합하고, 이동 시켜 장기기억으로 만듬&#46;

<a id="1f22d5bbf63446d1946aa28d7d88de85"></a>

###
