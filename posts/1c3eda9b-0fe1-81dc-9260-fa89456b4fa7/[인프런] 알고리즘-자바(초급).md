### 1&#46; <strong>Scanner 호출</strong>

<a id="1c3eda9b0fe1819cb554ffcbe2ab1901"></a>

```java
import java.util.Scanner;
```

<a id="1c3eda9b0fe1816a8170dbb8c77e5fd9"></a>

### 2&#46; <strong>Scanner의 객체 생성</strong>

<a id="1c3eda9b0fe181e4bd8cc314b1ebe697"></a>

```java
Scanner sc =new Scanner(System.in);
```

<a id="1c3eda9b0fe18114bbbeeda98c7cc7cf"></a>

sc라는 객체를 생성하여 System&#46;in으로 입력한 값을 바이트 단위로 읽는 것 의미

<a id="1c3eda9b0fe181c6b4e0d4bcfcb335b4"></a>

### <strong>Scanner의 메소드</strong>

<a id="1c3eda9b0fe18105a656ccd807da4740"></a>

```java
import java.util.Scanner;

publicclasstest {

publicstaticvoidmain(String[] args) {
		String name;
int age;
double height;
		String intro;
		String buffer;

		Scanner sc =new Scanner(System.in);
		System.out.println("이름을 입력하세요");
		name = sc.next();
		System.out.println("나이를 입력하세요");
		age = sc.nextInt();
		System.out.println("키를 입력하세요");
		height = sc.nextDouble();
		System.out.println("자기소개를 입력하세요");
		buffer = sc.nextLine();
		intro = sc.nextLine();

		System.out.println("이름은 "+name+"나이는 "+age+",키는 "+height+"입니다.");
		System.out.println(intro);
	}
}

```

- next &#43; {자료형}()
    - 뒤에 사용한 자료형에 맞는 값을 받을 수 있음&#46;

- nextLine()
    - 한 줄을 통째로 받아옴&#46;
        <a id="1c3eda9b0fe181ed8d66e33a67376171"></a>

         nextLine()은 개행문자까지 받을 수 있기 때문에 위에서 buffer라는 변수에 nextLine()을 받아주지 않는다면 앞에서 남은 개행을 받아와 자기소개는 입력을 받지 못하게 된다&#46; 따라서 buffer 변수로 한 번 더 받아줌으로서 이 문제를 해결하였다&#46;

- next()
    - 화이트 스페이스를 기준으로 한 단어를 받아온다&#46;

<a id="1c3eda9b0fe18174a5a7c7d687d5118d"></a>

```java
// ex) int
import java.util.Scanner;
  
	//args: int, int

    return ;
  }
}

    Scanner kb =new Scanner(System.in);
    String input1 = kb.next();
    char input2 = kb.next().charAt(0);
    System.out.println(input1 + input2);
```
