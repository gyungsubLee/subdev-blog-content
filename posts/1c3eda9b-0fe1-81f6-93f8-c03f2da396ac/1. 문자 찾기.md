# 문제

<a id="1c3eda9b0fe18125b136d3bd6921d47a"></a>

## <strong>1&#46; 문자 찾기</strong>

<a id="1c3eda9b0fe181cebc3cf4f96020eb66"></a>

### 설명

<a id="1c3eda9b0fe18144b0a4d73758f2cac6"></a>

한 개의 문자열을 입력받고, 특정 문자를 입력받아 해당 특정문자가 입력받은 문자열에 몇 개 존재하는지 알아내는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181968803e0989c294832"></a>

대소문자를 구분하지 않습니다&#46;문자열의 길이는 100을 넘지 않습니다&#46;

<a id="1c3eda9b0fe18111b415de5b1aa327cc"></a>

### 입력

<a id="1c3eda9b0fe1814ebc27db1ed2c0b63d"></a>

첫 줄에 문자열이 주어지고, 두 번째 줄에 문자가 주어진다&#46;

<a id="1c3eda9b0fe181cca7ced570eccc9525"></a>

문자열은 영어 알파벳으로만 구성되어 있습니다&#46;

<a id="1c3eda9b0fe181acacf5ff1100769f91"></a>

### 출력

<a id="1c3eda9b0fe1813db182fdc7d49978c9"></a>

첫 줄에 해당 문자의 개수를 출력한다&#46;

<a id="1c3eda9b0fe181e0b562df73ac0b8055"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1812ea513d4fa3c94475a"></a>

```plaintext
Computercooler
c
```

<a id="1c3eda9b0fe181b5a9a1f6f739d708b3"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181259e02dd4b2b096f07"></a>

```plaintext
2
```

<a id="1c3eda9b0fe18130abcfed7579636f07"></a>

# 풀이

<a id="1c3eda9b0fe181bb9107dfd256d8b615"></a>

## 풀이1)

<a id="1c3eda9b0fe18160b81af404d8c892ec"></a>

```java
import java.util.Scanner;

public class Main {
    public int solution(String s, char t) {
        int cnt=0;
        for(char a : s.toCharArray()){
            if( a == t) cnt++;
        }
        return cnt;
    }
    public static void main(String[] args){
        Main m = new Main();
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        char t = sc.next().charAt(0);
        System.out.println(m.solution(s.toLowerCase(), t));
    }
};
```
