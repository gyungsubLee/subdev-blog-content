# 문제

## <strong>13&#46; 섬나라 아일랜드</strong>

---

<a id="1c3eda9b0fe181c99752e45cab30b406"></a>

### 설명

<a id="1c3eda9b0fe1817d8a70e2b2fb338b1e"></a>

N&#42;N의 섬나라 아일랜드의 지도가 격자판의 정보로 주어집니다&#46;

<a id="1c3eda9b0fe18155827bdbace924f19b"></a>

각 섬은 1로 표시되어 상하좌우와 대각선으로 연결되어 있으며, 0은 바다입니다&#46;

<a id="1c3eda9b0fe18174811fcfb356a828c4"></a>

섬나라 아일랜드에 몇 개의 섬이 있는지 구하는 프로그램을 작성하세요&#46;

![](https://cote.inflearn.com/public/upload/7c81fe29cd.jpg)

<a id="1c3eda9b0fe1812495cccbbaffb75717"></a>

만약 위와 같다면 섬의 개수는 5개입니다&#46;

<a id="1c3eda9b0fe181a5a86be95ff087e185"></a>

### 입력

<a id="1c3eda9b0fe181a6b662f8f3fffdacfa"></a>

첫 번째 줄에 자연수 N(3&#60;=N&#60;=20)이 주어집니다&#46;

<a id="1c3eda9b0fe18186bbc2c4a65b6094f5"></a>

두 번째 줄부터 격자판 정보가 주어진다&#46;

<a id="1c3eda9b0fe181c7be96d2382012c460"></a>

### 출력

<a id="1c3eda9b0fe181c293efc70a9a826134"></a>

첫 번째 줄에 섬의 개수를 출력한다&#46;

## 풀이1) <code>내풀이</code> 대각선까지 범위 포함&#33;

<a id="1c3eda9b0fe1810faa98ce6d207277a1"></a>

<a href="https://github.com/gyungsubLee/Python_Algorithm_interview/tree/main/Leetcode(%ED%8C%8C%EC%95%8C%EC%9D%B8)/08-%EA%B7%B8%EB%9E%98%ED%94%84(DFS%2CBFS)/200-number-of-islands">이전에 푼 파이썬 문제 </a>참조

<a id="1c3eda9b0fe181e790f1d2028d6904ec"></a>

```java
import java.util.*;

public class Main {
    static int n;
    static int[] dx={1, -1, 0, 0, 1, 1, -1, -1};
    static int[] dy={0, 0, 1, -1, 1, -1, 1, -1};
    static int[][] board;
    public void DFS(int x, int y){
        for(int i=0; i<8; i++){
            int nx=x+dx[i];
            int ny=y+dy[i];
            if((nx>=0 && ny>=0 && nx<n && ny<n) && board[nx][ny]==1){
                board[nx][ny]=0;
                DFS(nx, ny);
            }
        }
    }

    public int solution(){
        int cnt=0;
        for(int i=0; i<n; i++) {
            for (int j = 0; j < n; j++) {
                if(board[i][j]==1){
                    board[i][j]=0;
                    DFS(i, j);
                    cnt++;
                }
            }
        }
        return cnt;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        board=new int[n][n];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                board[i][j]=sc.nextInt();
            }
        }

        System.out.println(T.solution());
    }
}
```

## 풀이2) <code>2차풀이</code> BFS

<a id="1c3eda9b0fe181cc9e13f868c20d5084"></a>

```java
import java.util.*;

class Point {
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n;
    int[] dx = {1, -1, 0, 0, 1, 1, -1, -1};
    int[] dy = {0, 0, 1, -1, 1, -1, 1, -1};
    static int[][] board;

    public void BFS(int x, int y){
        Queue<Point> Q = new LinkedList<>();
        Q.offer(new Point(x, y));
        while(!Q.isEmpty()){
            Point cur=Q.poll();
            for(int j=0; j<8; j++){
                int nx=cur.x+dx[j];
                int ny=cur.y+dy[j];
                if((nx>=0 && ny>=0 && nx<n && ny<n) && board[nx][ny]==1){
                    board[nx][ny]=0;
                    Q.offer(new Point(nx, ny));
                }
            }
        }
    }

    public int answer(){
        int cnt=0;
        for(int i=0; i<n; i++) {
            for (int j = 0; j < n; j++) {
                if(board[i][j]==1) {
                    BFS(i, j);
                    cnt++;
                }
            }
        }
        return cnt;
    }

    public void input(){
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        board = new int[n][n];
        for(int i=0; i<n; i++){
            for(int j=0; j<n; j++){
                board[i][j]=sc.nextInt();
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        T.input();
        System.out.println(T.answer());
    }
}
```
