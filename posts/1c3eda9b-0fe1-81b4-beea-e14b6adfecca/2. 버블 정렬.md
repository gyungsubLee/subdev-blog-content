# 문제

---

<a id="1c3eda9b0fe1815fb5fac943e6d5ffe3"></a>

## <strong>2&#46; 버블 정렬</strong>

<a id="1c3eda9b0fe181569358e6d2bf79cb93"></a>

### 설명

<a id="1c3eda9b0fe18182aa91fc47a8792366"></a>

N개이 숫자가 입력되면 오름차순으로 정렬하여 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe181b6b591e70594222da7"></a>

정렬하는 방법은 버블정렬입니다&#46;

<a id="1c3eda9b0fe18139b502ee6940115831"></a>

### 입력

<a id="1c3eda9b0fe181e1bbd9f8f8266f61ca"></a>

첫 번째 줄에 자연수 N(1&#60;=N&#60;=100)이 주어집니다&#46;

<a id="1c3eda9b0fe18156a285e696c75ffd1f"></a>

두 번째 줄에 N개의 자연수가 공백을 사이에 두고 입력됩니다&#46; 각 자연수는 정수형 범위 안에 있습니다&#46;

<a id="1c3eda9b0fe1813bb9c8ee604e372ff3"></a>

### 출력

<a id="1c3eda9b0fe181938ea1cf8adf4848d3"></a>

오름차순으로 정렬된 수열을 출력합니다&#46;

---

<a id="1c3eda9b0fe181eca3c3fe7955178e9c"></a>

### 예시 입력 1

<a id="1c3eda9b0fe18125a726c0b16b465888"></a>

```plaintext
6
13 5 11 7 23 15
```

<details>
<summary>코드</summary>

<a id="1c3eda9b0fe181cfbdc8f3e6b9e70de3"></a>

```java
import java.util.*;

public class Main {
    public int[] solution(int n, int[] arr){
        int i, j, tmp;
       for(i=0; i<n-1; i++){
           tmp=arr[i];
           for(j=i+1; j<n; j++){
               if(arr[j]<tmp){
                   arr[i]=arr[j];
                   arr[j]=tmp;
               }
           }
       }
        return arr;
```

</details>

<a id="1c3eda9b0fe18197b66df4280a8ffe0e"></a>

아래 <code>tmp</code> 변수를 <code>j&#45;for문</code> 외부에 만들 시 다음 번 반복 시, <code>tmp</code>에 이전 값이 저장되어 오류가 남&#46;

</details>

<a id="1c3eda9b0fe18131adeeefeb1033c6f1"></a>

```java
import java.util.*;

public class Main {
public int[] solution(int n, int[] arr){
        int i, j, tmp;
        for(i=0; i<n-1; i++){
            for(j=i+1; j<n; j++){
                if(arr[i]>arr[j]){
                    tmp=arr[i];
                    arr[i]=arr[j];
                    arr[j]=tmp;
                }
            }
        }
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(n, arr)){
            System.out.print(x+" ");
        }
    }
}
```

## 풀이2) 뒤 인덱스부터 정렬됨

<a id="1c3eda9b0fe181348311e574991768c0"></a>

```java
import java.util.*;

public class Main {
public int[] solution(int n, int[] arr){
        int i, j, tmp;
        for(i=0; i<n-1; i++){
            for(j=0; j<n-i-1; j++){
                if(arr[j]>arr[j+1]){
                    tmp=arr[j];
                    arr[j]=arr[j+1];
                    arr[j+1]=tmp;
                }
            }
        }
        return arr;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x: T.solution(n, arr)){
            System.out.print(x+" ");
        }
    }
}
```
