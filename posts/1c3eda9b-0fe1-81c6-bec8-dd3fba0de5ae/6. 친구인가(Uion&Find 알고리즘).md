# 문제

<a id="1c3eda9b0fe18175849ddc1a156f4111"></a>

## <strong>6&#46; 친구인가? (Disjoint&#45;Set &#58; Union&#38;Find)</strong>

<a id="1c3eda9b0fe181738c40f85b255417b3"></a>

### 설명

<a id="1c3eda9b0fe181eeb3b9cc5b4f7499fd"></a>

오늘은 새 학기 새로운 반에서 처음 시작하는 날이다&#46; 현수네 반 학생은 N명이다&#46; 현수는 각 학생들의 친구관계를 알고 싶다&#46;

<a id="1c3eda9b0fe181c4889ffef1579210a9"></a>

모든 학생은 1부터 N까지 번호가 부여되어 있고, 현수에게는 각각 두 명의 학생은 친구 관계가 번호로 표현된 숫자쌍이 주어진다&#46;

<a id="1c3eda9b0fe1814c8205cd8c29206c43"></a>

만약 (1, 2), (2, 3), (3, 4)의 숫자쌍이 주어지면 1번 학생과 2번 학생이 친구이고, 2번 학생과 3번 학생이 친구, 3번 학생과 4번 학생이 친구이다&#46;

<a id="1c3eda9b0fe18190a831eb3bda18bc2a"></a>

그리고 1번 학생과 4번 학생은 2번과 3번을 통해서 친구관계가 된다&#46;

<a id="1c3eda9b0fe181ed9af7c790404e75b5"></a>

학생의 친구관계를 나타내는 숫자쌍이 주어지면 특정 두 명이 친구인지를 판별하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1810387a7c187bf13dd80"></a>

두 학생이 친구이면 “YES&#34;이고, 아니면 ”NO&#34;를 출력한다&#46;

<a id="1c3eda9b0fe1811cb550ef1578d4ab64"></a>

### 입력

<a id="1c3eda9b0fe181ab9373d4fa4a1a67f9"></a>

첫 번째 줄에 반 학생수인 자연수 N(1&#60;=N&#60;=1,000)과 숫자쌍의 개수인 M(1&#60;=M&#60;=3,000)이 주어지고,

<a id="1c3eda9b0fe1817eaf8dd4a0fa780326"></a>

다음 M개의 줄에 걸쳐 숫자쌍이 주어진다&#46;

<a id="1c3eda9b0fe181cc9aa9c52f949689c2"></a>

마지막 줄에는 두 학생이 친구인지 확인하는 숫자쌍이 주어진다&#46;

<a id="1c3eda9b0fe1811d86fac88f6573ff24"></a>

### 출력

<a id="1c3eda9b0fe181289bf1f04131def0f7"></a>

첫 번째 줄에 “YES&#34;또는 &#34;NO&#34;를 출력한다&#46;

---

## 풀이1) <code>Union&#45;Find 알고리즘</code>

<a id="1c3eda9b0fe181249e02ebbcbc577e90"></a>

```java
import java.util.*;

public class Main {
    static int[] unf;


    public static int Find(int v){
        if(v==unf[v]) return v;
        else return unf[v]=Find(unf[v]);
    }

    // 집합 합침
    public static void Union(int a, int b) {
        int fa = Find(a);
        int fb = Find(b);
        if(fa!=fb) unf[fa]=fb;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int m=sc.nextInt();
        unf=new int[n+1];
        for(int i=1; i<=n; i++) unf[i]=i;
        for (int i=1; i<=m; i++) {
            int a = sc.nextInt();
            int b = sc.nextInt();
            Union(a, b);
        }

        int a = sc.nextInt();
        int b = sc.nextInt();
        int fa = Find(a);
        int fb = Find(b);

        if(fa==fb) System.out.println("YES");
        else System.out.println("NO");
    }
}
```
