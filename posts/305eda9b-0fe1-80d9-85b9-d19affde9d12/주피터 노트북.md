## 주피터 노트북 단축키

<a id="305eda9b0fe180eaae4bfaa8163330a2"></a>

### 모드 전환

- Command Mode&#58; <code>Esc</code>

- Edit Mode&#58; <code>Enter</code>

<a id="305eda9b0fe180259af8f2ceeae52034"></a>

### 셀 실행 관련

- 현재 셀 실행&#58; <code>Ctrl &#43; Enter</code>

- 실행 후 아래 셀로 이동&#58; <code>Shift &#43; Enter</code>

- 실행 후 아래 셀 생성&#58; <code>Alt &#43; Enter</code>

<a id="305eda9b0fe180c7a4d8de08c88d1b39"></a>

### 셀 추가 / 삭제 (Command Mode)

- 위에 셀 추가&#58; <code>A</code>

- 아래에 셀 추가&#58; <code>B</code>

- 셀 삭제&#58; <code>D &#42; 2</code>

- 셀 복제&#58; <code>C → V</code>

- 셀 잘라내기&#58; <code>X → V</code>

<a id="305eda9b0fe180af97b7e10a9fb7e5aa"></a>

### 셀 타입 변경 (Command Mode)

- Code 셀&#58; <code>Y</code>

- Markdown 셀&#58; <code>M</code>

- Raw 셀&#58; <code>R</code>

<a id="305eda9b0fe180c681a7c9f1229dc223"></a>

### 셀 이동 / 선택

- 셀 위/아래 이동&#58; <code>K / J</code>

- 여러 셀 선택&#58; <code>Shift &#43; ↑ / ↓</code>

- 셀 위로 이동&#58; <code>Shift &#43; K</code>

- 셀 아래로 이동&#58; <code>Shift &#43; J</code>

<a id="305eda9b0fe1805197d0dc249381e1a1"></a>

### 편집 모드 ( Edit Mode )

- 자동완성&#58; <code>Tab</code> 

- 주석 토글&#58; <code>Ctrl &#43; /</code>

- 한 줄 삭제&#58; <code>Ctrl &#43; D</code>

- 여러 커서&#58; <code>Ctrl &#43; 클릭</code>
