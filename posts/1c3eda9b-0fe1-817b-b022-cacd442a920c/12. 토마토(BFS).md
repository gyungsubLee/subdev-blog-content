# 문제

<a id="1c3eda9b0fe181679caddbc2497c4035"></a>

## <strong>12&#46; 토마토(BFS 활용)</strong>

---

<a id="1c3eda9b0fe181918a0ded71cf90ba79"></a>

### 설명

<a id="1c3eda9b0fe181b1b053e01ec1e8cd11"></a>

현수의 토마토 농장에서는 토마토를 보관하는 큰 창고를 가지고 있다&#46;

<a id="1c3eda9b0fe1814c9899db5944088333"></a>

토마토는 아래의 그림과 같이 격자 모양 상자의 칸에 하나씩 넣어서 창고에 보관한다&#46;

![](https://cote.inflearn.com/public/upload/a9d513f5a5.jpg)

<a id="1c3eda9b0fe18126871ed94c57b0cf3d"></a>

창고에 보관되는 토마토들 중에는 잘 익은 것도 있지만, 아직 익지 않은 토마토들도 있을 수 있다&#46; 보관 후 하루가 지나면,

<a id="1c3eda9b0fe1815abc18f7ed2797baa8"></a>

익은 토마토들의 인접한 곳에 있는 익지 않은 토마토들은 익은 토마토의 영향을 받아 익게 된다&#46;

<a id="1c3eda9b0fe1814982f1e3a4bd7caa1c"></a>

하나의 토마토의 인접한 곳은 왼쪽, 오른쪽, 앞, 뒤 네 방향에 있는 토마토를 의미한다&#46; 대각선 방향에 있는 토마토들에게는 영향을 주지 못하며,

<a id="1c3eda9b0fe1815895a3ee245f78ab43"></a>

토마토가 혼자 저절로 익는 경우는 없다고 가정한다&#46; 현수는 창고에 보관된 토마토들이 며칠이 지나면 다 익게 되는지, 그 최소 일수를 알고 싶어 한다&#46;

<a id="1c3eda9b0fe181fca655d5abde4a7e47"></a>

토마토를 창고에 보관하는 격자모양의 상자들의 크기와 익은 토마토들과 익지 않은 토마토들의 정보가 주어졌을 때,

<a id="1c3eda9b0fe1815f8f8cd1a57d23518d"></a>

며칠이 지나면 토마토들이 모두 익는지, 그 최소 일수를 구하는 프로그램을 작성하라&#46; 단, 상자의 일부 칸에는 토마토가 들어있지 않을 수도 있다&#46;

<a id="1c3eda9b0fe181cdbd21ecc4541cf2ab"></a>

### 입력

<a id="1c3eda9b0fe181d383b2cda200cad7fe"></a>

첫 줄에는 상자의 크기를 나타내는 두 정수 M, N이 주어진다&#46; M은 상자의 가로 칸의 수,

<a id="1c3eda9b0fe1810980dacc3df5b12bc4"></a>

N 은 상자의 세로 칸의 수를 나타낸다&#46; 단, 2 ≤ M, N ≤ 1,000 이다&#46;

<a id="1c3eda9b0fe181ce8ef5c1764f5515ca"></a>

둘째 줄부터는 하나의 상자에 저장된 토마토들의 정보가 주어진다&#46;

<a id="1c3eda9b0fe1815f82d4c092a5de58fa"></a>

즉, 둘째 줄부터 N개의 줄에는 상자에 담긴 토마토의 정보가 주어진다&#46;

<a id="1c3eda9b0fe1810ab01deb856987f9f4"></a>

하나의 줄에는 상자 가로줄에 들어있는 토마토의 상태가 M개의 정수로 주어진다&#46;

<a id="1c3eda9b0fe181a1bd59c8cecaeef809"></a>

정수 1은 익은 토마토, 정수 0은 익지 않은 토마토, 정수 &#45;1은 토마토가 들어있지 않은 칸을 나타낸다&#46;

<a id="1c3eda9b0fe181668f4ec3738fcebd50"></a>

### 출력

<a id="1c3eda9b0fe181d4a515e7a2322eefb3"></a>

여러분은 토마토가 모두 익을 때까지의 최소 날짜를 출력해야 한다&#46;

<a id="1c3eda9b0fe1818a8be1c0b5d6157150"></a>

만약, 저장될 때부터 모든 토마토가 익어있는 상태이면 0을 출력해야 하고,

<a id="1c3eda9b0fe1818693ccdbc2e1cbbc55"></a>

토마토가 모두 익지는 못하는 상황이면 &#45;1을 출력해야 한다&#46;

---

## 풀이1) <code>내풀이</code>  

<a id="1c3eda9b0fe181a89488c5c9f5bf29db"></a>

코드가 정갈하지 못함… 그래도 풀긴 풀었음 

<a id="1c3eda9b0fe181598195cc3d0a20fd94"></a>

```java
import java.util.*;

class Point{
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n, m;
    static int[] dx={1, -1, 0, 0};
    static int[] dy={0, 0, 1, -1};
    static int[][] board, dis;
    static Queue<Point> Q=new LinkedList<>();

    public void BFS(){
        while(!Q.isEmpty()){
            Point cur=Q.poll();
            for(int i=0; i<4; i++){
                int nx=cur.x+dx[i];
                int ny=cur.y+dy[i];
                if((nx>=0 && ny>=0 && nx<n && ny<m) && board[nx][ny]==0){
                    board[nx][ny]=1;
                    Q.offer(new Point(nx, ny));
                    int nextPointDistance=dis[nx][ny];
                    int currentPointDistance=dis[cur.x][cur.y];
                    if(nextPointDistance>0) dis[nx][ny]=Math.min(nextPointDistance, currentPointDistance+1);
                    else dis[nx][ny]=currentPointDistance+1;
                }
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        m=sc.nextInt();
        n=sc.nextInt();
        board=new int[n][m];
        dis=new int[n][m];
        for(int i=0; i<n; i++){
            for(int j=0; j<m; j++){
                board[i][j]=sc.nextInt();
                if(board[i][j]==1) Q.offer(new Point(i, j));
            }
        }
        T.BFS();
        int answer=0;
        for(int i=0; i<n; i++) {
            for (int j = 0; j < m; j++) {
                if(answer==-1) break;
                if (board[i][j]==-1) continue;
                if(board[i][j]==0) {
                    answer=-1;
                    break;
                }
                else {
                    answer=Math.max(answer, dis[i][j]);
                }
            }
        }
        System.out.println(answer);
    }
}
```

import java.util.*;

class Point {
    int x, y;
    Point(int x, int y){
        this.x=x;
        this.y=y;
    }
}

public class Main {
    static int n, m;
    int[] dx = {1, -1, 0, 0};
    int[] dy = {0, 0, 1, -1};
    static int[][] tomatoBox;
    static ArrayList<Point> starts=new ArrayList<>();
    public int BFS(){
        Queue<Point> Q = new LinkedList<>();
        for(Point s : starts) Q.offer(s);
        int L=1;
        while(!Q.isEmpty()){
            int len = Q.size();
            for(int i=0; i<len; i++){
                Point cur=Q.poll();
                for(int j=0; j<4; j++){
                    int nx=cur.x+dx[i];
                    int ny=cur.y+dy[i];
                    if((nx>=0 && ny>=0 && nx<m && ny<n) && tomatoBox[nx][ny]==0){
                        tomatoBox[nx][ny]=1;
                        Q.offer(new Point(nx, ny));
                    }
                }
                L++;
            }
        }
        return L;
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        m = sc.nextInt();
        tomatoBox = new int[m][n];
        for(int i=0; i<m; i++){
            for(int j=0; j<n; j++){
                tomatoBox[i][j]=sc.nextInt();
                if(tomatoBox[i][j]==1) starts.add(new Point(i, j));
            }
        }
        System.out.println(T.BFS());
    }
}

public class Main {
