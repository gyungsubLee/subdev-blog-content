### 패키지 설치

<a id="237eda9b0fe18058b450ebde253017ff"></a>

```bash
# nestJS 설치
npm i -g @nestjs/cli

# nest 프로젝트 생성
nest new {프로젝트명}

# validation
pnpm add --save class-validator class-transformer

# 데이터 암호화
pnpm add bcrypt
pnpm add -D @types/bcrypt

# swagger - 개발 환경에서만
pnpm add --save @nestjs/swagger

# TypeORM
pnpm add --save @nestjs/typeorm typeorm mysql2

# MySQL

# CORS
```

<a id="237eda9b0fe180f890b3ddfce2e8287c"></a>

### CLI

<a id="237eda9b0fe18026a186ff887500c894"></a>

```bash
# 서버 시작
npm run start

# 모듈 생성
nest g mo {모듈명}

# 컨트롤러 생성
nest g co {모듈명}

# 서비스 생성
nest g s {모듈명} 
```
