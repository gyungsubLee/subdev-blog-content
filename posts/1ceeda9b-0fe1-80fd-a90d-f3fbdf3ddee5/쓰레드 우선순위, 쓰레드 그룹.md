## 쓰레드 우선순위, 쓰레드 그룹

---

> 📖 
> 
> <a id="1ceeda9b0fe180bfa4bad366dfdf79dc"></a>
> 
> 쓰레드 작업에 중요도에 따라 우선순위 부여가 가능하며 <br>유사한 작업을 하는 쓰레드들을 묶어서 다룰 수 있다&#46;

<details>
<summary>쓰레드 우선순위</summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe1800ba110e04b3baa6cd1"></a>
> 
> 쓰레드 작업의 중요도에 따라서 쓰레드에게 우선순위를 부여할 수 있다&#46;
> 
> - 쓰레드는 생성될 때 우선순위가 결정되는데, 이를 직접 지정하거나 JVM에 의해 지정될 수 있다&#46;
> 
> - 작업의 중요도가 높을 때 우선순위를 높게 지정하면 더 많은 작업 시간을 부여받아 빠르게 처리 가능하다&#46; 
> 
> - 우선순위가 높은 쓰레드가 반드시 먼저 종료 되지는 않는다&#46; 

<details>
<summary>1&#46; 우선순위는 3가지&#58; &#91; 최대 / 보통 / 최소  &#93;</summary>

> 기본값(default) =  <u>보통 우선순위</u>

- 최대 우선순위 ( MAX&#95;PRIOPRITY ) = 10

- 보통 우선순위 ( NROM&#95;PRIORITY ) = 5

- 최소 우선순위 ( MIN&#95;PRIORITY ) = 1

---

- 더 자세하게 나눈다면 1 &#126; 10 사이의 숫자로 지정 가능하다&#46;

- 해당 우선순위는 OS가 아닌 JVM 내에서 설정된 우선순위이다&#46;

</details>

<details>
<summary>2&#46; 스레드 우선순위 지정, 조회 &#58;  <code>setPriority()</code> , <code>getPriority()</code></summary>

- 우선순위 지정&#58; <code>setPriority</code>
    <a id="1ceeda9b0fe18007bd59d313e3244a82"></a>

    ```java
    Thread thread1 = new Thread(task1);
    thread1.setPriority(8);
    ```

- 우선순위 조회&#58; <code>getPriority</code>
    <a id="1ceeda9b0fe1807bb31ee29148a2c660"></a>

    ```java
    int threadPriority = thread1.getPriority();
    System.out.println("threadPriority = " + threadPriority);
    ```

</details>

<details>
<summary>ex)  쓰레드 우선순위</summary>

<a id="1ceeda9b0fe18027a588d481bfad9117"></a>

```java
public class Main {
    public static void main(String[] args) {
        Runnable task1 = () -> {
            for (int i = 0; i < 100; i++) {
                System.out.print("$");
            }
        };

        Runnable task2 = () -> {
            for (int i = 0; i < 100; i++) {
                System.out.print("*");
            }
        };

        Thread thread1 = new Thread(task1);
        thread1.setPriority(8);
        int threadPriority = thread1.getPriority();
        System.out.println("threadPriority = " + threadPriority);

        Thread thread2 = new Thread(task2);
        thread2.setPriority(2);

        thread1.start();
        thread2.start();
    }
}
```

</details>

</details>

<details>
<summary>쓰레드 그룹</summary>

> ✏️ 
> 
> <a id="1ceeda9b0fe1803fa3b2f1a4af5b0ec2"></a>
> 
> 서로 관련 있는 쓰레드들은 그룹으로 묶어서 다룰 수 있다&#46;
> 
> - 쓰레드들은 기본적으로 그룹에 포함되어 있다&#46;
>     - JVM이 시작되면 system 그룹이 생성되고 쓰레드들은 기본적으로 system 그룹에 포함된다&#46;
> 
>     - 메인 쓰레드는 system 그룹 하위에 있는 main 그룹에 포함된다&#46;
> 
> - 모든 쓰레드들은 반드시 하나의 그룹에 포함되어야 한다&#46;
>     - 쓰레드 그룹을 지정받지 못한 경우, 자신을 생성한 부모 쓰레드의 그룹과 우선순위를 상속 받는다&#46;
> 
>     - 예제 코드들은 main 쓰레드에서 생성되어 main 쓰레드 하위에 포함된다&#46;
> 
>     - 따라서 그룹을 지정하지 않으면 자동으로 main 그룹에 포함된다&#46;

<details>
<summary>쓰레드 그룹 생성</summary>

> <code>ThreadGroup</code> 클래스로 객체를 만들어서 <code>Thread</code> 객체 생성 시 첫 번째 매개변수로 넣어주면 된다&#46;

<a id="1ceeda9b0fe180118b18e82d7bc6c24f"></a>

```java
// ThreadGroup 클래스로 객체 생성
ThreadGroup group1 = new ThreadGroup("Group1");

// Thread 객체 생성시 첫번째 매개변수로 넘김
// Thread(ThreadGroup group, Runnable target, String name)
Thread thread1 = new Thread(group1, task, "Thread 1");

// Thread에 ThreadGroup 이 할당된것을 확인 가능
System.out.println("Group of thread1 : " + thread1.getThreadGroup().getName());
```

</details>

<details>
<summary>쓰레드 그룹으로 묶어서 쓰레드 관리</summary>

> <code>ThreadGroup</code> 객체의 <code>interrupt()</code> 메서드를 실행시키면 해당 그룹 쓰레드들이 실행 대기 상태로 변경된다&#46;

<a id="1ceeda9b0fe1801c8a6eec06bc074e66"></a>

```java
// ThreadGroup 클래스로 객체 생성
ThreadGroup group1 = new ThreadGroup("Group1");

// Thread 객체 생성시 첫번째 매개변수로 넘김
// Thread(ThreadGroup group, Runnable target, String name)
Thread thread1 = new Thread(group1, task, "Thread 1");
Thread thread2 = new Thread(group1, task, "Thread 2");

// interrupt()는 일시정지 상태인 쓰레드를 실행대기 상태로 만든다.
group1.interrupt()
```

</details>

<details>
<summary>ex) </summary>

<a id="1ceeda9b0fe180cc9559daa15819f42c"></a>

```java
public class Main {
    public static void main(String[] args) {
        Runnable task = () -> {
            while (!Thread.currentThread().isInterrupted()) {
                try {
                    Thread.sleep(1000);
                    System.out.println(Thread.currentThread().getName());
                } catch (InterruptedException e) {
                    break;
                }
            }
            System.out.println(Thread.currentThread().getName() + " Interrupted");
        };

        // ThreadGroup 클래스로 객체를 만듭니다.
        ThreadGroup group1 = new ThreadGroup("Group1");

        // Thread 객체 생성시 첫번째 매개변수로 넣어줍니다.
        // Thread(ThreadGroup group, Runnable target, String name)
        Thread thread1 = new Thread(group1, task, "Thread 1");
        Thread thread2 = new Thread(group1, task, "Thread 2");

        // Thread에 ThreadGroup 이 할당된것을 확인할 수 있습니다.
        System.out.println("Group of thread1 : " + thread1.getThreadGroup().getName());
        System.out.println("Group of thread2 : " + thread2.getThreadGroup().getName());

        thread1.start();
        thread2.start();

        try {
            // 현재 쓰레드를 지정된 시간동안 멈추게 합니다.
            Thread.sleep(5000);
        } catch (InterruptedException e) {
            e.printStackTrace();
        }

        // interrupt()는 일시정지 상태인 쓰레드를 실행대기 상태로 만듭니다.
        group1.interrupt();

    }
}
```
