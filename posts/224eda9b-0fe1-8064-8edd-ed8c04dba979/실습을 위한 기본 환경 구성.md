<details>
<summary>3&#46; Node 설치</summary>

<a id="222eda9b0fe18099b3aef208fa4f184e"></a>

```bash
# node 설치
sudo apt-get update && /
	sudo apt-get install -y ca-certificates curl gnupg && /
	mkdir -p /etc/apt/keyrings && /
	curl -fsSL https://deb.nodesource.com/gpgkey/nodesource-repo.gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/nodesource.gpg && /
	NODE_MAJOR=20 && /
	echo "deb [signed-by=/etc/apt/keyrings/nodesource.gpg] https://deb.nodesource.com/node_$NODE_MAJOR.x nodistro main" | sudo tee /etc/apt/sources.list.d/nodesource.list && /
	sudo apt-get update && /
	sudo apt-get install nodejs -y

# node 설치 확인
node -v
```

</details>

### 3&#46; EC2 기본 환경 구성 2&#58; <code>pm2</code> 설치

> ✏️ 
> 
> <a id="224eda9b0fe180eb8095d14034eff14b"></a>
> 
> 실제 베포 환경처럼 pm2 활용해서 서버 실행시키기

<a id="222eda9b0fe1803eb3ebd06391c41d01"></a>

```bash
sudo npm i -g pm2
pm2 start dist/main.js --name "backend-server"

pm2 list # 서버 잘 실행되고 있는 지 확인
pm2 logs # 서버 잘 실행됐는 지 로그 확인
```
