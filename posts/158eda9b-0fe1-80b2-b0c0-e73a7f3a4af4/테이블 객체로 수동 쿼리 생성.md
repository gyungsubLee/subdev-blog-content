## JPQL

---

> 📖 
> 
> <a id="15beda9b0fe18073b762d53085c12382"></a>
> 
> JPQL을 사용하여 복잡한 쿼리를 수동으로 작성하고 실행할 수 있다&#46; 

<details>
<summary>JPQL <strong> </strong><strong>( </strong><strong>J</strong>ava<strong> P</strong>ersistence<strong> Q</strong>uery<strong> L</strong>anguage <strong>)</strong></summary>

- Table 이 아닌 Entity(객체) 기준으로 작성하는 쿼리 (ORM)

- <code>EntityManger</code> 또는 <code>&#64;Query</code> 구현체를 통해 JPQL 쿼리를 사용한다&#46;
    - SQL&#58; Table 명으로 쿼리 생성 ( JDBC, SQL Mapper … ) 

    - JPQL&#58; <u>Entity 명</u>으로 쿼리 생성 ( <strong>JPQL</strong>, <strong>QueryDSL … </strong>)

</details>

<details>
<summary><code>EntityMananger&#46;createQuery()</code></summary>

- 쿼리 문자열과 Entity 를 직접 넣어서 쿼리를 작성

- <code>setParameter()</code> &#45; <u>key, value 문자열</u>을 통해 <u>쿼리 파라미터 매핑</u>

<a id="15beda9b0fe18065b41ac145ab1944c3"></a>

```java
@Test
public void testEmCreateQuery() {
		String qlString = "select u from User u " +
							"where u.username = :username";
	
		Member findUser = em.createQuery(qlString, User.class)
				.setParameter("username", "teasun")
				.getSingleResult();
	
		assertThat(findUser.getUsername()).isEqualTo("teasun");
}
```

</details>

<details>
<summary><code>&#64;Query</code>  (repository interface)</summary>

- <code>&#64;Query</code> 의 인자값으로 간단하게 쿼리를 작성
    - 쿼리를 작성할때는 테이블명이 아니라 <u>Entity 명으로 조회</u>한다&#46;

<details>
<summary>변수 바인딩 (2)</summary>

> JPQL 로 쿼리를 작성하면 오타라거나 잘못된 변수명에 대해서 알 수 있다&#46;

<details>
<summary>1&#46;  <code>?변수순번</code></summary>

<a id="15beda9b0fe1807bb71ce9c970d2eb4b"></a>

```java

public interface UserRepository extends JpaRepository<User, Long> {

  @Query("SELECT u, u.password AS customField FROM User u WHERE u.username = ?1")
  List<User> findByUsernameWithCustomField(String username, Sort sort);


  @Query("SELECT u FROM User u WHERE u.username = ?1")
  List<User> findByUsername(String username, Sort sort);
}
```

</details>

<details>
<summary>2&#46;  <code>&#58;변수명</code> </summary>

<a id="a65dc1f5ab054712af90b2c1b390bd96"></a>

```java

public interface UserRepository extends JpaRepository<User, Long> {

	  @Query("SELECT u, u.password AS customField FROM User u WHERE u.username = :username")
	  List<User> findByUsernameWithCustomField(String username, Sort sort);
	
	
	  @Query("SELECT u FROM User u WHERE u.username = :username")
	  List<User> findByUsername(String username, Sort sort);
}
```

</details>

</details>

</details>

<details>
<summary>🤬 JPQL 사용 시 문자열을 통해 쿼리를 작성한다&#46; 이때의 <u>단점</u>은 무엇인가? </summary>

- 문자열은 <u>오타 발생 여지가 많다</u>&#46; 

- 공통적인 문자열을 처리할 경우, 한군데에서 수정이 일어나면 모두 수정해야한다&#46;

- 잘못된 코드가 있더라도 <u>문자열 자체를 컴파일러가 검사 하지는 않</u>는다&#46; <br>따라서<u> 컴파일 시점에 오류를 잡지 못</u>한다&#46; 
    - 버그가 있더라도 메소드를 실행하는 시점인 <u>런타임시점에 버그가 발생</u>된다&#46; 

- 런타임 시점에 발생한 버그는 <u>서비스 정합성에 영향</u>을 주며 원인을 찾기도 어렵다&#46;

</details>
