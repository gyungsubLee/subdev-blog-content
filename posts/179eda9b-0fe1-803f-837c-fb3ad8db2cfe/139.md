## 문제

<a id="179eda9b0fe180529506ee1443eb4a65"></a>

Query the list of <em>CITY</em> names ending with vowels (a, e, i, o, u) from <strong>STATION</strong>&#46; Your result <em>cannot</em> contain duplicates&#46;

<a id="179eda9b0fe180ffaabadfe837f1fe86"></a>

<strong>Input Format</strong>

<a id="179eda9b0fe180d89dd6eaa512fef3ae"></a>

The <strong>STATION</strong> table is described as follows&#58;

![](18d9a3a7dd65531f.webp)

<a id="179eda9b0fe18000b808e03fbe3c15ad"></a>

where <em>LAT&#95;N</em> is the northern latitude and <em>LONG&#95;W</em> is the western longitude&#46;

<a id="8d0d583b11d64cce9417bec6b5be3102"></a>

## 풀이

<a id="179eda9b0fe1806f993ed020313b244b"></a>

```bash
SELECT DISTINCT CITY
FROM STATION
WHERE LOWER(RIGHT(CITY, 1)) IN ('a', 'e', 'i', 'o', 'u');
```
