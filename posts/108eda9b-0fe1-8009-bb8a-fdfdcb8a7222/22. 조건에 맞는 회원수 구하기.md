## 문제

<a id="1d2eda9b0fe180868720ed9c1508d86d"></a>

### <strong>문제 설명</strong>

<a id="1d2eda9b0fe180a2b2e7c8e5ef66a99d"></a>

다음은 어느 의류 쇼핑몰에 가입한 회원 정보를 담은 <code>USER&#95;INFO</code> 테이블입니다&#46; <code>USER&#95;INFO</code> 테이블은 아래와 같은 구조로 되어있으며 <code>USER&#95;ID</code>, <code>GENDER</code>, <code>AGE</code>, <code>JOINED</code>는 각각 회원 ID, 성별, 나이, 가입일을 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| Column name | Type | Nullable |
| USER&#95;ID | INTEGER | FALSE |
| GENDER | TINYINT(1) | TRUE |
| AGE | INTEGER | TRUE |
| JOINED | DATE | FALSE |

<a id="1d2eda9b0fe180a0a168cf1a00d79877"></a>

<code>GENDER</code> 컬럼은 비어있거나 0 또는 1의 값을 가지며 0인 경우 남자를, 1인 경우는 여자를 나타냅니다&#46;

---

<a id="1d2eda9b0fe180caae0de73b3008c6b3"></a>

### 문제

<a id="1d2eda9b0fe180fbbfa9da513bb1074e"></a>

<code>USER&#95;INFO</code> 테이블에서 2021년에 가입한 회원 중 나이가 20세 이상 29세 이하인 회원이 몇 명인지 출력하는 SQL문을 작성해주세요&#46;

---

<a id="1d2eda9b0fe18008a436f68fca05e86b"></a>

### 예시

<a id="1d2eda9b0fe1801eb4f2e6abeda6ab70"></a>

예를 들어 <code>USER&#95;INFO</code> 테이블이 다음과 같다면

|  |  |  |  |
| --- | --- | --- | --- |
| USER&#95;ID | GENDER | AGE | JOINED |
| 1 | 1 | 26 | 2021&#45;10&#45;05 |
| 2 | 0 | NULL | 2021&#45;11&#45;25 |
| 3 | 1 | 22 | 2021&#45;11&#45;30 |
| 4 | 0 | 31 | 2021&#45;12&#45;03 |
| 5 | 0 | 28 | 2021&#45;12&#45;16 |
| 6 | 1 | 24 | 2022&#45;01&#45;03 |
| 7 | 1 | NULL | 2022&#45;01&#45;09 |

<a id="1d2eda9b0fe180f5a3d0c56e00d4fe41"></a>

2021년에 가입한 회원 중 나이가 20세 이상 29세 이하인 회원은 <code>USER&#95;ID</code> 가 1, 3, 5 인 회원들 이므로, 다음과 같이 결과가 나와야 합니다&#46;

<a id="1d2eda9b0fe180c78373e04cabf550c6"></a>

USERS

---

<a id="1d2eda9b0fe18078bf08fc8ae109acb9"></a>

3

---

<a id="1d2eda9b0fe180d08c67ca299ce27712"></a>

## 풀이

> ✏️ 
> 
> <a id="1d2eda9b0fe18097b9d5cc5166762847"></a>
> 
> 조건
> 
> - 2021년에 가입한 회원 중 나이가 20세 이상 29세 이하인 회원이 몇 명인지 출력

<a id="1d2eda9b0fe180bfa20bc004a974128b"></a>

### 풀이1) YEAR()

<a id="1d2eda9b0fe18000a0bfc5bbf56e6d25"></a>

```sql
SELECT COUNT(*) AS USERS
FROM USER_INFO
WHERE AGE BETWEEN 20 AND 29
  AND YEAR(JOINED) = 2021;
```

<a id="1d2eda9b0fe180f286c3f8251a30dd78"></a>

### 풀이 2)  BETWEEN()

<a id="1d2eda9b0fe18023b49fd692f621e02d"></a>

```sql
SELECT COUNT(*) AS USERS
FROM USER_INFO
WHERE AGE BETWEEN 20 AND 29
  AND JOINED BETWEEN '2021-01-01' AND '2021-12-31';
```

- YEAR() 함수를 쓰면 인덱스를 못 타는 경우가 생길 수 있다&#46;

- <strong>위와 같이 날짜 범위 조건을 통해 검색하면 더 빠르게 동작한다&#46;</strong>
