# 문제

<a id="1c3eda9b0fe1819b833afc852d1e59a0"></a>

## <strong>1&#46; 올바른 괄호</strong>

---

<a id="1c3eda9b0fe18162b8f6cb3a49e6a955"></a>

### 설명

<a id="1c3eda9b0fe181a9b954dbc294866839"></a>

괄호가 입력되면 올바른 괄호이면 “YES&#34;, 올바르지 않으면 ”NO&#34;를 출력합니다&#46;

<a id="1c3eda9b0fe181e1ad15ee39fd0452c6"></a>

(())() 이것은 괄호의 쌍이 올바르게 위치하는 거지만, (()()))은 올바른 괄호가 아니다&#46;

<a id="1c3eda9b0fe1814ea79fd35ad0674d32"></a>

### 입력

<a id="1c3eda9b0fe1819498c1e9307c030668"></a>

첫 번째 줄에 괄호 문자열이 입력됩니다&#46; 문자열의 최대 길이는 30이다&#46;

<a id="1c3eda9b0fe1812ea36aff62b6350082"></a>

### 출력

<a id="1c3eda9b0fe18115afcdd0be46cdfa74"></a>

첫 번째 줄에 YES, NO를 출력한다&#46;

---

<a id="1c3eda9b0fe1812a817af8f25c363bac"></a>

### 예시 입력 1

<a id="1c3eda9b0fe18164a81fc4d78c500ddb"></a>

```plaintext
(()(()))(()

```

<a id="1c3eda9b0fe1816ebf07c4b8e91be747"></a>

### 예시 출력 1

<a id="1c3eda9b0fe181248053d79dd77281e1"></a>

```plaintext
NO
```

<a id="1c3eda9b0fe181bcb2d8cc40e06e7f77"></a>

# 풀이

<a id="1c3eda9b0fe1818aae7ae90d59e2ae92"></a>

## 풀이1) 

<a id="1c3eda9b0fe1814bae28c9c6aff68cf5"></a>

```java
import java.util.*;
public class Main {
    public String  solution(String str){
        Stack<Character> stack= new Stack<>();
        for(char x : str.toCharArray()){
            if(x == '(') stack.push(x);
            else{
                if(stack.isEmpty()) return "NO";
                stack.pop();
            }
        }
        if(!stack.isEmpty()) return "NO";
        return "YES";
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        String str=sc.next();
        System.out.println(T.solution(str));
    }
}
```
