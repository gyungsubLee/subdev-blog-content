## 문제

<a id="1cfeda9b0fe18086aa6fd42d0646479f"></a>

### <strong>문제 설명</strong>

<a id="1cfeda9b0fe1802ebd97e79a7c9b78f5"></a>

<code>ANIMAL&#95;INS</code> 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다&#46; <code>ANIMAL&#95;INS</code> 테이블 구조는 다음과 같으며, <code>ANIMAL&#95;ID</code>, <code>ANIMAL&#95;TYPE</code>, <code>DATETIME</code>, <code>INTAKE&#95;CONDITION</code>, <code>NAME</code>, <code>SEX&#95;UPON&#95;INTAKE</code>는 각각 동물의 아이디, 생물 종, 보호 시작일, 보호 시작 시 상태, 이름, 성별 및 중성화 여부를 나타냅니다&#46;

|  |  |  |
| --- | --- | --- |
| NAME | TYPE | NULLABLE |
| ANIMAL&#95;ID | VARCHAR(N) | FALSE |
| ANIMAL&#95;TYPE | VARCHAR(N) | FALSE |
| DATETIME | DATETIME | FALSE |
| INTAKE&#95;CONDITION | VARCHAR(N) | FALSE |
| NAME | VARCHAR(N) | TRUE |
| SEX&#95;UPON&#95;INTAKE | VARCHAR(N) | FALSE |

<a id="1cfeda9b0fe180d3889ed91606025bca"></a>

동물 보호소에 들어온 모든 동물의 아이디와 이름을 ANIMAL&#95;ID순으로 조회하는 SQL문을 작성해주세요&#46; SQL을 실행하면 다음과 같이 출력되어야 합니다&#46;

|  |  |
| --- | --- |
| ANIMAL&#95;ID | NAME |
| A349996 | Sugar |
| A350276 | Jewel |
| A350375 | Meo |
| A352555 | Harley |
| A352713 | Gia |
| A352872 | Peanutbutter |
| A353259 | Bj |

<a id="1cfeda9b0fe1806e9397e09923336335"></a>

((이하 생략))

<a id="1cfeda9b0fe1800eb473f57ee23408ce"></a>

## 풀이

<a id="1cfeda9b0fe18003ba62d2291c71aebb"></a>

```sql
SELECT ANIMAL_ID, NAME
FROM ANIMAL_INS
ORDER BY ANIMAL_ID;
```
