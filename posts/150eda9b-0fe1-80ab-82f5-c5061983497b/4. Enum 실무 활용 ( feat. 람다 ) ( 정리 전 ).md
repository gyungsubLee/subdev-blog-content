### 추가 &#45; enum에 생성 메서드 패턴을 적용하여 필드를 추가로 설정

> ✏️ 
> 
> <a id="8e2c374b76624199a3c3f8e98f88db9b"></a>
> 
> enum을  생성 메서드 패턴을 적용하여 정적  클래스 필드 처럼 사용한다&#46; 	
> 
> - <a href="#/post/1c3eda9b-0fe1-815d-9f98-c943ffb02293">페이지</a>

<details>
<summary><strong>enum을 static처럼 활용하는 이유</strong></summary>

- 각 상수를 객체처럼 관리할 수 있음&#46;

- 정적 필드보다 <strong>캡슐화</strong>와 <strong>타입 안전성</strong>을 제공&#46;

- 특정 상수에 관련된 로직(메서드)을 포함해 <strong>응집도</strong>가 높아짐&#46;

- 실수를 줄일 수 있는 강점이 있음&#46;

</details>

---

<details>
<summary>&#91; 코드 &#93; &#45; <code>setter</code>를 사용한 필드 초기화</summary>

<a id="152eda9b0fe1809795d2e8f234bdbfd5"></a>

```java
public enum SampleEnum {
    TYPE_A,
    TYPE_B,
    TYPE_C;

    private String name;
    private int value;

    // 생성 메서드 (빌더처럼 동작)
    public SampleEnum setProperties(String name, int value) {
        this.name = name;
        this.value = value;
        return this; // 체이닝 가능
    }

    public String getName() {
        return name;
    }

    public int getValue() {
        return value;
    }

    // 초기화 시점
    static {
        TYPE_A.setProperties("Type A", 1);
        TYPE_B.setProperties("Type B", 2);
        TYPE_C.setProperties("Type C", 3);
    }
}
```

- setter를 통해 가가 필드  값들을  설정하고 enum 클래스를 넘겨 체이닝을  사용가능하도록한다&#46; 

</details>

<details>
<summary>&#91; 코드 &#93; &#45;<code> 생성자</code>를 사용한 필드 초기화 </summary>

<a id="152eda9b0fe180869f04de442d372516"></a>

```java
public enum SampleEnum {
	    TYPE_A("Type A", 1),
	    TYPE_B("Type B", 2),
	    TYPE_C("Type C", 3);
	
	    private final String name;
	    private final int value;
	
	    // 생성자
	    SampleEnum(String name, int value) {
	        this.name = name;
	        this.value = value;
	    }
	
	    public String getName() {
	        return name;
	    }
	
	    public int getValue() {
	        return value;
	    }
}
```

</details>

<details>
<summary>사용 예시 </summary>

- <code>SampleEnum&#46;values()</code>
    - 모든 enum 상수 값을 배열로 반환
        - <code>SampleEnum&#46;values()</code>  = &#91; <code>TYPE&#95;A, TYPE&#95;B, TYPE&#95;C &#93;</code>

<a id="152eda9b0fe180019e7edb6294c61513"></a>

```sql
public class Main {
    public static void main(String[] args) {
        // 필드 확인
        for (SampleEnum type : SampleEnum.values()) {
            System.out.println(type + ": " + type.getName() + ", " + type.getValue());
        }
    }
}
```

- 출력 값

<a id="152eda9b0fe180d1bf43e81e6fe41774"></a>

```sql
TYPE_A: Type A, 1
TYPE_B: Type B, 2
TYPE_C: Type C, 3
```

</details>

<details>
<summary>enum 사용 장점</summary>

- 불변성 유지

- 생성자 사용해서 초기화 가능

</details>
