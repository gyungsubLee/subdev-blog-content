## 1 &#45; OSI 7 Layer

![](52ac25e6b77e9133.webp)

<a id="1c3eda9b0fe1819aa843e06bf2cda95b"></a>

### • 1 Layer&#58; Physical Layer ( 물리적 계층 )

>  해당 내용은 다루지 않음

<a id="1c3eda9b0fe181e784ebf5b057bc60b1"></a>

비트 단위 데이터를 전기적, 광학적 신호로 변환하여 전송하는 역할 수행<br>ex) 케이블, 허브, 리피터 등 하드웨어 구성 요소 <br>

<a id="1c3eda9b0fe18197abbcd4cf78ee6268"></a>

### • 2 Layer&#58; Data Link Layer ( 데이터 링크 계층)

<a id="1c3eda9b0fe181c7882dc9e23865872b"></a>

네트워크 기기 간 데이터 전송, 오류 검출 및 제어, 흐름 제어 등을 담당

<a id="1c3eda9b0fe1813882c3e09b29b9faad"></a>

대표적으로 Ethernet이 있으며, <code>MAC주소</code>를 통해 식별함

<a id="1c3eda9b0fe18157898fe84794b6f71b"></a>

전송되는 데이터 단위는 <code>Frame</code> 임

<a id="1c3eda9b0fe1812f9abdc183115aa4a5"></a>

### • 3 Layer&#58; Network Layer ( 네트워크 계층 )

![](5f9ef2c1e8ba899f.webp)

>  Internet = Routes &#43; DNS 집합인 논리적인 네트워크 

<a id="1c3eda9b0fe18128acabed33e4389aad"></a>

중계 노드를 통해 데이터(Packet)를 전송 시, 중계 방법을 규정

<a id="1c3eda9b0fe18134a211e7f2842839e4"></a>

대표적으로 <code>Internet</code>이 있으며, <code>IP주소</code>를 통해 식별함

<a id="1c3eda9b0fe18170a6bde912421a8f9f"></a>

전송되는 데이터 단위는 <code>Packet</code> 임

<a id="1c3eda9b0fe1815287e6d8e9e4b7f6f9"></a>

### • 4 Layer&#58; Transport Layer ( 전송 계층 )

<a id="1c3eda9b0fe181d286afd8b83b79251f"></a>

대표적으로 <code>TCP, UDP</code>가 있으며, <code>Port 번호</code>를 통해 식별함

<a id="1c3eda9b0fe181e3977ae38ed671b30f"></a>

전송 데이터 단위는 <code>Segment</code>임

<a id="1c3eda9b0fe1811abdf8cffd24937fa2"></a>

### •5  Layer&#58; Session Layer ( 세션 계층 )

<a id="1c3eda9b0fe181cfb6e5d220624256f7"></a>

대표적으로<code> SSL(Secure Sockets Layer) / TSL(Transport Layer Security)</code> 가 있다&#46;

<a id="1c3eda9b0fe1816bb268ebae7f9bd228"></a>

해당 계층 이후로는 <code>Stream</code> 이라는 데이터 단위를 사용한다&#46;

<a id="1c3eda9b0fe1810a9618f0449027f797"></a>

### • 6 Layer&#58; Presentation Layer ( 표현 계층 )

<a id="1c3eda9b0fe18153b61cfc79df8a5db3"></a>

### • 7 Layer&#58; Application Layer ( 응용 계층 ) 

<a id="1c3eda9b0fe181e8b547df4f460cd195"></a>

사용자와 가장 밀접한 계층으로 인터페이스 역활을 함<br>응용 프로세스  간의 정보 교환을 담당

<a id="1c3eda9b0fe181f2842af3fc36e33565"></a>

댸표적으로 <code>HTTP</code> 가 있음<br>

<a id="1c3eda9b0fe1812bbe16c03274958d25"></a>

### 1&#46;2 &#45; 식별자

![](a4caf470cead2d5f.webp)

- L2&#58; MAC 주소

- L3&#58; IP 주소 ( v4/v6 )

-  Port 번호 
    - L2&#58; 인터페이스 ( 유선 케이블 단자를 가르킴 )

    - 네트워크 &#58; Service ( 웹서비스 동작 시 열리는 포트 )

    - 엔드포인트&#58; 프로세스

>

<a id="1c3eda9b0fe181e396cac8d6c6fd9d7f"></a>

## 3 &#45; Switch

![](70f400e0c2aa13a4.webp)

> Network = 도로망<br>자동차 = Packet<br>교차로  = Switch <br>이정표 = IP주소

<a id="1c3eda9b0fe181e8aa40c88aa1ff422b"></a>

네트워크를 예시를 들 때, 많이 비교하는 것이  ‘도로망’ 이다&#46;

<a id="1c3eda9b0fe18171addbe8512e382e08"></a>

보통 운전을 하면서  출발지에서 목적지를 향할 때, 각 표지판, 지도 등 이정표를 통해 경로를 선택한다&#46; 

<a id="1c3eda9b0fe1819984bac2a24772fc68"></a>

네트워크(Internet, L3)에서 IP주소(이정표)를 통해 각 Router(교차로)들을 지나서

<a id="1c3eda9b0fe181968383fb7c113b3078"></a>

목적지(수산받는 HOST)로 데이터(Packet)을 전달한다&#46; 

<a id="1c3eda9b0fe1814e92e5fc5e6cfac8d0"></a>
