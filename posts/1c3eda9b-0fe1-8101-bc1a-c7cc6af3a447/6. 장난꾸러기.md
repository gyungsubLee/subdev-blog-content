# 문제

<a id="1c3eda9b0fe1815e8e1cde1217c042fc"></a>

## <strong>6&#46; 장난꾸러기</strong>

---

<a id="1c3eda9b0fe1819c8cf4f3084fbce69d"></a>

### 설명

<a id="1c3eda9b0fe181a9acd1f1fe52176105"></a>

새 학기가 시작되었습니다&#46; 철수는 새 짝꿍을 만나 너무 신이 났습니다&#46;

<a id="1c3eda9b0fe18126b631f4bf45412e60"></a>

철수네 반에는 N명의 학생들이 있습니다&#46;

<a id="1c3eda9b0fe181fca26ddedf9d537417"></a>

선생님은 반 학생들에게 반 번호를 정해 주기 위해 운동장에 반 학생들을 키가 가장 작은 학생부터 일렬로 키순으로 세웠습니다&#46;

<a id="1c3eda9b0fe18151a09bf70d3f83e7c0"></a>

제일 앞에 가장 작은 학생부터 반 번호를 1번부터 N번까지 부여합니다&#46; 철수는 짝꿍보다 키가 큽니다&#46;

<a id="1c3eda9b0fe181999a90d3687424ae9f"></a>

그런데 철수가 앞 번호를 받고 싶어 짝꿍과 자리를 바꿨습니다&#46;

<a id="1c3eda9b0fe1817c8edde9cacd8de695"></a>

선생님은 이 사실을 모르고 학생들에게 서있는 순서대로 번호를 부여했습니다&#46;

<a id="1c3eda9b0fe181aea29afd066e245ee2"></a>

철수와 짝꿍이 자리를 바꾼 반 학생들의 일렬로 서있는 키 정보가 주어질 때 철수가 받은 번호와 철수 짝꿍이 받은 번호를

<a id="1c3eda9b0fe1812bba14c468a278bbdd"></a>

차례로 출력하는 프로그램을 작성하세요&#46;

<a id="1c3eda9b0fe1819baf34dd9f96e6847f"></a>

### 입력

<a id="1c3eda9b0fe1818e912acf3b7fc661cc"></a>

첫 번째 줄에 자연수 N(5&#60;=N&#60;=100)이 주어진다&#46;

<a id="1c3eda9b0fe18109b621fffa1f19f21f"></a>

두 번째 줄에 제일 앞에부터 일렬로 서있는 학생들의 키가 주어진다&#46;

<a id="1c3eda9b0fe1818faf88d46a7bdfa393"></a>

키(높이) 값 H는 (120&#60;=H&#60;=180)의 자연수 입니다&#46;

<a id="1c3eda9b0fe181669bbec984612d8220"></a>

### 출력

<a id="1c3eda9b0fe181e0a246d1e852c17bf6"></a>

첫 번째 줄에 철수의 반 번호와 짝꿍의 반 번호를 차례로 출력합니다&#46;

---

<a id="1c3eda9b0fe1814e9c75ff60d6a33d0b"></a>

### 예시 입력 1

<a id="1c3eda9b0fe181f99629cf913387d6f2"></a>

```plaintext
9
120 125 152 130 135 135 143 127 160

```

<a id="1c3eda9b0fe181068cccfb116deea95b"></a>

### 예시 출력 1

<a id="1c3eda9b0fe18187b5dee2fb113a9609"></a>

```plaintext
3 8

```

<a id="1c3eda9b0fe18163b576c0d316f18c2b"></a>

# 풀이

## 풀이1) <code>내 풀이</code> 

<a id="1c3eda9b0fe181e1974ee3b696226391"></a>

<strong>깊은 복사,</strong> Array의 요소들 일일이 복사 해줘야 원본 배열이  <code>sort()</code> 시에 같이 안 변함

<a id="1c3eda9b0fe1816a9e9de0fa52317afc"></a>

→ <code>arr2=arr</code>로 참조 형태의 <strong>얕은 복사</strong>인 경우, 원본 배열과 같이 변하였음&#46;

<a id="1c3eda9b0fe181218dcac0ee192f7287"></a>

```java
import java.util.*;
public class Main {
    public void solution(int n, int[] arr) {
        int[] arr2 = new int[n];
        for(int i=0; i<n; i++){
            arr2[i]=arr[i];
        }
        Arrays.sort(arr);
        for(int i=0; i<n; i++){
            if(arr2[i]!=arr[i]) System.out.print((i+1)+" ");
        }
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        T.solution(n, arr);
    }
}
```

## 풀이2) <code>강의 풀이</code>  array&#46;clone() , 로직 동일

<a id="1c3eda9b0fe1814098c5c91acaf36495"></a>

```java
import java.util.*;
public class Main {
    public ArrayList<Integer> solution(int n, int[] arr) {
        ArrayList<Integer> answer = new ArrayList<>();
        int[] arr2 = arr.clone();
        Arrays.sort(arr);
        for(int i=0; i<n; i++){
            if(arr2[i]!=arr[i]) answer.add(i+1);
        }
        return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n=sc.nextInt();
        int[] arr = new int[n];
        for(int i=0; i<n; i++){
            arr[i] = sc.nextInt();
        }
        for(int x : T.solution(n, arr)) System.out.print(x+ " ");
    }
}
```
