# 문제

<a id="1c3eda9b0fe181b180f9dc3b6a0091e5"></a>

## <strong>6&#46; 공주 구하기</strong>

---

<a id="1c3eda9b0fe181bea30ad9f17342716f"></a>

### 설명

<a id="1c3eda9b0fe18100839de00ef18a3dd0"></a>

정보 왕국의 이웃 나라 외동딸 공주가 숲속의 괴물에게 잡혀갔습니다&#46;

<a id="1c3eda9b0fe1815689bac341980ad04f"></a>

정보 왕국에는 왕자가 N명이 있는데 서로 공주를 구하러 가겠다고 합니다&#46;

<a id="1c3eda9b0fe181c1b1dad34be6674839"></a>

정보왕국의 왕은 다음과 같은 방법으로 공주를 구하러 갈 왕자를 결정하기로 했습니다&#46;

<a id="1c3eda9b0fe181a6a2e9d0b5623ce486"></a>

왕은 왕자들을 나이 순으로 1번부터 N번까지 차례로 번호를 매긴다&#46;

<a id="1c3eda9b0fe181368bdafe2045793eb7"></a>

그리고 1번 왕자부터 N번 왕자까지 순서대로 시계 방향으로 돌아가며 동그랗게 앉게 한다&#46;

<a id="1c3eda9b0fe18161b340c93e3ebbda90"></a>

그리고 1번 왕자부터 시계방향으로 돌아가며 1부터 시작하여 번호를 외치게 한다&#46;

<a id="1c3eda9b0fe181788c93d4d26a0c178e"></a>

한 왕자가 K(특정숫자)를 외치면 그 왕자는 공주를 구하러 가는데서 제외되고 원 밖으로 나오게 된다&#46;

<a id="1c3eda9b0fe18180a788ebf8c15a1748"></a>

그리고 다음 왕자부터 다시 1부터 시작하여 번호를 외친다&#46;

<a id="1c3eda9b0fe181df95f2caf58eaad133"></a>

이렇게 해서 마지막까지 남은 왕자가 공주를 구하러 갈 수 있다&#46;

![](https://cote.inflearn.com/public/upload/c0b0b7a761.jpg)

<a id="1c3eda9b0fe181798012f851fefabf98"></a>

예를 들어 총 8명의 왕자가 있고, 3을 외친 왕자가 제외된다고 하자&#46; 처음에는 3번 왕자가 3을 외쳐 제외된다&#46;

<a id="1c3eda9b0fe181799efbe29bc747a00b"></a>

이어 6, 1, 5, 2, 8, 4번 왕자가 차례대로 제외되고 마지막까지 남게 된 7번 왕자에게 공주를 구하러갑니다&#46;

<a id="1c3eda9b0fe18184a9afeeb07c3db45e"></a>

N과 K가 주어질 때 공주를 구하러 갈 왕자의 번호를 출력하는 프로그램을 작성하시오&#46;

<a id="1c3eda9b0fe181fe9721d987ad1d46d9"></a>

### 입력

<a id="1c3eda9b0fe181d583deec922ae31ac1"></a>

첫 줄에 자연수 N(5&#60;=N&#60;=1,000)과 K(2&#60;=K&#60;=9)가 주어진다&#46;

<a id="1c3eda9b0fe1816ea08ff2bdb2ba9c54"></a>

### 출력

<a id="1c3eda9b0fe181d28efef711d300348e"></a>

첫 줄에 마지막 남은 왕자의 번호를 출력합니다&#46;

---

<a id="1c3eda9b0fe181c3b524cbcc177c429f"></a>

### 예시 입력 1

<a id="1c3eda9b0fe1811b8bf9e995b898defb"></a>

```plaintext
8 3
```

<a id="1c3eda9b0fe18105854ec3c929f0e569"></a>

### 예시 출력 1

<a id="1c3eda9b0fe18111b076cc1f28f9b48e"></a>

```plaintext
7
```

# 풀이

<a id="1c3eda9b0fe1815e9545ee73bc0f0575"></a>

## 풀이1) 강의 풀이

<a id="1c3eda9b0fe181b19182d5d53c65eb72"></a>

```java
import java.util.*;
public class Main {
    public int  solution(int n, int m){
        int answer=0;
        Queue<Integer> Q = new LinkedList<>();
        for(int i=1; i<=n; i++) Q.offer(i);
        while(!Q.isEmpty()){
            for(int i=1; i<m; i++) Q.offer(Q.poll());
            Q.poll();
            if(Q.size()==1) answer=Q.poll();
        }
       return answer;
    }

    public static void main (String[] args){
        Main T = new Main();
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int m = sc.nextInt();
        System.out.println(T.solution(n, m));
    }
}
```
