# 문제

<a id="1c3eda9b0fe1817c87a7ff631cd0b5eb"></a>

## 13&#46; 경로 탐색(인접리스트)

---

<a id="1c3eda9b0fe18159bed1c2b74dbf5407"></a>

### 설명

<a id="1c3eda9b0fe181e29da9c29ba6350f35"></a>

방향 그래프가 주어지면 1번 정점에서 N번 정점으로 가는 모든 경로의 가지 수를 출력하는 프로그램을 작성하시오&#46;

<a id="1c3eda9b0fe181c19815fe568f6547a7"></a>

아래 그래프에서 1번 정점에서 5번 정점으로 가는 가지 수는 총 6가지 입니다&#46; 

![](82f74e7851eac94c.webp)

<a id="1c3eda9b0fe181718b57ef1f8351fa27"></a>

### 입력

<a id="1c3eda9b0fe18181a229c2502bcc7a1c"></a>

첫번쨰 줄에는 정점의 수(1≤N≤20)와 간선의 수 M가 주어진다&#46; 그 다음부터 M줄에 걸쳐 연결 정보가 주어진다&#46; 

<a id="1c3eda9b0fe18190b04df9634e45333e"></a>

### 출력

<a id="1c3eda9b0fe18101bef3d50ac055bac6"></a>

총 가지수를 출력한다&#46;

---

# 풀이

<a id="1c3eda9b0fe1819b98b2ee4dd36002a8"></a>

## 풀이1) <code>내 풀이</code>  이중 ArrayList, 로직은 이전 문제와 동일

<a id="1c3eda9b0fe181ac9fdee8572c1faf9c"></a>

```java
import java.lang.reflect.Array;
import java.util.*;

public class Main {
    static int n, m, cnt=0;
    static int[] ch;
    static ArrayList<ArrayList<Integer>> graph;
    public void DFS(int v){
        if(v==n) cnt++;
        else {
            for(int x : graph.get(v)){
                if(ch[x]==0){
                    ch[x]=1;
                    DFS(x);
                    ch[x]=0;
                }
            }
        }
    }

    public static void main(String args[]) {
        Main T=new Main();
        Scanner sc=new Scanner(System.in);
        n=sc.nextInt();
        m=sc.nextInt();
        graph=new ArrayList<ArrayList<Integer>>();
        for(int i=0; i<=n; i++) {
            graph.add(new ArrayList<Integer>());
        }
        ch=new int[n+1];

        for(int i=0; i<m; i++){
            int a=sc.nextInt();
            int b=sc.nextInt();
            graph.get(a).add(b);
        }
        ch[1]=1;
        T.DFS(1);
        System.out.println(cnt);

    }
}
```
