> 주입할 스프링 빈이 없어도 동작해야할 상황이 존재<br>→ <code>&#64;Autowired</code> 의 required 옵션의 기본값이 true 이다&#46; <code>(required = true)</code><br>⇒ <strong><code>&#64;Autowired(required = false)</code></strong>

<a id="1c3eda9b0fe181cfa5b5eedcda13ee6a"></a>

## 자동 주입 대상 → 옵션 처리 방법

---

- <code>&#64;Autowired(required=false)</code>&#58; 자동 주입할 대상이 없으면 수정자 메서드 호출 X

- <code>org&#46;springframework&#46;lang&#46;&#64;Nullable</code> &#58; 자동 주입할 대상이 없으면 <code>null</code> 입력됨

- <code>Optional&#60;&#62;</code>&#58; 자동 주입할 대상이 없으면 <code>Optional&#46;empty</code> 입력
    > Optional&#58; &#91; 값 or null(<code>Optional&#46;empty</code>) &#93; 상태를 감싸서 제공 (자바8부터 제공)

<a id="1c3eda9b0fe181a98be7fc77895c1ad9"></a>

```java
//호출 안됨
@Autowired(required = false)
public void setNoBean1(Member member) {
     System.out.println("setNoBean1 = " + member);
 }

// null 호출
@Autowired
public void setNoBean2(@Nullable Member member) {
     System.out.println("setNoBean2 = " + member);
 }

// Optional.empty 호출
@Autowired(required = false)
public void setNoBean3(Optional<Member> member) {
		 System.out.println("setNoBean3 = " + member);
}
```

<summary>전체코드</summary>

<a id="1c3eda9b0fe181f7bf28e33b973bc946"></a>

```java
package hello.core.Autowired;

import hello.core.member.Member;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;
import org.springframework.lang.Nullable;

import java.util.Optional;

public class AutowiredTest {
    @Test
    void AutowiredOption() {
        AnnotationConfigApplicationContext ac = new AnnotationConfigApplicationContext(TestBean.class);
    }

    static class TestBean {
        //호출 안됨
        @Autowired(required = false)
        public void setNoBean1(Member member) {
            System.out.println("setNoBean1 = " + member);
        }

        // null 호출
        @Autowired
        public void setNoBean2(@Nullable Member member) {
            System.out.println("setNoBean2 = " + member);
        }

        // Optional.empty 호출
        @Autowired(required = false)
        public void setNoBean3(Optional<Member> member) {
            System.out.println("setNoBean3 = " + member);
        }
    }
}
```
